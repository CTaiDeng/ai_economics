# 第8章：各有江湖

朔风如刀，割过总堂门前那片被踩得坚硬如铁的泥地。香堂外，两张刚刚糊上墙的皇榜在寒风里猎猎作响，墨迹未干，却已像两面针锋相对的战旗。左面是南离堂，右面是风雷堂。江湖客们围在榜下，吐出的白气氤氲了彼此惊诧的脸，许多人以为是两家发错了帖子，或是哪位爷喝高了，竟敢在同一座山头前唱对台戏。

南离的榜文，字迹沉稳，一笔一划都透着钱庄柜面上那种拒人千里的冰冷。条款清晰得令人心安，也令人心寒：凡愿接令箭者，凭双桥血战后录下的那支阵前曲为凭，入伙即享“基本参与份额五百元”的底饷，按月结清，绝无拖欠。另设“差异池七千元”为花红，按人头功绩分派。规矩是死的，银子是活的，签了画押，便是香堂养着的带饷锐士，刀口舔的血，换的是实打实的现银。

风雷的榜文则写得龙飞凤舞，带着一股子野火燎原的狂气。他们也要那支曲子，却只肯许下微薄到近乎羞辱的苦力钱作保底，大头全在后头——“生态奉献激励金”。这名头听着玄乎，说白了，就是将香堂日后所有进项，刨去本钱，尽数分润给画押入伙的弟兄。这红利或许大如山岳，也或许到头来一个铜板都见不着，纯看天时地利与各自的手段。但无论香火是旺是衰，那份白纸黑字写死的口粮钱，纵是香堂揭不开锅，也绝不会短欠分毫。

一个愣头青在人群里叫嚷起来，嗓门洪亮，带着初入江湖不知天高地厚的莽撞：“既然都是卖命，何不就在这总堂外挂出个统一的价码？省得大家挑花了眼！”

话音未落，一道清冷如冰的声音便从香堂门内传来。方婉音一袭素袍，俏立于门槛之内，目光扫过众人，最后落在那愣头青脸上，眼神里没有温度。“总堂的墙，是告示板，不是菜市场。各家开出的暗花，可以并排贴着，任君挑选。但哪天结账，哪笔花红带毒，能从哪家偷学到压箱底的绝技，退出的生门又开在何方——这些虚实，岂能捣成一堆干瘪的铜板，用一把秤来称？”她顿了顿，声音愈发清寒，“香堂的门面，只保证账本摊开在阳光下，让各位看得通透。但我们，绝不越俎代庖，替天下所有的山头，定下卖命的死价。”

众人噤声，那愣头青的脸涨成了猪肝色。

内堂，一张黑胡桃木长桌旁，许嘉榕正对着两本账册，指尖在算盘上拨得噼啪作响，快得只见一串虚影。她将一卷适合快攻搏杀的曲谱拓本，以信托处分的形式，准了南离堂口调用三次，倒计时从167:59:59开始，分秒不差。另一卷更为幽玄的琴谱，则送去了风雷堂试水，看看能在那片新开的局中，钓出多大的鱼。

她心里的那盘棋，算得比谁都精。只要两张签下的死契在法理上不犯冲，一把刀，自然能赚两家的钱。可若是两边的擂台比武，时辰撞在了一处，谁也别想着用分身术去两头谎报战功。她死死掐着出阵的更漏，确保每一刀的劈出，每一滴血的流下，都与落进口袋里的赏钱严丝合缝，账目清晰得像是用刀刻上去的。

真正捅出大乱子的，是那块不知哪个不开眼的家伙悬在总堂正门外的“天下群英榜”。

这榜单不知死活，竟将南离堂阵前拼杀换来的首级数，与风雷堂凭琴谱赚来的江湖名气，用一套粗鄙不堪的算法混为一谈，强行捏合出了一张所谓的“江湖总榜”。邱庭舟就因为手快，同时接了两份皇榜，竟被这荒唐的榜单稀里糊涂地拱上了榜首。那鎏金的名字高悬于顶，刺得他眼睛生疼。更要命的是，真有几个不知死活的家伙，竟拿着这块假招牌当令箭，去逼着别的堂口给他们多开几分花红。

这等行径，就如同将两张十九路棋盘上各自围下的实地，不问青红皂白地直接相加，却对棋手当初如何落子做活、如何弃子争先的阵眼与气数全然不顾。虎榜上的名字固然吓人，可底下那根“谁掏银子谁说了算”的血线，却早已被这般胡搅蛮缠扯得稀烂。

“荒唐！”一声断喝在议事厅内炸响，震得梁上尘土簌簌而下。杜启航一掌拍在桌上，震得茶杯乱跳。“把这套荒腔走板的算计，即刻给我停了！”他双目如电，扫过在场的每一个人，“南离的账册，用的是银票秤砣；风雷的规矩，赌的是未来收成；库里的现银更是两码事！长得再像的战绩点，也绝不能直接兑成通吃天下的银票！旧日的履历，可以帮新香堂辨认谁是好手，但绝不能让每一个新开张的金库，都得捏着鼻子为这堆陈芝麻烂谷子的老功名，再掏一次冤枉钱！”

邱庭舟站在堂下，额角渗出冷汗。他心头悬着的，还有另一把更锋利的剑。他早年督造神兵利器的“神机匠营”，在江湖上积攒了极高的名望。那狗屁不通的群英榜，竟把整个匠营打下的威风，全都盖在了他邱庭舟一人的印信之下。他如今既然换了山头，接手的是新的铁匠铺，就绝无道理把老东家那些尚未报废的炉鼎和淬火的秘方揣进自己兜里。他这双手里的打铁手艺固然还在，可那得凭手上的老茧和新的试刀石去说话。南离的功勋、风雷的声望、匠营的传承，再加上他个人的武艺，这四种表面上都顶着“品阶”虚名的玩意儿，绝没有道理融成一个可以随取随用的无底钱袋。

规矩很快改了回来。那张荒唐的总榜被一把撕下，付之一炬。发急脚递的信使四散而出，通知所有受牵连的刀客，重新核对自己的账目。

私心里，邱庭舟也曾迷恋过那张让自己名扬天下的金榜。尤其是在尝过被人抹去名号、视若无物的屈辱之后，那种被整个江湖仰望的快感，确实如同一杯最醇美的毒酒，令人难以舍弃。他死死盯住墙角，确认那些旧日的战报依然能凭暗号翻阅，这才一咬牙，亲手将那张虚假的榜文残片，卷进了火盆。

暮色时分，罗启锋与麦振铮结伴来看风雷堂的弹琴演武。两人都是战场上杀出来的滚刀肉，才在堂内熬了小半个时辰，听着那缠绵悱恻的琴音，便如坐针毡。麦振铮是个直肠子，起身抱拳，坦言道：“这等软绵绵的东西，我兄弟二人实在听不来。我们愿意为了刀刀见血的阵前厮杀，为了顶尖刺客电光火石的过招倾家荡产，却受不了一群人坐在这里，去回味什么劳什子的旧城晚钟。”

方婉音依旧是那副冷若冰霜的神情，却只摆了摆手，示意他们自便。“门在那边，出门左转，尽是些好勇斗狠的擂台，慢走不送。”她连一句“你不懂风雅”的闲篇都懒得说。

罗启锋跨出大门，正撞上一个急吼吼往里赶的锦衣客。两人皆是身负兵刃，却在门槛前不约而同地收敛了杀气，侧身相让，目光交错，谁也没费半句口舌去拉谁入伙。这十九路棋盘如此之大，大场与星位遍布，自有人急着去死地搏杀，打一场你死我活的劫；也自有人愿枯坐一夜，只为收一个无关胜负的单官。大家同从一个风雪渡口擦肩而过，本就不必磕头拜在同一座香堂。

门外，甚至还有人是专程来听那扇铁门开合时的嘎吱声，连战区如何布阵，琴谱是何曲调都懒得过问。江湖人花钱买醉的由头，本就千奇百怪。手里的绝活，也绝不需要靠踩着别人的刀法，自抬身价才能活下去。

高楼上，程砚舟凭栏远眺，将这一切尽收眼底。他默默抹掉了心中原想在全总坛硬压下去的“人头点卯”死令。他本想，若是每道山门前都设下关卡，拿鞭子抽着过客多留一更天，总能熬出些油水。现在看来，那除了熬死底下干活的弟兄，逼不出半点真金白银。看客的盘桓与碎银固然是摸底的好算盘，可必须把拂袖而去、翻脸退钱、门庭冷落和另投明主，全都摆在一把秤上称量。他绝不能仗着大当家的身份，先去给全天下定死，只能爱吃哪一碗饭。

夜深人静，南离与风雷的香堂各自落锁，闭上了自家大门。昔日同生共死的血债，让她们的当家能安稳地坐在一张八仙桌上议事。但地上用石灰画得清清楚楚的界线，也让她们能随时分道扬镳，互不相欠。

门外风中，那两张招兵买马的皇榜，依旧在寒夜里各自飘荡，绝没有再恬不知耻地糊成一张，去替天底下的刀客，选他们的命。
