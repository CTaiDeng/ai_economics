# 第10章：松风留白

正月将尽，京城的风依旧刮得像一柄淬了冰的钢刀，从每一个门缝里钻进来，搜刮着屋里残存的最后一丝暖意。贺敬山裹着一件厚重的玄色大氅，亲赴香堂。他此行的目的，是来取一份总坛恩准公之于众的孤本——那份在血战中打出来的“双桥阵”残局谱。

香堂门口，一个满脸风霜的客商正揪着当值的伙计，粗声大气地盘问着结账的规矩，腰间的雁翎刀随着他的动作一下下敲打着门框。程砚舟的脚跟下意识地一拧，身形微动，那是他过去千百次迎上前去、用三言两语和一身煞气摆平事端的本能反应。

可他只迈出半步，便硬生生定在了原地。

他看见那个年轻的伙计，虽额角见了汗，手上的动作却丝毫不乱，利落地从一叠文书中抽出过堂的死契，又从另一边取来按着鲜红手印的回执，一拍一递，口齿清晰，条理分明。今日的买卖，不归他程砚舟亲自当垆。这江湖的流水，也不必非得等他这个大当家发了话，底下的弟兄们才能摸清自己那份花红究竟是死是活。

贺敬山将他这记宛如太极“白鹤亮翅”起手却中途化为“野马分鬃”收势的动作尽收眼底，浑浊的眸子里闪过一丝笑意，却并不点破。

两人在临窗的一张黑漆茶座上坐下，听着堂内鼎沸的声浪。有交接卷宗时纸张哗啦的忙乱，有算盘珠子急促如雨的脆响，也有客商等得不耐烦时压着火气的骂骂咧咧。这套新立的香堂规矩，如同一套初学乍练的剑法，破绽百出，远未到圆转如意的地步。

但有一条根骨，已经立住了。那便是过路的刀客，再也无须揣着自己的身家性命，去烧大当家那座不知冷暖的灶，才能知道自己下一趟的死活签，该去哪张桌子上抽。这盘棋的星位与天元，已然昭示天下。

程砚舟端起那杯早已凉透的残茶，呷了一口，涩味从舌尖一直蔓延到心里。他谈起那道被总坛驳回、硬生生打回去重造的“天下群英榜”，字里行间满是压抑不住的火气；又谈起南离堂口如何软硬不吃，死活不肯接下总坛那支分明是烈火烹油的烫手令箭。

最后，他长长地叹出一口白气，仿佛要将满腔的郁结都吐出去。他说，自己总是按捺不住，总想用一句雷霆万钧的狠话，去强行挑落那些还在十九路棋盘上举棋不定的残子，一锤定音。

“落子无悔，杀手锏，确实出得快。”贺敬山的手指在冰冷的桌面上轻轻敲击，目光却像穿透了墙壁，落在了虚空中的一副棋枰上。

“可这一手，究竟快到了什么地步？”

一句话，如当头棒喝。程砚舟猛然回想起那些日子，那些在他一句狠话之后，熬着通红的眼睛替他收拾残局的弟兄们。他们为了摸清他那句话究竟是铁打的军令，是悬赏的暗花，还是一句仅仅为了试探的虚着，不得不反复推演，互相猜忌，搭进去成倍的香火时辰与心力。眼前他抢下的这一步先手，看似凌厉，可若是将视线拉远，纵观整条战线，这一记孤军深入的“点”，非但没能先一步做活大龙，反而给自家阵营留下了无数千疮百孔的薄处，处处都等着别人来“冲”和“断”。

贺敬山的手指捻起那卷用细麻绳捆扎的残局谱，指腹轻轻摩挲着纸张粗糙的毛边。“十九路盘上，波谲云诡。有时你拼死劫来的一步先手，背后留给自家阵营的，却全是刀刀见骨的薄味。”

程砚舟的目光，不由自主地投向堂下那张正在盖印的生死状。朱红的印泥，在昏暗的光线下，浓稠得如同鲜血。他看着那个满头大汗的当值伙计，看着他如何笨拙地解释着契约上的条款，如何应对客商的诘难。有好几次，程砚舟都几乎要开口，用一句更精炼的话替他解围。

但他终究是死死忍住了。他强迫自己，不再越俎代庖去指点这盘棋的局部得失，而是沉默地等待，等着那个局中人，自己在这片混沌里，摸索出下一手做活的气口。

总坛铁库里，正月那场“双桥血战”的总账已经尘埃落定，每一笔都用乌黑的墨锭写得清清楚楚，晾在所有人的眼皮子底下：

此役，连本带利卷入江湖资金一万二千两。
战损折耗，计兵器、汤药、抚恤，共两千两。
香堂日常开销，维系运转，共一千两。
分发各路英雄花红，即“差异池”，共七千两。
账房库底结余，可入总坛府库者，两千两。

每一锭银子，都严丝合缝地扣进了最初那份人人画押的死契。而陈绍武那笔曾惹出过血案的“同档”花红与鸣冤记录，依旧用朱笔扎眼地单挑在一旁，像一道永不愈合的伤疤。这本齐刷刷的总账，绝不准用一个笼统的数字，吞掉这十九路棋盘上，任何一步带血的做活过程。

两家在幕后注资的钱庄，如约拿到了契约里许诺的买卖回执，却没能如愿连根拔走所有主顾的族谱。他们仍在自己的小算盘上，锱铢必较地计算着眼下的进项、退单和新增的流水。那本真正能断定这桩买卖是赚是赔的铁算盘，至今还没拨出个最后的真章。岑绍庭虽然靠着摆擂台，为香堂挣下了两千两的结余，却绝不代表两家钱庄已经铁了心，要继续往这个看似无底的深潭里砸入真金白银。

宋振峰在信中冷笑着，只肯谈一盘更小的“试应手”，点到即止。罗振业则更像个狡猾的掮客，还在四处找别的山头比价。他们都明白，兵器铺里打出的袖箭，本就出自同一个火炉，可名号在江湖人心里的分量，却可能因为被供奉的香火长短而天差地别。也可能，那些刀口舔血的汉子们，只图个看热闹的痛快，事了拂衣去，半个铜板也不留。

即便如此，这等吝啬鬼的名字，也绝不会因此就被香堂从上过阵的花名册上强行抹去。来过，战过，便是落下的子，再无从棋盘上拿起。

许嘉榕从她那份六百两的花红里，拈出了一小块碎银，去西市的铺子里置办了几枚防身的透骨钉。剩下的整张银票，被她用油纸包了三层，死死攥在手心，贴身藏好。她半点不打算为了给东家凑一个好看的账面，去买那些自己根本用不上的破铜烂铁。

刘景和则决意下次投奔另一处香堂，去试他那套“千里传音”的秘术。他揣着自己昔日那份染血的履历，准备重新去结交未知的死士，踏上未卜的险路。但他清楚规矩，他可以带走自己的命和名声，却绝不能把“海岬”战区那些还未见光的阵图底牌，当成自己的敲门砖，偷偷带走。

一丝孤掌难鸣的失落，又不可遏制地从程砚舟心底翻起。只是这一次，他没有再立刻把这丝不甘，化作一把架在别人脖子上的刀，强行把人留住。他只是静静地看着，看着这些棋子，在他划定的规则内，走出自己的活形。

香堂高悬的虎榜上，唐梓豪到期的二当家令牌，被当值的香主面无表情地冷冷摘下。一个踩着他脚印上来的新人，在过堂查验无误后，接管了那方沉甸甸的帅印。唐梓豪在兵书上用血杀出的军功，自然还一笔一划地刻在功劳碑上，但这一次，他掌管香堂生死的虎符，已然到期失效。他当年领走的那八百两压惊费，也绝不会让下一个接盘的当家，自动再替他匀出一口断头饭。

江湖的大势，就这么顺着交接的兵符，浩浩荡荡地往前走。旧日的带血赏钱，终归是要洗净了，揣回寻常人家的钱袋里。

贺敬山凝视着那幅残局图上，被黑子拦腰截断的“断桥”，长长叹了口气：“棋局里，有些死子，终归是救不活了。剩下这半壁残山剩水，该怎么下，老天爷也还没给出定论。”

程砚舟的手，死死扣住了腰间的总把头令牌，指节因用力而发白。但他终究没有动用那份特权，去强行抹平那些旧日的伤亡，去粉饰这盘棋的败笔。昔日提着脑袋挣来的真金白银，捅下的大篓子，还没还清的血汗钱，统统都要在这副千疮百孔的残局里，硬着头皮，继续寻找做活的可能。

老人家临别时，顺口问起了小溪。程砚舟看了眼墙角的铜壶滴漏，说定好了酉时末去接人。他知道，堂口轮值的香主用不着眼巴巴地等他回山门发话，该交割的死契，该移交的兵符，早在那张八仙桌上清点得一干二净。

回到内堂，他将随身带着的机密军报，一卷卷地锁进该落锁的铁柜，发出沉闷的金属撞击声。然后，他脱下那件象征着权柄与责任的堂主大衣，只披了一件御寒的普通外氅。

原先他总觉得，大当家只要一转身，就活像是背弃了身后万千弟兄、临阵脱逃的懦夫。直到如今，在这血水与算计里反复翻滚过几遭，他才渐渐品出另一层滋味：当那把千斤重的斩马剑，终于有人能稳稳接过去之后，自己转身去赴一个寻常的家常之约，也必须拔步走得斩钉截铁。

一阵穿堂风猛地灌入，掀起桌上一页复盘的生死状。当值的弟兄头也不抬，伸出大手一把按住，口中接着盘问下一位客商的来路。

程砚舟站在香堂高高的门槛外，最后驻足回望。屋里的铁算盘依旧拨得山响，“海岬”战区的铁骑也依旧在各自的死局里，前仆后继地冲锋陷阵。

他缓缓转过身，将满肩的风雪，连同那屋里的喧嚣与血腥，一并关在了身后，去赴另一场，早就画过押的局。
