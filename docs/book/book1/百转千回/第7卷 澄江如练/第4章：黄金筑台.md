# 第4章：黄金筑台

议事堂厚重的楠木门被一只手推开，带进一股室外凛冽的寒气。陆文渊的身影被门框切割得棱角分明，他甚至没有掸去肩上残留的几点雪花，第一句话就如淬了冰的铁，砸在满室沉寂的空气里。

“两万两纹银，”他目光扫过在座诸人，最后落在主位上的程砚舟脸上，“能不能在议事堂这六把交椅里，买下一把？”

无人应声。长桌对面，一直沉默擦拭着一枚玉扳指的顾承安抬起眼皮，那双眼睛里没有半分波澜，仿佛陆文渊谈论的不是足以掀起一场江湖风暴的银两，而是一笔街边米铺的寻常交易。他将一份早已备好的死契，用两根手指不轻不重地推过磨得光滑的黑胡桃木桌面，契书滑行时悄然无声，停在陆文渊手边。

“陆先生，投银子入伙，按规矩，可以约定查库房、听风声，甚至在局势不对时断尾求生，这是金主的本分。”顾承安的语调平直得像一把出鞘的剑，“想入我们破阵堂的暗股，另有别的过堂规矩。但这总坛大门外的判官交椅，从立堂口那天起，就绝不跟着银票的厚度水涨船高。”

他顿了顿，目光在陆文渊脸上停留了一瞬：“你前三回砸进来的银子，没换来半张能指手画脚的令符。今天这两万两，自然也换不来能调兵遣将的虎符。”

这话说得毫不客气，几乎是当面封死了陆文渊所有的话路。陆文渊的嘴角牵起一丝冷笑，却没有当场发作。他伸出手指，却没有去碰那份契约，而是轻轻叩了叩桌面，发出笃笃的声响，像是在为自己的下一句话敲定节奏。

“好，椅子不卖，我认。但至少我得知道，”他的声音陡然压低，充满了不容置疑的力道，“将来，谁有权力在老子头上动刀子，改规矩？”

这一句盘问，字字句句都合乎江湖道义。十八般刑具怎么用、改规矩的香头要烧多久、已经画押的花红怎么保命，这都是金主在掏出真金白银前必须摊在阳光下的底牌。总不能把人家正常的盘道，统统打成夺权谋反的狼子野心。

顾承安像是早就料到他有此一问，将另一份卷宗递了过去，露出的底牌一干二净。刑堂论剑，他方才那一招格开了陆文渊的剑锋，却绝不等于要顺势把来客连人带棍全打出山门。他要斩断的，是那只妄图伸进权力阵眼的手；而应当敞开让金主过目的生门，则完全是另一码事。

陆文渊的目光在那份卷宗上停留了许久，终于将注意力转回了眼下的战局。他盯上了南离与风雷两大堂口准备联手合围的那场跨区血战，以及随之而起的滔天声势。他松了口，愿谈这两万两开拔的饷银。

“仗打赢了，我拿约定好的连本带利。打输了，我只认这一刀的亏空。”陆文渊的算盘打得极精，如同桃花岛主在推演奇门遁甲，每一步都预设了生路与死路。但他死死咬住一点，要在契约里加上一个极其漫长的独家买断期，好护住他先前为了筛查暗桩和招兵买马，早已撒出去的那些血汗钱。这叫“弃子争先”，他愿意弃掉一笔银子，争的却是未来整个棋局的先手。

一直沉默的方婉音终于开口，她的声音清冷如玉石相击。她伸出纤细的手指，在那份契约上，重重圈出了那段足以锁喉的期限条款。

“陆先生，你这道锁链，比我们这场仗打完的时辰，还要长出太多。”她冷着脸，毫不退让，“这不像是买卖，倒像是想将我们两大堂口，都变成你自家的护院。”

陆文渊面不改色，倒也痛快：“这趟走镖的进账账本，我可以全数抖落出来，绝不把一笔开销拿去找两家钱庄平账，如何？”

他亮出了自己的诚意，却在关键处寸步不让：“但我死活不肯把兄弟们还没开始打算的后路，也一并钉死在这份卖身契上。我陆宏远的人，不能走一步，就被人算计了身后三步。”

陆文渊没有立刻让步。他早先确实为这局棋花过探路的费用，绝不肯自己先在悬崖边上扛下所有的刀光剑影，等大局落定、棋形做活之后，便被一脚踢出棋局。这盘棋，他要从布局一直下到收官。

几个堂口的把手将眼前这场仗的护身符，与日后所有的买卖，用一把无形的刀狠狠劈开。议事堂内的空气仿佛凝固了，香炉里的青烟断断续续，一直熬到窗外的太阳沉入地平线，那份契约上，依旧空无一人的画押。真金白银没砸进钱庄，花红账册便只能悬在半空，像个无人收殓的孤魂。

程砚舟心下焦急如焚，这盘棋若是开局就脱先，大龙眼看就要被屠。他几乎要脱口而出，想用自己的私房银子强行填上这道血口。

“且慢。”

周慎衡冷着脸，如同一座万年冰山，拦住了他。他先盘问名目，每一个字都像是在法堂上审问犯人：“大当家，你这笔钱，是借高利贷，还是买暗股，又或者是白送给堂口的香火钱？”

他盯着程砚舟，目光锐利如刀：“名目必须清楚。若是赢了，分你几成利？期限多长？若是折了本，谁先扛？这些死规矩，绝不能因为掏钱的是大当家，便能稀里糊涂地一笔带过。”

周慎衡的声音在空旷的议事堂里回荡，他缓缓道：“创堂时五位元老砸下的那二百万两，是用来砌地基的镇山石，不是随意取用的活钱。八位头领后来靠着生死状握住的暗股和花红，另有明路可查。破阵堂有剩银子分红时，我们自然能正大光明地拿赏；可若是裤裆见了底，就绝不能去抢底下弟兄用命换来的血汗池，硬生生从里面刮出一笔金主大老爷‘该拿的’油水！”

程砚舟沉默了。他面前的传音入密机关还闪着微光，但他最终还是抬手，将其挂断。他终究没敢拿自己的私房钱，去强行买一个堵死所有人盘问的拍板权。周慎衡这一手，是围棋中的“收气”，看似不走大场，却将他所有可能落子的气点，一一收紧，让他无处腾挪。

两位分管堂主，方婉音与另一人，只能捏着鼻子，重新扒拉起那张缩水后的阵图。跨区调兵的计划，只留下一个过了明路的隘口，那些还没搭上线的两路人马，绝不再假充声势，画在同一张十九路棋盘上。减去擂鼓助威的排场花销，死死保住必须出阵的死士和负责造势的文人那笔底子钱。剩下的那些浮华排场，统统留到真金白银进了库房之后，再去摆谱。

阵仗缩水，固然会少些看热闹的江湖客，但这已经是他们手边唯一的生门。先做活一角，再图谋天下。

陆文渊冷着脸，终于收回了那份漫长锁喉的霸王条款，松口答应重新划定这趟镖局里的护身符，却根本没保证一定会接下这个缩水后的价码。他在香堂上吃了闭门羹，依然没权让这两家堂口从江湖拜帖里抹去名字；那两家自然也不能拿刀逼着他，白白承担所有的死局。

临走时，陆文渊站在门口，回头冷笑：“如今你们过堂算账，实在太慢。”

程砚舟却想起了原先许多连明细都没算清，就糊里糊涂画押的烂账，那些烂账如同棋盘上一个个未能补净的断点，随时可能被人冲垮。他硬邦邦地顶了回去：“有些所谓的‘兵贵神速’，不过是把漏风的阵眼，全留到了死人以后。”

他抬眼直视陆文渊：“上一季那四千两的血窟窿，还殷红地挂在陆先生你的账本上。”

陆文渊脸上的肌肉抽动了一下，冷哼一声，没再反驳，转身消失在风雪里。

人走后，方婉音立刻取出一只信鸽，写了封短信传给邱庭舟。信上只有寥寥数语：军饷尚无着落，此前受邀打造的兵器，暂不上炉。她绝没把对方早就习惯的拔刀相助，当成可以白嫖人家独门手艺的绿灯。大伙儿可以在自家后院随便试手艺，但只要是真刀真枪摆上明面的交付，就得等到死契过了明路，红色的印泥盖下去，才能作数。

她回到长桌前，在那张跨区行军阵图上，用朱笔将眼下能做活的一角死死圈住。剩下的半张棋盘，依旧是一片触目惊心的空白。

方婉音原先总怕棋盘上留着大片的“空”，会显得底气不足，像是未战先怯。可如今，她却终于能死死按住自己那颗总想在十九路盘上四处开花、抢占星位的冲动。

先让手边落下的这几颗黑白子，彼此连接，做活成势。之后，再去图谋更远处的血雨腥风。

墙上那张巨大的阵图，就这么硬生生地留着那片空白。它没有因为大伙儿嘴上喊着“盟军”，就稀里糊涂地将所有势力搅合在一起；也没有因为银子还没到位，就彻底堵死日后两军会师的生门。它就那样挂着，一半是精密的杀机，一半是未知的虚无，像一盘刚刚下到中盘的、生死未卜的棋。
