# 第3章：霜刃自珍

朔风卷着碎雪，撞在议事堂厚重的窗棂上，发出沉闷的呜咽。堂内，炭火烧得并不旺，空气里凝滞着一种比窗外严冬更刺骨的寒意。

方婉音那卷压箱底的母带，像一根淬了毒的芒刺，再次被人明晃晃地写进了一份上香堂的拜帖里。

那是一张用上好宣纸写就的请命书，字迹遒劲，意气风发，却字字透着一股不容分说的霸道。它躺在巨大的黑胡桃木长桌中央，仿佛一处刚刚落下、决定全局生死的星位。这回倒不是因为什么借名头敛财的伥鬼。堂口里有人提议，为示“万众一心”，干脆把破阵堂的铁匠炉子、兵器谱、独门绝技和香堂暗股统统充作大伙儿的公产，免得哪天总堂的老大突然砸了锅，让新立的议事会成了空谈的摆设。

这番请命，字面上看是为众人计的肺腑之忧，可在方婉音眼中，却像一盘精心布置的棋局，意在弃子争先，用几句慷慨激昂的“大义”，换取侵吞他人心血的先手。她的目光掠过那些熟悉的条目，最终，像鹰隼锁住猎物般，死死钉在了“母带”那一行。

她拿起桌上的朱砂笔，笔杆冰凉，触手如铁。一圈，一圈，又一圈，鲜红的朱砂死死框住了那两个字，力道之大，几乎要划破纸背，印泥的血色仿佛要从纸上渗出来。

“诸位，”她的声音清冷如玉石相击，在寂静的堂内激起一圈圈回响，“有些声轨，便是我这个吹曲子的，也只是从别家手里拿到了有时限的路条。我方婉音，绝不能越俎代庖，替人交出兵符。”

她将那页差点就盖上总堂红印的请战书，朝着提议之人推了回去，动作不大，却带着一股天山折梅手般收发自如的劲力，不偏不倚，正好停在对方面前三寸之地。

“我自己的那份家底，愿意掏出来，那是我的义气。可一柄宝剑，就算眼下由我保管，也绝不等于连剑鞘上刻着的别人名讳，都能任由我拿去典当。”她的眼神扫过在座的每一个人，“越是满嘴江湖大义的时候，诸位，越得在刀刃上看清自己，究竟有资格许出哪几两银子。”

坐在她对面的陈驰，一张国字脸早已冷得像铁。他猛地一拍桌子，震得茶杯里的残茶都溅了出来：“说得好！既然花红和香堂的暗股，早按着白纸黑字的死契分到了各家手里，那就是各家安身立命的真金白银，是家里老小糊口的柴米钱！这笔账，就得井水不犯河水！”

他的声音粗粝而响亮，像一块顽石投入深潭，“绝不能每逢哪位大爷要我等证明‘公心’，就非得让底下拼死拼活的弟兄，把嚼到嘴里的口粮再给吐出来！所谓‘六人共治香堂’，是共治，不是共产！更不等于大伙儿得先自断一臂，把已经落袋为安的花红再悉数上缴！”

“没错。”角落里，一直沉默不语的顾承安终于开了口。他没有拍案而起，只是缓缓从袖中抽出一柄沉甸甸的铁算盘，往桌上一顿，发出“哐”的一声闷响。随即，那算盘珠子在他指间如蝴蝶穿花般急促地跳动起来，清脆的噼啪声仿佛战场上的急鼓。

“破阵堂自家画的阵图和炉鼎，算公库，按着过明路的契约走，一清二楚。”他拨开一档珠子，声音平稳，却带着不容置疑的精准，“刀客们自己从外面淘换来的私货，是私产。弟兄们分到的花红，是血汗钱。总坛那份卖命的死契，是另一笔账。”他抬起眼，目光如刀，“‘晨港’那边，还死死卡着‘霁岳’的旧边界，那是别家的地盘。我们绝不能因为都在这片江湖里混饭吃，就恬不知知耻地把邻居山头的粮仓也当成自家的东西，统统充公。”

他话锋一转，算盘珠子“哗啦”一声归位：“反过来说，也一样。破阵堂不能仗着自己是山大王，就把所有家当全圈进私库，然后死死赖掉早就画押的四样东西：带走口供、关门告示、存留铁证、出局生门。想金盆洗手的弟兄，随时能全须全尾地走人，用不着非得先抢下整个山头的地契。总坛就算攥着大印，也休想借此抹掉早就刻在竹简上的血债。”

香堂里的舌战，很快就从总堂烧到了“山城”战区。一直靠在窗边、冷眼旁观的陆宏远被人点了名。他缓缓转过身，窗外的风雪给他勾勒出一道萧索的轮廓。

“南离堂口如果想换个地盘竖旗，”他开口，声音低沉，像是在陈述一个既定的事实，而非寻求许可，“我陆宏远，自然能带走我自己的走镖记录和过了明路的行头，所有私产，全凭本人画押。但是，”他顿了顿，目光在众人脸上逐一扫过，像是在审视一盘十九路的棋局，“我绝不会顺手牵羊，把别家弟兄的密信和整个战区的兵力部署，全揣进自己的兜里。”

他的眼神里没有半分贪婪，只有棋手对棋盘的绝对冷静。“江湖还在转，兵权和神兵利器，依旧死死锁在原来的红契里。那不是我当年掏钱租过两天演武场，走的时候就能把整个场子连锅端走的。刀客可以换一张八仙桌接着喝茶，但原先那桌，依然有别人在走着残局。我不能为了自己另起炉灶行事方便，就把对面那局棋的心脏给活活掏空。”

这盘棋里，哪些是死活未定的真筹码，哪些不过是借来打谱、早已气绝的死棋，他看得比谁都清楚。

议事堂总司程砚舟，长长地叹了口气。他从身后的书柜里，抽出了一卷用油布包裹得严严实实的卷轴，摊开在桌上。那是一份压箱底的封山死契。

“这是最坏的打算。”他指着上面的条款，一字一句地念道，“维系香堂最低运转的粮草、何时停止接新镖、提前多久张贴关门榜、带走底档和封存血本的责任……一笔一划，全都按到了人头上。我破阵堂，绝不敢发毒誓说自己能千秋万载永不垮台。那么，在底下卖命的弟兄，就绝不该到了城门落锁的那天才猛然发觉，自己连当年的一纸卖身契都赎不回来。”

他当着所有人的面，将一项刚刚被驳回的条款指了出来。那条款写着，弟兄退伙时，要按着这些年积攒的卷宗厚度坐地起价。

“这种黑心条款，就是锁死弟兄的琵琶骨！”程砚舟的声音里带着怒意，“总堂必须重新扒算盘，把基本带走的本钱，和额外要收的过路费，在门前给我贴得清清楚楚！还得容许有斤两的新东家，派人来验明正身！放人金盆洗手，自然要扒层皮，可这层皮，绝不能在暗处变成死死锁住人一辈子的铁镣！”

议论声渐渐平息。方婉音从随身的皮夹里，另挑了一段干干净净、全凭自己谱写的短曲，拓了一份，放在桌案中央。

“这支曲子，算我赠与香堂的。在限定的地界内，任凭各位免费过耳。”她说完，便将那卷装着她所有心血的母带，重新锁好，动作一丝不苟。她主动赏给公家的那点碎银，绝没有因此被人强行扩张成霸占她整座宝库的虎符。

有伙计在散会后不解地问她：“方堂主，既然愿意不收钱，为何还要死死咬住那限期的契约？”

她看着窗外纷飞的雪，冷笑着答：“明年，指不定我就要去投奔哪个新山头了。别人今天的热血，也保不齐明天就会冷。白纸黑字钉死了，不是为了糟践眼下的肝胆相照，恰恰是为了防着日后翻脸无情。”

许嘉榕从旁经过，低声问她：“你是不是仍怕自己压箱底的绝活，被人黑吃黑？”

她坦然点头，毫不避讳：“怕。所以，查验、追账和翻脸说‘不’的权力，必须死死攥在自己手里。”

不远处，陆宏远正靠在窗边跟人商议着南离堂口另起炉灶的打算。他没有把换地盘当成挟天子以令诸侯的刀，也没把死守旧山头当成查验别人忠骨的测谎仪。每个人都在为自己的棋局落子，或守或攻，或弃或取。

程砚舟独自站在总堂里，听着门外远去的脚步声，觉得这诺大的香堂似乎空旷了些。有些江湖事，再也不会围着他这个大当家的空头支票打转了。

可正因如此，他低头看着脚下的青砖，反倒觉得每个人的脚下，都各自踩出了能够死死站稳的钉痕。那是一种不再依赖于某个人的权威，而是由无数份清晰的契约与底线共同构筑的、如武当山门般渊渟岳峙的沉稳。
