# 第2章：黑白分明

刑堂之内，寒气凝如铁石。窗外是铅灰色的天，几片枯叶挣扎着，终究被朔风卷走，不知所踪。堂内，两座巨大的黑胡桃木长案分列左右，如同楚河汉界，泾渭分明。

这是开香堂，点的却是阵图，验的是人心。

陈驰站在堂前，背手而立，渊渟岳峙。他目光所及，是两拨埋首于故纸堆中的账房先生，他们拨动铁算盘的声音，像是战场上急促而冰冷的马蹄。他们面前摊开的，是同一份旧日残局，一堆来自沙场的血色功过簿，要在半个时辰内，用新立的门规，重新厘定每一个名字的生死与荣辱。

这里没有花红册，只有生死簿。陈驰只记名字，不判分数。规矩是冰冷的棋盘，落子无悔。

“当——”

铜锣声响，时辰已到。两边主事各自捧着账目，趋步上前。

左首那人声如洪钟：“禀堂主，依新规，此役共计军功一十一份，名录在此！”

右首那人却有些气虚，声音低了半截：“禀堂主……我等……我等只点出十份。”

一子之差，满盘皆输。

陈驰的目光骤然收紧，如鹰隼锁定猎物。整个刑堂的温度仿佛又降了几分。怎么可能？同一局棋，同一份棋谱，在自己眼皮底下，竟能走出两副截然不同的光景。

“少的是谁？”他的声音不大，却带着不容置疑的穿透力。

“回堂主，是一名司号兵。此人名帖上……漏填了师承门派，被堂口查验的竹牌直接折进了待补的暗匣。我等复核时，卷宗里根本就没见着这个人。”

言下之意，错不在我，在规矩。

陈驰一言不发，走到右边那张长案前，从一堆卷宗里抽出了一张薄薄的纸。那是一份军令回执，纸张边缘因反复摩挲而起了毛边，上面按着一个鲜红的指印，像是凝固的血。

“暗档里还有名讳。”一旁的伙计试图开脱，声音微弱得像蚊蚋。

“啪！”

一声爆响，回执被陈驰狠狠拍在案上，震得笔架上的狼毫都跳了起来。他指着那血红的指印，一字一句，如同刀刻斧凿：

“人家手里攥着军令回执，主审的判官却看不见！他拿命搏来的花红，就这么生生被狗吃了！”

他不是在发怒，而是在陈述一个冰冷的事实。这已经不是简单的错漏，而是新规矩这把刚刚出鞘的利剑上，出现的第一道裂纹。暗底下的身家早已对过暗号，那些用来给看客吹嘘的虚字，本不该成为断人生死的关隘。香堂的门槛没改花红的分量，却用一道看不见的门坎，偷偷卡死了能上秤的人头。更可怕的是，这两拨人马，竟能在各自的瞎账上，对出两套逻辑上挑不出毛病的死账。

这颗被遗忘在十九路棋盘外的棋子，硬是让整盘棋走出了走火入魔的模样。

“演武，暂停。”

开口的是一直沉默旁观的杜启航。他走到堂中，将那两本烂账并排放在一起，像是在展示一具丑陋的尸体。

“即刻重立门规。今日起，但凡接了令牌的弟兄，每一次被打回、补供状，或是被发配，刑堂必须一笔一划钉死缘由，将判决发回军令，并列出是谁下的黑手！绝不能再有人，就这么悄无声息地被扫进没人过问的死牢！”

另一处漏风的气口，出在对“功”的认定上。那名司号兵，当时正死守一线天隘口，双眼死死盯着粮车一辆辆挨个挤过，根本无暇分神敲响报功的更鼓。这难道就等于他当了逃兵？一拨人按着当年的生死状，认了他这份死守阵地的苦劳；另一拨却生搬硬套新立的严酷军令，说他未曾按时鸣金，硬是判了个渎职。

顾承安当即起身，声调平稳却带着不容置疑的决断力。“封存那一仗的所有旧号令、帅印归属，还有这份带血的阵中日记。”他走到那堆卷宗前，手指在发黄的纸页上缓缓划过，像是在抚摸一件凶器，“重新拨动算盘。记住，每个真刀真枪扛过阵的弟兄，都保着一份‘基本参与份额’，五百元，这是活命钱。多出彩的，再另论功行赏。但绝不能把‘没斩获首级’或是‘没敲满更鼓’这种狗屁借口，偷换成‘临阵脱逃’！”

他的话，为这场争论定下了“实活”与“虚地”的界限。

紧接着，他又从另一份旧账里抽出一张纸。“这份，只有一张投名状，和当事人自己画的一张旧阵图。此人既未领到发放军饷的虎符，也未接下任何一道拼命的差事。过堂查验，只能证明这帖子是他递的，绝不能顺水推舟，认下他打过一场根本不存在的仗。”

他将那张投名状与一枚刻着“驳回”的铁印一并交到主事手中，语气冰冷：“这是他被革出花红池的铁证，这也是鸣冤者该得的鼓锤。休想借着‘人人有份’的名头，拿几张车轱辘废纸，来骗池子里的真金白银。”

黑白分明，弃子争先。

两本账终于合二为一，可那落败的第一回演武，依旧像一道无法磨灭的伤疤，死死刻在刑堂的耻辱柱上。它只证明了，这堆带血的铁证，按着新规矩能被上秤称量；却绝没证明，所有递上来的口供都干净，更没把那些还掰扯不清的功名簿，当成供奉在祖师堂里永远不会错的泥菩萨。

“堂主断案如神……”一名伙计刚想在功名簿上添一句奉承话，却被一道更冷的声音打断。

“慢着。”

林静薇从阴影中走出，她面若冰霜，手里捧着一个沉重的铁匣。“啪”的一声，铁匣放在案上，里面不是金银，而是一叠叠校准用的陈年死局。

“整整二百份，从老战场上扒出来的带血战报，每一份都有另一路探子查实过的底牌。过堂的判官，在此之前，连碰都没碰过。”她的话语没有一丝温度，“一路杀到终审，仍旧算错了四份。其中两份，硬是把弟兄拼死多补的一刀，错判成了无用的单官。”

众人哗然。总库房里的银子固然没凭空少一块，可真金白银拿错赏钱的冤大头，却是结结实实挨了一刀。

“账面上的差异池，七千元，先从刑堂预留的赔命钱里补足。多吃多占的那份，顺着旧规矩另派人去讨，绝不去刮那些没有争议的老弟兄身上的半两油水。”林静薇的目光扫过全场，“这批试刀石，专为查验香堂规矩，所有花销，从议事堂的茶水库房里拨，共计两千两，一文钱也没沾刚才那十一位弟兄的血汗池子。”

她顿了顿，报出一个让所有人都心头发紧的数字：“按开战前画好的九成五保命圈去算，算错的几率，堪堪冒出百分之五的红线。刑堂保守估计，钉死在百分之五点一。到底，没冲破原定百分之十的那道斩首线。”

那四桩用朱砂圈出的冤案，如同四道流血的伤口，提醒着每一个人：谁也休想把“勉强及格”，涂脂抹粉成“从此再无冤假错案”。

“我提议，再支一千两，重买一轮查验。”陈驰沉声说道，他不能容忍这把剑上有如此明显的瑕疵。

“不必了。”顾承安却伸手按住了他的手腕，力道沉稳。他看着陈驰的眼睛，缓缓道：“你先看清，这一千两银子，究竟能堵住哪处漏风的气口？同一拨判官，再多磕一个响头，未必能凭空变出新的铁证。那些被打烂了的、找不到尸首的复杂战场，也休想借着这二百份干净战报的威名直接通关。这一千两砸下去，不过是重复一次已知的结论。若是下一批死局捅破了斩首线，那便先封死所有新来的门路。已经签了死契的苦差，继续拿真金白银砸人进去硬扛。”

陈驰默默地，将那份本想大肆招兵买马的帖子，重新压回了案底。他明白了顾承安的意思。剑胚上既然试出了一道裂纹，就绝不会凭空被磨成无瑕的绝世好剑。现在要做的，不是反复去试这道裂纹还在不在，而是先认清哪一寸刀口仍会崩折，下一回上阵时，才知道该怎么握住这把凶器。

“若是要改山规，该去拜哪个码头？”刘景和适时地问出了所有人心中的疑惑。

“误杀的案子，交由游离的刀客复核。但改门规，必须在光天化日之下，供所有人审议。”杜启航一锤定音，“若旧规矩已经踩过了道义的红线，该怎么赔命就怎么赔，休想靠着一句‘规矩如此’就想脚底抹油！”

年末那桩关于进内堂复盘的破规矩，也有了定论。那条必须掏出两份带血旧功名和当众露脸的霸王条款，终于被香堂一把撕烂。新规矩改为：在暗处核明真身，再拿旧残局当场试一次他的手段。这场切磋武艺，不给半个铜板的赏钱。想要正式接过那五把交椅的虎符，仍得等到库房里锁好了银子，再另外张榜。

门槛并没有被拆了当柴烧，只是再也不要求那些满怀一腔热血的新兵，非得去掏出一份他们压根就没资格上阵的“过去”。

七名曾经吃了闭门羹的刀客，全都收到了重新登门的令箭。两个早已投了别家山头，一个心灰意冷不愿再蹚浑水，剩下四个，捏着鼻子重新递了名帖。早前悬着的空缺和当更人熬烂的眼珠子，并没有因为规矩改了就当没发生过。刑堂的耻辱柱上，依旧死死钉着那次既把风险拦在外头、又把干将一一并折煞在门外的带血教训。

下午，陈绍武前来讨复盘的差事。

真身在暗处已经验过，但他死活不肯把门派、籍贯和面目，拿到大街上去卖。他板正地递齐了能接活的军令，陈驰也绝没敢把多扒别人一层隐私，当成发放行令的敲门砖。

造册完毕，陈驰习惯性地伸手，想去摸那本评价花红的账册，指尖却被一道无形的墙挡了回来。那是他自己亲手立下的门规，一道冷冰冰的权限屏障。他老老实实地把该审的案子转给了当值的判官，没有为了贪图一时顺手，再向上面讨要一把能随便开库房的万能铜匙。

哪怕是遇到天塌下来的军情，也有事先画好的死线和案卷，绝不拿“事出紧急”当借口，再去唤醒那些能一手遮天的旧日幽灵。

一道朱红色的警牌在他眼前的虚拟界面上无声亮起，提示着“权限不足”。

他原本攥紧的拳头，却在那一刻，缓缓松开了。过去，他总想在腰间多别一把能开百家门的钥匙，以为那是权柄，是效率。如今，他终于舍得把这一方关隘，交给别人去死守。这把剑在哪儿拔出，就该在哪儿收势。这江湖上，也总该有自己不能随手抹平的铁血界线。这是一种收官的自觉。

一旁的伙计见他停下，笑着打趣：“堂主何必作茧自缚，一件简单差事，绕了这么大个圈子。”

陈驰没有看他，目光仿佛穿透了墙壁，看到了多年前，“霁岳”大营倒塌时，那叠自己求爷爷告奶奶也找不到半个人去翻案的死账。他只冷冷抛下一句：

“往后，哪怕我陈某人不在这个位置上，这个堂口，也能自己运转。”

片刻后，陈绍武飞鸽传书，询问是否能亲手画一份阵图，来交复盘的差事。

陈驰依着规矩，将信笺转给刑堂专司此职的解铃人。他静静地站在窗前，直到亲眼看见对面屋檐下的灯笼亮起，代表着那份死契已被接手，这才安心地，合上了自己面前的铁窗。

窗外，风雪渐起。堂内，黑白分明。
