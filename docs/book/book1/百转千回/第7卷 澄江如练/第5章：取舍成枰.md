# 第5章：取舍成枰

冬至刚过，寒气便如无形的刀，刮得人骨头发疼。香堂里烧着三盆炭火，却依旧压不住从门缝地砖里渗进来的阴冷。

岑绍庭接下的那趟“双桥”走镖，总算在这炭火摇曳的昏暗中，钉死了最后一颗维系生死的铆钉。

黑胡桃木的长案上，两叠崭新的银票被一只骨节分明的手缓缓推到中央。左边一叠，是极轴堂口出的七千两，右边一叠，是凌拓堂口拨的五千两。两笔花红，分文不差，全是从他们各自打赢胜仗的私库里现提的银子，连票号上墨迹的干湿程度都透着一股新鲜的杀气。

一万两千两银票，像两块沉甸甸的铁，砸在钱庄的柜面上能听见回响。直到钱庄的伙计验讫盖印，香堂那面巨大的红木榜上，才由执事弟子用狼毫郑重挂出接镖的红绸。两家送来的顺风耳法器并排陈列，外壳的青铜光泽一般无二，只是极轴堂的剑鞘纹路是回字纹，凌拓堂的则是卷草纹，各有千秋。在鬼市里，这等成色的宝贝，身价都在二百六十两上下浮动。坏了包退的承诺，也用蝇头小楷写得清清楚楚，压在法器底下。这是规矩，更是血的教训——能让弟兄们在箭雨和嘶吼中听清号令的宝贝，绝不能因为上面刻着的门派印记不同，就在刀光剑影里给哪家偷偷塞进一道催命的暗号。

一万两千两的总镖银，账目在岑绍庭心中已如棋谱般清晰。

“两千两，是上路的干粮钱，马嚼草料，伤药火石，一应俱全。”他的声音不高，却像棋子落在石盘上，掷地有声，“一千两，是给香堂的茶水费，人来人往，打点通传，维护这方议事之地，不能让祖师爷的香火断了。”

他顿了顿，目光扫过堂下几十张或紧张或麻木的脸。

“剩下七千两，是发给弟兄们的卖命钱，入差异池，按功过赏罚。我话放在这里，这七千两是高压线，谁也碰不得。扣干净所有死契上的花销，账面上多出的那两千两红利，按香堂立下的规矩，入我大当家的私袋。若是半路超支或是断了粮，全凭我岑绍庭签下的生死状去扛，去借贷，去抵押，绝不准任何人把手伸进弟兄们这七千两的花红池里。”

他拿起干粮钱的账本，翻开一页：“这里面，已经划了四百两，是给破阵堂的过路费。人家占着地利，我们图个平安，这笔钱省不了。但买路的钱只此一笔，休想再有人从弟兄们的卖命钱里，刮走第二遍地皮。”

话音刚落，角落里一个生面孔的年轻人站了起来，脸上带着一丝不服气的涨红：“岑当家，既然香堂已经收了一千两的茶水费，为何您自己还要再吞下那两千两的红利？这……这未免也太厚了吧？”

满堂死寂。连炭火爆裂的哔剥声都显得格外刺耳。

岑绍庭没有动怒，脸上甚至连一丝波澜都无。他只是缓缓站起身，将香堂的苦力账、前头为这趟镖垫付的本钱、还有那份厚厚的、写满了各种意外条款的过堂死契，一摞一摞地，“啪”地一声，拍在了年轻人面前的案上。

“门外的规矩，由着你们去货比三家。想临阵脱逃的，在这炷香烧完前随时能走，今日的顶撞，我岑绍庭记在心里，但绝不耽误你日后走投无路时再来投奔的生路。”他冷冷地看着那个年轻人，“城南新出头的张掌柜，我听说他确实愿意少抽几分水，但他能替弟兄们扛事的时辰，也比我短得多。各家山头，自有各家招兵买马的本事。这江湖，从来就不是一碗清水，哪有什么谁比谁天然干净的道理？”

年轻人被那几本厚厚的账册和岑绍庭渊渟岳峙的气场所慑，张了张嘴，终究没能再说出一个字，默默地坐了回去。

再无人有异议。

拔营之前，二十四个前线死士和五个殿后核账的判官，全数上前，在生死契上画了押。猩红的印泥，像极了战场上凝固的血。只要是提着脑袋下过场的，每人手里都稳稳攥着五十两保底的安家费，这笔钱直接从那七千两的池子里预支，全锁在各自的花红分池里。这便是岑绍庭的规矩——绝不是等仗打完了，再挑几个砍下首级最多的人来论功行赏，而是让每个踏上征途的人，身后都有一个最起码的交代。

北侧的粮道出了岔子，比二月那趟镖多了一处塌方。唐梓豪这次只领了半块虎符，行事间多了几分沉稳，也多了几分掣肘。前面探路的车马飞鸽急报，说桥墩子被冬日的河水冲刷得发了脆，内里怕是已经空了。

他下意识地就想催动一组身法最好的“穿云燕”去试探阵眼，看看那桥究竟是虚是实。可他的手指都已经按在了发令的令箭上，一股熟悉的、争强好胜的煞气在胸口翻滚。然而，就在那军令即将脱口而出的前一刹，他硬生生刹住了脚步。

他抬起头，死死盯住中军帅帐的方向，确认正印先锋官是不是已经接到了他的预警哨音。他强迫自己，绝不能再像上次那样，给同一队兵马砸过去第二道会让人心神错乱、走火入魔的军令。

那是一种酷刑般的忍耐。出鞘半寸的剑锋，被他用全身的力气一分一分压回鞘中。他死死咬着牙，把一身翻江倒海的力气，全用来等待。等待自家弟兄把话说完，好让自己递出去的这记变招，能不偏不倚，稳稳地接在整个阵图的生门之上。这不再是少年意气的抢先手，而是懂得了弃子争先的道理。

前阵的死士们就地潜伏，与冰冷的泥土融为一体，干耗着等工兵验桥。这令人窒息的死寂，却让擂台外的某些看客耐不住了。罗振业凑到岑绍庭身边，想趁机塞一段叫卖自家法器的说书进去，填补这片空白。

岑绍庭眼皮都没抬一下，松口准许他拿过明路的邸报去向金主解释兵马为何停滞，这是生意场上的分内之事。但他语气一寒，补充道：“但绝不准你把黑市的招牌，硬插进传音入密的军令里。更不准让前线那些拿命在冰天雪地里干熬的弟兄，为了配合你多赚几声吆喝，而去多送一次无谓的死。”

罗振业讪讪地退下了。

干熬，本来就是死契里写明的一环。该拿的五十两保底花红，一个铜板都不会少。岑绍庭心里明镜似的，这趟镖，真正能在功名簿上拉开身价的，是谁一眼看破了桥墩子的死穴、是谁在众人束手无策时画出了改道的生门、是谁在弓箭告罄的危急关头瞬间变阵扛下了掩护的重任。功劳，从来不是看谁硬熬到最后才闭上眼。

岑绍庭冷眼看着阵前那令人窒息的僵局，脑子里却浮现出十九路棋盘上一记并不花哨的“做活”。有些落子，看似笨拙迟缓，不过是为了让整条大龙不再漏出死穴，补上一口气，未必能写进那些流传千古的杀招棋谱里。可若缺了这至关重要的一口气，后面再怎么气吞山河的攻杀妙手，也只会在收官之时，被对手屠戮殆尽，死得连骨头渣子都不剩。

收兵回营，尘埃落定。

香堂之内，灯火通明。五个判官拨着算盘，珠玉乱响。那七千两的池子，如今只剩四千两可供分赏。

居中坐帐、运筹帷幄的几位，合计拿走一千三百两；一个在关键气口递出致命一刀的行家，独得八百五十两；唐梓豪，因那一次关键的“忍手”，保全了全局的节奏，分得八百两；剩下的二十一个弟兄，每人只拿回了签押时就定下的那五十两保命钱。

这账本，明明白白，全罩在死契的红印底下，无懈可击。另外那三千两的查账库房，正等着五个画了押的判官去过堂点验，确保每一笔开销都有据可查。只要没当逃兵，每个人手里那份保底的苦力钱绝不会飞，多出的油水，全凭出阵前就钉死在墙上、墨迹未干的赏罚令。

唐梓豪对自己阵前那一次犹疑依然耿耿于怀。他没有立刻去领那厚厚的一叠八百两银票，而是硬留在了香堂里，拉住那个飞鸽传书的司号兵，仔细盘问当时为何只敢递一句模棱两可的话，为何不敢断言桥墩已朽。他拿了厚赏，便知自己还有没摸透的命门；底层的弟兄拿的赏钱虽薄，却绝不等于他们就能被主帅当成这场厮杀里的一抹草灰，可以随随便便地从因果账上被抹去。

香堂最终查实，那两千两的干粮钱不假，发落令箭的一千两茶水钱坐实，而那四千两的花红也一文不少地落进了弟兄们的口袋。岑绍庭手里攥着的那两千两红利，依然老老实实地压在库房的铁箱底，他要等着所有弟兄算清烂账、没有任何冤情要鸣，才敢将这笔钱收进自己的荷包。他绝没敢提前掏出来，当成下一场擂台的彩头。

金主那边验货，也得等着江湖上的风声彻底落定。打听价码的、真金白银买货的、和事后翻脸退货的，这三笔账得一笔一笔算清。那些只在台下看热闹叫好却没掏半个铜板的看客，绝不是刑堂该替金主去惩处的“叛门之罪”。钱庄的掌柜若是自己做买卖折了本，也休想在战后不要脸地逼着底下卖命的弟兄去退还那份花红。这是行规，也是底线。

刘景和眯着眼，呷了一口冷茶，缓缓问道：“下一场仗打完，还要不要留下这么多判官，来为了一盘死局重新复盘？”

“留。”岑绍庭的回答硬邦邦的，像一块铁。

刘景和便冷笑一声，将茶杯重重放下：“也好。把规矩在墙上写透了，这刀头舐血的活计，值不值当，留给那些还愿意来拼命的人，自己去掂量吧。”

岑绍庭合上那本厚厚的、浸染着汗水与血腥味的功名簿，丝毫没有去遮掩账面上自己最终落袋的那笔肥肉。该撒出去的花红，一文不欠；自己凭本事、按着死契挣下的红利，也就能这么坦坦荡荡地摊在阳光底下，摊在整个江湖的星位和大场之上，等着天底下的刀客，挨个儿来盘道。
