# 第6章：孤剑不平

香堂的朱漆重门正缓缓闭合，将堂内最后一丝烛火与暖意挤压成线，沉重的门轴在刺骨的冬夜里发出冗长而疲惫的呻吟。就在那光线即将彻底熄灭的瞬间，一道身影踏着碎雪，不急不徐地穿过门缝，将一枚冰冷的木制令符递到了守门执事的手中。

陈绍武的令符，比所有人都晚。

他递交的残局复盘，也远谈不上工整。那张用劣质麻纸绘制的阵图，线条粗犷得近乎潦草，墨迹深浅不一，仿佛是行军途中在马背上颠簸而成。批注更是惜字如金，寥寥数语，却如一柄淬了寒毒的匕首，精准地刺入“双桥”战区那场惨胜的核心。他未曾亲临战阵，却将一支先锋小队如何在强行拔旗的狂热中，鲁莽地抽干了粮道侧翼的护阵灵力，导致中军大帐的补给线险些被截断整整一个时辰的致命失误，揭示得淋漓尽致。他解铃人的身份来路不明，可手里攥着的，却是从枢密院拓印而来、过了明路的战报。每一个字，都像一枚钉死的棋子，牢牢卡进了那五位复盘判官赖以为生的规矩死契里。

初审过堂，设在暖阁。空气中弥漫着陈年卷宗的霉味与高级墨锭的松香。五位判官围坐在一张巨大的黑胡桃木方桌旁，面前摊开着五份截然不同的复盘阵图。算盘珠子拨得噼啪作响，最终归于沉寂。结论无可辩驳：五份战报，无一走眼，皆洞悉了战局的某个关键节点。按规矩，每人先支取五十两纹银，谓之“保命钱”，酬的是这份耗心费神的苦劳。

真正的较量，在于那三千两白银堆成的“花红池”。

“五份复盘，皆有独到之处，亦皆有未尽之言。功过相抵，难分轩轾。”首席判官声音嘶哑，像被风沙磨砺过的旧皮革，“依门规容错之限，终判权重，皆为二档。”

他特意加重了“同档”二字，眼神扫过众人，那是一种不容置喙的威严。这不是和稀泥，不是把已经杀出的高下用浆糊强行抹平，而是五路剑法虽招式各异，却都恰好点中了同一个死穴，功力深浅，实在难做霄壤之别。

账房执事高声唱喏：“花红总池三千两，先扣除五位底银共计二百五十两。余下两千七百五十两，按同档身价五人均分，每位可得五百五十两。底银五十两，花红五百五十两，总计，各分纹银六百两整。”

数字清晰，条理分明。就在众人以为尘埃落定之时，一封“黑贴”悄无声息地递到了首席判官的桌案上。有人眼红了。那封信笺的措辞阴狠而刁钻，它不质疑陈绍武的结论，却攻击他的身份：“陈绍武乃江湖生面孔，初来乍到，未立寸功，何以与四位为总堂效力多年的弟兄同享尊荣？理应贬其半个身位，以彰显尊卑劳苦之别。”

言下之意，是要将陈绍武的份额克扣下来，分给其余四位“老弟兄”。

许嘉榕，便在那四人之中。当她眼角余光瞥见那黑贴上的字眼时，心底竟无可抑制地窜起一股灼热的窃喜——那意味着她能多拿上百两银子，足够换上一柄上好的青钢剑。然而，那念头只是一闪而过，随即被一股冰冷的羞耻感彻底浇灭。她猛然抬头，视线越过摇曳的烛火，看到了那个坐在角落里、沉默得像一块石头的陌生人。那个险些就被这封淬毒的暗箭，在所有人默许之下，无声无息抹掉脖子的人。

她的脸颊一点点滚烫起来，仿佛被人当众掴了一掌。她一直以为所谓的“公道”，是自己遇险时，有人能挺身而出，为自己挡下致命一击。可当刀锋调转，借着“偏袒自己”的名义，要去割一个陌生人的喉咙时，自己竟险些成了那个递刀的冷血帮凶。

许嘉榕死死咬住嘴唇，直到口腔里泛起一丝铁锈味。她强迫自己移开目光，将那份诱人的厚赏从脑海中驱逐出去，转而从怀中取出报名时画押的生死契，那张写满了密密麻麻条款的羊皮纸，被她从头到尾，一字一句地重新审视。

“判官大人，”她霍然起身，声音因紧张而有些发颤，却异常清晰，“此议不公。我，许嘉榕，亦是局中之人，为避嫌，主动请辞退出议事堂闭门论剑。我只以当事人的身份，递交口供，是非曲直，悉听公断。”

她将自己的那份复盘阵图推到桌子中央，退后一步，昂首而立。

高坐刑堂的刘景和，虽与她私交甚笃，此刻却只是淡淡地瞥了她一眼，目光里没有半分徇私的暖意。他没有替她去讨要那份带血的黑钱，只是挥了挥手，示意她退下。公道，不是靠人情来施舍的。

陈绍武那边，很快收到了一枚悬而不决的红头牌。他甚至没有亲自到场，只托人附上了一份接榜时拓印的门规副本，并在相应的条款下，用朱砂笔划下了一道又深又重的血痕。随信送达的诘问，更是如出鞘的利剑，寒气逼人：

“规矩所列，唯论解题之功，何曾有过‘江湖名望’一条？难不成生面孔初登香堂，便天生该被剥下一层皮来敬献诸位前辈？在下身家来路，自有执事查清；解题手腕，亦经过铁算盘验证。旧日威望，根本不在开擂的条框之内，休想在分赃之前，强行加上一道‘熟人专享’的黑筹码！”

这封传书，如一块巨石砸入池水。有人立刻跳出来反驳，声嘶力竭地质问：“难道我等为总堂卖命多年的苦劳，就不值半分花红？”

“值。”这一次开口的，是那位一直游离在外的复核判官，他的声音铁面无私，像法场上斩落的铡刀，“但尔等的苦劳，应由总堂另设库房，提前画下论功行赏的死线，明正典刑地赏。绝不能将这份将来的人情债，偷偷塞进这次早已封盘定死的擂台花红里。此乃弃子争先，而非混水摸鱼！”

一言既出，再无转圜。

铁算盘重新拨过，珠落盘定，声声清脆。结果依旧是“同档”。许嘉榕、邱庭舟、陈绍武，以及另外两名素未谋面的刀客，每人各领六百两纹银，统共三千两，分毫不差。五人，都拿足了那五十两保底的碎银，额外的五百五十两花红也分得一般齐整。这杆秤上，既没有因为交情多加上半两偏袒的人情，更没有因为陈绍武是个新兵蛋子，就强行扣下他凭本事挣来的苦力钱。

陈绍武来领钱时，脸上没有丝毫得胜的喜悦。他只是沉默地数过银子，确认数目无误后，在收讫文书上痛快地画了押。紧接着，岑绍庭，这次擂台的做局人，在清扫完所有杂役后，按着另一份独立的死契，领走了那笔高达两千两的压箱底红利。

同档的解局人拿一样的赏钱，做局的大当家因扛的风险不同而拿走不同的红利。两者之间的界限，如同棋盘上的楚河汉界，被各自的生死状牢牢钉死，绝不允许任何张冠李戴的企图。

有相熟的伙计私下里笑话许嘉榕太死心眼，为个外人，险些得罪了堂里的老人。她却只是望着窗外的落雪，冷冷地回了一句：“该我进兜里的钱，一文没少。只是今日，我头一回看清，那些打着‘为我好’的名义来破规矩的刀子，原来也必须一刀挡回去。”

先前自己上堂喊冤时，心中积郁的那点不甘与委屈，在这一刻，终于让她辨认出，棋盘对面的那个人，那个与自己争夺利益的对手，也是一个活生生的人，有他该得的公道。

陈绍武没有立刻离开。他留在堂里，向管事判官打听下一回摆擂的规矩，却依旧死活不肯将自己的真名实姓，写上那份扬名立万的红榜。

判官点头确认门规里并无此等霸王条款，但也冷着脸敲打他：“下一场擂台，阵图新立，规矩或也不同。这六百两，可不是能端一辈子的铁饭碗。”

陈绍武闻言，竟放声大笑，声震屋瓦：“懂规矩。下次的十九路棋盘，保不齐在下就画得一塌糊涂，分文不取。”

许嘉榕追到大门外时，风雪正紧。她叫住了他，目光死死钉在他那张粗糙的阵图上，直指其中一条她反复推演过的救兵路线：“你这条驰援路线，太过凶险。若能提早半刻，撤下左翼第三组死士，以弃子换取先手，中军的压力会小很多。”

两人就在风雪弥漫的街头，当街争论起来。一样的花红，绝不意味着复盘的手法必须一模一样。一个认为应步步为营，稳固防线；一个则主张险中求活，弃子争先。争到剑拔弩张之际，陈绍武却突然停了下来，他盯着阵图上的一处死角，眉头紧锁，随即干脆地认了输：“你说得对。我漏算了一处藏在山坳里的暗哨。若按我此法，救兵未到，先折三成。”

他提起朱笔，不顾风雪打湿纸面，在那阵图的死角处，重重添了两个字：存疑。

许嘉榕看着那两个墨字，如两颗黑子，死死补在了棋盘的一处气口旁。她心中的那点争强好胜之火，反倒瞬间熄灭，让她更愿意静下心来倾听。这一刻，他们不像两个刚刚还在为钱财明争暗斗的对手，而像是两个棋痴，对着一盘尚未封盘的残局，拆解着其中无穷无尽的做活变化。只有坦荡地承认此处算不到死眼，后续争论的刀光剑影，才有真正能够落子的生门。

许知妍最终按着许可的界限，将这桩公案封进了香堂的铁卷宗，作为日后判罚的范例。但她没有将陈绍武推出去，当成什么宣扬门规的活菩萨。他只是在结案陈词上点了点头，认下了这桩公案，临走前，冷冷地抛下了一句话，那句话被书记官一字不落地刻在了刑堂的回执上：

“希望往后，别每次都非得老子自己跳出来，拿刀抵着自己的脖子，才有人想起要去挡那只乱改规矩的黑手。”

六百两银子已经落袋为安，可堵死下一道规则气口的苦差，绝没有因此就能高枕无忧。江湖的棋盘上，永远有新的劫争在等着他。
