# 第1章：云台论剑

倒春寒的冷锋像一把无形的钢刀，刮过堂前的每一寸青石板。香堂里，三足鼎内的紫檀香饼正燃着，烟气笔直地升腾，却驱不散那股浸入骨髓的寒意。

这是开春头一回开香堂。程砚舟破天荒地，将那把盘着螭龙、象征着“青云会”无上权柄的黑胡桃木交椅，空了出来。

他自己则坐在堂下客席的首位，像个局外人，静静地看着自己亲手点燃的这场风暴。那空着的宝座，此刻仿佛成了一个巨大的漩涡，将堂内所有人的目光、呼吸与心跳都吸了进去。

顾承安就立在香堂中央，身前那张宽大的八仙桌上，铺着一张泛黄的牛皮阵图。他手中一柄湘妃竹骨的折扇，“啪”地一声打开，扇骨轻点图上，声音清脆如棋子落盘。

“诸位叔伯兄弟，”他的声音不高，却清晰地压过了窗外呼啸的寒风，“这是旧日的规矩。”

他扇骨所指之处，是密如蛛网的线条。收发人马、拔除暗桩、立规解释……无数条象征着权力的血线，从四面八方汇聚而来，最终死死缠绕在图中央那唯一的一个点上——那把空着的交椅。从前，多少生死悬案，无论堂下如何争得头破血流，最终都凭着坐在这把椅子上的人金口玉言，一锤定音。八位老头领，看似是辅弼，实则更像八根锁链，既能互相掣肘，也能在瞬息间联手，将香堂外的万千弟兄，彻底排挤在棋局之外。

“这十九路盘上，看似处处留着活眼，可真正的死穴和阵眼，全攥在这八位手中。”顾承安的折扇缓缓划过图上几个关键的节点，语气平静，却字字诛心，“哥几个轮流坐庄，看似公允，却从未让局外的弟兄，摸到过半点棋盘的边角。”

他话音未落，角落里一个粗壮的汉子，川堂的刘景和，便皱着一对浓眉闷声问道：“顾先生的意思，是往后所有堂口大事，全凭大伙儿画圈表决？”

不等顾承安回答，他对面，一身锦缎短衫的陆宏远便发出一声冷笑，那笑声像是冰块在瓷碗里碰撞。“刘堂主，陆某倒想请教，这‘表决’二字，究竟决个什么？”他眼神锐利如鹰，直刺刘景和，“是不是今天几百号兄弟在庆功宴上喝高了，就能画圈赖掉昨儿个已经画押结契的花红？是不是也能用这劳什子的公投，把一条弟兄们正拿命在走的绝密粮道，大喇喇地吼给对头的仇家听？”

这一问，如同一盆冰水，兜头浇熄了堂内刚刚升起的一丝燥热。

几番暗中飞鸽传书的切磋，数次堂前唇枪舌剑的对质，最终的章程，在香烟燃尽第二饼前定了下来。旧的香堂规矩被付之一炬，新的议事会，如同一座新铸的剑台，拔地而起。

六人共掌门规。

破阵堂，顾承安，占一把交椅。
外围堂口，陆宏远，分一把交椅。
刀客与脚夫，许嘉榕与刘景和，各占一把交椅。
最后两把，给了两位身家清白、不沾黑市铜臭的坐堂客卿，来历、背景、乃至每月支领的车马茶水钱，俱都一笔一笔记在账上，过得是明路。

帅印，由这六人共掌，暂定到三月底，再行评议。

“议事堂单立库银，”顾承安的声音再次响起，折扇收拢，在掌心轻轻敲击，“用以打发车马费、传功和抄录卷宗的差事。绝不能逼着那些指望白天干活糊口的弟兄，还得饿着肚子免费熬夜，来搏一个说话的位子。”

话音刚落，新晋入席的许嘉榕便开了口。她是个面容清秀的女子，但眼神里的坚毅却不输任何一个刀口舔血的汉子。“顾先生，诸位堂主，晚间议事的更漏点，恰是我家小崽子啼哭索食的时辰。若为公事误了家事，嘉榕心有不安。”

堂内一时寂静。程砚舟的眼角微微动了一下。放在从前，这等“妇人之见”只会被当成笑谈。

然而，顾承安只是略一沉吟，便对身旁的记事道：“记下。议事更漏，为许堂主拨慢半个时辰。”

这桩看似微不足道的小事，却比任何豪言壮语都更具分量。规矩，开始为人服务，而非人去迁就规矩。

“最后一条铁律。”顾承安环视众人，目光最终落在了那张空椅子上，“这六个人，是守规矩的执剑人，但绝不能冒充当铺背后的金主掌柜，更不能直接披挂上阵，去当拔旗斩将的大元帅。开门立户、收发拜帖、贴红榜、查内鬼，所有程序皆由生死契钉死；但手底下的买卖和带兵拼杀的实权，依旧各家管各家，议事堂不得插手。”

“寻常大事，必须凑齐四支令箭方可通过。凡议案牵涉到在座某位的亲族旧部，该人必须避嫌，由候补顶上。至于旧契约的毁约改道，照旧走老刑堂的规矩，这六支令箭，绝不能强行盖住天下所有的死局。”

规矩立下，便是试剑之时。

头一份摆上香堂的请战书，便出自程砚舟之手。他想将正在各处死里求活的战区堂口，统统拢进总堂新立的“虎榜”，明示排位，好叫江湖看客瞧瞧，青云会还没死绝，依旧是那头下山猛虎。

文书刚一念完，陆宏远便又是一声冷笑，仿佛淬了冰：“程公的好意，陆某心领。只是想问一句，倘若南离分舵觉着这浑水太深，不肯上榜，会不会因此在总坛的拜帖里，被刻意打入冷宫？”

“绝无此事！”程砚舟几乎是脱口而出，语气里带着昔日大当家的威严。

“空口无凭。”许嘉榕清冷的声音响起，她甚至没看程砚舟，只是盯着那份文书，“程公，我们要的不是一句保证。我们要的是白纸黑字，写明如何排座次，如何上榜，又不合哪条规矩便会被请出局。绝不准只凭一句嘴上的空头支票，来蒙混过关。”

所有人的目光都转向了顾承安。他身上贴着破阵堂的标签，破阵堂又是程砚舟一手提拔的心腹。可他只是静静地看着那份文书，手中的折扇纹丝不动，没有半点要替旧主强行盖印的意思。

倒计时的沙漏无情地流淌。时辰一到，请战书被原封不动地打了回来。旧有的通关阵眼，照常留用。

程砚舟死死攥着那份被驳回的文书，纸张的边缘被他捏得起了毛边。他硬生生咽下了那股涌到喉头的、想要长篇大论辩白一番的冲动。他想，既然立了这云台论剑的规矩，若是来赴会的各路英雄，依旧只能跪在台下高呼“盟主英明”，那他这个退位的盟主，和稳坐钓鱼台的独夫又有什么区别？

这回结结实实砸在他脸上的退帖，总算让他真切地称出了那把被他亲手空出的太师椅，究竟有多重的铁血分量。这是弃子争先，他舍了自己的一份颜面，却保住了整个棋局的“活气”。

第二份军情，则直接烧到了战阵前线。一家兵强马壮的堂口，递上血书，妄图让议事会直接将“双桥”战区的大帅金印授予他们。他们仗着的，无非是兜里掏出的银子最多，声称就算是阵地丢了，他们也赔得起这笔抚恤金。

这一次，是刘景和站了出来。他一言不发，走到堂前，从文书袋里抽出那份堂口的战绩簿和另一份厚厚的出资契约，用两枚铁钉，并排钉在了刑堂的柱子上。

“铛！铛！”两声巨响，震得人耳膜发麻。

“银票，”刘景和的声音冷得像铁，“能稳住后勤粮道，能让弟兄们吃饱穿暖，但绝不能代替排兵布阵的将才，更不能用来直接买走挂帅的虎符！”

他转身，目光如刀，扫过那家堂口派来的代表。“想拔旗，可以！按照总坛告示上的规矩，去擂台死战，胜者为王！绝不允许议事堂靠着几张选票，就越过真刀真枪的演武场。若是觉得擂台规矩本身不近人情，大可上书来改，但绝不能因为这回谁手里的银子多，就立刻把祖宗规矩按着他们的体量，量身定做！”

程砚舟枯坐在香堂外圈，听着自己往日里大笔一挥就能顺手糊弄过去的烂账，如今被一块块拆骨剥皮，心底难免蹿起一丝烦躁。他固执地相信，自己那份立虎榜的帖子绝无私心，甚至觉得这帮人穷讲究的死规矩，硬生生耽搁了给弟兄们讨饭吃的活命机会。

可他也明白，倘若只有顺着他程砚舟心意的落子才叫“议事”，那他刚才交出去的，依旧不过是一枚唬人的假印。那不是云台论剑，而是请君入瓮。

议事散场，他面无表情地走到告示墙前，亲手扯下原定的挂榜时辰，转身对书记官道：“领命，去补齐虎榜缺失的铁证。”

刘景和走过他身边，脚步顿了顿，低声问：“程公，刚才驳了您的面子，心里可是添堵了？”

程砚舟没有回头，只是看着远处灰蒙蒙的天空，倒也坦荡：“不痛快，是有的。”他顿了顿，补上一句，“但怎么化解这口气，不是你刘景和该替我擦屁股的差事。”

夜深了。许知妍垂首在灯下，用小楷一笔一划地抄录着香堂今日的铁证。凡牵扯到旧日烂账的人名，依旧按规矩回避。没有黄袍加身的戏码，也没有哪路神仙登台点将的虚假排场。冰冷的八仙桌上，只留下了两份没被霸王硬上弓、强行按头的铁卷。

大门外，运粮车队的交接令符，依旧在一板一眼地发落。那些前来申冤或讨差事的弟兄们，心里跟明镜似的，早就知道该去敲哪扇门，见哪个人，再不必像从前那样，事事都得先去程砚舟的府门前，跪求一个点头。

香堂里的那把空椅子，在清冷的月光下，静默无语。它失去了唯我独尊的温度，却赢得了整个江湖的敬畏。
