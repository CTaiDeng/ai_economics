# 第9章：雪泥剑痕

朔风如刀，割过香堂檐角悬挂的铁马，带起一串喑哑的悲鸣。吴秀榕解下头上的斗笠，雪沫子簌簌而落，在她脚边洇开一小片湿痕。她将一纸状子递上高高的案台，纸页边缘因紧攥而起了毛，字迹却端正刚劲，一如她此刻挺得笔直的脊梁。

“求当值的判官大人，将黑市悬赏墙上那张旧告示，扯下来。”

接状子的伙计不过弱冠之年，眼神里透着股文书小吏特有的怯懦。他将状子凑到油灯下，只扫了一眼那赫然在列的名讳，手便是一抖。那张告示，他认得。它像一块牛皮癣，在黑市最显眼的位置贴了太久，上面泼的脏水早已干涸成丑陋的墨块，连同那桩空穴来风的罪名，成了茶馆里说书人的廉价笑料。每当吴秀榕背着剑匣去新的山头投军，总能感到背后有无数根芒刺般的目光，听见窃窃的私语。

“就是她，那个在黑市卖假通关文牒的……”

伙计不敢接这烫手的山芋，嗫嚅道：“吴女侠，这……这告示入了档，便是生死簿上的一笔，擅自揭了，怕是犯了‘抹杀因果’的忌讳……”

话音未落，一道清冷如冰的声音自内堂传来。“因果？”

林静薇自一扇月洞门后步出，未着判官官服，仅一袭素色长衫，却自带三分霜雪之气。她没有看那伙计，目光径直落在吴秀榕那张因隐忍而显得愈发倔强的脸上。她伸手取过状子，又命人取来刑堂的卷宗，两样东西并排摊在冰冷的黑胡桃木桌案上。桌角，一尊铜兽香炉里，残香已冷。

“这，是过堂的铁证。”她指着卷宗，声音不大，却字字如金石落地。“这，是大门外的告示。”她的指尖又移向那份状子。随即，她从笔架上抽出一柄裁纸的乌木戒尺，眼神一凛，手起尺落，“啪”的一声脆响，仿佛一刀挥出，精准地将桌上的虚实一分为二。

“混淆一谈，才是最大的忌讳。”林静薇的语气没有丝毫波澜，却带着不容置喙的威严。“该锁进铁匣的证据，按年限封存，一枚铜钱都不能少。泼错的脏水，必须当着天下人的面洗净。至于那些越界挂出来的私密物事，立刻撤掉。”她顿了顿，目光扫过堂上众人，“这张黑榜最初是怎么贴出来的，自有刑堂的案卷去查。但扒光一个女人的底细，让她体无完肤地暴露在光天化日之下，绝不是为了保全什么狗屁的铁血历史。”

她的话，如同一记收发自如的天山折梅手，看似轻描淡写，却精准地拆解了症结所在。“身家性命和真容，从未直接钉死在拔不掉的铁索上。铁索上验明正身的印记，更要防着顺藤摸瓜的仇家。规矩上到了该烧毁残卷的时辰，当差的，就必须亲手把案卷焚毁。若是被王法或是机关术卡住，暂不能毁，那就给它死死锁进密室，休想再拿出去到茶馆里去评书卖钱！”

在林静薇的亲自监督下，刑堂重写了告示。吴秀榕凑上前，就着灯火，将那张崭新的红纸又读了一遍。她伸出食指，蘸了蘸案上那碟尚未干透的红色印泥，血色一般，重重按在了告示的下半截。那里，坦坦荡荡地留着她确实替人传过话的案底，并注明“已受刑堂盘问，绝未沾手半文钱的黑心介绍费”。

她不准他们删掉这半截，不想伪装成一个彻头彻尾的清白圣人，更不想让潘俊棠觉得，她是在暗地里，偷偷洗刷那一日的过错。她想卸下的，是被人胡乱泼在剑鞘上的污墨，可剑身上那些真刀真枪拼杀留下的卷刃与刻痕，她依旧认得。那一天在阵前，她究竟出过哪几招，愿意面对天下人，照实吐口。

飞鸽传书送到了潘俊棠的案头。验过誊抄的告示后，他的回信只有寥寥数字：这样写，是对的。

两人依旧没能在一张桌上温一壶酒，驱散这满身的寒气。却终于能在这桩早已冰冷的死案上，点下同一个头。从此再相见，或许用不着一上来就拔刀相向，去死咬对方是不是想篡改昔日的战报。

同一日，香堂之上，又起波澜。有人上进言，想把旧日“大营哗变”那桩惨案的石碑从总坛大门外移走，只留下“兵强马壮”四个描金大字，以壮声威。

顾承安坐在主位，面沉如水。他一言不发，只是翻开一本封皮已经磨损的黑色账簿，那是一本尚未结清的死账。他冰冷的指节，叩在纸页上，发出沉闷的声响。

“七万二千两银子的赔偿已经付清，但这里，”他的手指重重一点，“还挂着六千两，是弟兄们的血汗钱，至今没从罪魁祸首那里追回来。该摘掉的顶戴，也还没全摘干净。”他抬起眼，目光如鹰隼般锐利，“新挂出的功名榜可以更亮堂，但绝不能让那些还在眼巴巴等着这笔钱救命的弟兄，连同他们的名字，直接从刑堂的待办卷宗里，彻底人间蒸发。”

程砚舟就站在顾承安身侧，死死盯着那页还没平账的血案。那一行行墨字，在他眼中渐渐化开，变成了一局凶险莫测的围棋残局。十九路棋盘的边角上，一枚黑子正悬在那里，是一记尚未落下的、要命的“打入”。把这页残局直接翻篇，绝不等于对面的仇家已经停手认负。只要那一口气还没补上，这个致命的气口就永远存在。新摆出的阵图再怎么烈火烹油、鲜花着锦，也填不死这处能让全局瞬间崩盘的死穴。

将自己栽过的跟头、流过的血，日日陈列在山门口，供人围观，这滋味绝不好受。程砚舟极不情愿，却还是咬着牙，对着顾承安，沉重地点了点头。

“就……让它留在门口吧。”他艰涩地说道，“一次已经补上的气口，不必再当成眼下的死局。可那些还没还清的血债，也休想轻描淡写地被塞进故纸堆里，蒙混过关。”

这股风气，仿佛一场倒春寒，吹遍了各个堂口。

岑绍庭在账房里，就着昏黄的烛火，翻查九月里那笔三千两的走镖账。他看见，银票兑讫的红印回执，与那份曾被毛贼借用他名号行骗的卷宗，被分别装入了两个不同的封套。前者，光明正大，可供查阅；后者，则用火漆封死，旁边朱笔小字批注：非持刑堂令牌者，不得启封。他用命换来的赏钱，干干净净，绝不会因为被骗子扯了一次大旗，就变成见不得光的黑钱。当年发下军饷的案底，也绝不会因为销毁了一张伪造的拜帖，就重新变成一笔悬案。

各大战区的功名簿上，也撞上了同样的麻烦。一个已经洗脱“逃兵”嫌疑的刀客，在堂口咆哮，他死活不愿自己的大名，永远跟那个被误判的印记绑在同一根耻辱柱上。刑堂的平反昭雪令，最终以八百里加急的规格，送达所有曾听过那句脏水的堂口。铁匣里，留着详尽的前因后果，供日后查考；大门外的皇榜上，则必须高悬他如今干干净净的身家。那道洗冤录，不是只配锁在不见天日的死牢底的秘密。

另一桩案子，则走向了截然相反的结局。有个刀客叫嚣着，要刑堂删掉他当年因贪功冒进、导致同袍全军覆没的案底。一名游离判官当堂驳回，声色俱厉。

“你踩过界的事实，吃过挂落的期限，重新拿回大印的门槛，一个字都不会少！”判官的判词掷地有声，“准许你鸣冤，是让你洗去被仇家添油加醋的骂名。但当年你实打实惹出的祸端，半个字，也休想抹掉！你日后自然能凭本事练成绝世高手，但刑堂的生死簿，用不着为了成全你今日的脸面，去凭空捏造一个你从来没挨过刀的假江湖！”

方婉音听闻这些事，回到自己的住处，连夜清点起那一堆声乐秘籍的过堂路条。她学着林静薇的法子，将那些用以千秋万代作证的铁卷，跟仅仅为了一次走镖留下的拜帖，死死劈开。时辰一到，该烧掉的废纸便按规矩付之一炬，只在死契上留一笔销毁的红印。她心中了然：把全天下人的老底都扒光了锁在自己库房里，确实最安稳，但这绝不能成为大当家无休止地偷窥弟兄们私产的借口。

角落里，陈驰默默将几张偷偷藏在袖兜里的备份旧账，一张张掏了出来，投进了火盆。火苗舔舐着纸张，将那些墨字化为灰烬。他原以为，手里多捏一张牌，总能在关键时刻拔刀相助，护个周全。如今却惊出一身冷汗，这些越过雷池的暗桩，一个不慎，就会变成扎在自家兄弟背后的毒镖。

吴秀榕攥着刑堂发还的洗冤令符，走在日暮的街头。她鬼使神差地绕回黑市，那张贴了许久的破纸果然已经不见了踪影。她知道，它没有真的消失，只是被锁进了该去的地方。只有持牌的判官，才能按着规矩，去铁匣里翻阅那桩旧案的本来面目。

她走进一家驿站，要了笔墨。对着烛火，她给那个许久不曾飞鸽传书的旧相识，写了一句简单的寒暄：

“下月初一，后山走走？”

没有人把她这次重新拔刀，当成什么招安归顺的军功。她大可以重新做回这片江湖里的刀客，一边继续去死咬那拖欠的二百两碎银，也可以在将来的某一天，因为任何理由，干脆利落地砸了剑匣，再不踏进这道山门半步。

生死簿只记该记的血债，绝不要求活人，永远被钉死在旧日残局的一角。

人生到处知何似，应似飞鸿踏雪泥。雪化了，鸿飞了，可那爪印，曾真实地存在过。这，便足够了。
