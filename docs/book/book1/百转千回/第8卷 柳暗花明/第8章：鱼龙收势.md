# 第8章：鱼龙收势

春灯观战的擂台，头一回被衙门打了回票。那回票并非朱笔勾决的死令，却比死令更令人憋闷。它不是说没人捧场买这茶水钱，恰恰相反，是捧场的人太多，喊杀声太响，惊扰了墙外的人间。

摆擂台的账房周慎衡，挑的是河边最便宜的野场子，冬夜的寒风能把骨头缝里的热气都刮走。他原想借这肃杀之气，连着三个晚上通宵打擂，再花钱雇些金盆洗手的老刀客，在台下支起茶摊说书拆招，把这“春灯擂”做成一桩开春的盛事。撒出去的泥金战帖上，用的是最张扬的馆阁体，笔走龙蛇，吹得天花乱坠。

可战帖的墨迹未干，隔壁泥瓦房里的街坊却先找上了门。那是个面皮被风霜刻得皴裂的老汉，身后跟着几个畏畏缩缩的妇人，手里没拿刀剑，只捧着一腔被搅扰得不得安生的怨气。他站在堂口门口，冷冷地问，那催命的战鼓，究竟几时能停。

管事的满脸堆笑，搓着手哈出白气，说看客入场全凭自愿，绝无强买强卖。

对方只硬梆梆地砸回一句：“老子没空掺和你们这江湖局。你们的刀光剑影，别溅到我们吃饭的锅里。”

管事的还攥着那张灯影如龙的画卷，嗓门却不自觉地矮了半截。他这才明白，香堂里的锣鼓敲得再震天响，刀客的剑法舞得再出神入化，那没长眼的声浪一旦越过了院墙，墙外的平头百姓照样得抱头鼠窜。他们用不着非得按了手印，入了你星原堂的伙，才有资格勒令你这脱缰的野马收蹄勒马。

程砚舟听见这声冷喝时，正俯身在一张巨大的沙盘前。那沙盘上，旗幡林立，兵马纵横，每一个棋子都代表着一笔资金的流向，一条人命的归属。他猛然从那盘中厮杀的幻境里抬起眼，隔着重重院墙，第一次真正“瞧见”了墙外那些鲜活的人。香堂里按着死契真刀真枪地打擂，规矩确实清清白白，一笔一划都刻在铁券上；但这绝不等于墙外的寻常百姓，就活该被这满院子的喊杀声吵得彻夜难眠，连条回家的活路都被看客的马车截死。

游离判官没去越俎代庖，顶替六扇门发那索命的令箭，也没因为一封状纸就一刀切死所有黑市拳局。他只是召集了人。掌柜、东家、街坊代表和六扇门的捕快，围坐在一张冰冷的黑胡桃木长桌旁，桌上的残茶早已失了温度。他们没谈江湖道义，也没论谁是谁非，只死死卡住三样东西：更漏、战鼓的响动，以及留给败者的活口暗道。

要在墙头加装塞满棉絮的隔音铁板，要多派护院死士维持秩序，那都得烧真金白银。

若是提早到三更前鸣金收兵，就得砍掉老刀客最精彩的说书时辰，看客的兴致便缺了一大块。

若是拔营换到更偏远的山头，就得挨更狠的过路费和地价，原先铁算盘上那点光鲜的油水，眼看就要被这几方角力生生刮干。

有个黑心账房动了歪心思，想从已经画押的死士花红里扣钱来补窟窿，这念头刚一出口，就被门规顶了回去。死契上没哪条规矩写着，拔刀卖命的人，还得替掌柜随时惹出的糊涂账垫底。要填这个坑，只能去挖大当家自己留着压箱底的“搏命本钱”。若是改了茶水钱和打擂的时辰，心中不快的看客大可退票走人，绝不准把这盘烂摊子砸在已经交了钱的主顾头上。

最终，那连战三晚的豪言壮语，被生生腰斩成两晚，且必须赶在三更前落锁清场。几家钱庄重新过了堂，退掉了一批预售的香火钱。剩下的散碎银两，刚好够给擂台上的死士发足饷。若是连这底账都兜不住，大不了就此散伙，绝不准厚着脸皮去挪用那根本不存在的“第三晚”的虚账，做空头人情。

四张底牌跟着判词一并张榜，贴在堂口最显眼处，字迹冷硬如铁：全盘封杀、只开一局、两局早收、三局死扛。

这棋盘上的变化，一目了然。前两手活棋，早已包在那“两局早收”的法门里，买茶水的看客照样可以只看一局便走。而那“三局死扛”的死着，因捅破了更漏和地界的红线，已是盘上废子，必须推倒重来。最终挑中“两局早收”，不是因为它能让谁赚得盆满钵满，而是因为它在这十九路盘上留出的气口最多，最能容纳各方辗转腾挪。衙门的意思也清楚明白：别处按规矩过堂的教头练兵和内堂演武，照样开门纳客。六扇门没把这江湖的独木桥，全留给星原堂口一家走。

周慎衡硬着头皮，亲手把被砍掉的那一晚，从铁算盘上生生抠下。那一瞬间，他眼前的局盘顿时逼仄得令人窒息。他悟了，目下能实打实围出几目地，就老老实实认下几目地。休想再把十九路盘上那些还没落子的漫天外势，那些虚无缥缈的“潜在收益”，全都大言不惭地算成兜里摸得着的真金白银。

战区里的死命博弈，绝不会陪着茶馆里的看客一起安睡。阵前扛刀的死士，依旧照着原来的更漏鸣金收兵、移交虎符。留下的残局卷宗，自有接手之人拿了令牌，在灯下慢慢拆解。茶馆这边吹灯拔蜡，绝不等于把边关的将士凭空抹去。堂上的司仪用不着拿大喇叭去喊一整夜的冤魂，活人更不必为了死守一张还在推演的残局图，就活活在太师椅上熬干血肉。

只在深夜才有空闲的看客，被砍掉了一程消遣，骂骂咧咧。墙外的街坊，护住了耳根一夜的清净，安然入梦。摆擂的堂主，少搂了一大笔油水，心头滴血。而那些跑腿的伙计，也总算盼来了能喘口气的活路。在这张犬牙交错的十九路盘上，根本没法用一杆秤去量平天下所有的血亏和横财。

韩知衡冷眼旁观，一语点破棋局中的虚实。他的话语像一把精巧的手术刀，精准地剖开账目：“死士领走的花红，在天下人的总账里，不过是左手倒右手的虚账，是内部流转，绝不能再当成烧掉的真金白银，重复记一笔亏空。可你砸在隔音铁板、灯油、打更人和白白流失的买卖上的血本，那是实打实的沉没成本，绝不会因为你换个山头开香堂就不翼而飞。”

周慎衡听得冷汗涔涔，他把堂口的铁柜账、死士的卖命钱和惹出的外部乱子，用三道朱砂线死死劈成三块。盘不明白的迷阵，就老老实实地在账本上留个空眼，再不敢丧心病狂地提笔画个“零”去粉饰太平。

与此同时，一封出红差的飞鸽传书，落到了许嘉榕的窗棂上。赏银给得足，是笔肥差。可信上写的更漏，却偏偏和她早已答应好，陪家人吃团圆饭的时辰撞了个满怀。她几乎没有犹豫，推了那封战帖，并诚心举荐了另一位身手不凡的把式。转过头，她只是默默在自己的账本上，划掉了一笔原想添置新神兵的预算。不赚那刀口舔血的钱，确实肉疼，但她也用不着把自己吹嘘成什么视金钱如粪土的江湖大侠。她想得很明白：自己既没在那张生死状上按手印，就没脸去讹诈总堂，拿银子补偿她这趟“缺席”的损失。

方婉音收到回信，只道了声“晓得了”，便痛快地准了换将。身为当家主事，她自然巴望着天下第一的快刀全都来自己的香堂挂号。但她更懂，提刀的人若是怀揣着不愿见光的隐情，或是心中有了比金钱更重的牵挂，照样能把战帖狠狠甩在地上。一个真正畅通无阻的生门，必定和一条写着“老子不伺候”的退路并排敞开着。这收发自如的气度，远比签下十张卖身死契更为难得。

第二夜，程砚舟没有安坐堂中，而是亲自站在了院墙之外，站在那老汉先前站立的位置，用耳朵去丈量那条无形的红线。风中传来阵阵闷响，那是拳脚到肉的声音，是兵刃格挡的脆鸣，但那股足以撕裂夜空的声浪，硬是被高墙和规矩死死压在院内，没敢越雷池一步。有喝高了的看客骂娘，嫌散场太早，搅了兴致，堂口的伙计只能赔着笑脸，指着天上的更漏一遍遍作揖。几个街坊牵着孩子，慢悠悠地从灯火通明的堂口门口晃过去，脸上没有一丝惊惧。

周慎衡砸进去的那大笔真金白银，就这么无声无息地融化了，才堪堪换来这副看似没半分火气的太平假象。

回到总堂那间四壁皆为铁柜的书房，程砚舟从卷宗上拿起蘸了清水的毛笔，一把抹掉了角落里那句“满盘皆活、皆大欢喜”的浮夸妄语。墨迹在纸上晕开，像一团散不去的愁云。

有的刀客，少斩了一夜的花红，却多了一份从容。有的街坊，多换回了一宿的安眠，代价却是别人的失落。规矩画出的边界，能让各路人马都在这拥挤的棋盘上，勉强找到一个落脚点，却休想拿一支“步步高升”的朱笔，去强行勾勒全天下所有人的活路。

棋盘之上，从来没有皆大欢喜，只有落子无悔。
