# 第6章：棋逢敌手

夜风如刀，割过新残局的每一寸焦土。罗启锋已连着杀透了两层敌阵，血腥气混着硝烟呛入肺腑，战至第三个搏命时辰，他那口无往不利的刀，终于一头撞上了麦振铮死守的那座旧仓房，撞上了一堵仿佛亘古便立于此的铁壁。

麦振铮依旧对新门规里那套繁复如拉弓射月的死讲究嗤之以鼻，但他早已凭着野兽般的直觉参透了其中最要命的“气口”。他就那么窝在黑暗里，如一头蛰伏的孤狼，不攻，不动，专等罗启锋这种大开大合的刀客强行变招时，肩胛与肋下必然会露出的那半寸致命破绽。罗启锋想凭着浸淫多年的老把式强行碾压过去，刀锋卷起的罡风刚递到货箱外三尺，便被一片从阴影中泼洒而出的箭雨逼回死角，箭簇攒射在墙上，发出令人牙酸的“咄咄”声。他只能咬碎钢牙，沿着唯一的边路狼狈退回。

十九路棋盘上，落子无悔。战场之上，更没法拿旧琴谱倒退更漏重新来过，也休想靠场外茶馆里那些摇着折扇的说书人，给你透半句风报半点信。

一枚穿云响箭带着凄厉的啸音，从他手中射向总堂方向——那是借火器的军令。然而中军帐的回令却如一盆冰水兜头浇下，令箭冰冷，将最后一批掩护用的火药，尽数拨给了远在后翼、负责断后收尾的另一营人马。阵前一角的锋芒与保全整个大盘的死活，在中军帐那杆冰冷的帅旗之下，从来不是同等重量的砝码。弃子争先，这是围棋的道理，也是战场的铁律。

罗启锋只能在自己干瘪的行囊里，在那几张几乎被手汗浸透的底牌里，重新做活。他没有嘶吼着抗令去强抢火药库，那是一败涂地的莽夫行径。他只是压低声音，命手下探子飞报侧翼尚有生门可走。半个时辰后，探子带回的不过是一堆沿途捡漏的散碎兵甲，残破不堪。他终究没能咬下那座死仓。

他死死盯着对面仓房上那面依旧迎风招展、印着麦字的旗号，把那句已经涌到嘴边的“再给我一把火”，硬生生嚼碎了咽回肚里。一隅的意气用事，终究要服从全局的死活。大当家把那一记至关重要的应手，拿去护了运镖后路的“大龙”，那他罗启锋，就只能在这片被遗弃的残局里，自己用指甲抠出一条活路。

战罢，功罪自有铁面判官分说。麦振铮凭着这一手“锁喉剑”，不仅扛住了大阵冲击，更护着残兵毫发无伤地退回本阵。论功行赏时，判官笔下的花红，稳稳压了罗启锋一头。堂下无人不服，两边只要是没死在阵上的弟兄，都按着入伙时画押的死契，领了一份垫底的汤药费。但麦振铮多拿的那笔赏钱，挣的是他那把剑的刀口钱，是没让手下弟兄白白流血的封口费，绝不是从罗启锋或是任何败军嘴里硬抠出来的买命钱。罗启锋在外头名头再响、听他评书的戏迷再多，也休想在这位铁面判官跟前，把写满了红黑名号的榜文倒过来念。

然而，在另一个专卖评书拆招的茶馆里，风向却截然相反。罗启锋的签筒卖得更爆，看客满堂。他能拉下脸，把自己走瞎的臭棋掰开了、揉碎了，一点点讲给那些刚入门的雏儿听，讲得深入浅出，引人入胜。麦振铮却最烦捧着一本旧账跟人掰扯上半天，只肯冷着一张脸，在台上默不作声地演练半个时辰的杀招，剑气森然，吓跑了大半看客。

两个顶尖的刀客，各自去画押自己投缘的死契，谁也没被逼着非得把一身铮铮硬骨头，熬成一味每样都得卖座的神仙散。

议事堂上，陈绍武突然发难，声音在空旷的厅堂里回荡：“是不是天下第一的快刀，就该通吃所有行当的油水？”

角落里，一直闭目养神的刘景和缓缓睁开眼，嘴角勾起一抹冷笑，顶了回去：“你先看清对方究竟卖的是哪门子手艺。守阵拔旗、中军排阵、说书拆棋、茶馆揽客，这本就是四条互不搭界的生路。按了手印的死契，也绝不会被扔进同一个花红池里吃大锅饭。茶馆里说书赚的名头，休想强行折算成阵前的斩首军功；刀法出神入化，也绝不担保天下人都愿意捧场听他磨一整晚的嘴皮子。”

话音刚落，一封“劫富济贫”的暗条被呈了上来。有人提议，想把顶尖刀客超出常额的花红，临时截下一刀，分给那些刚入伙、尚在嗷嗷待哺的雏儿。这招确实存着收买人心、培养班底的“养望”之心，却必须先把兜里的现银、堂上的规矩和卷宗旧案上的死契，一桩桩摆在黑胡桃木的长桌上，用算盘一颗颗算清楚。

“带新雏儿入阵、匀出历练的活计和师傅传帮带，”刘景和的声音愈发冰冷，“大可向总堂另起灶炉，单独立项，批下银两。绝不准等人家用命把钱赚回兜里了，再追着屁股往回找补，搞什么吃大锅饭的把戏。若要改往后的抽水门规，必须在香堂开坛之前，就把新规矩一笔一划写进铁卷，昭告天下，准许那些不服的人当场翻脸不认！”

一直沉默的麦振铮，终于抬起了眼皮，目光如剑，直刺那位提议的执事：“若是雏儿练废了，搭进去的功夫和更漏，有没有人能站出来，连本带利，全赔给我？”

满堂死寂，无人敢接这茬。

他并未因此就成了能在这议事堂里横着走的大爷，但也绝不该因为这回刀快，就被当成了可以随便放血去养闲人的肥羊。门派招人不招、称量功过的准星平不平、刀客手底下的真章硬不硬，必须一码归一码地过堂。总堂既不能拿账本上长短不一的花红去瞎喊什么天下不公，更绝不准拿一句轻飘飘的“能者多劳”，就替每个赚了大钱的大户，免去账房先生那把铁算盘的无情查验。

当晚，罗启锋竟一反常态，大发善心，在自己的院里开了一局不收过路费的残局拆招会。当然，他也把话说得明白：若要拿这本棋谱去茶馆长期说书，自然还得另签一笔买断的契。

麦振铮听得不耐烦，嫌他绕弯子，干脆提着刀亲自上阵。两人没有多余的废话，直接用他们在阵前那段活死人般的视角，把那场苦等风来的熬煎，剖得一干二净，淋漓尽致。一个雏儿听得入了迷，怯生生地问：“那……那下回，我能不能只花钱买这口拆招的茶，不下阵去拼命？”

此言一出，罗启锋与麦振铮猛然对视一眼，都在对方眼中看到了一丝惊奇。这茶馆里，竟又多出了一条愿意真金白银砸钱的活路。

两个白天还在阵前杀得眼红的老冤家，此刻在沙盘前为了同一个死角的推演又杠上了，谁也不肯让半步。可争到酣处，麦振铮竟肯主动把白天没喂完的刀法补齐，罗启锋也坦然指出自己变招中的滞涩。能在这盘血淋淋的江湖里，撞上一个能死死咬住自己、逼出自己所有本事的对手，原来竟能是这般惺惺相惜。罗启锋咧嘴一笑，把半边沙盘让了出来，豪气干云。

就在同一个更漏里，东瀚镖局一桩十人份的短契探雷差事也走完了账。

两千四百两的总花红池，清清楚楚。十个活下来的探子，每人先按规矩保底领走八十两的汤药费，这是死契上的仁义。剩下那一千六百两，则全按照各自点破的死穴多寡、递上阵图的精细度和危急关头续命的功劳，来分这块肥肉。生死簿上，十个名额都画了押，白银也真金白银地落了袋。直到此时，才有人猛然从张榜的案卷里，瞧出了两段简直像从一个模子里刻出来的判词。

第一个闻着血腥味的是陈绍武。他端起算盘，指节在算珠上敲得发白，照着总堂的门规重盘了一遍，发现自己应得的花红，不多不少，生生少了二十两。他原只想去账房讨个公道，问问斤两，却在翻阅黑榜时，眼尖地揪出另外两份隐去了名号的案卷，竟死死咬在同一处偏僻的死胡同雷区上，连后来用墨笔涂黑改掉的破绽都一模一样。

他没急着点名道姓地抓贼，只在次日的堂会上，冷笑着问了一句：“同一处破阵的刀法，是不是被账房先生昧着良心，记了双份功劳？”

陈驰提着刀，顺着最初的案卷一路查到了一个叫魏泽安的名字，以及另一个十分生分的名头。两块记录功劳的玉简、两段入门时留下的虚影、甚至是两块挂在腰间的铁牌，都不一样。可当他去钱庄兑出银子的画押记录，和玉简过手时留下的暗号，所有的线索，都如百川归海，死死指着魏泽安一个人！

管着第一道验明正身关卡的执事，冯至成，当年曾和魏泽安在同一个脚行里讨过饭。他明明知晓这两份投名状都出自同一把刀，竟硬生生把一次破阵的买卖，劈成了两半，盖了两遍戳。东瀚镖局给拉客中间人的赏银，是验明一个探子给三十两，在这两人的飞鸽传书里，还赤裸裸地留着事成之后，坐地分那六十两银子的脏账。

刑堂之上，灯火冰冷。魏泽安梗着脖子，嘶声嚷嚷着自己是连着错过了两次搏命的档口，不过是把老天欠他的买路钱讨回来。冯至成则哭丧着脸，一把鼻涕一把泪，说都是东瀚逼着他凑足十个名额，他自己也指望着那六十两银子活命。

主审座上，蒋克己死死盯着自己亲手画押颁布的那条“按人头给赏”的门规，那条被钻了空子的规矩，但他脸上没有半分动容，更没让这两句苦水，成了可以法外开恩的免死金牌。苦衷，只证明了他们为何敢吃下这熊心豹子胆去踩红线，绝不可能靠耍几句嘴皮子，就把一具肉身凭空化出两具能过堂领赏的真人。

发出去的十份真金白银，没法靠拍一下惊堂木就一键追回。顺着这条黑道走的新死契，即刻被死死锁死，但别处验明无误的探子，依旧照常发饷，分毫不差。和东瀚那点赏银毫无牵连的铁面判官接手了卷宗。魏泽安和冯至成，各自领到了一份罗列着铁证、门规和准许喊冤期限的问剑帖。休书上也死死钉着招兵时就摆在明面上的下场：若是最终定死了这招“一将化两身”的偷天换日之罪，只断他此后两轮同类悬赏的花红；那些不掏钱的练兵营和别处山头的差事，照样按着各自的规矩量人。

而陈绍武少掉的那二十两和其他人的亏空，全被记作“待平之冤”，入了另一本账。总堂绝不会为了火速掐灭丑闻，就不由分说地随便从哪个冤大头兜里硬抠银子来填这个坑。

冯至成被一把撸掉了这案子的查验大权，东瀚镖局也被喝令立刻掐断了那条“按人头数发赏银”的毒脉。进门的拜帖、验明正身的关卡和按手印画押的判词，从此必须拆给三个人管，层层设防，步步留疤。凡沾着香火情的，过堂前就得自报家门，主动避嫌。重新翻案的卷宗被随意打散，丢给了另一拨素不相识的“瞎子判官”去审。查出有同门之谊，只是提审的由头，绝不能因此就把冯至成经手的所有探子全当成贼党来砍；但他近期摸过的所有生死状，每一笔，都得扒开底裤，重新过堂。

江湖上新开的财路必须实打实地存在，绝不能任由参透了机关的人，使出分身法去占尽所有的坑位。可若是门规只死死盯着两份投名状的笔迹像不像，却不敢去深究，为何守门的判官会心甘情愿地放两具分身过堂，不敢去扒下他那条穷得叮当响的底裤；那么下一回偷梁换柱的烂戏，照样会顺着生了锈的门轴旁，大摇大摆地绕过去。

夜色深沉，三更的梆子声远远传来。麦振铮踩着更漏的时辰，冷着脸收刀入鞘。罗启锋没有拿今晚盆满钵满的赏钱去蛊惑他多卖一会儿命。仓房的防务已经交给了下一班提着刀的更夫，他的买卖，早已两清。

这漫长的残夜，绝不会因为他今天打赢了一场硬仗，就强行变成总堂死契上，属于他的所有物。
