# 第1章：春风试剑

二月早春，风是冷的，像一柄淬过冰的软剑，无孔不入地刺着人的骨缝。宋振峰却浑然不觉，他掌中那份正月双桥阵的盈亏底单，反倒被他攥得微微发烫。他大步流星，袍袖带风，一脚踏碎了刑堂门槛上凝结的薄霜。

刑堂里，黑胡桃木的长案如一口停尸的巨棺，森然静置。案上，两本账册摊开，像两具被剖开的胸膛，脏腑毕现。

左边是凌拓钱庄的局。砸下五千两银子，如泥牛入海，只在同一段过堂的时辰里，搅起了四千四百两的毛利。刨去散给外围眼线的暗花，账面上一个冰冷的窟窿——净亏六百两。

右边是极轴钱庄的局。七千两的血本放出去，如同一招凶险的弃子，却盘活了全局。收官之时，铁算盘敲出的进项是七千六百两，净赚六百两。

两家都已刨净了过路抽成，两批兵器的成色、制式也都在伯仲之间，黑市挂牌价稳在二百六十两上下，连包退包换的死契条款都几乎是一个模子刻出来的。宋振峰的目光如鹰隼，死死盯着那两个刺眼的“六百两”。一进一出，高下立判。至于更深处的图纸差异、成交底价、善后汤药费和别处山头的暗花差别，账房还得另开一局，做更精妙的复盘。但此刻，这组死数，就像棋盘上两块无法做活的孤棋，明白无误地宣告了他的败局。

凌拓的牌子，在江湖刀客堆里挂了几十年，已经老了。熟面孔认得这块腰牌，却未必肯再为这份情面掏出真金白银。极轴那一仗，打得敞亮。他们把自家兵器的窍门，在擂台上喊得震天响，挑出来的花样也更刁钻，更对新一代刀客的胃口。宋振峰悟了，在这香堂里，江湖名望如同陈年的香火，看似烟雾缭绕，实则一钱不值。你砸下重金，也换不来一张永葆富贵的免死金牌。

他没有掀岑绍庭的桌子，更没去逼他吐出兜里的过路费。江湖有江湖的规矩，香堂按时辰打完了擂，出过力的刀客都拿走了应得的花红。自家兵器卖不上价，只能怪自己这个掌柜的眼光，还停留在昨日的江湖。那是一步臭棋，一步落了后手的死棋。

他咽下这口夹着冰渣的恶气，心中却已在推演另一局棋。换个山头，另起炉灶，或许能撞上一拨缺刀的生客。他必须跳出这盘被对手占尽先机的旧棋局。

他将那张已被体温焐热的残局图卷起，在新呈上的阵图前默然伫立，渊渟岳峙，气息却在胸中翻涌。上一局，十九路盘上那些闭着眼都能下对的先手定式，换了个时辰，换了个对手，就成了引颈就戮的死穴。宋振峰此刻终于肯挪开身子，让出自己盘踞多年的那个“天元”之位，用一种彻骨的冷静，重新审视天下刀客究竟从哪条道上来，又要往哪条道上去。

恰在此时，方婉音与陆宏远合递上来的那份“两岸回声”拜帖，如同一记精妙的“点”，恰好点在了他气脉的虚处。

拜帖的羊皮卷上，海岬战区那条内河被墨线劈开，两岸如同十九路棋盘上的两个修罗场，遥遥对峙，杀气腾生。冬水暴涨，旧桥的石脊断了，撑不住辎重车马。东岸的废墟里，木石堆积如山，却无人问津；西岸的伤兵营，百里加急的军报上字字泣血——再无火种，这个冬天就要冻死整营的弟兄。

他们向香堂递上的是一份连环生死状，要包下足足三个连轴转的时辰。第一时辰，遣死士摸清河床暗流，探出偷渡路径；第二时辰，两岸合力，用人命将救命的木石运过天堑；第三时辰，全身而退，片甲不留。这局棋的凶险之处在于，它不是各自为战，而是接力。绝不会每局开场，老天爷都慈悲地把断桥变回原样。第二场的死局，必须死死踩在第一场留下的残兵、断刃和满地狼藉上，接着往下走。

方婉音的手指纤细，指甲染着丹蔻，此刻却用一支朱笔，沿着羊皮卷上的河道，死死圈出那三个搏命的时辰。她的声音清冷如玉石相击：“两岸隔水相望，如同一局棋的左右两块孤棋，不想被屠龙，就必须联络。这场买卖，要做就要做成接力护送镖银的局。每一程活下来的弟兄，都必须把剩下的人头和镖箱，完完整整地交到下一拨人手里。谁要是只顾自家这一段杀得威风八面，到了接头的渡口却把一个烂摊子扔下，拍拍屁股走人，那对岸的弟兄，就是给他陪葬的。”

她顿了顿，目光扫过堂上众人：“拔刀见血之后，阵前的斩首军报，和点过头才能放出去的营帐私语，在香堂外，必须各占半边榜，泾渭分明。”她一字一顿，掷地有声，“有人是真正在大河东岸提着脑袋熬过日子的，有人不过是在皮影戏的河谷里充当了一夜的死士。这两种刀口舔血，必须标清出处，绝不准搅进同一碗血酒里，冒充生死弟兄。拿着兵符的将头，按军法称量首级；唱曲的戏班子，按签下的契约拿打赏。战场上的军功，绝不靠谁的故事讲得更凄惨，就能多记上一等。”

陆文渊重写的借条也递了上来，纸上还带着新鲜的墨香。两万两雪花银，每一个字都透着谨慎。这笔钱，被一条朱砂线死死圈在这趟有头有尾的镖路里，只为护住已经砸下去的血本。那道原本想在往后几十趟镖里一直独吞花红的霸王条款，被一笔浓墨抹去，如同一道狰狞的伤疤。条款旁有批注：放贷的钱庄，休想借此霸占琴谱的地契、在香堂安插自己的判官，或是直接夺走刀阵的兵符。刀尖上的风险和完事后的红利，每一笔都掰扯得清清楚楚，如同棋盘上的官子，半目都不能让。直到如此，两位掌门人才肯在那张生死契上，按下鲜红的血手印。

账房将这笔进项记作“搏命的本钱”。宋振峰知道这四个字的分量。它能让榜上挂牌的磨刀差事立刻转起来，但真正能让死士们填进去的坑位，还得等总库里拨下现银才能敲定。绝不准画一张“连开三场，必定满座”的大饼，去提前支取那些八字还没一撇的带血花红。这是在拿弟兄们的命，去填自己的欲壑。

陆宏远的手指粗壮，重重戳在羊皮阵图上，仿佛要将那纸面戳穿：“第一场死局一开，两岸的坐堂大爷，还得各自看好自家地盘上的命案。过江的镖，是两头通气，但调度之权，必须要有总堂的火签令箭。我南离的令旗一旦过了河，休想顺手去使唤风雷招来的刀客。”他抬眼看向方婉音，目光锐利，“同样，方掌门也绝不会因为搭了个戏台子，就一步登天，拿到了我南离阵前的虎符。”

他们挑出了能扛起这副千斤重担的总镖头，将兵符的令限、交接的死口、以及万一全军覆没的善后条款，一字一字写得如同刀劈斧凿。若是哪一边扛不住先溃了阵，对岸休想在唱完自家那出戏后，就擦干净血迹装作没事人；但这结盟的铁券，也绝不等于谁就得掏空自家家底，去填对方留下的无底债坑。这是联手，不是吞并。

议事堂的判官许嘉榕，也递上了司号和收声的拜帖。她半个字没拿自己的身份当垫脚石，公事公办。她甚至主动声明，只要撞上了自己经手的局，香堂议事时她照样会避席。她手里这把刀够不够快，全凭阵眼上的规矩去评判，不沾半分人情。

有个衣着考究的看客，在悬赏榜前盯了半天，最终还是摇了摇头，没肯掏钱，只留下一句：“等道上的朋友传回风声再说。”

方婉音亲自将人送出大门，姿态坦荡，没有在背后阴恻恻地敲着更漏催命。

刑堂里，算盘声再度噼里啪啦地响起，像冬日里爆裂的冻竹。众人围着那张阵图，死死算计着那座残桥还能扛住多少步兵、箭筒里还剩下多少羽箭，以及这开台唱戏的本钱，究竟够不够烧到曲终人散。

春寒依然料峭。十九路盘上，这条新劈出的气口虽然有了活气，却远还没到能被吹嘘成“谁走都能发大财”的阳关坦途。

它只是一个机会，一个或许能让宋振峰落子争先的机会。
