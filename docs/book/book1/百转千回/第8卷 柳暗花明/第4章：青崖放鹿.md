# 第4章：青崖放鹿

第三局死斗的硝烟尚未散尽，数据洪流的轰鸣仍在耳膜深处回响。许嘉榕的个人终端上，一枚加密信标无声地闪烁，是“深水”资本信托递来的一张暗花帖——一份预付三万生态奉献激励金的独家创作协议。

她指尖轻触，全息光幕在冷寂的机房中铺开，幽蓝的字迹像冰河下的裂纹。最先映入眼帘的，是那笔足以让她在未来三年内不必为任何账单皱眉的巨款。但紧接着，她的目光就被那些盘根错节的条款攫住，如同陷入泥潭的孤鹿。“独占性授权”、“三年期绑定”、“全平台连轴发布”，每一个词都像锻造精良的镣铐，闪着冰冷的金属光泽。协议的附录里，是一张几乎无穷无尽的清单，不仅将她过去所有作品的版权一网打尽，甚至用一行小字预定了她“未来创作的、无论何种形式的、尚未存在的”所有智力成果。

她原以为，这只是拿几次攻防复盘的私密日志，换一笔体面的润笔费。然而，当她伴着服务器风扇单调的交响，将这份长达三十页的协议从头看到尾，彻骨的寒意从尾椎一路窜上天灵盖。这份所谓的“死契”，竟是要用三万块钱，买断她此后人生所有思想的火花，将她还未踏上的道路，用代码与法条彻底锁死。

信托的管理人倒也未在字里行间涂满蜜糖与毒药，在随后的视频通讯里，他语调平稳，逻辑清晰：他们愿意投入庞大的资源为她造势，用资本的洪流冲刷出一条通往顶峰的星光大道，替她扛下所有市场反馈的冷暖与波动。他们唯一的要求，是她成为一台永不枯竭的创意引擎，源源不断地为他们的平台供上新鲜的“琴谱”。

这笔交易从纯粹的商业逻辑上看，并无不妥。她确实能靠着这笔钱，安稳地度过下一个技术寒冬。问题不在于资本是否天生嗜血，而在于那三万激励金，究竟值不值得她将自己整个棋盘的星位与大场，一次性地拱手相让，从此沦为别人棋盘上的一枚棋子。

方婉音坐在她对面，手指在光幕上逐行划过，像个经验丰富的排雷手，点破协议中每一个伪装成机遇的陷阱。“看这里，‘一票否决权注销’，这意味着在合作期间，你对作品的最终解释权理论上存在，但实际上可以被他们以‘商业利益最大化’为由无限期搁置。”她顿了顿，端起冷掉的咖啡，“风雷核心当然希望你留下，我们都是局内人，我不会假扮什么悲天悯人、劝你舍身取义的青天大老爷。我只能告诉你，这步棋一旦落下，就是生死劫，你得想清楚，这个劫材，你打不打得起。”

许嘉榕切断了通讯，转而向社区的“游离判官”——一位以精通治理律法而闻名的独立仲裁者——提交了匿名咨询。得到的回复冰冷如铁：她可以尝试反向邀约，咬死只出售存量作品的有限授权，所有新增创作必须另立新约，旧的贡献记录与新的价值评估绝不能被一纸协议模糊覆盖；若要中途解约，违约金的计算方式、赔付上限与支付时限，必须白纸黑字，一分一毫地提前厘定。

“深水”信托自然不愿接受如此苛刻的反向约束，他们砸下三万块，买的就是一个可预期的、被驯服的未来，而不是一个随时可能脱缰的合作者。两边的算盘珠子在冰冷的空气中拨得噼啪作响，却始终无法在同一个点上咬合。最终，许嘉榕在倒计时167:59:59的签约时限前，手起键落，毅然决然地点击了“拒绝”。

没有一丝迟疑。她死死盯着那片空白的、等待她挥洒未来的创作面板。眼前这三万激励金圈出的实地确实厚壮得诱人，可若是为了这一口肥肉，便彻底封死了自己这辈子在十九路棋盘上的所有变化，往后每想在天元落子，都得先看一眼金主的脸色，那她宁可不要这片实地。她冷着脸，将那份协议的副本拖进了回收站。

没画押，她的账户里自然不会凭空多出三万块。原本列入采购清单的几件高性能计算设备——那些能让她下一次出手时更加挥洒自如的“趁手神兵”——只得被无奈划去。新构思的算法模型，也不得不砍掉最耗算力的几个复杂分支，硬生生削减到现有硬件能勉强支撑的规模。在这片由代码和资本构筑的江湖里，想要“来去自由”这四个字所代表的奢侈气口，就必须自己吞下两手空空的代价。这亏空，绝不是靠吼两句“不为五斗米折腰”的豪言壮语就能填平的。

“两岸回声”第三局的贡献结算很快下来了。核心治理委员会验过了她在战场遮断、信源分析和提交复盘报告的全程记录，在那总额两万一千元的差异池中，精准地划给她一千八百元。这笔钱，一文不少，是她用不眠不休的鏖战换来的。拒签“深水”信托的独占协议，半点没妨碍她拿走自己该得的赏钱；那笔没落袋的横财，也休想将她这碗用命换来的断头饭，当成谈判桌上的抵押品。

战区节点那边也传来新的邀约。一位负责核心网络维护的指挥官，希望整体打包她下一季度的全部夜间值守时段，理由是“原有团队磨合良好，知根知底，能最大程度确保关键链路稳定”。她心里确实偏爱这群一同扛过1.2Tbps峰值流量冲击的战友，但也深知，一旦接下这道“军令”，自己未来不知多少个可以用来学习新架构的夜晚，和赚取额外贡献值的“野路子”，都得悉数奉上。

老战友递来的酒碗，盛满了并肩作战的情谊，确实让她舍不得推开。但最终，她依旧没有把未来三个月的夜色，全部押在这一张赌桌上。她只应下了其中两个关键业务时段的邀约，绝不签那张等同于随时能用“系统安危”这顶大帽子压人的随叫随到契。

青崖之外，还有她自己想闯的生路。她大可以提着自己的刀，去棋盘上任何一个她认为有先手之利的大场落子。同生共死过的弟兄若是还想并肩作战，那就等下一封写明具体时间、目标和酬劳的战帖递到门上时，咱们江湖再见。

她推掉的那些值守时段，自会有其他渴望证明自己的节点贡献者，或是社区里那些如同铁人桩一般稳定可靠的自动化脚本去补上。她在贡献墙上用战功积攒下的信誉，绝不会因为少值守一次就一笔勾销；但下一次突发事件带来的超额红利，自然也可能落入别人的口袋。主动退出，与触犯规则被罚，是截然不同的两件事。她绝不会霸道地要求战区永远为她空着那个位置，像供奉牌位一样，等她哪天兴致来了再回去坐。

社区里有人鼓噪，询问核心治理层是不是要从此彻底封杀预付激励和项目合股的模式。陈驰的回应，是在下一次全体会议上，将陆文渊那份堪称典范的合作协议投影在所有人的光幕上，条款清晰，权责对等。他那张素来没什么表情的脸上，此刻更是冷若冰霜：

“找谁融资、签署多大体量的协议、合作周期多长、利润如何分配、风险如何共担，完全由参与方自行依据社区治理基本法进行谈判。但是，”他加重了语气，“没有经过严格审计和压力测试的虚假承诺，绝不允许被包装成金光闪闪的‘保底收益’去蛊惑人心。江湖上出过‘仙人跳’的骗局，但这绝不是我们一刀切，砍死所有正常融资渠道的理由。”

许嘉榕听完这番话，心中一块石头落地，但依旧没有半分后悔。信托的生意只要合乎法规，自然可以开张；但这并不代表，他们递过来的那副手铐脚镣，就一定合她的手腕。

傍晚时分，她沿着数据中心冷却水循环系统的管道散步，冰冷的金属外壳传来低沉的震动。一个在社区小有名气的观察者认出了她，凑上来问她什么时候再发布新的分析报告。她险些脱口而出一句“很快”，话到嘴边，却被理智咽了回去，只是淡淡地答道：“还没定，得先看看，胸中还有没有真正值得一吐的块垒。”

那位观察者脸上掠过一丝不易察agis的失望，却也知趣地拱手告辞。天底下没有哪个刀客，需要为了满足别人看热闹的心思，就必须时刻剖开自己的胸膛，沥出心头热血。

回到自己的居所，她将那份已经失效的独占协议、刚刚签订的有限值守合同，以及尚未结清的云服务账单，分门别类，用军事级别的加密算法封存进一个独立的存储区。战阵上的冲杀尚有鸣金收兵的时刻，一个活生生的人，更不该因为曾经拼过几次命，就在自己的身份标识上，永远挂着“任凭差遣”的死签。

她熄灭了工作台的灯，给自己煮了一碗清淡的麦片。新录制的一段音频样本在播放器里循环，那是她从一段庞大的数据流中截取出的、一段极其细微却规律完美的白噪音，像是深海的水流声。整段音频短得可怜，只有几秒钟，她半句多余的解释和渲染都没有添加。

宁可残局留白，也绝不为了去凑够“深水”信托所要求的那种工业化量产的时长，强行塞进一段没有灵魂的梦话。
