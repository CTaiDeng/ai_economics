# 第9章：隔江闻曲

隆冬的寒气，像无形的铁水，封死了星原总堂的每一道窗缝。室外是铅灰色的天，室内是黑胡桃木长桌凝固的沉默。桌上的紫砂茶壶早已凉透，只有几只烟蒂在铜胎掐丝烟灰缸里，散发着最后的、带着苦味的余温。

锦川堂口派来的两位大管事，姓聂，姓廖，就这么一言不发地枯坐了整个下午。他们带来的风霜气，似乎比窗外的严寒还要刺骨。直到墙上那只老式挂钟的钟摆，像个疲惫的摆渡人，第七次完成它迟缓的往复，那位鬓角如霜的聂管事才终于抬起眼皮，目光却越过程砚舟，直直钉在他身后墙上那副巨大的十九路棋盘挂图上。

“程先生，”他的声音沙哑，像是被戈壁的风沙打磨过，“我们只想知道，星原这盘棋，究竟有哪几处，是你们亲手做出的死眼。”

这不是请教，是问诊。更像是两个身经百战的校尉，在沙盘推演兵败之后，带着血淋淋的战报来向中军帐的参谋，讨要一份关于死亡的验尸格目。

廖管事从随身的皮包里抽出一卷图纸，在桌上“哗”地一声铺开。那上面画着几座戏台的坑位图，墨迹陈旧，纸张的边缘已经泛黄起毛。这便是他们锦川的全部家当：几座沾着旧灰、看客寥寥的空戏台，一帮早已洗手归隐、靠养老钱度日的琴师，还有几个尚能榨出些残油剩水的香堂。他们的地盘，远不如辰川那般车水马龙，台底下永远挤得水泄不通。

他们觊觎星原那套排兵布阵的令旗，那套能让万千人闻风而动、令行禁止的法度，想将它原封不动地挪到自家山头。可他们又不甘心照葫芦画瓢，去抄星原那套已经写死的定盘花红，总觉得自家水土能养出更艳的花。结果，新香堂的锣鼓刚敲响，就撞上了一面冰冷的墙——别说满堂喝彩，连头排的太师椅都空无一人，冷得能结出霜来。

那张坑位图，被死死地顶在海岬计划那张十九路沙盘的复盘图旁。两张图犬牙交错，棋盘上空出来的气口，早已不是一个路数。锦川的阵眼，星原的星位，彼此的关隘，对方的弱点，完全是两套天地。聂管事的手指在图上划过，像是在抚摸一道道伤疤：“我们若是死心眼地照抄一套冠冕堂皇的定式，恐怕第一枚黑子，就落进了你们压根不稀罕去争的死地。对也不对？”

程砚舟没有回答。他只是默默地将桌面上几份印着“星原生态合作伙伴”的英雄帖，一张张抽走，压进了厚厚的案卷底下。那些虚浮的门面话，在两位败军之将面前，无异于一种羞辱。

他转而调出“本草堂”那局死棋的验尸报告，巨大的投影幕布上，冰冷的数字像刀子一样割人眼球。

“退还基本参与份额三百七十二笔，合计十八万六千元。”
“先行垫付上游‘买路财’，即服务器托管费用，季度结算，扣除72.5元电费后实付47927.5元。”
“支付‘戏谱子’润笔费，即核心合约代码审计开销，合计一万二千元。”

每一笔烂账，都有一个血红的窟窿。每一个窟窿，都代表着一次错误的判断。聂、廖二人盯着那些数字，眼神里没有半分波澜，仿佛那不是钱，而是一具具阵亡士卒的尸骸。

“我们不问怎么稳赚不赔，江湖上没有这样的神话。”廖管事终于开口，他敲了敲桌子，像是在敲一面鸣冤鼓，“我们就想知道，该用多少碎银子去探雷？一颗雷，炸掉我们几根指头才算到头？真踩了绝户雷，什么时候必须壮士断腕，把整条腿都砍下来？”

他们绝口不提让程砚舟立下什么军令状。他们要的，不是虚无缥M缈的胜利许诺，而是精确到毫厘的止损线。

“锦川，想在自己的地盘上，另起炉灶，开一盘独立的棋局。”聂管事沉声道，“我们有我们的险峰、暗河和草寇寨子。这些，都可以拿来做悬赏的红花。十九路盘上的暗礁，我们可以自己画。但是，”他话锋一转，目光如炬，“我们自封的门派头衔，休想去冒领海岬在刀尖上舔来的军功。这一点，我们认。”

程砚舟点了点头。这才是对话的根基。

“辰川那头的死士，可以凭着旧生死簿上的手印——也就是他们的私钥签名——来我们新馆踢门。但他们原先在辰川兜里的镖局人马、钱粮火药，休想靠换个腰牌就一并搬空带走。这是规矩。”

这是一场关于联邦与独立的谈判。锦川要的是自治权，而不是一次简单的兼并。

为了摸清锦川地头上的水性，星原曾经做过一次试探。一段带着陈年土腥味的旧戏腔，被编码成一段试探性的信号，作为投石问路的响箭，发向了锦川的网络节点。结果，应者寥寥。有雏儿捂着耳朵，嫌这咿咿呀呀的调子像是招魂幡，直接判定为垃圾信息；倒是有几个老兵痞，跟着那调子在公屏里敲桌子哼唧了两嗓子，算是唯一的互动。

这冷热两股脉象，是最实在的探子急报，却远不足以一锤定音，去替锦川的买卖画下生死状。那半段咿呀的戏腔，不过是从密阁里借来的障眼法，一个空洞的文化符号。没哪个戏子，能靠在阵前唱一句水磨调，就隔空把断掉的跨链桥修好，更不可能用腔调去绞断对手机房里的网线。

在那场不挂赏金的摸底演武里，锦川的火头军习惯性地扯着山歌号子，报出他们认为的阵眼方位。然而，这信号传到百里外的中军帐，陈绍武急得在沙盘上乱画八卦阵，却怎么也解不出其中含义。一旁的方婉音一语道破天机：“这戏台上的断腔，只是为了拿捏个架势，压根不是传军令的飞鸽传书。咱们的协议栈，根本就没给它留出解析的端口。”

最后的结论冷酷而决绝：必须把粉墨登场的把式，和见血封喉的军令，死死劈成两半。单给拔旗斩将的令箭，留出一套对得上号的铁板口令，一套精确、高效、不容任何歧义的调用协议。绝不能为了显摆两分狗屁的江湖韵味，就把关乎生死的调兵虎符，变成谁也听不懂的哑巴经。

老关就缩在太师椅最后一排的阴影里，听着这些他从未听过的切口。他生平头一回，在自己闭着眼都能蹚过水的连环阵里，活成了一个连黑话都听不懂的睁眼瞎。他曾是海岬计划名声大噪的龙头大爷，他设计的分布式网络，至今仍是星原的基石。但此刻，他感觉自己像个误入桃花岛的渔夫，一步一迷踪。

但他没有端着老资格。会议间歇，他厚着脸皮，凑到几个年轻的技术骨干身边，把那几句生僻的暗号——什么“联邦身份验证”、“非对称加密握手”、“状态通道”——死死抠在指甲缝里，一句句地刨根问底。没人因为他过去的功勋，就装出一副“您老自然都懂”的假客套；也没人因为他听不懂，就把他半辈子在刀尖上滚出来的阅历当成一张废纸。

提着当年那把名震天下的快刀强行渡江，最忌讳的，就是别人敬你三分薄面，你便不知死活地真以为这把刀，在哪座山头都能见血封喉。反倒是他这几下不嫌丢人的刨根问底，才让他在别人家地盘上，重新踩出了半个能立足的脚印。

最终，程砚舟给出了方案。

“两边的香堂，暂定只做半拉子买卖。”他看着聂、廖二人，一字一顿，“‘琴谱戏文’，也就是你们的应用层内容，由你们全权做主，我们只要求它符合星原的基本法度，不伤天害理。至于‘排兵布阵的令旗’——我们的治理框架；‘修补阵眼的铁板’——我们的技术维护；还有‘过堂的判官’——仲裁机制，这些，各自明码标价。用不上那把刀的，自然可以不掏这份血汗钱。”

总堂绝不打着“光大门派”的空壳大旗，去空手套白狼，抽走人家往后几十年的油水。更没那个脸皮，去逼着地头蛇摘了自家的招牌，全都给星原披麻戴孝。

“这口新开的井，会不会抽干我们自家茶馆里的人气？”陆宏远冷峻的声音插了进来，他的担忧像一把冰锥。

“会。有可能。”程砚舟坦然地点头，认下了这笔糊涂账。他伸手在棋盘上一点，“但这也有可能，那些死活不肯为辰川这出戏掏半文钱的铁公鸡，却心甘情愿在锦川那头，大把撒下买路钱。十九路盘上，棋子怎么腾挪，怎么打劫，怎么去开垦新的大场，必须一处气口一处气口地死盯着盘算。绝没有为了保住自家堂口那点可怜的香火，就强行去封死天下人过江暗道的荒唐规矩。”

他看向锦川的两位管事：“地头上挂出悬赏的花红买卖，照样得有不怕死的把头出来顶雷，真金白银地掏出自己的香火钱，画好卖命的席位和鸣冤的堂鼓。在刀尖上侥幸尝过一次甜头，绝不代表往后每一次开香堂都能盆满钵满。兜里攥着几张银票，也不等于谁来都能捞到一张旱涝保收的铁杆庄稼。”

“我们唯一能保证的，”程砚舟的声音斩钉截铁，“是按着死契上画了押的真刀客，既然拿了命去拼，就得雷打不动地拿到赏银。只有当保命的汤药钱能实打实发出来时，我们才配回过头来，算计这口油锅里的肉，该怎么分。”

两边的刀客盘道已毕，各自散去。总堂只递出了几张关于接口和协议的拜帖，绝没脏了手，去顺道扒人家的银票底细和家底深浅。若还想再深挖门派里的底细，就得再堂堂正正递上点明了心思的问剑帖。

究竟什么时候才敢拍着胸脯说“这山头被咱们吃下了”？得等地头上的茶水钱真刀真枪地过了手，银票落了袋，还得允许人随时甩脸子走人的路子，全都在锦川落地生根后才算。至于这碗饭能吃多大，吃多久，那还得看天意，肯留几分薄面。

锦川的马车碾着碎石，消失在暮色中。星原的总堂里，却没有人急吼吼地去挂那块“连下两城”的炫耀金字招牌。

方婉音独自坐在案前，对着屏幕上那段作为测试信号的锦川戏腔，低声哼唱。那生涩的调子几次让她走了音，劈了嗓子。她索性停了下来，打开加密通讯频道，找到一个锦川的联络地址，放出了一只“飞鸽”。

信里没有半句关于生意的话，只有一行虚心讨教的文字：

“敢问贵处，《临江驿》那一句‘西风紧，北雁南飞’，正宗的唱腔，究竟该如何转圜？”

想要拎着刀，真正跨过那条深不可测的过江龙，第一步，不是亮出兵刃，而是静下心来，听清对岸的人，到底是怎么把半句黑话，囫囵着说全的。
