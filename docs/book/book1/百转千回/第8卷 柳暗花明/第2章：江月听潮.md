# 第2章：江月听潮

第一场“两岸回声”的铜锣在霜寒中敲响时，十九路棋盘的星位上，早已没有一条可容车马的通衢大道。

西岸渡口，两根被江水冲刷得惨白的桥桩，如巨兽的枯骨直指阴沉天穹。东岸那条泥泞的官道，则被先行探路的铁骑踏出纵横交错的沟壑，凝固的辙痕里，是泥与血的暗红。中军大帐之内，烛火摇曳，将墙上那幅原定为雷霆一击、一波强攻的阵图映照得明暗不定。探子们用半条性命换来的江水深浅回报，工兵们在沙盘上用枯枝死死盘算着摸黑渡河的每一寸生门，最终，那张完美的阵图被一道道朱笔划掉大半，只剩下一副支离破碎的残局。

想在这片死地之上，重新落子，盘活一局连环棋，最先要扛住的，便是这令人窒息的开局。

冰冷的铁库里，极轴钱庄的一万八千两现银与凌拓送来的一万四千两搏命钱，已与那笔两万两的本金一并落锁，账目分明，封条火漆。落进锁眼的银票，是厚实的底气，是重伤弟兄的汤药费，是前线死士的保命粮，也是事成之后花红池里叮当作响的犒赏。白纸黑字的契约上写得清楚：若是后两场死斗因营啸溃散或触了死契的忌讳中途散伙，便依此账目点收结算。这盘棋，绝不准按着刀客的脑袋，逼他们为还未到手的横财去填无底洞。

第一拨斥候如水鬼般顺着冰冷的河道摸索出去。许嘉榕立于中军帐，身前长案上铺着堪舆图，她左手攥着代表东岸的红旗，右手攥着代表西岸的蓝旗，两岸的军报雪片般飞来，在她这里汇总成整盘棋的生死脉络。

“禀报总堂！”一名东岸探子踉跄奔入，声音嘶哑，“卯时三刻，‘犬牙’位东南三里，发现一处浅滩，水深及腰，可涉水而过！”

话音未落，西岸的暗哨传回的信鸽扑棱着落下，解下的蜡丸里是截然不同的凶信：“‘犬牙’位是断堤形成的夺命回漩，水流湍急，人马俱焚！”

许嘉榕的目光在两份军报上缓缓移动，帐内死一般寂静。两边的刺客都没有谎报军情。她心如明镜，不过是此刻的水势，在这十九路盘的不同阵眼上，显露出了截然不同的杀机。站在东岸，看到的是求生的“气”；立足西岸，望见的却是吞噬一切的“劫”。

“传我将令，”她的声音清冷而决绝，不带一丝犹疑，“所有军报，必须死死钉住回报的时辰、精准的方位，以及预估看走眼的余地！绝不准再用一句轻飘飘的‘水能蹚’，去掩盖背后吞噬人命的杀机！”

她将两份沾着水汽甚至血迹的军报，一左一右，用两只沉重的铜镇纸死死压在桌上，没有急着去捣糨糊，更没想过去和稀泥。站在棋盘不同的死角，同一处气口也会显出截然不同的厚薄。她必须将两边探出的雷区原封不动地递进主帅的视野，才可能让帐中那位真正执棋的人，落下一手扭转乾坤的续命之棋。

战局在另一处角落陡然收紧。一名死士奉命摸进江岸一座废弃的旧泵房，意图掏出敌军埋设的暗线。那鬼地方空间逼仄，窄得只容得下四个名额。大门外的铁骑被犬牙交错的废墟死死卡住，无法策应；而摸进去的这四具肉身，也自然从大阵图的视野中暂时消失，如一枚弃子，躲过了敌方投石机覆盖式的轰击。东岸的主帅只知门口有敌方眼线死死盯着，却完全摸不透这四名深入腹地的弟兄，是不是已经捏住了他的死穴，还是早已化为冰冷的尸体。

“鸣金！让他们立刻撤出战阵！”统筹席上，一枚火漆封口的令箭被狠狠甩在沙盘中央，激起一片尘土。

许嘉榕双手稳稳接过令旗，却没有立刻传令。她先发出一道回执，用不容置喙的语气，死死咬定了这四名弟兄安全撤出所必需的救命时辰。“禀主帅，泵房内暗梯已断，工兵回报，需一炷香的功夫另劈生门，方可接应弟兄们逃生。”

上层主帅焦灼等待的那一炷香，绝不代表军令成了一纸空文；而陷在死局里的弟兄，也休想一直拿“我们正在拼命”当借口，切断与中军的联络。每一息的动静，都必须被看见。

对岸，一道狼烟猛然烧起，笔直地刺向铅灰色的天空。一队仇家的游骑兵，如嗅到血腥的饿狼，正高速逼近渡口。守备营阵中，麦振铮魁梧的身躯如铁塔般纹丝不动，他一把攥紧了腰间的兵符，冰冷的金属硌得他掌心生疼。他死死压住了己方阵地的视野气口，忍住了提刀出阵的嗜血冲动。

他的双眼如鹰，冷冷地盯着那队游骑兵在高速机动中露出的一个致命破绽——那是足以让他一击凿穿的软肋。他手里的剑柄被握得咯吱作响，指节已然发白，却硬是没有扑出去收割那唾手可得的首级。那口带血的花红确实诱人，可他死死咬着牙关，心头只有一个念头：泵房里的弟兄还没撤出来。他这把负责堵门的剑若是为贪功而冒进一寸，背后弟兄们用命开辟的撤退之道，就会被敌人当胸刺穿。这是弃子争先，他必须忍。

一炷香的时间仿佛一个世纪那么漫长。泵房的侧墙轰然破开，那支四人小队攥着一卷偷来的暗线军报，浑身浴血地杀了出。两名弟兄的箭筒已经射空，另一人胳膊上挂了彩，鲜血浸透了衣甲。这副残破的肉身，沿着生死簿上早已规划好的路线，趁着敌方火炮更换弹药的短暂断档，退回本阵。

探查营的弟兄们，终于用这条命悬一线的军报，将地图上那条真正能走的浅滩，用朱砂笔死死地标实了出来。

第一场生死状的时辰到了尽头。江上的断桥依然没能接上，但第二场搏命所需的暗渡口，下一次冲锋必须抢占的落脚点，总算是在一片血肉模糊中，拼出了一条生路。两边的人马在交接阵位时，都死死地将每一个细节交到接防弟兄的手里。他们清楚，今夜一拉黑幕，绝不能让这条用命铺出来的路，在黎明前就灰飞烟灭。

待所有带血的军报张榜通报完毕，榜单之侧，另一轴更长的画卷才徐徐展开。上面没有刀光剑影，只有真实的河东传来叮当作响的打铁声、河西那扇虚掩的雕花木窗背后模糊的人影，以及几位说书人各自愿意掏出的、关于这片土地的旧日迷踪。看客们可以循着线索自行探查，也可以只做个隔岸观火的闲人。这等消遣，算不上阵前斩首的军功，更休想把旁人刻骨的悲欢，强行征用成总堂免费派发的戏本。

江畔的茶馆里，几张售卖“神兵利器”的桌子旁，都有过客驻足。极轴钱庄的桌前，有掌柜模样的老者，正襟危坐，对每一位客商的诘难都一一对答，条理清晰，滴水不漏，颇有武当宗师的渊渟岳峙之风。而凌拓的场子则更为写意，任人拿起桌上的长剑随意挥舞几下，感受其分量与锋芒，满意与否，皆随君意。

歇脚喝茶，终究算不上按了手印的买主。神兵再怎么削铁如泥，也绝不可能替戏台上的评书，强行添上半分真假。

一位须发皆白的老爷子，颤巍巍地走近方婉音的案前，打听哪里有带解字和便宜点的小道，他想带着远在塞外的女儿隔空看这场大戏。先前的戏牌子，都默认是写给懂行的老主顾，这一下，直接暴露了棋盘外的疏漏。方婉音当即拍板，下一场的抄书费用，直接揉进过堂的老本里，她对着身旁的书记官冷声道：“绝不准拿什么机关术自动生成的东西去糊弄人，更不准临时黑下心来，向这些散客商贾收那笔不要脸的暗花。”

夜深人静，方婉音借着一盏孤灯翻看今日的账本。她发现，那些由文书们费尽心血撰写的长篇评书，描绘战局如何精妙，人物如何英勇，反倒被人无情地略过。反倒是那几句从前线传回的、真刀真枪接头的短促暗语——“犬牙位是死路！”“暗梯断了，需一炷香！”——却被后来的刀客们在传抄本上反复摩挲，圈点批注。

她忽然明白了。那些人听见的，不是地图上的一条死路。

而是那个生死关头，有人在拼了命地，等待另一头兄弟的回答。

陆宏远脚步轻快地凑了过来，脸上带着一丝兴奋：“婉音，你看今夜这风势，咱们是不是该趁热打铁，再加演几场？”

方婉音的手指，死死按在卷宗上一份还没过堂的批文上，那力道让指尖微微泛白。她抬起头，清冷的目光像深夜的江水，没有一丝波澜。“三场。说好了，就是三场。”她一字一顿，不容置喙，仿佛天山折梅手，收发自如，已将陆宏远那股浮躁的真气化于无形。“做完这三场死局，我们便收手。”

河畔的旧桩子旁，依旧留着总堂安插下的几根铁人桩，冰冷地矗立在风中。方婉音知道，下一次，当真刀真枪的活人再杀到这片修罗场时，他们只能认命，接手这段已经被前人打得千疮百孔的残局。

而这，便是他们留下的，唯一的遗产。
