# 第7章：曲终江上

“两岸回声”这局惨烈的生死劫，终于走到了刑堂复盘、铁账清算的时刻。

寒冬的冷气顺着会议室巨大的落地玻璃渗进来，凝成一层薄翳。窗外是钢筋水泥的丛林，天色灰败，像一块被反复擦拭过的旧铁。室内，黑胡桃木长桌的表面光可鉴人，倒映着天花板上冰冷的条形灯，也倒映着围坐的几张面无表情的脸。空气里弥漫着咖啡因和尼古丁的余味，烟灰缸里几根燃尽的烟蒂，像是沙盘上被拔掉的死棋。

那条用血肉蹚出来的暗渡口并未就此封死，它像一道横亘在服务器集群间的幽灵通路，随时等待着下一次的数据洪流。伤兵营——那个24小时待命的运维中心里，象征着警报状态的孤灯也依旧长明，只是颜色从刺目的猩红，调回了代表警戒的橙黄。

第二场死斗，用几乎全部预备队换来的那批救命辎重，大半都填进了维持生路的无底洞里；第三场惨烈的拼杀，虽成功撤回了残余的伤兵和核心资料，可折损在阵前的那两件重器——一台核心路由和一套数据库阵列，像两道无法磨灭的刀疤，被死死钉在了总堂的亏空账本上，猩红的负数触目惊心。

邱庭舟将一份加密的USB盘和一把物理秘钥轻轻推过桌面，交出了修缮残局的兵符。他眼窝深陷，两天的鏖战仿佛抽走了他半生精力。他对面的许嘉榕，也将一张印着最高权限的门禁卡和口令信封一并交割，那是她司号发令的令箭。这间会议室的阵眼，就此全盘移交给下一拨接下悬赏榜文的死士。三场带血的买卖既然已经过堂，账目分明，但江湖规矩从来不是一锤子买卖。没人会天真到以为，这座用命搭起来的破桥，就该免费让人白走一辈子；更休想让退下来的刀客，躺在那几排铁人桩似的服务器机柜功劳簿上，世世代代吃绝户。

方婉音端坐主位，神情渊渟岳峙，仿佛一位正在收官的国手。她面前的笔记本电脑屏幕上，是一份尚未最终签署的电子信托契约，一份画押之后再无更改的死契。那个将旧日迷踪悉数道出的“说书人”——“两岸回声”项目的发起方，只肯让参与的过客们留住那段曾一起熬过167小时59分59秒倒计时的交情，却不肯再拿自己的皮肉和声誉去卖门票。他以一票否决权强行注销了项目法人，勒令按着最初签订的路条，停掉后续所有的“说书戏码”。

然而，规矩就是规矩。已经唱完的那几出戏，仍需照着门规一文不少地打赏。绝不能借着项目终止，反咬一口，硬逼着那些签了短期合同的“刀客”们，把吞进肚里的卖命钱连本带利吐出来。

邱庭舟调出另一份文件，一叠还能在江湖上抛头露面的琴谱——经过脱敏处理的技术复盘报告。那些真正关乎生死存亡的攻防细节、那些沾着血的漏洞利用代码，必须按着保密协议的年限封进数字密阁。他绝不会允许任何人，当面满嘴江湖道义说“只作内部留档”，背地里却把别人的伤疤挂在公开的城墙上，当成炫耀的资本去卖钱。那段从完整卷宗里被抽走的核心战报，在公开文档里暂时留白，也绝不准任何人拿旁人泣血的回忆，像填鸭一样硬塞进更漏的空当里去凑数。

方婉音的目光冷冷地盯着屏幕上那段刺眼的留白，没有用任何花哨的辞藻去强行粉饰太平。琴谱里的绝响断处，活像棋局收官时，十九路棋盘上仍旧留下的那几个无法填上的死眼。并非每一个坑都非得填得严严实实，并非每一段故事都要有个圆满的结局。这里曾有刀客拔剑悲鸣过，往后的江湖，也该容得下她收刀入鞘后，选择沉默的权利。

投影仪的光束将最终的账目打在幕布上，冰冷的数字不带一丝感情。一个戴着金边眼镜的会计师，用不带波动的语调开始清算：

“经崇远信托审计，‘两岸回回声’项目，由主要投资方实缴资金，三万二千元整。”
“经第三方平台结算，扣除渠道费用及退款后，生态奉献激励金及周边收入，共计一万八千元整。”
“本项目合计实收资金，五万元整。”
“另，由崇远提供的两万搏命本金，单列铁账，不入此池。”

会计师推了推眼镜，翻过一页。

“经核查，已确认的死账共计两万，包含网络工程量——峰值1.2Tbps带宽租赁、16台机柜共120台服务器托管费、两万个网络节点的部署开销，以及项目宣发、法务公证等费用。”
“已发放的薪酬与激励金共计两万一千元，此为所有幸存‘刀客’的基本参与份额与绩效奖金，确保了他们的保命粮与论功行赏的拔筹钱。”
“预留四千元，充作公司下一季度的运营储备金。”
“综上，本局活棋，最后净胜五千元。”

账目清晰如刀刻。照着那份电子死契上的数字签名，崇远信托的代表陆文渊，当场授权划转。两万本金完璧归赵，再卷走两千元的花红，整个过程行云流水，收发自如，犹如一式精妙的天山折梅手。

剩下的三千元碎银，由南离和风雷两个堂口——项目的两个执行团队，当堂坐地分赃。南离的技术部主攻，领走两千；风雷的运维部主守，分得一千。

一笔通天透亮的明白账。统共七万的真金白银，两万填了前期攻坚的无底洞，两万一千买下了众刀客的肝与命，四千养了堂口的香火，两万还清了旧债，两千填饱了金主的胃口，最后的三千才落入两位大当家的口袋。这里面，绝没有拆东墙补西墙、拿后来者的命钱去填旧坑的龌龊脏水。

许嘉榕那一千八百元，连同其他几十名死士的卖命钱，每一笔都死死圈在那两万一千元的红线之内，半文钱也没算进总堂的余粮。有人拿得比她厚，有人只能咬着一块五百元的基本参与份额。给谁多少，给多少钱，全凭后台日志里记录的军功，绝没拿“谁在茶馆里买过最贵的刀”——谁的资历最老、名头最响，来充作加官进爵的筹码。

陆文渊将那张两万二千元的电子回单存入手机，神色没有半分波动。他甚至没用这笔进项去冲抵上一局“桃花岛”项目亏空的那四千元血坑，那是另一盘棋，另一份因果。他冷眼瞧着方婉音，话却是对所有人说的：“下一场赌局，必须先把看客的胃口和赔命的底价摸个底朝天。一朝搏命博出了活路，绝不等于从此多了一个怎么也填不满的提款香炉。”弃子争先，他宁愿放弃眼前的些许利益，也要抢占下一局的主动。

苏怀青在那份电子劳务合同上签下了自己的名字，只同意在公开的技术志上，留下一段商量好的、冷冰冰的招式拆解——一行关于防火墙策略的伪代码。她绝不准任何人再拿她的ID，去当招揽生意的噱头。
“理应如此。”方婉音一口应下。刀客在阵前拿命换钱，留下一抹惊艳的剑影，事了拂衣去，深藏身与名，这本就是江湖的体面。绝没有逼着人家把感激涕零，当成后半生随叫随到的卖身契的道理。

另一桩公案，在角落里的小会议桌上清盘。东瀚那十张短图——一个外包测试任务的死契，在另一本铁账上，由独立的仲裁人进行清算，半点没和“两岸回声”那五万香火钱搅在一个池子里。

游离于公司之外的判官——一位第三方审计师，重审了所有的提交记录后，冷着脸拍下结论：“魏泽安，实打实只攻破一处阵眼，按门规，应得酬劳二百六十元。但他利用两个相似的ID，制造重影，从信托账户里骗领了四百八十元，生生黑下二百二十元。”

审计师的声音在角落里回响，不大，却字字诛心。

“这笔昧心钱里，八十元，是他用分身法冒领的、本应拨入公共差异池的八个基本参与份额外溢，合计四百元；剩下的一百四十元，全是他用两份内容几乎一样的残卷——两份几乎相同的测试报告，硬从其他八位真正付出的刀客嘴里抢走的带血花红。”

剩下那八个拿命填出战功的弟兄，到手的花红活活被削了一百四十元。陈绍武，那个最先发现问题的年轻人，就被这无形的手，生挖了二十元的血肉。

方婉音甚至没等审计师说完，便已授权财务：“立刻按重盘的死账，从公司储备金里垫付，把那八个人的窟窿填上。”
绝不等揪出贼赃才开饭，更没脸去扣那八个人嘴里本该有的那口保命干粮。

规矩继续往下走。多冒领的那八十元，按死契退回无人动用的七千元差异池；那一百四十元，必须从魏泽安账上讨回，原封不动塞回点拨阵眼的赏钱袋，分发给应得之人。至于请外头判官来查这笔黑账花掉的四百八十元审计费，全由东瀚自己咽下这口管理不善的苦水。

魏泽安只肯在强制执行令上，同意退还六十元，涨红了脸，梗着脖子要为剩下的一百六十元去敲鸣冤鼓，声称那是他应得的“创造性劳动”的报酬。而他的同伙冯至成，也死死护着自己账上那六十元的引路钱不放，一口咬定自己只是在帮旧日脚行的弟兄抄几卷账本，对双重冒领之事毫不知情。

这两个原本绑在一根绳上的蚂蚱，先前还在一把鼻涕一把泪地哭诉“江湖路难，极客命苦”，此刻却当着众人的面互相撕咬，都说是对方先起了黑心。接榜的判官将两份附有数字签名的血书——两份截然不同的申诉邮件分开存档，绝没因为这对露水兄弟当场翻脸，就断定其中哪只疯狗说的话更干净。

陈绍武的手机震动了一下，提示一笔二十元的款项到账。他攥着手机，指节发白，却没有大度地点头说一句“这事就算了”。他为了追查这笔烂账而错过的盘道时辰——一个更有利可图的项目申请窗口，早就顺水流干了。另外几个弟兄，也为此生生熬了七天的更漏，在无数的聊天记录和日志里翻找证据。铁算盘能把被人顺走的银票算回来，却休想让那段空等的煎熬，从他们刀口舔血的日子里，抹得一干二净。

打完这几局，有几个疲惫的死士想解甲归田，歇上一阵；另几个则提着自己的笔记本电脑，去接了别处山头的悬赏帖。熟门熟路的老营就此散了，再拉起一支新的队伍，需要花更多的银子去磨合、练兵，下一次冲阵，照样有可能输得血本无归。方婉音却依旧让助理，一笔一划地重新写下招贤榜，绝没霸道地把“同生共死过三局”当成筹码，强压着别人不能离桌。

招贤榜的邮件群发出去后，她将那些没有续约意向的ID，从核心通讯组里移出，扔回了冷宫。杀过河的刀客们各自收拾行囊，有人提着带血的剑——一份亮眼的履历，奔赴下一场杀劫；有人在运维中心的孤灯下停步，为自己倒上一杯冰冷的可乐。这份曲终人散的寂寥，本就是他们这趟拔刀护镖，应得的善终。

会议室清场时，角落里还有两个看客死死捏着各自的平板电脑，为一个技术细节较劲。一张屏幕上满是网络拓扑的断桥痕迹，另一张屏幕上只留着几行辨识流量来源的暗语。散会的陆宏远敲了敲桌子，催促道场子要落锁了，让他们去别的堂口接着盘道。两人如梦初醒，小心翼翼地保存了文档，塞进加密文件夹，相约下月初一，去真的那条鬼见愁河边——那个项目的实地机房走一遭。这段未尽的盟约，没被账房先生早早估作下一场的买路钱。

暗阁里，那几台用于存档的服务器续命的电费，和看场子的运维人员的汤药费——加班补贴，一文不少地钉在铁账上，扣除72.5元的电费后，实付47927.5元。河谷那片修罗场——核心机房的香火钱，也全划在护局的常例花销里。

附庸风雅的诗词买不来十九路盘上的真金白银，那本死死咬着人头的账簿，也同样算不尽今夜每一段同生共死的过命交情。

方婉音收到银行递来的最后一张结清账单的电子回执，冷着脸，合上了笔记本电脑，如同合上了一本生死簿。那些在刀光剑影里悄悄抽芽的变数，那些人心与技术的纠缠，大可等有命活下来的刀客，日后自己来盘这局尚未终了的棋。
