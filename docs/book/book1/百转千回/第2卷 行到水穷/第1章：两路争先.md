# 第1章：两路争先

周日的惨淡晨光，裹挟着昨夜未尽的寒意，透窗漫入双桥战区的总控工坊。全息沙盘在幽暗的室内投射出冷蓝色的全景图，然而那片象征着生命线的微光，已比昨日初见时黯淡了大半。

刘景和方才走近沙盘，眼底的红血丝还未褪去，便见南桥外的通路已被生生斩断，化作一片森然的死地。他侧头看向操控台前的杜启航，干涩的喉咙里挤出一句问询：“昨夜……系统副官接管后，又是一场熬神费力的恶战？”

杜启航未发一言，那张被屏幕冷光照得惨白的脸上看不出情绪。他只默默抬手，在键盘上敲下一串指令，切出夜间战报摘要。系统守备部队在冷酷演算了损耗比后，如同对弈时果断弃掉的一颗死子，毫不犹豫地舍弃了补给断绝的前哨，将残存单位悉数撤回堤岸。屏幕上的交接日志，依然毫无温度地衔接在昨日真人指挥官的指令之下，仅凭一行灰暗的时间戳，便轻描淡写地刻录了控制权易手的冷硬瞬间。

“那我们昨日呕心沥血，踩着刀尖拼出来的局面，究竟留下了什么？”刘景和死死盯着沙盘上那片沦陷的废墟，声音因一夜未眠而透着嘶哑。

“北桥保住了，抢渡的车队皆已过河。”杜启航的声音沉郁如水，手指在南岸的废墟上空轻轻划过，“但南路……有两辆伤员转运车未能突围，小队也折损了一个单位。南桥这段千疮百孔的残局，我们只能踩着这些战损的印记，继续往前蹚。”

此时的南桥，犹如十九路棋枰上尚未补净的一处断点，气口已被重重封死。纵然换手执子，那残局中的森然隐患依旧横亘于野，逼迫着后手必须直面这生死劫。刘景和将手重重搭在椅背上，指节因用力而泛白。昨日那句“我要是……能早半分钟看见就好了”的叹息，带着浓重的愧疚，再度萦回耳畔。那一千元的差异份额仍在排队复核，那一分一厘都是拿命搏出来的真金白银；但他心底最挂碍的，始终是那支残缺了一个单位的小队。昔日江湖走镖，到了交班的驿站，路上损兵折将总要向接盘人盘道个明白，这是绿林好汉拿命立下的规矩；而今在这片数据交织的虚拟战区，这些战损的缺口与无声的遗憾，亦必须有人毫无粉饰地交递到下一双手里。

门轴发出一声沉闷的摩擦声，罗振业裹着夹着霜气的风衣推门而入，手里死死攥着一张传播数据的热度截图。定格的画面上，正是唐梓豪带队杀个回马枪、惊险穿过西门的那一瞬间。枪火的硝烟与残垣断壁交织，宛如桃花岛奇门兵刃在绝境中挽出的惊艳一击。然而，在这段全网疯传的影像中，“极轴”一掷千金买下的展示大页早已被镜头无情切走，半点光影都不曾留下。反倒是测试者与两家企业获准回勘的内部群里，被反复转发、讨论得最热烈的，是刘景和果断指出东出口原有安全消息已经失去依据的那段惊险语音。“凌拓”那并不起眼的品牌标识，就这般静静伏在复盘页的一角，如同蛰伏在草莽中的暗器，却清晰入眼，反客为主。

“我们明明出价更高！”罗振业死死盯着屏幕上的截图，眉头拧成了一个死结，声音里透着毫不掩饰的火气，“为什么全网铺天盖地的流量，最后只让你们捡了便宜？”

正在一旁不紧不慢褪去外套的宋振峰闻言，动作微顿，那双锐利的眼睛里闪过一丝老谋深算的光芒。他语气平波无澜，却如武当绵掌般绵里藏针：“罗总，我们买的，本就是不同的地界。”

许知妍应声从案头抬起头，手指在触控板上轻轻一滑，唤出两家最初的展示排期。极轴财大气粗，豪掷千金包揽了游戏大厅与开场动画，犹如在棋盘中央狂妄地拍下重锤，妄图以绝对的体量吞噬一切；而凌拓剑走偏锋，偏偏挑了延迟战报与复盘入口，似在棋盘边缘处悄然布下一枚不起眼的暗子，深谙“高者在腹，下者在边”的虚实之道。

“两份合同里，谁也没有授权买断参战者的语音频道。”许知妍目光冷峻地扫过二人，语调不带一丝偏袒，“获准使用的片段，仍须受制于参与者各自确认的公开范围。白纸黑字的契约皆已落定，但看客的目光与情绪真正肯栖息的地界，从来不会按照你们资本砸下的厚薄来均摊。”

直至此刻，罗振业起初只死盯着流量最盛的展示位，宛如初涉棋道的新手，满心只贪恋最惹眼、最辽阔的星位，恨不能一口吞下中腹大场。而在这同一方十九路巨盘之上，落点的分量，从不取决于拍板那一瞬的雷霆声势，而要由后来者如何在这片危局死地中腾挪跋涉来决定。

“下一段战事，能不能把我的商标直接焊在作战画面的正中心？”罗振业犹有不甘，语气中带着几分输急了眼的偏执。

独坐在角落里调试旧耳机的唐梓豪蓦地抬起头，那双平日里总是带着几分慵懒的眼睛此刻锐利如刀。他冷声掷出一句：“你这牌子哪怕只遮了半寸视野，我也可能漏看对面掩体后探出的半个身子。那是拿人命填的坑，不是给你挂招牌的墙！”

顾承安见状，适时切出系统准允展示的安全视界，用不容置疑的代码逻辑封死了罗振业的非分之想。罗振业嫌版图逼仄，竟还荒诞地提议买下一次全屏霸占的强行弹窗提示。而在沙盘另一端，战役指挥官正神色凛然地点开夜间的单位阵亡记录，那是一份带着血腥气的清单。在这瞬息万变的数据沙场里，没有人能将那未竟的救援指令按下暂停，只为等待一个商业商标华丽登场。

最终，罗振业自行咽回了那句荒诞的提议，改口探问能否独家冠名下一场的现场复盘。

周慎衡推了推鼻梁上的无框眼镜，将连夜收拢的销售反馈表推至两人案头。极轴与凌拓的两款耳机品质在伯仲之间，外形殊异，标价与保修期亦是半斤八两。昨日的参演者确有多问了“凌拓”几句的，但这仅仅剥离出“品牌已入眼”的表象；而“极轴”在开场大厅里框取了海量的合照，也充其量只证明他们曾到此一游。两份报表最底端的“净转化回报”一栏，此刻依旧是一片虚无的留白。在随后的四周里，两家门店将凭授权各自回溯开场与复盘片段，打捞自愿反馈；眼前这区区十六人的购买意向，委实撑不起整盘大棋的辽阔分野。

“观察期未结，先剔除退货折损，再去与历史同时段及未涉足此战的客群做对标。”许知妍语调极冷地划定着财务与数据的护城河，“品牌究竟被翻了多少次牌子，以及整个大盘因为这场鏖战多溢出了多少真金白银，这两笔账，必须拆骨剥皮地分开算。”

罗振业用力揉搓着突突直跳的额角，疲惫与焦躁顺着指缝溢出。他最渴盼带回总部的，是一条能立刻为其决策背书的陡峭昂扬的曲线。然则观察期尚未结束，眼前这些冰冷的数据迟迟不肯显出方向，就像一潭死水，倒映着资本的虚焦。

宋振峰看上去则游刃有余得多。他表态，凌拓愿趁热打铁，当下便开启下一轮的谈判。

许知妍却并未急于奉上合约：“复盘之所以聚拢了目光，是因为昨夜当真有作战单位陷入绝境，又当真有人在有限信息下作出决断，将其中四个单位硬生生带了回来。假使下一阵少了这种由真人选择、拿命相搏形成的经历，哪怕原样复刻页角的位置，也未必能重现昨日的效果。”

待两位企业代表离席，陈驰将昨夜那十六张结算回执在桌案上一字排开。红色的印泥在冷光下泛着近乎残酷的血色。有人仅领了五百元的基本参与份额，有人则凭借刀尖舔血的精准判断取得了数千元的差异份额。数字间的参差，如同江湖中武功高下的阶级，清清楚楚地钉在纸面上。

昨日未曾分得差异份额的一位运输手打来电话，声音里透着熬夜后的沙哑与难以掩饰的不甘。他开口第一句，先问南桥折损的那辆车还能否找回，那可是他昨夜拼死护过的兄弟；第二句方才小心翼翼地问及，为何自己在战区的漫长等待，最终只计入了区区五百元的基本参与份额。

陈驰握着听筒，目光扫过那些红色的印戳，循着公开标准向他解释：“那段等待，发生在有效指令的覆盖期内，那是您完成这一席事前约定的一部分。但在这期间，没有产生可区分的新判断、协作或额外支援。兄弟，规矩就是规矩，没有超出常人的险中求胜，便不足以形成差异贡献。”

对方在电话那头沉默了一阵。那漫长的几秒钟里，陈驰仿佛能听到电话那头深沉的叹息声。半晌，那人终于开口，声音反倒平静了许多：“好……下一次，我想试试‘侦察位’。我想看看，自己这双眼睛，到底能不能承担更多判断。”说罢，他预约了下个周末免费的演练日程。

“好歹，他知道该朝哪个方向去蹚路了。”陈驰搁下听筒，发出一声极轻的叹息，犹如老僧见到了执迷初醒的剑客。

工坊门首恰逢此时又转出两道生面孔。两人行色匆匆，扫完墙上张贴的意向表，便急不可耐地追问今日能否立刻入局，眼中闪烁着对快钱的渴望。

然而，新一轮的参与资金尚未锁死，测试邀约的名册也还在严苛的勘验之中。陈驰只得请他们端详桌畔获准放出的样片，温言细语地掰扯明白：“今日只做意向录入。既无法即刻接入战局，亦没有明码标价的有偿任务可派。”

其中一人登时拧紧了眉峰，不悦地冷笑一声：“那你们招募榜上高悬的‘参与即分配’，莫不是在唱空城计？拿我们当猴耍呢？”

程砚舟闻声，从沙盘后缓缓踱步至门边。他身上那股内敛却犹如太极般渊渟岳峙的气场，让那两人不由自主地退了半步。他将昨日厚重踏实的十六份回执，与今日尚未开张的空荡招募簿，坦荡荡地并陈于前。

“我们所恪守的‘分配’，是对每一份已然承接、且被切实践履的有偿参与负责。”程砚舟目光中透着不容置疑的寒意，犹如一把出鞘的霜刃，直面对方，“今日既然这盘口吞吐不下，资金未曾落定，我们就必须在您砸下宝贵光阴之前，把这道生死劫的劫材挑明。我们断不能让您一头扎进这深渊，枯熬过一整个长夜，待到天光大亮，才像那些嗜血的机构一般，凉薄地丢下一句‘账上无钱’。”

那人俯下身，细细端详过回执上那猩红的结算印戳，感受到了那份不容置疑的契约重量，终是决意留下一份运输测试的投石问路。而另一人则摇头哂笑，嫌弃这草莽山门规矩太多，拂袖遁入长街。

他们未曾将拂袖而去者从试验的底表中抹除，亦未曾将留下之人草草算作粉饰门面的纸上业绩。一切皆如实记录。

暮色四合时，冬日的阴霾重新笼罩了整座城市。刘景和取走复核安排通知单，忽然转头问杜启航：“夜班的系统副官，能否把东出口那条已经过时的旧消息改掉？”

“系统只会更新当前状态。”杜启航答道，他的声音在空旷的工坊里回荡，仿佛敲击在铁板上，“昨日那个节点，您收到过什么消息，那条记录就会永远留在那里。无法抹去，无法篡改。”

刘景和默然点头，不再言语。光屏之上的南桥，此刻依旧蜷缩成一条纤细的暗线。它宛如一着已经落定的旧棋，得失都已写进苍凉的棋谱；后来者能做的，只是在这片残局里继续周旋，落子无悔。

罗振业与宋振峰各怀心思地揣走了新一茬的意向表，没入霓虹闪烁的夜色中。但究竟谁会在这场资本暗战中继续掷金加码，谁又能真正在这片被系统榨干的虚拟焦土中淘洗出真金白银，答案从来不会写在那些花团锦簇的财报曲线上。这一切的一切，皆要等河谷里那些真正作出选择的人，深一脚浅一脚地蹚完下一段泥泞的险途，方能在这场天下大劫中拨云见日。
