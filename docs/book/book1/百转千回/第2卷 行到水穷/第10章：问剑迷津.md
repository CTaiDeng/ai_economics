# 第10章：问剑迷津

三月下旬，江岑大学的玉兰花事已近荼蘼。残雪般的白瓣在料峭春风里飘落，几片旋舞着贴上韩知衡书房那面一尘不染的落地窗，像是一局终了后散落的棋子。

室内，空气里弥漫着旧书页与黑胡桃木的沉静气息。韩知衡的手指瘦长而稳定，捻起桌上一本硬皮账册，翻页的动作不带一丝烟火气，仿佛不是在审阅账目，而是在检视一卷武功秘籍的内页。他的目光从“双桥首试”四个字上掠过，最终停在“回声夜会”的收官记录上。

“两次合计，实收五万元整。”他的声音平缓如古井之水，却让对面的几位年轻人感到一丝无形的压力，“四万九千元来自企业席位，一千元来自观众散票。支付给参与者三万五千元，直接成本消耗九千元，团队组织收益五千元，另有一千元划入储备金。”

他抬起眼，视线落在周慎衡脸上，像一枚精准点向穴位的棋子。“储备金仍在？”

“分文未动。”周慎衡答道，声音有些发紧。

韩知衡微微颔首，又翻开另一本更薄的册子。研发、常设场地租赁与治理机制试验的开销另列一册，由初始投资承担。他注意到，就连刘景和那次作为友情支援的独立复核，也 meticulously 记录了实际工时与差旅支出，没有因为是熟人帮忙，就让这笔成本在账面上无声无息地蒸发。

他的指尖停在“基本参与份额”一行上，像是点住了一条至关重要的经脉。“每人五百元，”他轻声念出那个数字，随即问道：“这条规矩，是你们主动设下的‘山门’，还是说，你们天真地认为，所有上线的人，天然就该分走一份？”

“我们先锁定资金池，再开放约定参与。”林静薇接过话头，她的声音清脆而坚定，像出鞘的短剑，“我们设计的规则是，任何完成有效战术行为的参与者，都应获得正向份额。这五百元的基本部分，是我们对‘共同在场’这一行为的承认；其上的差异池，才是对个人能力的奖赏。若没有这笔启动资金，就不能先承接风险任务；但若只是挂机占位，也休想将之冒充为履职，系统会自动甄别并剔除。”

韩知衡听着，拿起一支笔，将她的话原封不动地在页边空白处记下，字迹瘦硬，力透纸背。他又问：“席位从十六人扩编至二十人后，是否有人利用规则空隙，将自身拆分为多个身份，冒领基本份额？”

陈驰立刻调出后台记录，将席位交接日志、真人生物特征验证和最终的合并结算流水投射在墙壁的白幕上。“我们有防范。但必须承认，冒名顶替的风险依旧存在，如同江湖上总有精于易容术的刺客。这是我们下一阶段必须加固的防线。”

问询至此，暂告一段落。韩知衡将账册轻轻合上，转而摊开那份一月份的产业萧条简报。纸页已经有些微微卷边，上面的每一个字都透着寒气。裁员潮、空置的商铺、断崖式下跌的收入缺口……这些冰冷的词汇如同一座座墓碑，沉默地排列着。落到每一条具体的产品线上，死因却千差万别。两家外设合作企业的标准化制造产能早已过剩，继续添置同样的机器，也接不到更多订单；但另一边，新材料、工业用电、物流运输和售后服务的成本却依旧在失血。医院床位的紧张与城市住房的供给，更是另一组错综复杂的棋局，绝不是靠算法生成代码的速度就能替它们落子签字的。

“那场寒意，是真的。”程砚舟的声音低沉沙哑，像是从一口深井里发出。他永远无法忘记，站在霁岳集团三十六层那扇巨大的落地窗前，俯瞰着整座城市在资本海啸中，如同一张星盘般一盏接一盏地黯淡下去。他绝不能容忍，让纸面上几项轻飘飘的模型参数，就把那些曾为他、为霁岳卖命的、一个个有血有肉的生命，简化为可以抹除的误差。

“所以，才更要拿稳你手里的算筹，一寸一寸地盘清，究竟是哪一截经脉断了真气传导。”韩知衡的目光如炬，仿佛能洞穿人心。他将那份旧简报推回程砚舟面前，又从手边抽出一张打印得密密麻麻、布满分行业数据的附表，叠在旧纸之上。“产能放宽这道‘化功大法’施展之后，工资、投资、公共支出和底层民众的实际收入，是怎样一番此消彼长的景象，必须拆骨剥皮地分开来看。程先生，你要找的，是一条能在万丈深渊之上，重新接住活人的悬索。而不是像个怨妇一样，预先就假定，往后每一次机器席卷人间的浪潮，都会是同一场万劫不复的通缩寒冬。”

程砚舟的指节因用力而微微发白，他将旧简报与那张新添的数据页并排压在桌上，没有逃避。几个月前，是旧纸上的累累枯骨，让他勘破了十九路棋盘上那片看似无解的死局；而眼下，他必须学会在同一片冰冷的残局里，凭借更精妙的算计，分清哪里是万劫不复的断桥死地，哪里又是尚在承重、可以做活的棋筋。即便为了救活一处断点，他也不能像个鲁莽的棋手，愤然将棋盘上其余尚能周旋的星位大场，一一砸烂。

“先立下你们的山门，再向整个江湖证明，它能在最嗜血的围剿中守得住。”教授的目光扫过在场的每一个人，“别以为在自家门前写下几句公开的门规，就敢宣称这世道已经海晏河清。”

程砚舟把腹中准备好的那几套花团锦簇的愿景说辞，默默咽了回去。这场所谓的名家问剑，甚至没有一丝一毫的刀光剑影。韩知衡只用最平淡的语气，沿着他们自认为防御最森严的罩门，一寸一寸地往里深探；而每问进一寸，那套看似圆融无漏、密不透风的太极招式，便不可抑制地露出一处尚须千锤百炼的死穴。

许知妍适时地递上首轮品牌反馈报告，将话题引向另一片战场。两款合作的耳机品质相当，价格区间与保修条件也极为接近。在双桥河谷首场战役及随后四周，获授权门店的回看观察期内，数据显示：

“极轴耳机，预估增量毛收益六千元，扣除注意力投入成本一万一千元，净亏损五千元。”她冷静地报出每一个数字，不带任何感情色彩。“凌拓耳机，预估增量毛收益一万元，扣除投入成本九千元，净盈余一千元。报告中的毛收益，均已扣除相应的商品制造成本、销售佣金及预估退货损失，我们不能拿虚高的销售额去减广告投入款。”

“样本量还很小，比较的维度也有限。”她补充道，“不同的外观款式、终端成交价的微小浮动，以及售后服务的口碑差异，都会影响消费者的最终选择。眼下，我们还不能将这些变量的影响完全剥离。第二轮为期四周的观察尚未结束，我们不会拿未来的数据，替第一轮的账目粉饰太平。”

“极轴为什么还愿意跟投？”韩知衡问道，这个问题直指商业逻辑的核心。

“他们预定第二轮时，首轮的四周观察期还没结束。极轴的负责人是看过了现场的用户反馈热度，判断失利只是因为投放位置不佳，想换一个阵地再试一次。”许知妍对答如流，“现在，即便拿到了首轮的净亏损估算，他仍然愿意继续谈下一轮的合作。而凌拓，也没有因为首轮告捷就选择无限加价。这是他们各自在商场上的判断，不是我们对投资回报做出了任何保证。”

就在这时，许知妍的手机屏幕亮起，一条信息无声滑入。她看了一眼，抬头道：“罗振业先生和宋振峰先生已经约好，下午到工坊拜访。他们分别带来了新一轮的合作意向金，一笔一万二千五百元，一笔一万元。”

两家并没有为了所谓的“公平”而出相同金额，也无人向他们保证，数额较大的那笔就一定能赢下心仪的阵地。

韩知衡听完，沉默片刻，将目光投向窗外那株开败的玉兰：“有几个人拿到了钱，只能证明这几笔支付真实发生过。但你们这个世界，究竟能承接多少人，市场的需求能支撑多久，维系这套规则的治理费用，最终会不会反过来吃掉所有人的所得……这些，是后面的账，一笔比一笔更难算。”

程砚舟深吸一口气，在面前的触控板上划开一幅更宏大的星图。双桥河谷之外，崎岖的山路通往漫长的海岸线，而在海岸线的另一端，还有另一个庞大的战区正在被点亮。那些局部灰暗的区域，并没有在服务器上实时运行每一名士兵的全部动作细节，只以加密形式保存了经过授权的态势摘要，如同被封印的棋谱，等待着指挥官激活时，再从各自的历史存档中精准接续。

“人可以换防，但世界必须留下来。”他说。

“最高权限的‘天眼’，是否可以看见所有房间内的战况？”教授冷不防地问道。

顾承安摇了摇头，斩钉截铁。“高层权限只掌握全局资源调配与战区授权摘要。当他们亲自进入某个小队时，只能接获该角色被准许的战场信息；其原有的高层席位将自动交由系统代理。室内的敌人，仍需他亲自索敌、发现。绝不允许任何人，靠同时占据三处不同维度的视角，把其他玩家有限的信息差，当成自己的掌中玩物。”

他们又谈到了落败的一方。战区会失去战略资源与关键通路，但参与者在战役中已经形成的现金权利，将通过独立的信托账户另行结算。败方，也无需向胜方缴纳一个充满赌博性质的奖池。游戏内的虚拟资产、团队的指挥资格，与每个人的现实所得，三者被严格切分。如此，才不至于让一场桥头堡的失守，就将一个人在现实世界里的身家性命全部吞噬。

会议的最后，韩知衡终究没有在那份分量极重的“生态顾问”英雄帖上，落下自己的名字。他只同意，继续作为一个冷眼旁观的棋手，定期审阅他们的战报，并毫不留情地刺出那些可能致命的反例与诘问。他绝不愿让自己的清名，沦为这新兴资本盘口上，用来背书套现的一块金字招牌。

许知妍没有丝毫的失望或强求，她干脆利落地收起那份烫金的邀请函。反而，她更加郑重地，将教授那张写满了尖锐反例、画满了问号的薄纸，小心翼翼地折叠好，收进怀里。对他们而言，一位绝顶高手在死局棋谱边，随手指出的一处“薄味”，远比那些碌碌庸人题上的一万句“此局必胜”，要来得凶险，也来得珍贵。纸上那如冷箭般钉死的问号，还带着刺骨的寒意。他们下一次重返这间书房，必须带着能在乱局中亲手做活的硬记录，才能来拔剑作答。

下午，众人回到工坊。服务器机柜的低沉轰鸣，像是蛰伏巨兽的呼吸。顾承安正在演示多战区的无缝入口。他特别强调，破阵引擎与星原的全部资产，都是在他从霁岳离职后，独立搭建的。霁岳时代的“晨港”项目代码、旧的雇佣合同和玩家财产数据，没有一行、一个字节被搬过来。系统可以为玩家生成全新的地形与身份，但过去在另一家公司服务器里拥有的豪华房屋，却不能在这里自动变成一份等值的收益权。这是法律的红线，也是他们立身的根基。

许嘉榕不知何时也来了，她从一台公共终端进入访客系统，问道：“我那些旧作品，这次不便展示。可不可以只旁观一下你们的夜班交接流程？”

她得到了许可，便安静地坐到休息室的窗边。

透过巨大的单向玻璃，她看到一名挂着“系统副官”头衔的真人玩家，正在交接一支在先前战斗中被打残的小队。新接盘的真人指挥官，默默地检视着屏幕上几近干涸的弹药储备和一份惨烈的阵亡名册。他没有选择去硬闯那座危机四伏、已被敌人炮火覆盖的近桥，而是做出了一个刀口舔血的决断——带领残部，沿西侧的堤岸悄然摸索。

暗夜的对面，另一支友军的频道里，突然传来一句支离破碎、夹杂着电流音的急报。他猛地一拉虚拟的缰绳，整个小队瞬间停在了死地边缘，所有人都屏住呼吸，静静地等待着那句可能决定生死的、致命的下一句话。

程砚舟静静地伫立在窗边，看着那幅由无数光点构成的十九路巨盘，在夜色中缓缓铺排、次第亮起。双桥河谷那道深可见骨的旧伤依旧横亘在那里，提醒着所有后来者曾经的惨败。但新开辟的血路，也没有替任何人预设一条通往胜利的坦途。他知道，在城市的另一端，出版管理司正像一位顶级的刺客打磨暗器一般，处理着他们递交上去的、冰冷而繁复的审批规程；破阵公司的运营执照，也正在被一枚枚鲜红的官印层层加持、封印。

星原，这方刚刚初具雏形的江湖，必须先熬过这些来自现实世界的铁律封印，才有资格向天下真正地开山立派。

而眼前，这在生死一线的寂静等待，终究需要有人拔剑回应。

程砚舟想，那个在黑暗中敢于出声示警的人，那个在绝境中敢于拔剑回应的人，理应能堂堂正正地在这片星原留下自己的名字，并从资本的虎口里，拿走那份分毫不差、属于他的银两。
