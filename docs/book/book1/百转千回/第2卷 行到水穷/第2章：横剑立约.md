# 第2章：横剑立约

周一的清晨，一场冷雨将这座城市的街道冲刷得泥泞不堪。一名鬓角夹着白发的中年人，裹着一件不合时宜的单薄旧夹克，局促地站在城北数字创意工坊的席位栏前。他干枯皲裂的手指搓弄着衣角，眼神飘忽，最终还是咬着牙问道：“你们这儿……有没有底薪？”

他把墙上张贴的运输、通信、战术执行席位逐一看过，最后目光死死盯在了“支付条件”那一栏。陈驰见状，从角落里搬来一把折叠椅，用袖子擦了擦椅面，请他坐着细读。

“我们下一轮的资金尚未确定，目前的页面只收意向。”陈驰耐心解释道，“等确定接受的窗口开启，我们会先白纸黑字地写明基本参与份额、有效参与条件和差异分配办法。”

那中年人没有坐下，而是梗着脖子，急切地追问：“如果我什么都不管，只要我在这里端端正正坐满八小时呢？”

“您得先知道，自己接的是哪一席的重担。”陈驰打开周六首场的结算记录，指着屏幕上交织的数据线，“通信席可能在风暴中等一段救命的消息，运输席可能在枪林弹雨里等一次道路放行，这些等待，只要属于任务所需，系统都有记录。但如果您只是把人物挂在战区里，自己去睡大觉，把命运交给机器替您做判断，那不能算您的真人贡献。我们不发‘枯坐’的工钱。”

“我……我只想知道，下个月固定能有多少。”中年人的声音低了下去，透着一股被生活逼到死角的绝望。

陈驰听着，并未急于抛出虚妄的饵料劝他入局。若连对方要走哪条道、能抗多少压都没盘清，贸然伸手邀约，便如同截住过客强按牛头，逼他先拜一个连门槛都没摸清的险恶山门。他把刚准备调出的那份带着血色的战报关掉，重新直视那双布满血丝的眼睛。

“老哥，这里是按场算盘口的江湖，您可以自己挑愿意跳的火坑。”陈驰的声音冷硬却坦陈，没有一丝商人的市侩，“基本盘，只认我们在场共同流过的汗；差异盘，则要拿刀见红地拼判断与协作。单靠枯坐熬时间，孵不出一分钱的工资。第二轮眼下还在收意向，资金只要一日不落袋，我们就绝不发有偿邀约的英雄帖；眼下我不能给您承诺新席位，更保证不了，您下个月能糊多少口的余粮。”

那中年人默然，将攥得发皱的资料缓缓放回桌上。他没有骂人，也没有失态，只低声喃喃了一句，说自己得先去找一份能按月按点吊住命的差事。陈驰默默送他到门口，看着他将洗得发白的衣领死死翻起，试图抵御门外灌进来的刺骨寒雨。看着那个佝偻的背影，陈驰忽然感到一阵极寒顺着自己的脊背往上爬——那是他自己每月必须偿还的房贷月供。再清醒的规则与推演，也无法替这茫茫深渊中的任何人，填平哪怕一笔账单的窟窿。

下午，阴云未散，工坊内的白炽灯将长桌照得惨白。八个人围坐在桌旁，审查下一轮现场测试的合同条款。气氛冷峻得如同战前点兵。

杜启航皱着眉头，用红笔在“按综合贡献决定收益”这一行上重重圈了一圈。“这句话太虚了，虚得能装下一切私心。”他冷冷地抬起眼，“按这个写法，一个通信员拼死发出的情报救了整支队伍，到头来也能被一句‘击杀数不够’而剥夺所有的赏金。”

许知妍毫不避讳地承认那句含糊的官话是自己写的。她原本想用管理学的模糊空间，让系统有余地处理新情况。但此刻，她脑海中猛然闪过晨港项目里那些被高管随意篡改的评价体系，心头一凛。她抓起笔，毫不犹豫地将那一行横扫划去，如同挥剑斩断一处烂肉。

“按席位分别列出要看的事。”许知妍目光灼灼，语调清晰，“统筹席看授权、资源与目标；战役指挥看部署、协同和损失；基层看真实执行；专业支援看自己的作用。一岗一责，不容混淆。”

她紧接着又把“档位”旁边的横线狠狠擦掉。“只要是能可靠区分的贡献，就必须进入最终权重。不能先认定一个人多做了一项有效支援，到了付款时却用‘没有跨过整档’来赖账！证据只要足以认作相同的，就说明容限与理由，给予相同权重；基本任务之外未验证出追加贡献的，差异权重就是零。我们先定可比较的岗位组，定好各组资金，再在组内按权重分。不能把通信与击杀硬排成一条榜单去分高下，那叫关公战秦琼！”

“要是一场战斗下来，人人都认真做完，却谁也没多出那一分呢？”陈驰抛出了最极端的情况。

周慎衡推了推无框眼镜，镜片上闪过一抹理性的寒光。他在空白处龙飞凤舞地补上一行：“同组全零，已锁定的差异池由该组有效参与者等分，基本款另付；若无人完成，预留款按事前约定留存或返还。这笔钱，既然承诺了，就不能等看完结果，再厚颜无耻地把这笔余额改名叫‘我们公司的奖励’！”

唐梓豪那带着硝烟味的突入记录，与刘景和在后方拼死护住通信频道的记录，并排投射到冷光灼灼的幕墙上。前方有人如死士般顶住炮火集火，后方有人拨开迷雾果断指出旧消息已经失效，更有暗子死死钉在楼梯口做最后掩护。没有哪一行冷冰冰的结算代码，能凭一己之力讲完五个作战单位破阵冲杀、最终只残破地回来四个的惨烈棋局。

“基本份额，必须先承认这些由真人履约的真实岗位，那是他们拿命守住的底线。”程砚舟双肘撑在桌上，声音透着金石交击的清音，“至于差异份额，再拿刀枪棍棒去拼能力的高下。我们绝不能把那些共同托起整个十九路底盘的参与者，贬成只配给‘冠军’做垫脚石的耗材！”

林静薇适时抛出法律上的暗礁：“那中途接班如何算？”

周慎衡在白板上画出一条切割线，将一个席位窗口分成前后两段：“写明按已完成责任分段确认。绝不能让前后两个人各领整席的基本款。系统接手的那一段，不记到任何真人名下，先前已经成立的份额照旧保留；旧任务交出之前，绝不允许第二个人占上同一份。”

“如果判断错了，能追着人讨回已经发的钱吗？”陈驰又问，这是防备黑产最敏感的防线。

“先查这笔权利原本是否成立。”林静薇字斟句酌，如履薄冰，“品牌卖得不好、指挥后来输了，都不能成为追款的理由，那是你们自己相马看走了眼。若是伪造、重复，或者有明确责任的损害，另立依据，给申诉渠道。”

为了谈论开发者参战的边界，顾承安当着所有人的面，将自己的管理入口彻底锁死，换成了普通账号。屏幕瞬间清空，只剩下普通报名者能看到的视野。

程砚舟下意识地想要纵观全局：“给我打开全局图。”

顾承安摇了摇头，如同铁面无私的判官：“程总，您这次拿的观察资格，按规矩只能看延迟摘要。”

程砚舟微微一怔，随即收回手，笑了一下。他没有用创始人的权威让顾承安开任何例外。这便是法度。

方婉音将一份母带许可的契约轻轻放在桌上。旧钟声可用于这一轮场景，玩家通话的公开、战报的剪辑、另外售卖的声音作品，每一项都必须分别征得同意。她作为创作者，拥有作品报酬；若她另行参战，也只能像普通武人那般按该席规则领赏，绝不能让一次录音的特权，自动占据每一场战争的利润分成。

许知妍用精钢笔尖重重压住约定的末页，宛如名剑封喉：“能扛大旗领一队的人，先得画下道来，讲清自己究竟能把兄弟们带到哪一步。过了这条生死线，谁要另投山门，悉听尊便。”那森然的语气，瞬间让程砚舟想起岑绍庭教棋时冷酷划出的结界：这手棋，哪里的空能围得住，哪里的子注定要被屠，都得咬碎了牙自己认下来。

组织者的固定报酬与满足条件后的经营回报，同样一笔一划、清清楚楚地钉在条款上。周慎衡绝不肯用一句虚无缥缈的“大家先奉献”，就把这笔生死账轻飘飘地抹去。陈驰的测试服务报酬、三人的条件股份，以及各自必须扛起的万丈波涛，皆沿用最初分毫不差的单独约定——亲兄弟，明算账，这才是最正宗的江湖规矩。

陈驰翻出自己那张长期开发安排。前一周约定的测试服务已经完成，如今他每天接受公司的研发排班与管理，双方另签劳动合同，严格按照工资和社保的规则办理；过去已成立的服务报酬照付。偶尔接一个自主选择的体验窗口，和持续为公司上班，各有其真实的物理安排。他坚定地说：“绝不能只换一个合同名字，就把两笔账混为一谈。”

周慎衡也将收款人资料与申报记录严丝合缝地接上。该开具的发票、该预扣申报的所得、平台业务依法须报送的身份与收入，各有负责人。页面只展示实付数，个人回执则能清晰查到税前数和预扣数；成本预算接不住，就立刻挥刀缩减尚未承诺的窗口。

最后，林静薇把登记、评价、付款三处的签名分开。复核环节另留位置。做过哪一步，就对哪一步负责，绝不能只在页尾堆一排华丽的签名，出事时却一哄而散，谁也找不到。

晚上九点，工坊外雨势渐歇。许知妍的手机震动了一下。她把尚未议定的条款标成待办，收起外套。屏幕上，一个托管副官正在无声地接手夜班，它继承了防线，也继承了还没运到的物资，没有要求她继续坐在这里熬命。

走到门口时，她看见上午那名中年人的意见被单独抽出来，放在了第一页。没有留下姓名，只有他真正需要的东西。

她停下脚步，把“按月稳定收入，当前未能提供”那一行在心里默默读完，才伸手熄掉了桌灯。

新世界要让人愿意进去，也得容得下一个人看清底牌后，体面地转身离开。
