# 第8章：三杯然诺

三月初，凛冽的寒意尚未被初春的暖阳驱散。空气里还带着一丝冰川融水般的清冽，刮在脸上，像一柄无形的戒尺。

第二轮结算的电子表格在屏幕上泛着幽冷的光，许嘉榕的目光像两枚探针，精准地掠过一行行姓名，最终钉在了自己的名字上。

一千五百元。

数字下面是更小的附注：基本参与份额二百五十元，通信与声音贡献的差异份额一千二百五十元。她心头微动，像棋手复盘时确认了一步精妙的官子。两项证据，两份劳作，各有其独立的价值源头，但系统的铁律清清楚楚——她没有因为在同一个窗口承担两种活动，便领到两份安身立命的基本款。规则，冷硬如铁，却也公平如镜。

她的视线不由自主地滑向旁边，方婉音的名字下，应付栏里的数字是四千五百元，但到账状态仍是三个灰色的汉字：待支付。税前所得和预扣税在另外的单元格里纤毫毕现，合同约定由组织方负担的税款已然计入本场成本；至于将来按全年收入汇算清缴的补退，那是每个人与税务系统之间的对弈，与此间无关。许嘉榕凝视了片刻，终于忍不住低声问：“方老师也参与这一场，她的份额，是谁来定？”

身旁的陈驰没有立刻回答，只是轻点鼠标，调出了另一个文档，那是规则的版本库，字字句句都像是用刻刀雕在玄铁之上。

“方老师退出了本期的内部评价循环。”他的声音平稳，像机房里服务器恒定的低鸣，“她的贡献由外部评审团根据创作成果与授权协议进行核对。观众的有效选择，也只计入她声音演绎及战报约定的那一部分。她指导过谁、与工坊相识多久……这些江湖人情，在这张池子里，一丝一毫也休想暗添权重。”

许嘉榕的目光回到自己的评估细则上。短章的“结构完整性”一栏，评价是“仍有不足”，像一记不轻不重的点穴，指出了她的气门所在。而“通信的两次确认”，则得到了明确的肯定，干脆利落。她可以不服，可以申请复核，但她心中清楚，这远比一句含糊的“总体表现不错”要珍贵得多。江湖过招，不怕伤筋动骨，就怕死得不明不白。

不远处，另一名参与者正在为自己的差异份额据理力争。他的声音有些尖锐，划破了办公室里凝滞的空气。

“这条有效反馈被误判为重复，我有原始回执为证！”他将手机屏幕递到复核者面前，那上面是一张清晰的截图。

一番核对，记录被迅速修正，那条被误删的反馈恢复了原位。但复核者没有就此打住，他当众调出了反馈的详细内容：它仅仅是确认自己已收到任务，是基础履约流程中一个必要的应答。事实被恢复，但它并未如规则所定义的那样，增加任何当时声明的判断、纠错或协作贡献。

最终的裁决冰冷地落下：追加权重，零。

“若这份材料能证明任何可区分的追加贡献，哪怕微乎其微，也必须修改权重与金额，”复核者解释道，“规则里没有‘未跨档则不计’这种和稀泥的说法。但眼下，它确实不构成。”

“改了半天，还不是二百五十？”那人额角青筋暴起，声音里满是挫败与不甘。

林静薇从旁走了过来，她将更正前后的两份记录并排放在他面前，动作从容，渊渟岳岳，仿佛武当宗师演练太极，不见半分烟火气。“这二百五十元，是你有效参与的一份凭证，已经确认无误。错误的记录必须修正，这是对事实的尊重。但追加的份额，也必须按既定的规矩来算，这是对所有人的公平。”

那人死死盯着两份几乎没有差别的文档，胸膛剧烈起伏了几下，最终迸出一句：“下一期，我不来了。”

林静...薇没有挽留，也没有表露出丝毫意外。她只是平静地帮他导出了所有属于他自己的记录，没有要求他先撤回那句负气的话。门边的桌上，基本参与份额和差异参与份额的清单分成两栏，这一次，他的名字没有在两栏之外凭空消失。

林静薇将那份记录递出时，修长的指尖没有丝毫拖泥带水地压住纸角。那一刻，她不像个项目经理，倒像个仗剑立约的侠客。所守的诺言，本就包括对方可以毫不领情、可以拂袖而去的自由；若非要用一点施舍换一句感恩戴德才肯放人下山，那原先宣称敞开的山门，便与吃人的鬼门关再无分别。

当晚，二十份参与款全部支付完毕，总额两万元整。账目清晰如刀刻：方婉音四千五百，唐梓豪三千，刘景和两千，许嘉榕一千五百，其余十六人合计九千。这二十人都已完成了各自事前约定的基本责任，如同一场精密的合击阵法，人人守住自己的方位。基本参与份额合计五千元，是阵法的根基；其余一万五千元，则按已确认的贡献差异分配，如同阵法中那些或奇诡、或刚猛的杀招。有人擅长组织声音，是阵眼；有人擅长护送，是游骑；有人以最普通的回应和交接撑住了战线，是坚实的步卒。金额，便是他们在这场厮杀中各自的战功。

三万元的实收总额中，另外六千元支付了本场看得见的成本，三千元是组织的收益，还有一千元，则注入了早已约定的风险储备池。周慎衡在做账时，特意没有把这笔储备金描绘成已经流到玩家手里的收入。那是整个生态的护城河，不是个人的战利品。

陈驰前期测试服务的尾款，与他转入持续用工后的工资、社保，各列一页，清晰地注明由公司的研发预算承担。周慎衡绝不允许因为他整日坐镇战区，就将他的薪酬混进这二十份江湖卖命钱里。陈驰核对完毕，指了指那两万元的总额，叹了口气：“这些钱，能给人增加一点选择的余地，但还远不能让所有人按月去交房同贷。”

“这就对了。”周慎衡点头，目光沉静，“初始资本撑住的是研发，是根骨。若此刻将它改名算进参与收入，粉饰太平，那明天我们就更难看清，这套内功心法，到底哪里还没接上真气。”

就在这时，许嘉榕的手机发出一声清脆的提示音。她看了一眼，是银行的到账短信。她没有丝毫犹豫，立刻转出八十元到另一个账户，那是她的购书预算。其余的一千四百二十元，静静地躺在卡里。她想继续精进通信的技艺，也仍在寻找一份稳定的工作，她绝不会将下一次尚未开放的席位，当成已经收入囊中的生活费。那无异于看着棋盘上的虚势，就以为自己已经围住了实地。

几日后，罗振业带着他那商人本色的精明找上了门。他提议，下一轮能否将部分现金换成极轴商城的购物代金券。在这场资本的绞杀战中，他想用这种化功大法，强行将一部分底层流水吸回自己的经脉。

许知妍当时正在审阅下一轮的约定草案，闻言，她缓缓抬起头，目光冷得像出鞘的刀。她将那份草案从文件夹里抽出的动作，不带一丝温度，犹如从鲨皮鞘中拔出半截寒刃。

“罗总，有偿席位的卖命钱，必须是可自由支配的真金白白银。”她的声音不高，却字字如冰珠砸落，“您可以另外撒一些自愿领取的诱饵优惠券，那是您的阳谋。但绝不能拿它来抵扣血汗钱，更不能把卖身购物，列为上桌的投名状。”

“他们拿着我的钱，转身就可能去买凌拓的设备！”罗振业咬牙切齿，脸上的肥肉微微颤抖。

“也可能去菜市场买二两肉给家人糊口，或者就让它烂在卡里，对抗这个通缩的冬天。”许知妍的声音里没有一丝波澜，“那是他们的钱，他们的自由。”

她将“现金参与款”与“可选优惠”在白纸黑字间强行斩开，泾渭分明，然后便用那双冰冷的眼睛，等着罗振业决定是否还要继续纠缠。这就像十九路棋盘上，一局棋还没正式落子，双方仍可讨价还价，算清这笔买卖值不值得入局；可一旦在现金约定上画了押，签了生死状，就得眼睁睁看着对手把活命的气，做到不受你丝毫摆布的腹地去。

罗振业重重地跌靠回宽大的皮椅里，发出一声沉闷的呻吟。那一瞬间，他真真切切地感到一阵无力回天——自己砸下的真金白银，确实已被斩断了附着其上的所有锁链。剩下的，只能是各凭本事的贴身肉搏，再也无法端着金主居高临下的架子，去傲慢地发号施令。这一手，是弃子争先，许知妍弃掉了他后续控制的可能，却争得了规则的绝对公信力这个“先手”。

方婉音收到了四千五百元，她没有全部存起，而是留下一部分，准备投入到新的作品中去。许嘉榕找到她，想请她听一听自己的修改版，她欣然应允，但另约了半小时的固定时间。她没有把今晚拖成一场无限延长的免费辅导，也没有因为自己收入较高，便不好意思接受这份小小的回报。江湖规矩，有来有往。

夜深了，正式战区已经交由夜间托管的团队。后台的日志一行行滚动着，记录下控制者的更替；支付页面的状态，也一行行从“待支付”变成了绿色的“已到账”。两种记录，如阴阳鱼般互相对照，却又各自承担着一件事：一个说明谁曾在场，一个说明承诺的钱去了哪里。

陈驰将最后一张按满了血红指印的付款回执单锁进抽屉，发出“咔哒”一声轻响。他走到窗边，窗外的寒风卷着枯叶，在长街上打着旋。远处，许嘉榕单薄的身影已经走到了那座破败的公交站牌下，在昏黄的路灯下，像一个倔强的墨点。

他望着深不见底的夜色，心中忽然惊觉——真正被带出这间屋子的，能在这通缩寒冬里吊住一口真气的东西，根本不需要一直挂在资本那花团锦簇的屏幕上，发出虚假的光。它就在那个女孩的银行卡里，在那一千四百二十元的余额里，沉默，却重逾千斤。
