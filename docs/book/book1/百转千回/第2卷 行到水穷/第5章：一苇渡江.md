# 第5章：一苇渡江

连着几日，那扇厚重的玻璃门外，总有一个年轻女人的身影一晃而过，像一只在寒冬里找不到巢穴的鸟。她会驻足片刻，借着反光整理一下被风吹乱的额发，然后用手机对着工坊的招牌，拍一张模糊的照片，匆匆离去。

周三，凛冬的寒气仿佛凝固了整条街道，她终于推开了那扇门。

门轴发出一声低沉的呻吟，将室外砭人肌骨的冷气卷了进来。她叫许嘉榕，二十四岁，身上那件洗得有些发白的羽绒服，显然不足以抵御这样的天气。她摘下绒线手套，露出一双因寒冷而微微发红的手。

“我……我叫许嘉榕。”她的声音不大，带着一丝久未与人交谈的生涩，“前几天在门口……”

“我们知道，”方婉音从操作台后抬起头，目光温和而锐利，像探照灯，却不灼人，“欢迎。”

许嘉榕原先在家居卖场做导购，舌灿莲花是她的本事，能把一张平平无奇的沙发说成是通往梦想生活的云床。但卖场换了全息自助展示系统，冰冷的电子音取代了她温热的话语，半个班组的人被“优化”了。经理说得客气，“有客人需要人工服务时再叫你。”她等了许多天，手机安静得像一块墓碑。

“我不太会打游戏。”她站在巨大的双桥地图投影前，有些局促地搓着手，那上面闪烁的红蓝光点，像一盘她完全看不懂的棋。

她已在手机上收到了这次现场演练的邀请，成年身份在进场时通过一道冰冷的电子门廊核验过。邀请页的条款她逐字逐句读了三遍：免费、自愿练习，不承诺任何报ak酬，亦不收取任何任务成果。确认无误后，她才按下了那个“到场”的按钮，仿佛签下一份审慎的生死状。

方婉音没有多言，只是拉开一张人体工学椅，示意她先看。

屏幕上，战况正陷入泥潭。一辆装甲车死死卡在三岔口，动弹不得。

“跟上！我在桥头掩护，快跟上！”耳机里传来队长焦躁的嘶吼，背景是噼啪作响的枪火。

“跟哪边？你说清楚！仓库区后面还有人！”另一个声音在频道里绝望地反问。

“我已经说清楚了！就在那个红房子后面！”

“这里他妈的有三栋红房子！”

争吵像病毒一样在频道里蔓延，吼声越来越响，信息却越来越乱。每个人都像被围困的野兽，拼命叫喊着让别人往自己这边靠拢，却把整个阵线撕扯得支离破碎。

许嘉榕静静地听了一会儿，忽然极轻地问了一句：“为什么……每个人都叫别人往自己这边来？”

这个问题像一枚精准的银针，刺破了喧嚣的脓包。

杜启航闻声，摘下自己的战术耳机递给她。那耳机冰凉沉重，像一顶铁冠。她没有碰触键盘或鼠标，只是戴上耳机，先用极快的语速问清了每个人的精确位置和视野。然后，她那常年在迷宫般的卖场里锻炼出的声音，清晰而沉稳地切入了混乱的频道。

“桥墩下的一号位，你的左前方是灰色仓库。仓库二楼的二号位，你的视野能覆盖到堤岸。堤岸边的三号位，确认装甲车的位置。”她没有说“来我这边”，而是把桥墩、仓库和堤岸这三个孤立的点，用语言串成了一条看不见的线。

装甲车引擎重新轰鸣，终于开始移动。抵达那个致命的岔路口时，她的声音再次响起，不带一丝情绪：“注意，是那栋屋顶有破洞的红房子，不是水塔旁边那间。”

方婉音的目光顺着她纤细的手指在地图上移动，眼神里掠过一丝不易察觉的惊异。原本各自为战、乱作一团的报点，在许嘉榕几句简短的话语下，竟被理顺了脉络，接成了一条清晰而坚固的防线。

那感觉，就像是在一盘支离破碎、败象已露的围棋残局里，眼看就要全盘崩坏，却见一位不知名的棋手，极其实用、极朴素地补上了一手“本手”。这一手棋，既没有凶狠地提掉对手的大龙，也没有贪婪地圈占中腹的广阔模样，却像一道温润的真气，瞬间贯通了整盘棋淤塞的经脉。所有支离的棋子仿佛都被唤醒，气脉相连，让后续所有的腾挪、冲杀、打劫，都有了最稳固的根基。

“以前在卖场带客人找展区练出来的。”许嘉榕摘下耳机，脸颊有些发烫，“我们那儿楼层都长得一样，像迷宫。一旦给客人指错一次路，他就再也不会信你了。信任，比什么都重要。”

方婉音没有立刻夸赞她有吃这碗江湖饭的天赋。演练结束后，她沉默地调出两段录像，请许嘉榕复盘。一段，是刚才那辆装甲车在她的及时确认下，于枪林弹雨中化险为夷的瞬间。另一段，则是她初次尝试指挥时，因为说得太细碎绵长，生生堵死了前线一名队员呼救的生命通道。

许嘉榕清晰地听见，耳机里自己那喋喋不休、自以为周到的声音，完美地盖过了一声临死前短促而绝望的惨叫。她的脸“刷”地一下烧了起来，血色直冲耳根。羞愧像一只冰冷的手攫住了她的心脏，但她还是咬着牙，主动将那段惨痛的复盘又播放了一次，仿佛要将那声惨叫刻进骨髓里。

“我以为……服务态度好，就得多说一点，才算周到。”她的声音在颤抖。

“战场上，气口就那么几个。你把频道的口子全堵死了，别人连求救的‘气’都没了。”方婉-音的声音柔和依旧，却带着一种不容置疑的冷硬，像淬了火的冰，“你的善意，杀了他。”

许嘉榕捏紧了手中的笔，在那本陈旧的笔记本上，把自己刚才记录下的那些越界抢断的长句，狠狠地划去了一半。墨水在纸上洇开，像一滩血。她小时候看武侠剧，总迷恋那些大侠仗剑飞渡独木桥的场景，迷恋那飞身而起、衣袂飘飘的孤绝一剑。直到今天，在这残酷的数据沙场里真切地滚了一遭，她才骤然惊醒：窄桥之上，若是人人都红着眼、拼了命地往前死挤，谁也活不过对岸攒射而来的乱箭。

要争渡这盘“生死劫”，她得先学会收起那自以为是的锋芒，让出那致命的半步。那不是怯懦，而是为同伴留出生机，更是为自己争得先手。

这天下午，没有有偿任务，也没人要求她提交任何作品。她可以随时尝试，也可以随时离开。所有的练习记录都归她自己，不会因为她的参与而自动变成一份已经约定付款的劳务合同。许嘉榕把这些规则在心里反复咀嚼，确认自己没有被任何看不见的契约捆绑后，才低声提出，想再练习半小时。

休息时，她犹豫再三，还是给方婉音听了一段自己手机里的旧录音。那是卖场最后一天关门时的声音，沉重的卷帘门轰然落下，同事在门内说了一句含混的“下次见”，门外，公交车正在用毫无感情的电子音报站。她想把这些充满人间烟火气的声音，放到战区那个冰冷的公共休息室里，让那个地方……像曾经有人真实地生活过。

“你的同事，同意你把她的声音公开吗？”方婉-音听完，只问了这一个问题。

许嘉榕的眼神黯淡下去，摇了摇头。那位同事还没告诉家人自己失业的消息，依旧每天“上班”，只是去图书馆坐着。

“那段录音，先锁在你自己的心里。”方婉音将手机推还给她，动作轻柔却坚定，“你可以自己重录一句，也可以等问过你那位旧同门之后，再做定夺。这里的规矩，不拿别人的伤口做文章。”

许嘉榕紧绷的肩膀，在那一刻微微垮塌下来，她长长地松了一口气，像是卸下了千斤重担。来这间工坊之前，她做好了最坏的打算，以为自己得像个摇尾乞怜的外门弟子，把失业的伤疤撕得足够难看，把故事讲得足够凄惨，才能博得一丝同情，换来一个活命的坑位。

可刚才，那辆在她的沉着指挥下，终于破开迷雾、驶过夺命岔口的车，却硬生生塞给了她一把属于自己的剑。那是一种……不需要靠出卖悲惨，也能在这冰冷乱世里立足的理由。

她问，正式报名需不需要买新设备。她的旧电脑已经坏了，手机流量也总是不舍得多用。顾承安领她去看角落里一排公共终端的预约表，耐心地告诉她怎样导出自己的练习记录，怎样在离开时彻底清除登录状态，并且强调，她不必把任何密码交给工作人员。

“这个……免费多久？”她小心翼翼地问。

许知妍正好端着水杯经过，停下脚步解释：“放心用。这一阶段的设备与网络接入支出，有专门的预算和期限，出自另列的试验支持项目。它不会从刘景和先生那一千元的启动金里扣，也不会从下一批参与者的基本份额里扣。你即便以后决定不参加，也可以在公布的公共开放时段里继续使用。”

许知妍还在一张便签上，写下附近社区阅览室和免费法律援助的地址，一并递给她。“生活上的缺口，要对接到已有的社会帮助渠道去。我们这里，不能规定人必须先上战场，才准许申请吃饭和通信的支持。”

许嘉榕捏着那张写着地址的卡片，指尖传来纸张的温度。她重新坐回演练席，戴上那顶冰凉的“铁冠”。

第二次，她的话少了很多，却重了很多。她开始在每一句重要消息后，刻意留出几秒的空白，等待一个确认。有一回对方没有回答，她没有默认信息已经送达，而是像一名老练的棋手在收官阶段谨慎收气，直到另一条线路传来侧面回应，确认目标安全，才让车队继续前行。

傍晚时分，刘景和路过，在她身后静静地站了一阵。他没有把她的失业经历当成什么值得同情的资格，只是在她一次判断后，指着屏幕上一处不起眼的烟尘，用一种不容置疑的口吻说：“这里你听见的，是前一辆车的引擎回声。后面那辆，得另问一句。”

许嘉榕浑身一凛，立刻在笔记本上画了两个小方框，一个写着“直达”，一个写着“回响”。

她离开工坊时，口袋里没有多一分钱的收入，但U盘里，却带走了一份完全属于她自己的、沉甸甸的演练记录。在下一轮“通信指挥”与“公共空间声音设计”的参与意向表上，她毫不犹豫地勾选了前者，而后者那一栏，她暂时留白了——等问过那位旧同门再说。

在寒风呼啸的公交站台，冷气从裤管直往上钻。她鼓起勇气，给旧同事发去了那段录音和一条语音信息。许久，对方才回了消息，也是一段语音。风声很大，背景里有孩子在哭闹，女人的声音带着浓重的鼻音，却异常清晰：

“……用吧，嘉榕。但是，别把它放在故事的最后啊，搞得好像咱们真的被这世道冲散了，以后再也见不着了似的。”

许嘉榕把冰冷的手机紧紧贴在耳边，听了两遍。她迎着冷风，眼眶发热，却笑出了声，对着空气用力地点了点头。

一辆公交车打着惨白的远光灯，从夜色深处嘶吼着驶来，像一头钢铁巨兽。光柱刺破黑暗，照亮了她面前的一小片地。她忽然想起屏幕里那条枪林弹雨、窄如鬼门关的河道。

第一次踏入这片生死未卜的江湖，或许，未必要去争那个冲在最前面、最惹眼的破阵先锋。

一苇渡江，哪怕只做个在岸边默默守着气口、在最关键时为同伴递上一盏灯的提灯人，也足以在这片通缩的酷寒里，替自己，也替别人，趟出一条活路。
