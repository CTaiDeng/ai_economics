# 第3章：名实迷局

周一的寒气，像无形的针，透过玻璃幕墙渗入工坊的每一个角落。第二轮现场测试的意向表，如撒向冰湖的饵料，开始在网络上集中推广。周末两天积压的登记申请被悉数保留，新的报名者如过江之鲫，汹涌而来，总数很快便越过了一千的门槛。然而，这沸腾的数字背后，名单尚未经过最终的勘合，通往那个世界的门扉依旧紧锁。

杜启航背对着喧嚣的数据，站在墙边，正专注地用一把内六角扳手拧紧一张办公椅松动的扶手螺丝。金属与塑料发出轻微而固执的“咔哒”声，是他此刻唯一愿意倾听的实在。一声清脆的系统提示音响起，他头也不抬，只用眼角余光瞥了一眼屏幕。罗振业的消息几乎是同时抵达，言简意赅，却带着资本特有的急切与压迫感：“下一次，展示预算是否需要翻倍？”

陈驰没有回复。他指尖的寒意，比窗外的冬日更甚。他打开了一份附件，一份被宣称来自首轮测试的实况记录。十几份“新手”的录像，如同一支被无形丝线操控的傀儡军团，沿着完全相同的路线输送补给，甚至在同一个街角转弯时，做出毫秒不差的同步停顿。每一份文件的属性栏里，都用鲜红的标记勾选着“真人执行”的选项，但与之对应的邀请函与现场签收记录，却是一片空白。更诡异的是，录像中那支用于练习的车队，其番号早已在系统日志里被重置，而附带的战报，却像一个执拗的疯子，翻来覆去地提及一辆根本不存在的尾车。

顾承安坐在他对面，神情如同解一道围棋里的生死劫。他将报名人数的洪流与真实有效的参与记录拆分成两张独立的图表，泾渭分明。“共用一个公网IP，不能证明谁是提线木偶；行动轨迹高度相似，也不足以单独定罪。”他的声音冷静得像手术刀，“我们必须保留所有提交的材料及其数字来源，然后，与现场设备保存的原始动作流、控制源ID和任务日志，逐帧逐秒地进行交叉勘验。”

筛查的结果，如同一幕荒诞剧。有人将早已录制好的行动脚本，像一件不合身的旧衣，生硬地套在了全新的任务上。其中一份录像里，西门哨站自始至终都处于封锁状态，回报书上却赫然写着八个大字：“已从西门，安全撤出”。

“一张画得极好看的战报，跑在了人的前头。”杜启航终于拧好了最后一颗螺丝，他站起身，拍了拍手上的灰尘，语气里听不出是嘲讽还是悲哀。

下午，一个电话不请自来。对方的声音油滑而自信，毫不避讳地承认，首批那股“热启动”的虚假流量，正是出自他的手笔。一个做黑产推广的掮客。他说，从账号矩阵、设备指纹到每日在线时长，一切都可以被精准地操盘。他甚至能像南疆的蛊师一般，为他们“养”出第一批权重极高、贡献卓著的虚假玩家，用以装点门面，引诱真正的资本入局。

杜启航冷眼盯着屏幕上那些整齐划一、毫无生气的僵尸轨迹，脑海中浮现出一张绝望的棋谱。十九路棋枰之上，纵然被黑子铺满，密不透风，但只要没有做出两只活眼，那终究是一具冰冷的尸体。没有真实的临阵博弈，没有血肉之躯在电光石火间的取舍与挣扎，那一片虚假的繁荣，不过是涂抹在财务报表上的一层脂粉，风一吹，就散了。

“真人下场太慢了，不成气候。”电话里的声音循循善诱，“各位老师，得先把这个盘口炒热，那些嗜血的资本秃鹫，闻到肉香，才愿意继续往里砸钱。”

陈驰按下了免提键，那油滑的声音立刻充满了整个房间。“这些任务，实际上由谁来做？”

“机器呀，老板。”对方轻笑一声，仿佛在点拨一个不开窍的顽童，“您系统里不是本来就有NPC吗？把它们的名字换成真人的ID，不就行了？”

长桌旁，瞬间陷入了死寂。系统副官，那些无名的守护者，本就在为这个世界的昼夜更替而默默戍守。而这个人的建议，无异于为这些沉默的兵马俑披上活人的画皮，然后堂而皇之地从真人参与的资金池里，领走本该属于血肉之躯的粮饷。

“它可以帮助世界运行。”陈驰的声音很轻，却字字千钧，“但它替谁做过，做了多久，这些痕迹，必须留下来。”

电话那头爆发出毫不掩饰的笑声，充满了对这种“天真”的怜悯：“陈总，您是真想知道，还是……只想对外宣称，您知道？”

陈驰挂断了电话。他没有因为轻易识破一批粗劣的伪装而感到丝毫轻松。这就像下棋，对手弃掉的几颗死子，往往是为了在更大的战场上争得先手。下一批涌入的虚假玩家，可以做得更逼真，而真正的真人，也可能两人共用一个账号，将有限的席位与基本参与份额五百元的权益悄悄分食。名与实的界限，正在被前所未有地侵蚀。

许知妍的决断，快如刀锋。她亲手将那些已经发出、高歌猛进的增长曲线截图，从全网的渠道上尽数撤回。紧接着，两份措辞冰冷、不带任何感情色彩的更正声明，被同时递交到了两家主要赞助企业的法务部。声明中明确指出，那支尚未形成实质收益权的异常报名大军，已被直接从资金池的测算模型中无情剔除；唯有那些经得起数据与逻辑推敲的真实意向，予以保留。而所有现有参战者已经确权所得的收益，则壁垒森严，不受这场虚假洪流的任何牵连。

罗振业的电话，像一柄裹挟着怒意的重锤，轰然砸了过来：“我已经把那条昂扬的增长曲线报给董事会了！”他的声音在听筒里因为愤怒而微微变形。

“那就请您，把这份更正声明一并呈堂。”许知妍的声音干脆利落，像冬日里碎裂的薄冰。

“等你们内部先把这笔糊涂账查清了再撤也不迟！现在这是自乱阵脚！”罗振业几乎是在咆哮。

许知妍垂下眼帘，目光落在手边那份刚刚被自己签字批准、油墨未干的华丽宣传稿上。它是在她连续熬了两个通宵后，由市场部满怀希望地呈上来的。那条陡峭攀升的用户曲线，美得几乎能让人心甘情愿地沉沦其中，相信通往生机的大道已然铺就。

“那张虚高的图，用的是我亲自批印的口号与口径。”她的语气森寒，没有半分退让的余地，仿佛一位清理门户的掌门人，“如今，要亲手戳破这镜花水月的假象，也必须由我来。”

傍晚时分，筛查工作又撞上了一堵新的高墙。一位受邀前来工坊参与封闭测试的成年报名者，她的操作方式极为特殊：全程使用屏幕朗读软件与一个硕大的实体按钮进行交互。工具自动读出任务简报与选项，她只在关键的抉择点按下按钮，做出输入。这套操作的节奏，与一批被标记为高度可疑的自动代理脚本惊人地相似，因此，她的账号在第一时间被系统拦在了门外。

陈驰征得了对方的同意，调出了她的演练录像。在幽暗的屏幕上，他静静地重看了一遍。她没有选择系统推荐的最短路径，在听到桥头传来的火力警告后，她的光标停顿了足足三秒，然后先向虚拟队友发出了确认信号，再控制车辆缓缓退回掩体。这一个“退”的动作，恰好偏离了所有机器代理预设的攻击或规避模型。操作者在随后的沟通中解释，自己的视力不太好，在工坊安排的两次测试里，她都是这样操作的。

她的真实意向被恢复。系统档案里，关于她的工具用途被清晰注明，那条错误的标记被追加了一条措辞严谨的更正说明。她的联系方式，则被加密封存，只留给拥有最高权限的必要核验人员。

陈驰静静地看着屏幕上那页冰冷的更正记录，心中却波澜起伏。他想起了刚才那扇险些对一位真实玩家永久死锁的大门。在这虚拟世界里辨明真伪，便如同江湖中辨认一柄绝世名剑。绝不能因为剑鞘的形制有几分相似，便将执剑之人一并诛杀。关键，是要看这一剑的剑招，是由谁的心志所发，那一道剑气，是如何遇强则强、遇弱则收，而不是先去苛求一种世俗眼中所谓“漂亮标准”的握剑姿态。

方婉音询问，能否将这段明辨真伪的公案全网公开。那位玩家同意了，但有一个坚决的请求：绝不暴露自己的真实姓名。于是，平台最终只如实刻录了这场不见血刃的交锋过程，没有将她的面孔与遭遇，变成装点“平台伟光正、高效纠错”这面门楣的廉价物料。

夜色渐深，那条曾一度冲上云霄的增长曲线，无声地落回了它本来的低谷。杜启航坐上自己刚修好的椅子，用力晃了晃，稳如磐石。按照研发测试服务约定到场的几位测试员，已经做完了当天的工作，他们各自的测试报酬，分毫不差地记在了研发项目预算的账下。有人还想留下多演练一会儿，陈驰明确告知，这一段纯属自愿练习，平台不再收取任何任务成果，自然，也没有任何额外的收入承诺；下一次有偿邀请，仍须另行正式确认。

陈驰回复完刘景和关于复核时间的最后一条消息，伸手关掉了那个不断跳动、撩拨人心的报名总数显示窗口。

在正式战区的一角，夜幕之下，一名系统副官依照它自己的名字——“哨兵07”——从指挥中心接过了新一轮的巡逻任务。它没有伪装成任何一个真实的人类ID，也没有在那个记录着每一笔真实付出的账本上，伸出另一只不属于它的手。
