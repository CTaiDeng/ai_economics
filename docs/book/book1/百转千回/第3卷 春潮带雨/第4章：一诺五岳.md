# 第4章：一诺五岳

五月中旬的空气已经有了夏日的黏腻，工坊里却因为服务器集群的恒温空调，弥漫着一股深冬般的寒意。杜启航走进来时，身上还带着医院消毒水和室外燥热空气混合的复杂气味。他将一沓钉在一起的预约单放在黑胡桃木会议桌上，那雪白的纸张与厚重的木色形成刺眼的对比。每一张都印着他孩子的名字，以及一连串他看不懂，却足以让他心惊肉跳的医学术语。

“孩子需要治疗，还得有人陪着。钱，家里能凑出来，但时间……我没法两头跑了。”他的声音很平静，却透着一种被巨石碾过的疲惫。他目光扫过众人，“我负责的基础模块已经交付。新加的那个无人接管区域推演，我做不完了。这周就是贡献权益确认会，我不想拖着。”

他顿了顿，像是做了个艰难的决定，用一种近乎斩断后路的决绝语气说：“我先把这批收掉。”

林静薇什么也没说，只是从文件柜里找出年初那份用血色印泥盖过章的协议。她翻开，指尖点在交付条款上，那上面白纸黑字写得清楚：约定的交付范畴是身份、控制权与物资在各层之间的连续性。新增的需求，那些后来因为信任与默契而追加的任务，并未写在里面。绝不能因为大家已经习惯了倚重他的算无遗策，就在这清算功过的关头，将情分长成新的门槛。

杜启航拿起一支签字笔，笔尖的金属寒光一闪。他没有去碰那份股权确认书，而是俯身在一张空白的A4纸上，开始书写交接的“心法”。他的字迹清隽而凌厉，仿佛在刻一座碑。他列出一处必须时刻留意的凶险情形：高层指挥员为应对战局突变，临时接管前线某个空缺席位时，其原有的指挥席位，必须强制交由权限池内的另一名真人，或是一个预设逻辑的NPC托管。

“绝不能让两个控制入口，同时等着同一个人的下一条命令。”他一边写，一边用笔尖重重地点着纸面，发出笃笃的声响，“否则，在那个时间窗口里，究竟谁该为战损负责，这笔账，就成了永远算不清的烂账。”

顾承安默默接过那张写满字的纸，纸上还带着杜启航指尖的余温。他没有说话，转身回到自己的终端前，在沙盘演练环境中，将这个场景走了一遍。指挥权被强制交出，战况摘要如常返回，但那个接任者的选择列表里，杜启航的名字已经变成了灰色。他再也无法像过去那样，从另一个上帝视角的窗口，悄无声息地替继任者改掉一个看似愚蠢的决定。

这一剑，斩断了过往所有的牵连，却也让顾承安感到一种如鲠在喉的窒息。他看见自己在这个杜启航设下的死局里，用了一条截然不同的路子突围——一条在他看来充满破绽、近乎自杀的险路。他几乎是本能地想开口，想拔剑干预，想告诉他那一步棋的后续变化有多凶险。然而，话冲到嘴边，却又被他生生咽了回去，只化作喉结一次沉重的滚动。

那条陌生的剑路，有它自己的生死考量。接下这副重担的人，必须清楚地知道，他握在手里的，究竟是生杀予夺的无上大权，还是前任掌门留下的一具处处受制的牵线木偶。

杜启航修长的指尖在桌沿无声地痉挛了一下，指甲因用力而微微泛白。那感觉，就像在十九路棋盘边观棋，眼睁睁看着对弈者漏算了一处致命的气口，恨不能当场越俎代庖，替他补上那决定生死的一手。可最终，那份冲动还是被他以绝大的克制力生生收住。那条生路，未必合乎他惯用的星位布局，但这一局惨烈的残棋既然已当众交出，那么接过帅印的人，就该有权在悬崖边，砸下属于他自己的第一颗落子。

随后，陈驰、杜启航与方婉音，这三位自草创之初便投身其中的元老，他们的贡献契约被逐项进行近乎严酷的验收。桌上，三份文件并排摊开，每一份都沉甸甸的。五名金主投入的两百万元真金白银，与他们三人呕心沥血的开宗立派之功，泾渭分明地摆在那里。前者是攻城拔寨的粮草，后者是开疆拓土的刀剑，各有其不可逾越的来路与归途。这八名合伙人，绝不打算靠一句轻飘飘、廉价的“兄弟同心”，去强行抹平彼此早已用契约画押的楚河汉界。

“我再确认一次，”方婉音的声音清冷而坚定，她的指尖划过合同中关于知识产权的条款，“我投入的是协议附件中明确列出的作品使用权，这绝不意味着我此后所有的个人创作，都将无条件归于公司名下。”

“我的现金报酬，”陈驰则点开笔记本电脑上的财务报表，核对着一笔已到期的款项，“我愿意用我的那份功劳承担股份的风险，但这不等于我今天应得的工资，也只能画成一张未来的大饼，等着虚无缥缈的估值来兑现。”

会议桌的另一角，还放着一本独立的参与者结算簿。许嘉榕贡献代码获得的一千五百元，刘景和提供第三方复核服务应得的款项，以及最新一次“海岬窗口”任务中所有参与者的报酬，都清晰地列在上面。这些账目，与公司此次的股权登记毫无干系。将来即便引入滔天资本，也不能再把这些已经明明白白归于别人的钱，拿回来重新摆上谈判桌。

程砚舟看着这森严的壁垒，忽然开口提议：“未来工坊若有了结余，我建议，可以优先全部放进公共预算，用于生态建设。”

“优先分红可以谈，但要让所有人把自己的血汗钱永远、全部留在公中，那是另一桩霸王买卖。”顾承安的声音像淬了冰，冷冷地截断了他的话，“有人在这里砸下了真金白银，有人扛着被整个江湖围剿的风险立下了汗马功劳。这绝不代表，大伙儿从今往后就只能当牛做马的苦力，永远只有往里贴钱的义务，没有分毫取走的权利。”

一句话，如同一记重锤，狠狠砸在程砚舟心头。他猛地回想起离开霁岳山门时，那些劈木断金、与旧日恩怨一刀两断的豪言壮语。他骨子里厌恶资本用分红这种虚伪的仪式来为它们的罪恶洗地，却在转瞬之间，差一点又亲手将“断绝红尘钱财”这条霁岳的清规，变成了逼迫同道画押的变态门规。

他脸上露出一丝自嘲的苦笑，提起桌上的朱笔，在那份草案的“全部”二字上，划下了一道血痕般的叉。他转头，用一种前所未有的严肃口吻对周慎衡说：“重拟。固定报酬、风险回报、山门公中留存，以及成员自愿捐献，这四条，必须给我列出森严如铁的铁律，分毫不爽。”

桌上原本放着三份制度草案。

第一份，只公开收支流水，却仍将所有的创作与协作成果笼统地记在组织名下，个人在其中拿不到任何可独立执行的请求权，像个空头支票。

第二份，最为激进，试图将工资、作品许可、场次收入等一切现金流，全部折算成平台的股份，用一个虚幻的未来绑架所有人的现在。

第三份，则保留了现有的工资、产权、税务与银行结算体系，只在此基础上，补上本次事件中失灵的个人贡献登记、独立的分配合同、第三方复核机制，以及必要的法律责任安排。

他们逐项核过在实际运作中对每一条的依赖程度，最终选择了第三份。新增的核验流程确实要付出额外的成本，但那些原先一直正常运作的现金工资体系，却无须为了一个理想国的幻梦而陪着一同推倒重造。这个选择，仅仅是在眼前三份可实施的草案中，做出了改动最小的那个。往后若有更好的办法，依然可以重新比较；其他组织，也可以继续采用他们自己的固定报酬、合作分成或任何合法的合同，不必先对天发誓，宣称旧有的一切都一无是处。

程砚舟亲手将那份充满理想主义、却也浸透着专制剧毒的第二份草案，扫进了桌下的废纸篓。碎纸机发出沉闷的轰鸣，将那些美好的词句撕成无法辨认的碎片。他想，当年反出霁岳山门时，挥剑斩断所有牵绊固然痛快淋漓；可如今，要在这通缩时代的凄风苦雨里，亲手撑起一方能为众人遮风挡雨的新屋檐，就必须冷酷到毫无人情地认清：旧朝代的殿堂里，哪些大梁已然朽烂如泥，而哪些只是沾满了灰尘，却仍能在暴雨中替活人挡住刀剑的柱子。

临行前，杜启航走到机房门口，将那把沉甸甸的黄铜钥匙，压在了门禁系统下方一个约定的凹槽里。他没有说一句“有事随时找我”之类的客套话。江湖规矩，必要的求援他会回应，但这绝不意味着他会再纵容自己，默认在那间冰冷的病房陪护椅上，还锁着一个被工坊的公事抽打得不敢合眼的同袍。

那枚黄铜钥匙落在金属凹槽里，发出一声冷脆的撞击声，清澈得像冰面裂开的细响，瞬间刺穿了机柜风扇永恒的低吼。

这声轻响，让程砚舟霍然抬头。他想起昔年与兄弟们结伙闯荡江湖，谁都爱在酒酣耳热之际，把“赴汤蹈火”这四个字喊得震天响。可到了真正要践行“一诺五岳”的时刻，他才发现，这世间真正的义气，不是说出来的，而是做出来的——是当你看到同伴将一座千斤重担砸向你时，你必须死死地、纹丝不动地接稳了，好让他能卸下这半座工坊的生死存亡，独自去面对那间比江湖更冰冷的病房。

许知妍看着杜启航的背影消失在门口，拿出手机，给丈夫发去一条消息：“周末复诊我带孩子去，资料我晚上看，你不用再给我列清单了。”

对方隔了很久，久到她以为信号断了，才回过来一句：“时间确定了吗？”

她把日程截图发了过去，也同步在合伙人群里知会了一声，自己那半天不在。手机屏幕上，她负责监控的那个“海岬运输队”数据流，在短暂的交接后，换过了一次控制人，却依旧沿着原定的道路，分毫不差地继续向前行进。

换人，没有令这趟漫长的远征半途重来。
也没有让前一个人，为此欠下整整一夜的不得安眠。
