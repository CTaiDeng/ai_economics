# 第5章：龙蛇成阵

五月末，京城的天气像个翻脸无情的赌徒，前一日还熏风和暖，转眼便被一场倒春寒打得万木凋零。冷雨敲打着星原数据中心十二楼会议室的落地玻璃，模糊了窗外灰蒙蒙的天际线。室内，中央空调的暖风安静地流淌，却驱不散空气中那股无形的、因利益交锋而生的寒意。

会议室里，黑胡桃木的长桌光可鉴人，倒映着天花板上冰冷的矩阵灯光。桌面上，星原平台那不断滚动的报名页，第一次被挤满了一整屏，像一张徐徐展开的、群雄逐鹿的古战场地图。

海岬的攻防战火，已从线上烧到了这张会议桌上。每一条滚动的申请，都代表着一方势力的野心。有的组织开出高价，只为招募在虚拟战场上双手沾满鲜血的熟练前线队员；有的则更像开山立派的宗师，愿意花费心血，手把手带新人完成最基础的通信与运输交接。相邻的窗口，价格与名额天差地别，更有不为钱财、只为义气的散人玩家，申请完全自费，只求能与三五兄弟，在虚拟的冷雨夜里，一同守一晚仓库。

星原平台将共同的规矩——那冰冷的、由代码与法务条款铸成的铁律——摆在入口最显眼的位置，却并未试图用一刀切的霸道，去统一所有人的趣味。这方天地，既要有阳春白雪，也要容得下下里巴人。

岑绍庭就是在这龙蛇混杂、群雄并起的当口，如一棵姿态嶙-峋的古松，撞进了这间充斥着现代商业气息的玻璃盒子。他穿着一件洗得发白的旧中山装，腋下夹着的，仍是那本在老城破败棋社里用了多年的、满是油污的手写册子。他身上有股挥之不去的、老棋盘上松木与烟丝混合的味道，与这间屋子里的咖啡香气格格不入。

当他将册子“啪”地一声放在光洁的桌面上时，程砚舟的目光如鹰隼般锐利，瞬间便锁定了那册子卷边的折角处，一道被老式机械棋钟的金属底座重重砸出的、深入纸页纤维的陈年旧痕。那是一个时代的烙印，是无数次黑白子在十九路棋盘上惨烈厮杀、时间在旁无情流逝的见证。

岑绍庭翻开册子，指节粗大，动作间却透着老派裁判不容置喙的规矩。册页的第一行，写的不再是“棋手某某对弈散人某某”，而是带着硝烟与海风咸腥味的八个字：“港北潮汐站，双方各八人”。

他骨子里，还带着手谈对弈的执拗。他给红蓝两边各留出了一道雷打不动的边栏，字迹工整，连为变数预留的空处都死死保持着绝对的对称。办了半辈子棋赛，他最怕的，不是棋逢对手的惊心动魄，而是在十九路棋盘上，只剩下一边倒的屠杀与陪衬。若无一个能与你杀得天昏地暗、血溅五步的旗鼓相当的死敌，那纵然你下出惊天动地的妙手，在这凄清的江湖里，又有谁能真正接得住？又有何意趣可言？

“连溃败的守方，也能分这笔参与池里的银两？”宋振峰皱起了眉，他的问题像一把精准的手术刀，直指这套规则的核心。

“当然。”岑绍庭粗糙的手掌在那本旧册子上重重一拍，发出沉闷的响声，仿佛敲响了棋钟。“若没有对面死战不退的守军，攻过来的人算什么英雄？不过是一群在空旷舞台上哗众取宠的戏子罢了。这盘棋，就成了死局。”

他申请的，是一个已获批准的战役窗口。夺取潮汐站，将永久性地改变海岬区域的抽水与货运条件，这不是一场打完便能为下一场广告复位的儿戏。他的方案里，两方各自接管已有单位，新增的补给则来自更高层级的中央仓库。那些未被真人玩家占据的位置，将照常由系统NPC填充，他明确规定，组织者不能为了凑一个漂亮的真人数量，而将这些关键的“官子”随意替换。这是对战局最起码的尊重。

窗口之外，他额外安排了三个有偿的复盘岗位，专门负责在战后解释：现场信息是如何在炮火与嘶吼中传递的？哪里的判断出现了致命的偏差？哪些看似无法挽回的损失，其实本可以避免？

他提出的财务模型，如同一盘精妙的棋局。十九名参与者的基本参与份额先行锁定，确保人人有份；而那笔更大的差异份额，则再按照各自的岗位贡献进行分配。他用这种方式，立下了一道规矩：绝不允许排名前三的“大龙”，将其他散落的“棋子”从账面上彻底抹去，赶尽杀绝。

“报价？”凌拓言简意赅，他习惯了用钱来衡量一切。

“八千元。”岑绍庭说。他用手指在册子上划定了一个清晰的边界，给宋振峰看：“这次的范围，只包括潮汐站当场的行动，以及那三份复盘。不包含二月首期试验时，那种长达整月的内容使用权与深度回访。报价、参与池和基本份额，都按这一场重订。所有规矩，白纸黑字，报名的人必须先看个通透，再做选择。”

宋振峰又问：“能保证多少观众？”

岑绍庭的回答，像是一招朴实无华的本手：“我能交付的，是这套安排。真实到场的人数，事后可以逐一核对。但人心向背，人愿不愿来，恕我不能打包票。”

桌子的另一头，东瀚公会的会长蒋克己，则代表着另一种截然不同的气魄。他申请了港口主货场的更大窗口，准备让两支各十六人的精锐队伍，如两柄重锤，正面碰撞。他背后的金主“极轴”，更是直接拍出了两万元的预算，打算邀请知名主播，做一场声势浩大的延迟转播。他追求的，是星位开局，抢占大场，气势上先声夺人。

巧合的是，两家推广的，是同款机械键盘。同样的规格，同样的价格，同样的保修条款。每一件，售价均为五百元。而按本次星原平台统一口径核算的生产、履约、税费等非注意力成本，则均为四百元。键盘的键帽上，印着两家截然不同的商标，但拔下键帽，底下绝没有一套特意为哪家准备的、性能更优越的零件。

“那我砸下去的真金白银，拿什么来保证回报？”极轴的代表罗振业终于忍不住了，他咬紧了牙关，声音里透着资本最原始的焦虑和暴躁。这就像一场豪赌，他押上了万贯家财，却看不到一丝稳赢的迹象。

许知妍一直沉默着，此刻，她面无表情地提起一支万宝龙金笔，在那份由蒋克己提交的、措辞华丽的提案上，将那句妄图逆天改命的“预期收益保证”狠狠划去。一道浓黑的墨迹，如一道无法逾越的深渊。她的眼神冰冷如铁，内心却有一段独白在燃烧：在这片混乱的江湖里，顾客可能因为你这场血战记住你的名号，也可能转头就投入另一家更便宜的怀抱，更可能的是，他们会捂紧自己干瘪的钱袋，根本不为你的任何表演拔一毛钱。流水线上的死物固然能无限增产，但这绝不意味着——只要你把活人像牲口般圈禁到屏幕前，销售的奇迹就会如约降临。

凌拓一度仗着财大气粗，妄图更进一步。他想买下星原公共入口的排他性霸王条款，让所有流量都汇入东瀚公会那条波涛汹涌的大河。这无异于一招“化功大法”，要将其他门派的内力悉数吸干。

林静薇出剑了。她的声音不高，却如出鞘的利剑般清冽：“凌先生，请把手缩回去。”她轻轻一点，将话题引回岑绍庭那场已划定清晰边界的观看服务里，“这点买路钱，买不到沙盘上的虎符。星原的规矩是，绝不容许资本的黑手，遮断其他门派的生路，更不可能让你卑劣地用钱，就让对面的阵营在开战前凭空少掉一队精兵。”她的姿态，渊渟岳峙，正是武当太极以柔克刚的精髓，四两拨千斤，将凌拓那汹涌的攻势化于无形。

岑绍庭仔细看过东瀚那份排得密不透风的流程表，只问了蒋克己一个问题：“如果一个刚来的新人，看不懂你们那支潜伏的地下小队为何迟迟无法突破，他能在哪里提问？”

“有回放。”蒋克己的回答干脆利落，带着大公会长的自信。

“回放的时候，能问到当事人吗？问那个在地下通道里苦苦挣扎了十分钟的队长？”岑绍庭追问，他的问题像围棋里的“刺”，直指对方阵型的薄弱处。

蒋克己翻到流程表的末尾，指着一处说：“以后可以补。眼下，先把大场面做起来。”他已经把观众能看到的每一段空隙都用广告和精彩集锦排得很满，不愿再为了几个散兵游勇的“为什么”，去打散自己精心营造的、一往无前的节奏。

两笔钱分别到账，八千元与两万元，分属两份独立的合同，被锁入各自的信托账户，井水不犯河水，绝没有混成一个可以随时挪用的总奖池。岑绍庭拿到了活动许可，但他仍须遵守平台的军法：组织能力和战场指挥能力，是两种需要分别证明的本事。

他提起笔，将自己的名字稳稳地落在了“组织者”的一栏。而那张象征着战役主帅的虎皮交椅，却如一局收官阶段的残局般空悬着，静候着真正的高手前来落子，歃血为盟。他能在江湖上广发英雄帖，约来各路悍将，却未必有足以震慑群魔的本领，亲自替他们提剑领阵。这位老派的裁判比任何人都清楚，通向胜利或死亡的那道沉重闸门，究竟该由谁的白骨去推开。

深夜，万籁俱寂。许嘉榕在宿舍的电脑前，看到了岑绍庭那份古朴的复盘英雄帖。她犹豫了许久，终于用鼠标在那份英雄帖下，画上了自己的押。

她没有附上战绩，也没有豪言壮语。她只是把自己在一次惨败的通信席上，死磕了三天三夜后，仍百思不得其解的一段锥心迷局，附在了帖子后面：

“在那张喋血的沙盘上，明明图纸标注的两个方向都叫‘后门’，为什么……为什么只有那条铺满了友军残骸的路，才能让沉重的补给车，碾过去？”

黑暗中，岑绍庭的屏幕亮了。他看着这个问题，仿佛看到了一块顽固的劫，一个看似无解的生死难题。他敲下了一行回复，字字沉稳：

“先把这个沾满血污的问题挖透。不用急着像个狂妄的看客般，去给整场绞肉机般的战争，轻易地下一个结论。”
