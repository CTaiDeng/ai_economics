# 第2章：灯前试剑

当罗启锋用指节“啪”地一声敲下回车，将直播间那惨白空洞的标题替换为“今晚找回这条路”时，那个ID名为“守夜人”的对手，头像已然灰暗下去。一行系统提示冷漠地悬浮在公屏上：用户已离线。

聊天频道里，猜测的暗流正在汇聚成涡。有人言之凿凿，说这守夜人必是平台内部请来镇场子的高手，一招一式都带着官方喂招的匠气。毕竟，陈驰公开演练的这套系统，从规则宣讲、初始资源配置，到双方获准向观众展示的战争迷雾视角，一切都严谨得如同法庭呈证。没有真实姓名，没有背景故事，更没有一份合约替任何人担保下一场的胜负。

第二天，北京时间晚上九点整，守夜人的头像准时亮起，分秒不差。他通过了身份验证，ID下方浮现出一行细小的真名：关振海。资料里只有一句话：前龙门重工第十七车间，高级机械装配师。这个职业烙印般地刻进了他的骨头里。他习惯在拧上任何一颗螺丝、接通任何一根线路之前，用游标卡尺般的眼神问清每一处接头通向哪里，承载多大的扭矩。这个习惯曾无数次在千钧一发时救下整条生产线，也曾让他错失过无数个需要凭直觉豪赌的先机。昨夜，罗启锋只见识了前者。

今晚，棋局再开。罗启锋的杀意凝练如冰。他不再像昨日那般直冲中宫，而是先行手筋，压住对方视野所及的一座高架灯，只一枪点爆了灯泡，让一大片区域瞬间沦为伸手不见五指的黑暗。几乎就在枪响的同时，他早已埋伏下的队友，如鬼魅般沿着黑暗的掩护，悄无声息地绕向大堤之后。

关振海的应对，依然带着机械师的沉稳与固执。他像是在等待一道严丝合缝的指令，全部注意力都集中在那片被正面火光照亮的战场，计算着对手从正面突破的每一种可能。直到他那辆负责运输核心器材的卡车，左前轮胎被一发精准的子弹撕开，发出一声沉闷的爆响，整辆车狼狈地朝一侧倾斜下去时，他才悚然一惊，意识到对方的主力早已暗渡陈仓。

他立刻下令，声音在通讯频道里没有一丝波澜：“全体后撤，固守三号闸门。”但终究是慢了一线。仓促的转移中，三箱标记着高价值的器材，有两箱永远地留在了那片泥泞里。

“这江湖里，哪有人能一直赢。”通讯器里传来关振海冷得掉渣的一句话，带着一丝电流的嘶嘶声，像一句勘破生死的谶语。

罗启锋原以为，昨日撞见的是一套如“独孤九剑”般无招无解的绝世剑谱，每一剑都直指自己体系的破绽。可今夜再度近身相搏，他才发觉，这根本不是什么剑谱。对方在迷雾中，同样要依赖冰冷的数据和概率的算筹去猜测自己的动向，同样会在意想不到的地方被破去罩门，同样会鲜血淋漓。然而，正是这份发现，让他血管里那股嗜血的兴致被彻底点燃，愈发狂烈：活人的招式，是会随着对手的杀意而变阵的！昨日那记刺破自己咽喉的惊艳诡剑，今日在这纵横十九路的沙盘上，已然演化出了截然不同的狠辣来路。它不再是神坛上的圣经，而是一门在生死间不断进化的活武功。

这一局，罗启锋赢了。但一种前所未有的焦躁攫住了他，让他出奇地没有急着拔剑离场，享受胜利的果实。他将刚才那段带着硝烟与血腥味的复盘录像，像一纸战书般，“砰”地砸到对方面前，在公共频道里咄咄逼问，声线里满是压抑不住的亢奋：“车胎爆掉，这是致命的‘断点’！你为什么不让所有人立刻撤回死守？你的人还在外面，你在赌什么？”

“叫了。”关振海的声音依旧平静，却带着一股不容置疑的精确，“我有一个人，当时正在地下检修室，他要跑到闸门出口，需要穿过整个泵房，耗时至少十二秒。而你的人，已经把闸门外那条唯一的街道纳入了火力覆盖。我的召回指令，不能把战场当作安全的搬家公司。”

两人几乎同时点开了各自的第一人称视角录像，画面在屏幕上并列。罗启锋这才看到，在他以为藏在卡车后方、随时可以撤离的那名队员，在关振海的视角里，当时正身处一个逼仄的地下空间，正费力地为运输车打开一道被淤泥堵塞的排水门。画面里，没有一只上帝之手能伸出屏幕，将他瞬间提回安全区。每一步，都是在罗启锋铺开的死亡棋盘上，小心翼翼地收官。

第三次试剑，罗启锋的剑锋愈发刁钻，他汲取了上一局的教训，变招去死死封锁所有可能的出口，意图将关振海的队伍做成一块“死棋”。而老关则如一条身法滑溜的泥鳅，指挥着残余的车队在迷宫般的街巷里辗转腾挪，不断做出匪夷所思的小范围变向。双方在这片数字构成的泥潭里，耗尽了最后一颗子弹，流尽了最后一滴虚拟的血。终局之时，谁也没能按自己最初预演的那套绝杀谱赢下全盘，棋盘上形成了一个罕见的“双活”僵局。

他们停在灰败的战绩结算页上，谁也没有说话。空气仿佛凝固了。随后，两人几乎是不约而同地，在频道里像两头红了眼的公牛，用夹杂着战术术语和坐标代码的语言，激烈地争论了整整十分钟。最后，他们破天荒地达成一致，一起打开系统日志，去逼问那名负责分发指令的AI通信员：那条决定生死的改道指令，究竟是在服务器时间的哪一个纳秒，被哪一个网络节点接收，又因为百分之几的丢包率，产生了致命的延迟？

两个人，像两个痴迷于棋谱的疯子，把沙盘上那条九死一生的迂回路线，用鼠标拖动着，放大、缩小，看了又看。罗启锋的额头渗出了冷汗。他终于明白，在这十九路的巨盘之上，你若想强行争得一处出口的“厚势”，必然会导致棋盘上别处的“星位”瞬间变得“薄”弱不堪。过去，他只像个一味猛冲的莽夫，执迷于如何抢出那惊世骇俗的第一剑，讲究一击必杀的“先手”之利。可现在，他却不得不像个最谨慎的账房先生，在出剑之前，冷汗涔涔地算清：自己抢下这凶险无比的一手之后，身后那空门大开、岌岌可危的半壁江山，究竟还能不能照应得过来。

看客们早已为罗启锋最初那招熄灯佯退的诡剑，起了个响亮的江湖诨号——“借灯看路”。许多人以为这是某种氪金就能买到的必杀技，在论坛里四处求购。罗启锋却在直播里对此嗤之以鼻，用一种近乎残忍的清醒戳破了这层幻想：“灯的亮灭，不过是沙盘上随机生成的一处环境‘气数’。这名字，只是我们拿命趟出一条路后，叫顺口的代号罢了。一旦这层窗户纸被对手看穿，原来的剑法，就会立刻沦为送命的破绽。”

一名新来的玩家在弹幕里问：既然机器的算力那么强，能算出更稳妥的路线，为什么还要看着你们犯错？

关振海没有直接回答。他只是默默打开了系统的战术演示工具。果然，AI基于全局信息，瞬间生成了一份规避了所有风险、堪称完美的行动方案。但在下一场模拟推演中，他的一名队友，因为网络波动，战况报告晚了整整七秒。就是这七秒，让AI方案里最关键的那个时间窗口，那个作为一切后续推演基础的前提，如泡影般消失了。

“我想知道，他这一回，会信那份完美的方案，还是信我这个会犯错的人。”罗启锋盯着屏幕，声音低沉，像是在对自己说，“我也想看看，我下回，还会不会那么急。”

风声已经传开。“极轴资本”与“凌拓科技”的商务代表几乎同时发来了合作问询，询问能否为他们的对决开设一个正式的商业化窗口。一时间，基本参与份额、组织服务费、高清观赛权都有了初步的报价单。一份草拟的合同里清晰地写着：基础参与份额五百元，胜负双方将根据表现从七千元的差异池中获得浮动奖金，同时设立“生态奉献激励金”以奖励对系统漏洞和战术创新的贡献。但所有条款中，最醒目的一条是：任何投资方，均不因此获得指定或影响任何一队胜负的权利。

机器可以生成无数个顺畅无误、效率最高的执行片段，但人们真正愿意掏钱，愿意屏息凝神去看的，却恰恰是这些已经见过彼此最狼狈的失误、最致命的弱点的人，在下一次交手时，将如何应对。

剪辑室里，方婉音正在整理这几天的录像。她戴着降噪耳机，将一段关振海在私人频道里接听家人电话的音频精准地切除。那句带着疲惫的“今晚可能晚点回”，与这场冰冷的数字战局无关，被她归入隐私素材库。但与之相关的所有战斗事实，从他那一瞬间的决策分神，到操作上的微小迟滞，仍由最原始的系统记录完整保存。授权公开展示的英雄故事，与可供复核存证的冰冷事实，不必共用同一个传播范围。

客厅里，程砚舟看得入了神。小溪抱着一堆卡纸和胶水，从楼梯口探出小脑袋叫他：“爸爸，周末的纸桥展示，老师要我们今天报上尺寸了。”他下意识地应了一声“来了”，但手指还停在回放的进度条上，眼睛死死盯着罗启锋那个惊险的侧翼穿插。女儿没有催第二遍，只是默默地抱着材料，坐在楼梯上等。

一种微小的刺痛感让程砚舟猛地回神。他锁上屏幕，屏幕暗下去，映出自己一张疲惫而陌生的脸。他上楼，坐到女儿旁边，空气里有手工白胶淡淡的酸味。小溪只需要他帮忙扶稳一根作为主梁的硬纸筒，她没打算把整个制作过程都交给他。但他知道，自己差一点，就又让她为自己的一个“稍后”，空等了整整一个晚上。

城市的另一端，工坊明亮的灯光下，许知妍也被一个电话拖过了晚上九点。电话那头，丈夫的声音听不出情绪，只回了句“知道了”。在过去，她会把这三个字当作默许，但今晚，她第一次没有将它理解成“没有代价”。她挂断电话，立刻在协同软件上把明晚的工作指派给了值班的同事，并在日程表上用红色加粗标明：已交接，勿扰。

夜里的海岬，依然有人在虚拟的哨位上值守。罗启锋打完了最后一局演练，退回到主界面。系统弹出一个确认框：【是否确认结束本次控制？】他没有立刻点击，而是先核对过队友的ID已经进入接续状态，确认了指挥权平稳交接，才摘下那副几乎要长在头上的战术耳机。

一个世界能不眠不休地运转下去，不该是靠着让每个人都永远舍不得下线。他想。
