# 第10章：一枰分晓

七月流火，会议室里的空气却凝滞如冰。

那两万四千元经营留存，被周慎衡用一张冷冰冰的单子呈在黑胡桃木长桌中央。数字本身没有温度，却像一小堆炭火，在众人眼中烧灼出不同的光。有人按捺不住，声线里带着一丝贪婪的亢奋，提议将这最后的火种悉数投入下一个参与池，毕其功于一役。

程砚舟没有立刻接话。他的指节无声地叩击着桌面，每一次落下，眼前便浮现出一幅幅具体的图景：海岬那座被风暴撕开巨大豁口的仓库，铁皮在咸湿的海风中哀鸣；双桥那条被泥石流冲垮的路基，至今仍是乡民心头一道未愈的伤疤。还有那些隐在公开窗口之外的成本，服务器的电费、人员的薪水、乃至一杯提神的苦咖啡，世界从不会因为品牌方暂时停止注资，便自动定格在一个无需开销的完美画面上。江湖的运转，每一刻都是真金白银的燃烧。

“先认清这些钱。”周慎夕的声音不大，却像一把淬了冰的刻刀，将所有不切实际的幻想从众人脑中剔除，“这是六月的结余，仅此而已。它不等于累计的亏损已经填平。所以，暂不作股东分红。何时具备分配条件，要看账，看我们当初立下的规矩。至于那些已经确权的参与款，那是别人的血汗钱，更不在此列。”

他的话语冷静得近乎残忍。他们像一群经验最老到的外科医生，围着一具濒死的躯体，精准地剖开肌理，芟夷出最低限度的吊命预算、下一轮浴血奋战必须抢下的窗口，以及那些无论多么可惜，都必须舍弃的“景观”。程砚舟原想仗着这口气，一剑劈开内陆三处胶着的战区，可当他的目光扫过那份薄薄的账本，指尖触到那冰冷的数字时，他只能咬碎牙关，将其中两处绝地的攻伐计划，生生划回到沙盘的纸面推演之上。

那些沙盘上的恩怨与棋形并未被抹去，只是在干瘪的钱袋面前，暂且容不下真人去前线填坑送命。这就像一场惨烈的围棋对局，为保大龙安活，不得不弃掉边角几颗看似重要的棋子。弃子争先，是不得已，也是求活的唯一正解。

周慎衡把账面上抠出的这两万四千元做了死记号，用红笔在旁边标注了每一笔预期的用途，没有虚伪地画上一把能护住整个江湖的保护伞。这就像亡命天涯的剑客，临行前死死捏在手心里的几块碎银，只够用来修补断裂的剑鞘、编织磨破的草鞋。它勉强能让下一次拔剑时，手腕能更稳一分，却绝不意味着，谁能就此躲过下一场席卷天地的凄风冷雨。

杜启航的脸冷得像一块铁。他一字一顿地说道：“我宁可断尾求生，少开一条战线，也绝不能今天仗着别人的血汗钱，在江湖上吹嘘这把火永不熄灭，明天转头，就把修补残局、收拾烂摊子的要命差事，无耻地砸给那些愿意为我们死守山门的手足兄弟！”

话音刚落，山门便被叩响了。

午后的阳光斜斜地照进来，给来客镶上一道金边。崇远资本的陆文渊，就是踏着这道金光走进来的。他不像其他金主那般，急着去看沙盘上最血腥热闹的战报，去听那些激动人心的捷报。他像个行走了三十年江湖的老辣捕快，目光如鹰隼，不看花招，只盯要害。他的问题刀刀见血，直逼命门：

“一旦品牌的粮草全部断绝，那些已经在火线上接管了阵地的死士，他们的赏银，是否还有着落？你们这片江湖的吊命气数，到底还能撑多久？若真到了树倒猢狲散的那一天，这些带血的宗卷，以及眼前这副十九路的残局，最终的归属权，该怎么分？”

程砚舟的视线从那张充满诱惑的资金意向书上缓缓移开，那上面的数字足以让他们把刚刚划掉的两处战区重新点燃。但他最终望向的，是墙上一幅巨大的电子屏，上面滚动着每一个火线人员的名字，以及他们未卜的生死。背后多靠上一座金山，当然能让这十九路棋盘上的步子走得渊渟岳峙，从容不迫。可若代价是拿所有兄弟下一次拔剑的自由、下一次选择战场的权力去抵押，那份高高在上的从容，便只剩下资本家在幕后独自把玩的冰冷棋子。

周慎衡面不改色，仿佛早已料到此问。他没有辩解，也没有描绘蓝图，只是静静地拍出了底牌。他将那份预留的吊命资金明细、每一笔带着契约的赏银支付路径、以及那条一旦触及便会壮士断腕的熔断红线，一笔一画，如同在棋盘上落子般，分列在陆文渊面前。那不是一份乞求，而是一副带刺的铠甲。

陆文渊的目光在那副铠甲上仔细检视了许久，确认了每一根尖刺的硬度，才终于开出了他的价码。

“可以投你们的底层公司，也可以只承担你们某几场行动的前期风险。两种方式，我要看的回报不同。”

“请分别列出条件。”林静薇的声音清脆而坚定，像是在这浑浊的商业博弈中，划出了一道清晰的界线。“投资公司，不代表您能取得任何玩家的既有份额；投资单次行动，也不代表您因此拥有了参战者，更没有动用公共储备金为您作默认担保的道理。军阶、勋章，以及下一次的指挥任命权，这些是弟兄们拿命换来的，不能夹在投资回报里一起卖。”

她的每一句话，都是在收官，堵上对方可能侵入的每一个单官。

陆文渊笑了笑，将一个经过精算模型测算出的“稳定”增长曲线，写在了预期收入旁边。许知妍的手指轻轻一点，将那个词圈了出来，红色的圆圈像一个警示。

“六月的战报，只能证明一些交易重复发生过。它不能证明，这些交易会永远按照您画的这条线上升。”

“那再看一个周期。”陆文渊收起了笑容，语气变得冰冷，“如果下个周期结束，你们的运转始终只能靠自己那点原始出资来补贴，我不会一直投下去。”

这句冰冷的算计刺耳至极，却无人能当场反驳。这个吞噬着金钱与人命的新世界，每天都在燃烧着天价的带宽费用、核验人力与维持秩序的粮草。刀口舔血的下注者，本就有权索要带着利息的岁贡。他们真正要死守的底线，是绝不允许把自身算崩了的死局，毫无契押地转嫁到任何一个无辜的替罪羊头上。

或许是觉得气氛过于僵硬，陆文渊换了个话题，却提出了一个更傲慢的要求。他想看一场掀翻整个江湖的惊天大戏，提议道：“能否把岑绍庭、东瀚，还有那个原声社，这几股现在各自为战的势力，强行捏合到一起，做成一季供人消遣的戏码？”

程砚舟的目光骤然变冷，他缓缓转向沙盘。那上面，三路人马正在十九路棋盘的不同气口上各自搏命。这边，岑绍庭的团队正在尸山血海里复盘一次惨烈的遭遇战；那边，东瀚的人马正在连天的硝烟中抢运一批关键的辎重；而在一个不起眼的角落里，原声社的成员们，只愿在风雨中，静静守护那些残存的绝响。

他程砚舟，根本没有权力，只为了让金主看戏看得爽，就把这些用生命落子的侠客，当成牲口一样，强行赶进同一个戏笼里。

“您可以冷眼旁观他们各自的厮杀，也可以单挑其中一个门派去下注。”程砚舟的声音不大，却带着不容置喙的决断。这手棋，是反先。

“包括他们比你们办得更好？”陆文渊的眼神锐利如刀，紧紧地逼视着他。

程砚舟停顿了一下，空气仿佛凝固。然后，他缓缓地，却无比清晰地点了点头。

傍晚时分，陆文渊告辞。

夜幕降临，控制中心的选择页面上，岑绍庭和蒋克己的新方案并排出现。前者保留了核心的问答机制，但主动缩减了网络拥挤时段的规模；后者则大刀阔斧地删掉了战斗中根本无法兑现的固定镜头承诺，重新编排了内部的组织职责。上一次的成功，没有换来永久的席位；上一次的失败，也没有使任何一个人从此失去参与的资格。这棋盘，只认当下的妙手，不问过往的胜负。

在另一个通讯频道，方婉音和许嘉榕为了秋天的声音展争执不下，索性，她们保留了两个截然不同的版本，各自详尽说明了成本与授权的利弊，交由众人公决。

周慎衡在他的工作日志上，将陆文渊的来访记为“洽谈中”，而在“到账”那一栏，依旧是一片刺目的空白。

深夜，海岬的潮声涌入窗内。上一班的指挥员沙哑着嗓子，将未完成的任务清单和敌我态势，交接给刚刚换防的同伴。那座损伤的仓库仍有缺口，但好消息是，潮汐能源站已经恢复了抽水功能。

程砚舟静静地看着屏幕上那份既非全胜也非全败的战局报告，良久，他伸出手，将那只一直压着陆文渊意向合同的空棋罐，轻轻放回了身后的书架上。

而后，他转身离开了灯火通明的控制台，走入身后的黑暗中。棋局未终，长夜未央。
