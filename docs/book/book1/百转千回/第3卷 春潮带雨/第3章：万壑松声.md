# 第3章：万壑松声

风雷原声社的第二次售票，开场前二十四小时，售出率的曲线在后台屏幕上凝固成一道难堪的平线，大半席位都空着，像一片被遗弃的棋盘。

方婉音独自坐在调音台前，幽蓝的辉光映着她毫无血色的脸。她把那段名为“西行”的样片放了又放，第五遍，还是第六遍，她已经记不清。经过她精细打磨的音频里，机器生成的海浪声干净得像玻璃，港口起重机沉闷的低鸣也被柔化到了最舒服的位置，仿佛一头温顺的钢铁巨兽在睡梦中发出呓语。她甚至连战场通信里最细微的呼吸都用算法修掉了，整段撤离听起来，有一种不真实的从容，仿佛讲述者早已洞悉天命，正平静地念出一份神谕。

“刘景和那次，中间停了足有半分钟，去哪儿了？”一个声音在她身后响起。是上次听过现场的老观众，也是社里如今仅有的几个帮手之一。他身上还带着室外的寒气，话音里夹着一丝困惑。

“杂音太多。”方婉排音的指尖在冰冷的金属旋钮上停住，没有回头。

“可我们当时……我们所有人都屏着呼吸，在等他回答。”

这句话像一根针，刺破了她用技术精心缝合的完美袍服。方婉音咬住嘴唇，指尖的皮肤感到一阵刺痛。她终究还是移动鼠标，在素材库深处，重新调出了那份带着原初毛刺的底件。

播放键按下，那段被她视为瑕疵的、令人窒息的停顿，如山洪般冲回耳中。这一次，她听见了。那空白的几十秒里，并非空无一物。远处断桥方向传来一阵细碎而急促的脚步声，像死神在敲击鼓点。更深处，有一句被死死压在喉咙里的颤声询问，含混不清，却充满了末日来临时的恐惧。若抽干了这些在死地中摸爬滚打的迟疑、恐惧与挣扎，那最后如出鞘之剑般斩钉截铁的三个字——“向西走”——便只剩下一道冰冷枯燥的系统指令。后来的听客，将再也无法从这声音里辨认出，那个下达命令的人，当时紧握刀柄的手，究竟抖得有多厉害。

方婉音把进度条拖回那段生死停顿之前。被她刻意削平的三十秒，恰似一局围棋的残局里，一手迟迟悬空不落的劫材。眼前的劫争已是生死一线，肉眼凡胎还没能算清所有的变化，可身后的绝壁却已燃起大火，不容你无限期地枯坐下去。倘若这生死局解得太顺、太光鲜，看客们便永远听不见，那一手落在星位的棋子，究竟有多么千钧之重。

“婉音，要不……再拿许嘉榕上次关店的事做做文章？”另一个声音插了进来，带着一股精明的算计，“把标题写得更惨痛些，更刺人些。‘一夜破产的她，如今在这里……’，流量不就来了？”

方婉-音的脸彻底冷了下来，像一块被寒风吹彻的铁。她没有答应。许嘉榕已然在那方寸大小的通信席上，重新开始磨砺她的剑锋，也在这个冷酷的江湖上四处奔波，靠自己的本事谋生。她绝不需要每周像个被押上刑台的小丑，被人剥光衣袍，重新展示一遍早已结痂的伤口，只为乞讨到几张留在这个沙盘上的门票。

那一场最终缩小了规模，后台向所有购票者发出了通知，可以无条件退款。三个人退了。筹备的场地与设备损失，由原声社按合同条款一力承担。而上一期已经支付给作者的稿酬，分文没有追回。这是规矩，也是体面。

散场后，剩下的人没有走，自发围在那段关于运输频道的录音旁，争论不休。一个嘶哑的声音在录音里喊：“往左！左边有路！”另一个声音立刻回答：“看不见门！全是烟！”死寂了片刻，司机忽然叫道：“等一下……我认出墙上那道蓝色的划痕了！”

对于没有亲身走过那条地狱之路的人，这几句对话几乎没有任何旋律可言，只是几段破碎的信息。可对于当晚就在那辆车里的人，这几句话让他们清晰地记起了被颠簸甩出车外、没能带走的最后一箱物资。

“是不是……只有我们这些老玩家才听得懂？”许嘉榕轻声问，她的眼神里有一丝茫然。

方婉音沉默了片刻，转身在电脑上调出一张当时的战术地图，用灰色的图块遮住了尚未解密的邻区部署，只留下那段关键的街区。许嘉榕看着地图，读出了自己当时的第一遍误解，然后再一次播放原声。这一次，新来的观众脸上露出了恍然大悟的神情。他们终于明白，那声迟疑的“看不见门”，不是因为驾驶员忘词或者慌乱，而是在生死关头，用最简洁的语言确认，耳机两端的人，说的是不是同一扇门。

那一夜，他们决定重置下一场的门规。方婉音在一张白纸上写下几行字，笔锋凌厉。

公开报名，绝不是供人白嫖的猎场，不能把那些落选的自愿投稿，都偷换成自己虚假的履历。

凡被选入筹备席位之人，必须先歃血画押，签下契约。白纸黑字，红印为凭。

凡是按约上交了兵刃的作者，无论最终成品是否惊艳，都能拿到一笔吊命的基本稿酬。剩下的，再凭各自的本事，去那口高悬的差异池里搏杀。

倘若组织者仗着自己坐庄，临时起意要额外试招，也必须先把买路钱当场拍在桌上，绝不容许靠着一句轻飘飘的“也许我们会采用”，去无限压榨别人的心血。

五月那场，暗中另有四名签了生死状的情报整理者。扣清所有成本后，锁死在账目上的四百元赏银中，基本口粮，即参与份额，定为每人五十元。那口高悬的差异池里，则另外悬赏二百元。整整一周，四人都在故纸堆和数据流里熬红了双眼，完成了所有基础的核对工作，却谁也没能在那片信息的迷局里，挖出那条足以一举扭转战局的绝密线索。系统后台的追加权重冷冰冰地全部清零。

方婉音握着笔，看着账本上那二百元差异池，一度想将它扣留，滚入下一场的奖金。可当她的目光落到自己亲手画押的契约副本上时，指尖却猛地一顿，像被火燎过。最终，她提笔，将这二百元差异池由四人平分。连同各自五十元的基本口粮，四人最终各收到一百元整。其中一人，哪怕第二天就传出消息，反水投了别的山门，应得的银两也照付不误，分文不差。方婉音在转账确认的那一刻，才真切地体会到：白纸黑字留给别人的气口，绝不能因为眼见没有斩获，就仗着掌门之威，冷血地收回到自己脚边。这口气一松，整个门派的根基也就散了。

又有一份素材递上来，是一段未经同意录下的私人争执，戏剧冲突感极强。方婉音听了开头十秒，便直接点了删除，并将原件退回。另有一段，据说是从敌方频道里被人从私聊中截获转来的，既不能证明来源与公开授权，也可能暴露我方下一场的战术安排，同样没有进入候选作品池。这已经不是简单的取材，而是江湖上的暗算，她不屑为之。

有作者对最终的分配方案极为不满，在散场后拦住了她。“最动人的那句明明是我说的，为什么最后你拿得比我多？”他质问道，语气里满是委屈与不平。

方婉音没有争辩。她只是平静地调出后台记录，把授权、筛选、编排和承担筹备风险的约定条款，一条条指给他看。那人看着屏幕上的记录，认可她确实做了这些事，但仍旧认为，下一场可以、也应该换一种分法。

“好。”方婉音只说了一个字。她点开项目文件，将所有属于他的独立创作材料，一丝不苟地导出、打包，发送给他，并在邮件里清晰注明，哪些是共同素材，若要他用，需要另外征得其他参与者的同意。

冷眼看着对方拂袖而去的背影消失在楼梯拐角，方婉音心里仍难免升起一丝刺骨的寒意。一个刚刚才在这个残酷的江湖里扎下脚跟的小门派，根本禁不起门下常用的剑客成批出走。但她比谁都明白，若连拔剑离开都只能沦为一种虚伪的客套和要挟的筹码，那他们今晚在桌前信誓旦旦许下的、关于“自愿留下”的豪言，也就成了一堆不堪一击的废纸。

她忽然想起自己曾无数次在书中读到、在心中艳羡过的那些携琴远行的侠客。他们走到风雪渡口，便与同袍利落道别，一杯酒尽，各自天涯。那些压箱底的绝世曲谱，绝不会被无耻地扣留在前任掌门的死局里，当作要挟的资本。想到这里，她胸中那口郁结之气忽然通畅了。她坐回电脑前，将刚才尚未导出的、一段她参与润色过的心血之作，也毫无保留地传送了过去。做完这一切，她才终于重重地放下那只已经微微发抖的鼠标，仿佛放下了一柄沉重的剑。

五月的一次傍晚场，那个曾经退过票的人又来了，就坐在第一排。屏幕上没有为了讨好观众，而替战死的角色添上一场虚假拙劣的复活戏。画面里，只有那辆在火光中最后驶过路口的车，以及那些没能回来的人，留下的最后一段记录。许嘉榕读到自己当时情急之下，把固若金汤的西门叫成了不设防的后门，台下先是响起了两声压抑不住的轻笑，随后，更多的人也跟着善意地笑了起来。那笑声里，没有嘲讽，只有劫后余生的温暖。

散场时，灯光亮起，刘景和却没有动。他指着屏幕上定格的地图，轻声问：“能不能……把地图再留一会儿？”角落里，一位新来的观众站起身，有些羞涩地问：“我想知道，那道蓝色的划痕，后来还在不在？”

“墙……墙被炸坏了。”刘景和的声音有些沙哑，他望着屏幕，像在看一个早已逝去的朋友，“可是我们还认得那一处。就算闭着眼睛，也还认得。”

方婉音没有把这句锥心刺骨的话，立即收进片尾。她先是走到刘景和身边，郑重地问他是否愿意。然后，她又穿过人群，找到了那位提问的观众，征求他的许可。得到两人允许后，她才重新打开录音设备，给这段崭新的、带着现场温度的对话，添上今天的日期。
