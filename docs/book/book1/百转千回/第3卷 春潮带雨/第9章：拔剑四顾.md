# 第9章：拔剑四顾

七月下旬，暑气被阻隔在城北工坊厚重的工业门外。沈婉衡走进来，高跟鞋敲击环氧树脂地面的声音，在一百二十台服务器低沉的轰鸣中显得格外清脆、孤绝。她没有先去看那面实时显示着参与人数的巨型数据墙，那上面的数字，于她而言，不过是沙盘上虚张声势的旗帜。

六个月。一个轮回的生死劫，到了收官的时候。

半年前那张餐桌上，她亲手划出的两栏空白，至今仍像两道深不见底的裂谷，横亘在程砚舟面前：企业为何再来？参与者拿到钱以后，生活究竟如何？

程砚舟没有言语，只是将一叠崭新的材料，静静地放在了那张旧纸旁。他没有将这片战区的喧嚣与热闹，剪辑成一张廉价的胜利照片。他知道，在她面前，任何粉饰太平的“手筋”，都只会被看作是自寻死路的“愚形”。

周慎衡上前一步，仿佛递交一份战损报告，将六月的到账资料呈上。他的指尖有些发白。

“六月，各类窗口与活动总收入，二十四万元。”他声音平直，像在宣读一份判决，“其中，企业投入十六万，自愿购票、作品与兴趣体验等个人交易八万。岑绍庭先生的八千元，以及东瀚集团的两万元，均已计入企业投入，不再重复计算。”

沈婉衡的目光如同一柄最锋利的解剖刀，顺着数字的脉络一寸寸地剖开。

“参与者酬金，合计十四万四千元，已按各自签署的协议，结清了包含基本参与份额与差异份额的所有款项。项目运行、技术核验、场地租赁及相关税费等现金成本，共计四万。固定与条件组织报酬两万四千元，核心成员对应的份额，也已包含在内。”

“本期现金结余三万二千元。计提两千元设备折旧后，账面结余三万。依照章程，六千元自动划拨风险储备金，剩余两万四千元，归经营主体留存。”

“只是六月。”沈婉衡的声音没有一丝温度，像机房里循环的冷媒。

“是。”周慎衡点头，额角渗出细微的汗珠，“二月份那两场试验的五万元实收，以及三万五千元的参与分配，记录在旧账中，并未混淆。首期的内容使用与回访也已结清。六月的计价，严格按照本月各场次的实际范围重新核算，没有将旧款重复计入。”

他翻开另一页，是此前触目惊心的亏损。那初始投入的两百万元，仍在承担着早期试验与研发的沉重代价，远未被这一个单薄的正数完全收回。银行余额里，还有一笔笔尚负付款义务的款项，像棋盘上尚未做活的孤子，随时可能被提走。这些，都不能被轻佻地称之为“利润”。

她冷冷地审视完那些冰冷的金额，又将锐利如剑的目光，逼向那满纸血汗的明细。这杀机四伏的账本里，记录着一场场无声的厮杀。有人在对冲中没有夺下半个人头，黯然离场；有人的阵营在沙盘推演上一溃千里，资产归零；有人只在后方苦熬着保障通信与撰写复盘，籍籍无名。可就是这些草根，这些在江湖中连姓名都未曾留下的蝼蚁，他们应得的真金白银，一分不少地被钉在了结案的卷宗里。连同那些被无奈斩断的合作窗口、带着血泪的申诉记录、乃至团队自掏腰包倒贴的退款，统统被毫不留情地摊在阳光下，没有任何一笔被阴暗地掩埋在无人翻看的废墟中。

程砚舟死死盯着她翻动纸页的手，那只手仿佛正执着黑子，在他的空门里落下致命一击。他几次想拔剑抢出一步，替自己辩白那些数字背后的挣扎与坚守，却又生生将涌到喉头的话咽了回去。他骨子里太熟悉怎样在十九路盘上，用一套花里胡哨的连环手筋，将一块濒死的坏棋机巧地引向别处，搅乱局面。但他此刻无比清楚，那些自作聪明的算计，一旦摆在这张审判桌上，只会让这片本就满目疮痍的残局，凝结成永远化不开的冰窟。

宋振峰的声音打破了沉寂，他代表凌拓而来，言辞审慎：“我们续投，是承认小场次的组织质量与参与者的自愿回访数据，确实有价值，值得再试一次。”他顿了顿，补上一句，“但这不保证，我们的预算会跟着你们的注册人数一起无限增长。”

罗振业也坐在角落，极轴在那场风波里估计的六千元损失，被单独列为一行，像一道无法愈合的伤疤，没有被另一家企业的成功案例合并冲淡。他们下一期的款项已经到账，但附带的条件各不相同，如星位与边角，各有各的图谋，却无一例外，均未要求玩家必须拿所得酬金，去购买他们的指定商品。

沈婉衡的目光没有在收入最高的那几位“高手”身上停留。她翻到了许嘉榕的记录。上面清晰地写着她通过通信保障和作品获得的全部所得，也同样记录了一份她自愿投稿但未被采用的稿件，并注明“事前无现金承诺”。而已签约完成的复盘报告，则不因其支持的阵营排名靠后，而失去分毫基本稿酬。她多了选择，但仍在寻找一份能长期承担生活的工作。这江湖，并未许诺她一步登天。

一位退出的运输玩家，授权留下了一段话，被投影在墙上：“这里的时段不适合我照护家人。”他结清了所有参与款，导出了自己的行为记录，平静地去了别处。他离开后，那个世界由后来的人和NPC接续运转，系统没有为了留住他而巧立名目扣掉一分钱，也没把那些NPC在他离开后的夜间自主行动，荒唐地算进他的收入。

经本人允许的匿名反馈里，资金的去向被如实罗列：有配了新眼镜的，有买了专业书籍的，有添置了家用物品的，也有选择储蓄和明确标注“不愿说明用途”的。许知妍的团队，将品牌转移带来的销量，与真正意义上新增的消费，做了审慎的区分估算，无法识别的部分，诚实地留作空白。她没有借那几个熟人的温情故事，去虚伪地声称全体参与者的消费能力都已获得提升。

公共终端旁，还贴着社区接入预算的截止日期，白纸黑字：有限的设备支持，不等于无限的全城保障。生活真正困难的人，走的是独立申请渠道，他们不必先在虚拟的战场里赢下一场血腥的战争，才能获得现实中的一张床。

“在这片刀光剑影里，确实发生了一些你妄想能改变江湖的事。”沈婉衡终于开口，她合上账本，冷厉的目光如刀锋般直刺丈夫，“但也仅此而已。金主的热钱会赔光，看客的好奇会一哄而散，修补这座破庙更要源源不断地砸钱。你想在这个破落的山门里继续熬下去，可以。但妄想拿这六个月的残局，去替整座城市的众生交出一张救世的答卷，你还不配。”

他沉痛地点头，像一个被对手下出了“神之一手”后，瞬间看清全局败势的棋手。他原本下意识地想从袖底摸出一枚光洁的白子，递给她，作为这十九路盘上艰苦收官的信物。可指尖刚刚碰到那冰冷的木制棋盒，他又颓然地、羞愧地收了回来。他终于明白，在这满地狼藉的残局里，她今天需要的，绝不是一件虚伪地象征着胜利的所谓战利品。

晚饭后，小溪上楼去整理她那座屡战屡败的纸桥，餐厅里只剩下死一般的安静。程砚舟将手机正面朝下，推进了黑胡桃木的抽屉里，说出了那句他一直用各种借口绕开的话。

“我和知妍，做过对不起你的事。这是我的选择，不是公司逼的。”

沈婉衡抬眼看他，眼神里没有惊讶，只有一种被利刃反复切割后留下的、疲惫的平静。

“我肯认你们的账，不等于把我们之间那笔，也一笔勾销。”

“我知道。”

“先别说知道。”她打断他，字字清晰，“家里怎样安排，小溪不用再替大人等一个虚无缥缈的结果。你把你的责任，做出来。至于我愿不愿继续，这需要时间，也由我来决定。”

他没有不知廉耻地，拿这半年里那少得可怜的陪伴，去抵扣自己亲手犯下的业障。楼上传来小溪带着哭腔的、无助的声音，说有根桥梁的主心骨，怎么也粘不牢。

沈婉衡漠然地坐在原处，像一座冰封的雕塑，没有替他接下这声属于父亲的呼唤。

他默默咽下喉间的苦涩，拔出仿佛灌满了铅的双腿，一步步走上楼。他没有急着从女儿手中接管那片狼藉，而是先蹲下身，放低自己，静静地听女儿把那个摇摇欲坠的绝境，完整地哭诉说完。

那座脆弱的小桥，无法替他的人生开脱半句。程砚舟曾经狂妄地把舍弃一切的远行，看作是“拔剑出门、四顾茫然”的快意恩仇。他天真地以为，只要在江湖上做下一件惊天动地的大事，那个被自己亲手撕裂的罩门，就会奇迹般地自行合拢。

直到此刻，站在冷彻骨髓的家门前，他才绝望地发现——连一声乞求来的原谅，他也无权越俎代庖地，替那个被他伤害至深的人应下。

在那个由代码和血肉堆砌的战区里，打下一城，便能清算一城的赏金；可回到这张审判生死的小桌前，他要赎的罪，才刚刚在这望不到头的残局里，落下第一子。
