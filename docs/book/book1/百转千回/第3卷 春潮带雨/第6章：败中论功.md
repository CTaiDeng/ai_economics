# 第6章：败中论功

六月，海水没过潮汐站第一道防波石阶的时刻，麦振铮的枪口，依旧沉默如铁。

海风带着咸腥的寒意，从指挥中心的通风口渗入，像无形的蛇，缠上每个人的脖颈。岑绍庭站在巨大的战术光屏前，背影渊渟岳峙。他没有因为守方是一支籍籍无名的临时队伍，便在盘口上妄下半句论断。他将红蓝双方的兵力阵图数据流压在手边，那动作，像极了老派棋手在纹枰对坐、摆好棋钟后，缓缓退离桌沿的仪式。

眼下，是刀口舔血的临阵者互试锋芒的时刻。棋盘已经布下，棋子已经落位，旁观者再如何焦躁，也只能死死屏住呼吸，等那定生死的一手，真正落下。

战局的“气”，正紧在那一处交叉火力的咽喉。麦振铮就像一枚钉死在星位的黑子，死死卡住了攻方的突进路线。暗夜里，罗启锋领着攻方的死士，如壁虎般沿外墙冰冷的混凝土摸索。三次极具压迫感的试探，前两次，只引来夜色中短促而狠毒的枪火，像毒蛇吐信，一击即收。他忌惮在直播画面里停滞太久，堕了自己“破壁者”的威名，终于冒险向侧门多压了半寸气口。

就是这半寸，身后跟进的队友瞬间被另一处暴起的火力死死钉在墙角，曳光弹在混凝土上拉出刺眼的白线，碎石崩溅。

转播永远晚于真实的战局，上帝视角的看客看得分明，那处夺命的掩体如鬼魅般潜伏。但在局中挣扎的罗启锋，却如盲人瞎马，坠入桃花岛的奇门阵法，步步杀机。有人在公开频道里抑制不住，妄图大呼提醒，声音刚起，便被主持后台挥出无情的门规当场斩断。任何越过安全延迟的作弊，都休想沦为某一方的免费侦察，这是铁律。

罗启锋咬碎了钢牙，带着残部退了回来。第一次，他将那句“对面两处火力，位置未全明”的血淋淋战况，一字不差地完整上报给战役席位。他没有用任何花里胡哨的行话去掩盖自己的狼狈，这份坦诚，是败局中唯一的亮色。老关在另一段九死一生的防线上听见这句不加修饰的报告，心中一凛，果断收住了原定的突击剑路，那是他早已蓄势待发的一招“天外飞仙”。他没有犹豫，将保命的烟幕优先砸给了罗启锋受困的同袍。

地下入口狭窄，只容四人并行。前一组还没有完全撤出，后面的工兵就只能在地面上焦灼地等待，工程车巨大的引擎低沉轰鸣，守住唯一的通路。罗启锋急得想再加人，强行破局，得到的系统回答却冰冷如铁：“入口已经满员，新的进入请求被拒绝；必须等候单位实体撤出，才能重新申请。”系统不会凭一道命令，在物理上变出第二个地下室。

守方最后还是失去了潮汐站。但他们一直拖到了主货道另一段的友军完成疏散。麦振铮撤出时，左臂负伤，弹匣也几乎见底。当他的单位图标在战役地图上重新亮起时，那上面清清楚楚地标注着“负伤”与“弹药不足”的减益状态。战局推演，不容许丝毫侥幸，不能因为镜头从巷战切换回远景，便能凭空再打一次满状态的仗。

战后清盘，空气仿佛凝固在零度。许嘉榕抽出复盘初稿，指尖点在光幕上，声音清脆而锋利，像出鞘的匕首：“罗启锋，你一次莽撞的贪刀，让整个小队付出了三死两伤的代价，直接导致了战线延误。”

罗启锋“霍”地站起，双眼熬得通红，像一头被激怒的困兽。他一拳砸在沙盘边缘，指着那个最终被换上蓝色旗帜的潮汐站模型，怒吼道：“旗不是已经被我们拔了吗？赢了就是赢了！”

两人剑拔弩张，僵持不下。

“咚。”

岑绍庭用指节冷冷地敲了敲黑胡桃木的会议桌，桌上的烟灰缸里，几枚烟蒂安静地躺着。他的声音不大，却瞬间压制了满屋的火药味：“许嘉榕，把原始军令、双方交战日志，以及他们各自的第一视角底件，一并投到主屏幕上。”

光影流动，冰冷的数据与血腥的画面并陈。

攻方小队的局部夺旗确实完成了，可满地血肉的代价远超大营的预期。守方虽然丢了城池，却在死地里不折不扣地完成了上级交托的绞肉机任务，成功迟滞了主力两个小时。一个轻飘飘的“赢”字，根本盖不住这十九路棋盘上层层叠叠的惨烈因果。岑绍庭的目光转向许嘉榕，眼神锐利如刀：“更不能由你这个事后开了上帝视角的人，反过来去苛责局中人在迷雾里的瞎眼与挣扎。这不叫复盘，叫泄愤。”

许嘉榕的脸一阵红一阵白，她紧紧咬着嘴唇，删掉了报告里那句傲慢的结论。在岑绍庭的注视下，她把稿子逐字逐句地改成了三个见血的问题：

一、在漆黑的迷雾中推进时，你看到了什么？
二、是哪一句带血的战报，逼得侧翼主帅改了道？
三、为了少死一个兄弟，当时你手里，还攥着哪一张被遗漏的底牌？

听完岑绍庭的解释，再看着这三句拷问，会议室里那些亢奋的新人们终于安静下来。他们开始沿着录像，死死盯住那个决定生死的“气口”，那个罗启锋犹豫了半寸的瞬间，而非只记得哪个莽夫拔剑的姿势更潇洒。

清算开始了。十九名有偿参与者在各自的终端上确认了合同完成，每人先收到五十元人民币的基本参与份额。随后，战场表现的激励金开始分发。十六名战场参与者，共计分得两千四百元。麦振铮，作为虽败犹荣的迟滞战核心，合计获得九百元。老关，因其果断变招、保全友军，获得五百元。一名在最后关头及时修通退路的工兵，因其关键作用，获得二百五十元。一名提供了精准掩护的火力手，获得一百五十元。其余十二人，各得五十元。

三份复盘报告的总稿酬分别为八百、五百、三百元。许嘉榕得到的五百元，系统注明“已包含五十元基本份额”，没有重复计算。

麦振铮所在的阵营，在沙盘上彻底丢了潮汐站，但他仍堂堂正正地拿走了战场组最丰厚的一份卖命钱。那份电子军功状上，白纸黑字地写明了“死守迟滞117分钟”、“有效掩护友邻梯队撤退”、“自身伤亡折损42%”，每一条功过都量化到了极致。绝不需要用文过饰非的脂粉，把这场惨烈的败退，包装成一场荒谬的假胜。

麦振铮望着光屏上那片已经改换门庭的血色区域，眼神平静。先前在那处死穴死死撑住的几次反扑，都已刻进铁一般的战报里。整盘棋的棋形，固然已经被资本的铁蹄踏破了，可在这残局里，他们怎样咬牙死撑过，哪一步本可以少填几条人命，却绝不能随着结局的溃败被一笔抹杀。他坦荡地将自己最狼狈、最难看的那段战斗录像，也一并扔进了复盘的解剖台上，供所有人检视。

那笔八千元的总投入，也有着清晰的去处：直接费用一千元，用于设备损耗与网络带宽；固定组织报酬一千元，维持团队基本运转；参与池四千元，即方才分发的所有参与者酬劳；风险储备金五百元，以备不时之需。

剩下的一千五百元，是岑绍庭的条件报酬。合同规定，这笔钱要等真实自愿回访达到约定门槛、所有结算与异议处理完毕后，由第三方独立核验支付。若未达到，则原路退还给企业，绝不能扣着参与者的钱，逼人回来帮忙走流程。

宋振峰原想把“凌拓集团”的巨幅Logo挂在转播画面的正中央。预演时，岑绍庭没说什么，只是请他自己观看一段录像。那巨大的Logo恰好遮住了罗启锋被压制时，侧门那道致命的火线。宋振峰沉默地盯了一会儿，叫人把牌子挪到了不遮挡关键画面的固定边角，更详细的品牌材料，则链接在可自愿点开的回放页面。这是对局本身的尊重。

月底，所有条件核验完成，岑绍庭的账户里，合计收到了两千五百元组织回报。他不必为了向谁证明公心，而把这笔钱藏着掖着。这就是规则，是他亲手建立的、清澈见底的规则。

商品端的回报也出来了。报告按事前确定的比较方法估算，“凌拓集团”在同一观察窗口内，取得了一万八千元增量毛收益。这份收益，已经扣除了所有非注意力成本，并核清了退货订单。再扣除全部八千元的活动投入，净增利润恰好为一万元。相对投入回报率，百分之一百二十五。报告的末尾，用冷静的字体保留了识别方法的局限性，没有许诺下一次也能如此。

宋振峰来谈续投时，岑绍庭正在看潮汐站最新的卫星战报。抽水泵已经恢复，先前没能通过的货运船队，终于缓缓驶入了港口。

棋局，已经变了。

岑绍庭指着屏幕上那片繁忙的港区，对宋振峰说：“下一次可以做什么，要从这个已经变了的地方，再谈。”
