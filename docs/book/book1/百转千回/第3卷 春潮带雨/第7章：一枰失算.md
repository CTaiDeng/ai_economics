# 第7章：一枰失算

六月的空气沉闷如铅，燥热黏在每一寸皮肤上，预示着一场将至的雷暴。东瀚公会的另一场盛大约战，却选在了这样一个令人心浮气躁的午后。货场外，两支队伍如出鞘的利剑，肃立在滚滚热浪之中，汗水浸透了他们作战服的内衬。然而，进攻的号角迟迟未响。

蒋克己站在冷气开到极致的导播间里，背着手，如同一位正在审视棋局的国手，渊渟岳峙。他透过巨大的单向玻璃，漠然地注视着场外焦灼的等待。他的目光没有落在那些鲜活的战士身上，而是紧盯着监视器一角那个鲜红的倒计时。

“再等四分钟。”他声音不大，却带着不容置喙的决断，“赞助商的开场动画必须播完，一个像素都不能少。”

许知妍坐在角落的暗影里，指尖无意识地在冰凉的金属桌面上敲击着，那节奏，仿佛是在复盘一局早已注定败局的棋。她想起那些在老城棋馆里教过的野路子棋童，他们一旦在连环劫中尝到甜头，便会红了眼，不顾一切地提子、扑劫，妄图将十九路棋盘上的每一寸气口都蚕食殆尽，却忘了贪吃的棋形最是笨重，早已失去了转身腾挪的余地。

此刻，那份被商业诉求塞到令人窒息的转播安排表，在许知妍眼中，就如同一张下得毫无章法、只知蛮力争地的棋谱。资本的嗜血与贪婪，与那些野路子棋童同出一辙：只顾眼前强争那一点星位官子，却亲手堵死了大龙转身做活的所有气眼。

监视器里，主持人花团锦簇的开场白终于念到了尾声，极轴键鼠的产品特写画面随之切入，雷打不动地占据了整整四分钟的黄金时间。前线的“敢死队”早已按合同在火线待命，神经绷得如同满弓之弦。这强加的四分钟“等待”，被组织方在直播间里傲慢地粉饰为“战术静默”与“有效待命”。

可沙盘上那个由代码与逻辑构成的冰冷世界，却绝不会为了一场作秀的转播而悬停一秒。

就在这致命的二百四十秒里，无人机侦察画面的一角，几个像素点发生了微妙的移动。NPC守军如同幽灵般，悄无声息地完成了换防。那条原定为主攻路线、情报显示一击即溃的薄弱路口，此刻，豁然横亘出一辆钢铁巨兽般的装甲运兵车，黑洞洞的炮口，正对着他们预定的突破方向。

“侦察摘要更新！‘主街’出现重火力单位！请求变更路线，改走西侧仓库窄道！”罗启锋的声音从通信频道里传来，冷静，却带着金属摩擦般的急迫。

蒋克己没有战场指挥资格，他只能将耳机里的战术请求转述给身旁的战役负责人。他的眉头拧成一团，不是因为战局的变化，而是因为这变化打乱了他的剧本。“主街的镜头机位已经全部预设好了，这是最佳的观赏角度，”他压低声音，与其说是建议，不如说是施压，“我希望……他们不要改。”

战役负责人瞥了一眼屏幕上跳出的火力威胁报告，那猩红色的警示符号刺得人眼角一跳。他没有片刻犹豫，对着麦克风下达了不容置疑的命令：“命令确认。放弃主街，全体绕行仓库窄道。”

于是，数万名守在屏幕前的观众，看到了一段堪称完美的运镜——漂亮、空旷、光影绝佳，却连一个鬼影都没有的主街。导播间的气氛瞬间凝固。

后台终于在一片慌乱的叫喊声中，将画面切回了那片真实交战的修罗场。镜头摇晃，火光冲天。罗启锋和他的队员们，已被暴雨般倾泻的火力死死压制在一排排破败的货架之后，金属碎片如同致命的冰雹，在他们头顶呼啸。

主持人脸上闪过一丝不易察觉的慌乱，但职业素养让他立刻见缝插针地补上了品牌念白：“……正如我们看到的，战况异常激烈！而极轴的GK-950型机械键盘，它那高达八千赫兹的回报率和零点一毫米的触发键程，正能帮助我们的英雄在这样瞬息万变的战场上……”

他的话音未落，通信频道里猛地撕裂出一声带着血腥味的嘶吼：“C点通路被堵死！请求确认撤退路线！重复，C点是死路！”那是一名工兵最后的呼喊。

高高在上的公开节目固然可以为血腥的画面打上马赛克，可以挑选最上镜的角度，却绝不可能让前线的血肉之躯，为了配合广告商的节奏，去把那条洒满鲜血的死路重新走一遍。蒋克己生平第一次感到一种发自骨髓的恐惧，他惊骇地发现，这个活着、流血、会死亡的战局，是一个拥有自我意志的对手，它绝不会按照他写好的戏码，乖乖地倒带退回上一秒。

战斗结束。那段本该用来总结生死、剖析战术的复盘环节，被粗暴地腰斩。两名浑身浴血的队员刚从模拟舱里出来，还未咽下胸中的不甘，准备解释为什么在那种情况下，必须忍痛弃掉货场那一角价值连城的“肥子”，镜头便在导播无情的指令下，冷酷地切向了那把光鲜亮丽、一尘不染的键盘。

看客们的情绪在评论区里彻底爆发，弹幕如潮水般刷屏追问那批拿命换来的物资到底保住了没有，得到的，却只有主持人一句公式化的傲慢敷衍：“详细战况，请稍后收看我们为您精心制作的完整回放。”

一条被顶到最高的评论，像一记耳光狠狠抽在所有组织者的脸上。有人在愤然退场前，冷冷地丢下一句：

“老子是来看他们复盘生死局的，不是来看你们这群戏子念产品说明书的。”

导播间里，罗振业的脸色铁青，但他依旧固执地抓着最后一根稻草。“核心卖点不能少，”他低声对蒋克己说，像是在说服自己，“两款键盘的规格、价格与保修条款完全相同，越是这样，越难用性能区分。我们必须依赖反复出现的商标，让观众记住它。”

每多念一次品牌名，他便觉得那两万元的投入更实在了一点。然而，屏幕右上角那个代表在线人数的数字，却在以一种毫不留情的姿态，持续稳定地跌落。

血战落幕。兵家必争的货场，最终只凄惨地啃下了一半。一处囤满了关键辎重的仓库，在冲天烈火中化为灰烬，屏幕上的战损报告，每一个字都像烧红的烙铁。资本方要求罗启锋带队补拍一个“顺利进场”的虚假片段，被他当场断然拒绝。他的眼睛熬得通红，像一头被激怒的孤狼。

“我的人，可以退到那个打着你们标识的复盘沙盘里，去认栽，去解释我们为什么输，”他一字一顿，声音沙哑却掷地有声，“但绝不容许让天下看客误以为，那拙劣的摆拍，就是刚才发生过的那场血肉横飞的实战！”

蒋克己本想搬出金主的身份强压一头，可当他的目光触及行动记录里那一行行冷冰冰的伤亡时间戳时，那股盘踞心头的傲慢，终于像被戳破的脓包，流出了冰凉的胆怯。他挥了挥手，声音里带着前所未有的疲惫，叫剪辑师把那致命的四分钟等待、那九死一生的仓皇绕行，以及看客们拂袖离去的每一个时间点，一笔不改地，封存在了战报的底件上。

罗启锋死死盯着那份经过妥协、但依旧被广告时段切割得支离破碎的展示安排，骨节泛白地揉了揉那只紧握鼠标、已经有些僵硬的手。应那张两万元的英雄帖来此试剑，技不如人，输掉一阵，大可以回去闭关磨剑，来日再战。可若是连剑锋何时饮血、何时出鞘，都得像个提线木偶般，眼巴巴地等着资本的幕布升起，锣鼓敲响……

那眼前这片江湖，便再也不由自己的意愿走了。

清算的时刻，冰冷而公正。这场战役共有三十二名履约的战场参与者，按照规则，每人五十元的基本参与份额雷打不动，共计一千六百元。其余六千四百元，则按照战前议定的分岗贡献规则进行分配。最终，合计八千元的参与池分文不少，照约结清。组织的失误，并没有成为克扣酬劳的借口：那些认真守住阵地、给予他们重创的对手，没有被系统判定为零贡献；就连那名自始至终在后方等待交接命令、未能开一枪的通信员，也拿到了属于他的那份基本份额。

账目在许知妍的监督下一笔笔划清。两万元的总投入，其中场景、传播、技术与执行费用合计九千元，东瀚公会的固定组织报酬两千元，风险储备金一千元，以及支付给参与者的八千元。至于因延期解释而造成的直播事故责任，将另行核对，但绝不能因为品牌方失望，就将参与者已确认的所得拿来填补亏空。这是规矩，是这片新兴江湖里，最后的底线。

月底，财务报表如同一张冰冷的判决书，摆在了罗振业面前。极轴键盘按与另一场凌拓成功的案例采用相同的非广告成本口径，剔除退货和可识别的其他促销活动影响后，估算本次活动带来的增量毛收益为一万四千元。然而，扣掉那笔高达两万元的注意力投入成本，净增益赫然是一个刺目的负数：负六千元。相对投入回报率，负百分之三十。

凌拓花八千元，获得了一万元的估计净增益。极轴花了两万元，反而亏损六千元。

许知妍将这份结果轻轻推到罗振业面前，旁边并排摆放着两场活动的组织安排表和观众反应曲线图。它们不是在绝对受控条件下进行的科学实验，却足以像两面镜子，让他清晰地看到，那些由他本人强烈要求、反复加上的口播，是如何一步步将一场潜在的胜利，拖入了亏损的泥潭。

“总归……总归是卖出了一些货。”他低声说，像是在寻找最后的慰藉。

“但没有收回全部投入。”周慎衡的手指点在那“负六千元”的数字上，语气平静却不容辩驳，“而且，这笔亏损，绝不能从那八千元的参与池里扣。”

蒋克己没有拿到任何额外的成功报酬，他寄予厚望的新一季长约也被无限期搁置。他只拿到了已履行部分的固定报酬，然后带着这场惨败的复盘报告，重新提交了一份小额试办方案。

这一次，方案的第一行，用加粗的黑体字写着：

一切转播，绝对依附于真实战局；任何需要临时变更的商业展示，由品牌方承担全部变更成本。

在七月试办的意向名单里，极轴保留了他的名字，但删掉了所有保证收益的条款，大幅缩短了口播时间，并要求必须为观众留出完整的、未经删减的提问环节。

棋已经下完了。失去的货场不会因为改了流程而回到昨天，棋盘上阵亡的大龙也不会复生。

但人，仍可以从一次惨痛的失算之后，收拾棋子，再做一场。
