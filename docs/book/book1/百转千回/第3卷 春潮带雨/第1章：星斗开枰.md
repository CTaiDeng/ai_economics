# 第1章：星斗开枰

四月的风还带着倒春寒的锋刃，但星原的服务器机房里，只有恒温的、钢铁的吐息。一排排森然矗立的黑色机柜，如同沉默的兵阵，内部蓝绿色的指示灯在幽暗中明灭，像无数双冷静的眼睛。空气里弥漫着臭氧与金属混合的、近乎无菌的气味。

顾承安站在主控台前，面前的巨幅曲面屏上，一纸数字批文的影像静静悬浮。那不是一张简单的图片，而是一个由多层加密水印与时间戳构成的、活的法律凭证。他指尖轻点，一行行冷硬的宋体字逐次亮起：

【合作出版单位：海燕电子音像出版社（实际审校完成）】
【审核部门：上海市新闻出版局（审核通过）】
【批准机关：国家新闻出版署（批准）】

每一个机构名称后面，都跟着一枚鲜红的、不可篡改的电子印章，仿佛宗师对决前，在生死状上按下的血色指印。他继续向下检视，破阵信息技术有限公司自身所需的《增值电信业务经营许可证》、ICP网站备案号、移动应用备案号，一应俱全，像一套刚刚开刃的兵器，寒光凛凛。首页的公示区，出版单位与运营主体的名称被严格区分，并列分明。这一切繁复而冰冷的程序，都在无声宣告：二月工坊里那场带着江湖草莽气的封闭测试，终究只是试剑，今日，才是真正的开山立派。

“防沉迷实名验证系统，最后一次接入回报。”顾承安的声音在机房的低频轰鸣中显得格外清晰。

“回报正常。公安部‘网络游戏防沉迷实名认证系统’接口稳定，响应延迟低于50ms。星原现阶段策略锁定，仅对核验通过的成年公民开放。任何未满十八周岁的账号，访问权限将被阻断在登录协议层，连免费演练的门都摸不到。”

“很好。”顾承安点头，“公开昵称与核验身份的数据库物理隔离，确保万无一失。”

在他身后不远处，程砚舟正亲手将一张海报从公告墙上揭下。那张海报是内测时设计的，底色是温暖的橙黄，上面用写意的字体印着“人人都能来”。他揭得极其缓慢，仿佛在剥离一层过于理想主义的旧皮肤。这张海报，连同它所代表的那个天真愿景，都已不属于这个即将开枰厮杀的真实世界。

海岸集散区，是星原呈现给所有初来者的第一站。这里没有新手村的喧闹与温情，整个空间设计得像一座未来主义的交通枢纽，冷灰色的金属地板倒映着天花板上流动的白色光带，空气中只有微弱的电子提示音。一个穿着夹克的男人在这里已经转了两圈，他的眼神锐利而实际，像是在评估一处新矿脉的价值。

他终于在一个服务终端前停下，开口问道：“哪里领能换现金的每日任务？”他的声音不大，却带着一种不容置疑的交易口吻。

顾承安不知何时已来到他身边，没有直接回答，而是抬手在男人面前的空气中划出一道光屏。屏幕上，三张正在运行的战争牌桌以三维星图的形式缓缓旋转：【双桥牌桌：北岸道路紧急修复任务】、【海岬牌桌：港口控制权争夺】、【山城牌桌：运输与渗透侦察】。

“那些黑着的地方是什么？”男人指着星图上大片的沉寂山谷。

“尚未启用的战场，”顾承安解释道，“但它们并非空白的装饰品。那里的物资和天气，正沿着自己的时间线独立演进。我们只是不需要把每一块石头都同时呈现在所有人面前，仅此而已。”

男人的眉头拧了起来，显然对这种哲学式的回答不感兴趣。“打谁都算钱吗？”他把问题拉回了最根本的层面。

顾承安的手指在光屏上再次滑动，一个名为“有偿参与窗口”的界面弹了出来，里面的条目清晰得如同一份银行对账单：岗位、时段、已存入托管信托的参与激励金总额，每一个数字都精确到分。旁边，【自由游玩】、【战术演练】与【已满额】的窗口则以灰色区隔开来。

男人盯着屏幕看了许久，每一行都看得极慢，像是在用算盘反复拨打。最后，他摇了摇头：“我只有晚上有空，这些时间都不合适。”说完，他转身便走，没有丝毫留恋。

站在一旁的杜启航脸上闪过一丝惋惜，那是一个潜在的“职业玩家”，是生态系统里最现实也最强大的力量。然而，半小时后，那个男人竟带着一个朋友回来了。他径直走到终端前，预约了两个周末的免费演练席位。

“没有收入承诺，”他对朋友说，“但这里面，好像有我们想试的东西。”

  

海岬牌桌，在当天下午开始接管第一批正式报名。上层指挥部给出的战略任务简洁而残酷：【抢通港北货道】。战役席位下辖两支标准步兵队和一辆重型工程车。然而，真正的瓶颈在于一处关键节点——泵站。要进入泵站的地下核心层，只有四个步兵突击位置。那扇厚重的合金小门，工程车庞大的身躯无法挤入，只能在外面清理路障。这意味着，剩下的兵力必须在炮火横飞的地面死死守住出入口，绝不能随着指挥员一个孤注一掷的念头，全部消失在那片幽深的地下。

报名者中，一个ID为“罗启锋”的主播尤为显眼。他的虚拟形象头盔上，贴着一枚极具侵略性的银色狼形标记。他一进入准备区，便直奔虚拟商店，手指在装备列表上飞速划过，像一头寻找猎物破绽的饿狼。

“没有能直接用现金换伤害的付费配件？”他抬起头，眼神里带着一丝挑衅。

当值的陈驰推了推眼镜，镜片反射着数据的冷光。他平静地将两个不同的入口分别投射到罗启锋面前。“左边，是购买独立演练中的限时指挥体验。它不产生任何现金奖励，也无法取得任何正式指挥权。右边，是有偿指挥席位的申请与考核通道，全程免费，不设任何充值或购买前提。你在体验模式中的任何记录，都不能替代资格审查与战场委任。”

陈驰顿了顿，声音平稳得像一段代码：“对局内你所能获得的一切装备，都来自部队后勤补给，商业付款，在这里，换不来一发额外的子弹。”

“呵，有意思。”罗启锋的嘴角勾起一抹冷笑，“那先来一局不用钱的，让我看看你们这葫芦里卖的什么药。”

系统为他匹配到了一位名叫“守夜人”的玩家。两支队伍被投入同一起点的独立演练副本。这意味着，无论他们在里面杀得如何天翻地覆，现实世界的海岬港依旧会按照自己的时间线继续运转，历史不会为任何一场匹夫之勇而重新洗牌。

战斗开始的瞬间，罗启锋便展现出他嗜血的本性。他如同一柄出鞘的利刃，从堤岸连下两处关键掩体，枪法狠厉，走位刁钻，直播间的弹幕瞬间沸腾。他的攻势如水银泻地，很快就逼近了泵站主体。观众们刚要为他即将到来的雷霆一击喝彩，前方一盏提供关键照明的灯架却毫无征兆地，“啪”的一声，熄灭了。

永恒的黑暗降临了三秒。罗启锋的战斗本能让他立刻抓住这个机会，借着夜色扑向侧门。然而，他刚一动，一阵来自远方高点的精准压制火力便如暴雨般泼来，将他死死钉回了来时的矮墙之后。

奇怪的是，那个“守夜人”并没有乘胜追击。就在罗启锋被那阵突如其来的火力吸引了全部注意力的瞬间，在他视野的阴影里，一支迟迟未曾露脸的运输小队，悄无声息地将最后一箱工程器材拖到了对岸的指定位置。

任务完成的提示音冷冷响起。

罗启锋冒着寒气的枪口，还死死咬着那堵救了他一命也困住了他的矮墙。他这一阵突击，锋利得宛如古龙笔下剑客的夺命一剑，讲究一击必杀；直到运输箱安然抵达对岸的系统提示弹出，他才猛然惊觉——自己这几记自以为算无遗策的狠辣杀招，竟全都落在了空处。他以为的“天元”，在对手的棋盘上，不过是一颗无关痛痒的废子。那个藏在幽暗中的对手，落子始终在十九路棋盘的另一处、真正的生死眼上。

他红着眼拉开结算页面，几乎是掘地三尺地检查着双方的装备、数据，却找不到任何一件可以被称为“不公平”的道具。

“刚才那灯，是谁掐断的？”他几乎是咬着牙，在公共频道里问道。

守夜人的声音通过电流传来，极冷，不带一丝情感：“我叫通信员断的。我在高点看不清你在烟雾里的残影，但你为了追求突进速度，自己先拔掉了探照灯旁那颗被我们当做‘气口’的观察哨。”

气口。

围棋里的术语，从那个冰冷的声音里吐出来，让罗启锋浑身一震。那不是什么上帝视角的全知全能，而是一场刀尖舔血的豪赌。守夜人算准了他急于求成的性格，以一盏灯的视野为诱饵，布下了一个弃子争先的杀局。他罗启锋自以为是在主动进攻，实际上却是在对手预设的劫争里，身不由己地填了一口气。

罗启锋倒回自己的战术视角，看着暗夜中，自己开火时那致命的枪口闪光，如何在对手的狙击镜里，变成了一个清晰无比的坐标。他第一次没有气急败坏地砸键盘，也没有羞愤地关掉那耻辱的败局画面。

  

集散区的小厅里，又是另一番景象。风雷原声社的负责人方婉音，正在一份电子合约上签下自己的名字。合约条款细致入微：厅内禁止任何形式的交战行为，战区内的实时语音只能经授权后延迟传入；所有声音素材的母带所有权、转播权和使用期限，被逐项分开，清晰界定。她想为那些在炮火中来不及说完的话，在刀剑声里被湮没的情感，寻一个可以继续聆听和诉说的地方。

另一边，一个年轻人拿着一张“晨港”旧宅的截图，希望能在这里换一套新房。陈驰认真地看完了他所有的凭证，然后依旧温和而坚定地告诉他：“先生，您这份旧合同的履约方是霁岳集团，您的主张应当向他们提出。星原欢迎您带来任何您拥有合法授权的个人作品，但我们不能把别家公司未兑现的许诺，转变成这里的新债。”

夜色渐深，海岬的第一条正式战报通过系统公告传来：【一支NPC后勤车队在K7无人接管山路遭到伏击，两辆卡车损毁，道路阻断。】

这意味着，明天上线的玩家们，将要从那片狼藉的断路上，接着走下去。

罗启锋在冰冷的预约栏里，精准地翻出了“守夜人”这个ID，甩去一张带着凛冽杀气的次日演练战书。

而在破阵的中控室，程砚舟静静地立在那幅巨大的战区态势图前。屏幕上，无数红蓝光点仍在残酷的夜色中游走、碰撞、厮杀。他忽然想起了十九路棋枰上那冷冰冰的九个星位。那些星位，自古以来就矗立在那里，它们能勉强为对局者标定出东南西北的死生方向，却绝不可能替棋盘前的任何一个凡人，走完这通向深渊或者天元的，下一步。

战书发出，罗启锋破天荒地没有立即开始下一场匹配，而是将刚才那令他毛骨悚然的战术博弈，单截了一段录像，加密保存。在这片冰冷的数字江湖里，一旦碰见能毫发无伤接下自己杀招的高手，他便如嗅到血腥的孤狼，本能地想要递出更凶狠的第二剑。

而这一次，连剑路中被对方一眼看破的死穴与空门，他也非要赌上自己的全部声名，再去问个明明白白。
