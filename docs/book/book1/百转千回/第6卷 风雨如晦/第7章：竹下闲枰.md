# 第7章：竹下闲枰

冬日的风，带着一股子能钻进骨头缝的阴寒。岑绍庭在西山深处借了间竹舍，四面漏风，唯有一炉红泥炭火，将一壶水煨得咕咕作响。他约了几位弟兄，说是周末，来演练一段旧山道的阵法。

帖子发出去，回帖的却比从前少了一半。岑绍庭没骂他们树倒猢狲散，江湖路远，谁也没资格逼着别人饿着肚子来证明什么生死义气。有人得给老娘抓药，有人得去码头接能换三餐饱饭的苦差事，那才是眼下最要紧的江湖。

他当着最早到的几人，把底交得明明白白：“这趟演练，没有花红。半个铜板都没。竹舍的茶水钱，全是我从旧日香火钱里抠出来的。愿者上钩，不收拜帖费，不竖破阵堂的招牌，更算不上任何正式拼杀的战功。”他顿了顿，目光扫过一张张冻得发红的脸，“若有谁想把今日复盘的手段拿去黑市换钱，也行。但得另起一契，把名分、职责、还有那笔生态奉献激励金怎么分，一笔一笔掰扯清楚。今日这炉火，暖不了明日的锅。”

刘景和提着一网兜金黄的橘子，呵着白气踏进竹舍时，听到的正是这番话。他把橘子往桌上重重一放，发出沉闷的声响：“说这些屁话。谁是来跟你讨赏钱的？”

唐梓豪没露面，只托人递了句抱歉，说家里临时有急事。岑绍庭点了头，回话的人便知，这分毫未损他日后凭本事抢先锋印的资格。杜启航带着崽子坐了不到半柱香，小家伙被满屋子的大人闷得直打哈欠，他便歉意地笑笑，抱起孩子去竹林里看那些套着辕的马车。没人觉得他这是不给面子，硬逼着一个几岁的娃娃陪着熬这趟江湖闲话，那不是义气，是霸道。

演练的沙盘，是一套由十六台机柜、一百二十台服务器虚拟出的庞大网络，屏幕上闪烁着两万个明灭不定的节点，构成一幅半残的旧阵图。刘景和一眼就认出，那拓扑结构和如今重兵把守的“真山城”根本不是一码事。他指着屏幕上一处数据流三岔口，嚷嚷起来：“我认得这鬼地方！就是这儿，上次许嘉榕指错了生门，害得整个B段下行流量被掐断了整整三分钟！”

竹舍里顿时哄笑起来。许嘉榕的脸涨得通红，却也梗着脖子回敬：“行，今儿你来当司号兵，你去调度那1.2Tbps的洪流！我去拉粮车，我去看管那个基本参与份额五百元、差异池七千元的账目，总行了吧？”

“一言为定！”

几柱香后，轮到刘景和自己手忙脚乱。他耳朵里塞着监听用的听风竹简，左耳是模拟的用户端高频请求，右耳是系统后台发出的资源预警，两道“军令”同时涌入，他一时慌了神，竟把一个关键的数据包路由指向了后山一处早已废弃的备份服务器——一个数据的死胡同。

许嘉榕逮住机会，故意扯着嗓子高喊：“刘总调度！到底是哪个后口啊？你倒是给个准信儿，我这四万七千九百二十七块五毛钱的款子（扣除72.5元电费后实付），可就等着你放行了！”

竹舍里再次笑成一团，连炉火似乎都更旺了些。刘景和满头大汗，手忙脚乱地在阵图上比对暗号，好半天才找对端口，将那辆悬在悬崖边的“粮车”缓缓导入正途。他摘下竹简，长吁一口气，苦笑着抹了把汗：“以前听人复盘死局，总觉得前人愚不可及，破绽百出。真轮到自己耳朵里同时塞进两道军令，照样慌得找不着北。”

岑绍庭一直坐在一旁，指间捻着一枚冰冷的黑玉棋子，渊渟岳峙，只是微笑。他没有出声去替刘景和捂那个漏风的气口。这和打谱是一个道理。看前人留下的残局，自然觉得招招是妙手，处处可翻盘；真轮到自己坐到那十九路盘前，面对一片混沌厮杀，往往是顾头不顾尾，一着不慎，大龙立死。这在棋社里早就见怪不怪。肯有人愿意在这死门处停下来，挨一刀，重看一遍自己的愚蠢，远比那些装模作样、从不出错的高手，更能长进真本事。

算盘上，没人给他记上丢人现眼的份额。刑堂里，也没人因为这次走眼去砍他的帅印。他们这回摆的本就是一局切磋的闲枰，可以随时脱先、悔棋、推盘重来。但所有人都心知肚明，绝不能恬不知耻地拿它去冒充拼过命的带血军功。

方婉音想把这久违的笑声录进风雷社的母盘。她挨个问过一圈，有人爽快点头，有人却冷着脸摇了头。她没有强求，最后只在散场后，求肯赏脸的人重新对着一只铁匣子留了段声。她死死立下规矩：此段声轨，仅在破阵堂内部信托档案中留个念想，绝不出售，永不公开。虽然听起来没了先前的真性情，但也绝不能偷偷把不愿留名的人给录进去。人家嗓子好，是人家的本事，绝不欠你风雷社半分人情。

陆宏远来借一套用于压力测试的行头时，当面跟她谈定了一段新算法的授权价码。就在竹林夹道上，两人把登台的日子、能传唱的地界和赏钱一笔一笔钉死在口头契约里，谁也没仗着今天在竹舍里白喝了同一壶茶，就厚着脸皮，以为明天的买卖也可以空手套白狼。

程砚舟是最后一个踏进竹舍的。他一来，便听说明日还要继续，习惯性地打起了心里的算盘，问岑绍庭，能不能把这事写进破阵堂重振声威的红榜里，也好让外头的人看看，咱们的人心还没散。

岑绍庭没搭理他那套虚的，只用合拢的折扇，指了指桌上刘景和带来的橘子，示意他先把屁股坐稳。

剥落的橘皮懒散地堆在案头，散发着清苦的香气。没谁眼巴巴地等着程砚舟来吼一嗓子东山再起的口号。这间破竹舍，就像是冷雨夜里的一座残破山神庙，几个凑巧同路的夜归人，暂且解下腰间的刀，放下各自的心思，借着一豆残灯说上几句闲话。等天一亮，是去劫道还是去保镖，各奔东西，谁也没必要在今晚，强行按着对方的手指在投名状上画押。

“今天肯来喝茶，保不齐明天就提刀去投了别的山头。你那红榜，是想给别人看，还是想骗你自己？”岑绍庭的声音很冷，像窗外的风，一下就戳破了他的妄念。

程砚舟脸上一热，放下了手里的事务，默不作声地接过一趟赶“粮车”的粗活。他刚一“扬鞭”，就贪快想抄近道，试图绕过一个高拥堵节点，结果触发了连锁反应，把自己身后跟着的几个数据队列全堵在了一条名为“一线天”的窄带通道里，系统延迟瞬间飙升。

刘景和毫不留情地一顿臭骂：“你当这是天山折梅手，收发自如？这是死棋筋！倒回去，老老实实排队，等前头的ACK信号！”

程砚舟破天荒地照办了。他没仗着自己是画阵图的祖宗，就用什么缩地成寸的法术去硬闯。他猛然想起十九路盘上，那些因为贪恋大场、强行脱先，结果被对手抓住薄弱处，惨遭屠龙的带血教训。这一刻，他咽下了嘴里那番关于效率和架构优化的长篇大论，只把“粮车”死死拉住，像个最笨拙的新手，老老实实地等前头的探马吹响那代表放行的牛角号。

散场时，竹舍的茶钱按着人头结得干干净净。有刀客直言下周未必有空，岑绍庭也只是在那虚拟名册上划了个圈，道声保重。隔壁刑堂那盏象征着未决诉讼的鸣冤灯笼，还在风雨中顽固地亮着，屏幕上那个167小时59分59秒的倒计时，仍在冷酷地跳动。那些堆积如山的带血烂账，那些关于一票否决权注销和信托处分的法律纠纷，绝不会因为这个稍微喘了口气的下午，就凭空化作一缕青烟。

方婉音把那段过了明路的声轨，郑重地存档，取名叫作：《周六，等前方的车马过去》。

那绝不是什么宣告天下太平的洗地檄文，它仅仅是几个满身泥泞的人，在还没爬出泥潭的时候，凑巧围在火堆旁，烤过火的一段微薄证明。
