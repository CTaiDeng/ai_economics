# 第4章：负剑责躬

刑堂之内，炭火无声，却驱不散那深入骨髓的寒意。

周慎衡渊渟岳峙，立于堂前。他一言不发，只一个手势，身后两名壮汉便将四口沉重的铁边木箱顿在地上，发出“哐”的闷响。箱盖掀开，是码放得整整齐齐的雪花银锭，在窗外投进的惨白冬日里，反射着冰冷刺眼的光。

整整两万两现银。

银光映着八位管事铁青的脸。周慎衡的目光如刀，从他们每个人脸上刮过，绝没有厚颜无耻地将这笔钱称作“茶水费”或是“封口费”。这是割肉赔罪的钱，是拿命来填的账。

挂错帅旗，擅自放行。白纸黑字的罪状早已在刑堂过了明路，堂下跪着的是一排排按了血手印的苦主。破阵网络，如今被江湖人沿着这一季的血雨腥风，惯称为“破阵堂”，硬生生扛下了这笔血债。每一个银锭，都从破阵堂自家的私库里剜出，带着体温，也带着血腥。这笔钱，不去黑市买那删帖的江湖令，也绝不要挟任何一个拿钱的冤大头，去替他们唱一曲洗白重生的赞歌。

堂后，一扇紫檀木的屏风隔开了内外。程砚舟独自坐在案前，账簿摊开，上面是下个季度眼看就要见底的粮草数目。他面无表情，在那份割肉补疮的契书上重重画了押，反手又取过另一份文书，狼毫笔蘸饱了墨，一道浓黑的斜线，划掉了那场原本要大摆排场的誓师大会。

战死刀客的抚恤，一文不能少；封在钱庄的抵押金，那是崇远商行续命的老本；各有各的主顾，各有各的命门。谁敢把脏手伸进别人还没捂热的钱袋里去拆东墙补西墙，他程砚舟第一个斩了那只手。

铁画银钩，力透纸背。当他掷下笔时，才惊觉紧攥的掌心早已渗出黏腻的冷汗。低头认下这笔血债，就像把自己亲手淬火千百遍的剑锋，以一种决绝而缓慢的姿态，硬生生地折了回来，逼着自己看清刃上每一个丑陋的豁口。撤掉那场撑门面的大戏，固然是灰头土脸，颜面扫地，却总好过把这把带血的断剑，扔给台下那些还信着他的兄弟，让他们去替自己扛。这盘棋，他宁可弃子认负，损了外势，也要保住中腹那几块尚未活透的孤棋。

许知妍红着眼圈快步绕过屏风，声音发颤：“堂主，这笔钱……我名下还有些私产，至少能顶下一部分。”

“站住。”周慎衡的声音从堂前传来，冷硬如铁，“把堂口的江湖外债，与自家的家法，劈开来算。”他头也未回，话语却像冰锥，字字扎在许知妍心上。“要领几记杀威棒，该吐多少银子，刑堂日后自有规矩清算。但绝不能让堂外的苦主，干等着我们关起门来分完锅再拿钱。”他顿了顿，补上一句，“刑堂办案的火耗也得另外掏腰包，休想从那两万两割肉钱里先扒掉一层皮，再恬不知耻地拿着原数去外面邀买人心。”

六扇门的捕快很快就到了，公事公办，不带丝毫人情。他们腰挎朴刀，眼神锐利，顺着卷宗上的气口，逐笔核死了被封条锁住的那四万两银子，和从骗子狗嘴里硬生生扒出来的一万两千两。确认这轮开仓放粮，既不会毁了追凶的罪证，也不会让别的苦主寒了心，这才取出官印，在猩红的印泥里重重一摁，盖上大印，准予放款。

五万两千两真金白银，顺着那本写满了人命与亏空的生死簿，直接落进一个个苦主的口袋，半个铜板都没沾破阵堂的私库。破阵堂另外掏出的两万两割肉钱，如同另一条血脉，并入其中。两路并流，总计吐出七万两千两。而卷宗上核实的净亏空，是七万八千两。那剩下的六千两死账，如同一根拔不出的毒刺，继续死死钉在追魂簿上，日夜噬心。

那张分赃的生死簿，此刻成了还债的判词。每一笔账都算得骨肉分明。先算死每个赌徒从官府手里领走的追赃款，刑堂的调停人再拿破阵堂掏出的那两万两血钱去填坑，硬生生把这两股水流，按着净亏空的十三分之十二，不多不少，填平了大部分窟窿。以前贪小利吃过的诱饵，早已一笔笔扣得干干净净；那些没补齐的黑洞，连同骗子当初在黑市上画下的虚妄暴利，一笔笔，全记得清清楚楚。每个人画押认领的，只是自己断掉的那根骨头，谁也没资格拿这薄薄的一张纸，去勾销六扇门还要继续办的杀头大案。

吴秀榕的手在发抖。她看着算盘上为她单独扒平的碎银子，听着调停人毫无感情的语调。她砸进去收不回来的两千六百两命钱，先拿回了两千四百两，还悬着两百两的断点。潘俊棠也是一样的下场。至于骗子当初许诺的那三千两的虚妄大饼，调停人说得明白，那不过是画鬼充饥，绝不可能因为过了趟堂，就莫名其妙地变成了大豪岑绍庭新欠下的血债。

“画了押，”吴秀榕的声音嘶哑，像被砂纸磨过，“剩下那两百两……还能提着刀去要吗？”

调停人冷冰冰地将抵扣的碎银、未收回的烂账和还能继续追魂的底档，挨个指给她看，又讲了一遍。她死死咬着牙，血腥味在口腔里弥漫开来。良久，她才伸出食指，在那份文书上，按下了一个鲜红的指印。

钱庄入账的喜鹊凭证递到她手里，薄薄一张纸，却重逾千斤。她没有挤出半点笑，只像个失了魂的泥塑，死死盯着窗外枯败的枝丫看了很久很久，才取出信鸽，写了张字条缚在鸽腿上，手一扬，飞向城的另一头。

字条上只有四个字：我拿到了。

片刻之后，另一只信鸽飞回，带着潘俊棠的回信：我也是。

当年一起走镖时，在篝火旁击掌为誓、粗豪放言的玩笑，再也没能跟着那笔带血的碎银一起活过来。飞鸽传书，死死停在那两句形同陌路的口令上。死局上的一处断点，好不容易被外力强行接上，可人心里的那盘残局，却再也做不活了。

程砚舟隔着厚重的琉璃窗，眼睁睁看着他们将那份象征着了结的文书收回怀里，像收起了一面破碎的兵符。他没有出面，没有去替这盘远远还没收官的恶战，写下一句虚伪的判词。

旁边一个摇旗的小弟机灵，想举起绘影晶石，把苦主们拿到钱的“感恩戴德”画下来。程砚舟目光一凛，手臂横伸，如同一把出鞘的剑，拦住了他。“入库的账本，自然要留档，”他声音低沉，“但苦主脸上是哭是笑，绝不是破阵堂拿去往脸上贴金、装作天下太平的投名状。”他一字一顿地补充道，“愿意站出来替我们洗地的，另写切结书。冷着脸不愿吐半个字的，也绝不能少他们半个子儿的活命钱。”

风波未平，一波又起。邱庭舟随后冷着脸找上门来，声如寒铁：“早先被无端褫夺兵权、蒙受不白之冤的弟兄，是不是也拿这七万两千两来封口？”

周慎衡从卷宗中抬起头，眼神锐利地劈开这笔糊涂账：“这是给买命钱被骗的苦主填窟窿的本金。至于洗清战场上的骂名、补齐克扣的花红，以及因延误战机而流的血汗，各有各的刑堂去判，各有各的账簿去算。”他将两份卷宗重重拍在桌上，发出两声脆响，“哪怕是被错抠下的一两碎银，也绝不容许混进这锅大杂烩里。休想用一个连锅端的恩典，就把所有人还在流血的刀口，强行贴上封条。”

夜深了，顾承安点亮了堂中的灯，开始逐一核对名册，把那些被平反的弟兄，重新放回了点将台。洗脱逃兵的骂名，不代表就能闭着眼睛直接抢到先锋的帅印，依旧得凭着刀法，在校场上与别的刀客一较高下。但那记早已被砍碎的斩首令，却再也不能成为一道无形的枷锁，把他们拦在点将台外。

战场上早已流干的血、死掉的兵卒，必须当成板上钉钉的正史，死死刻在功过碑上；而那些冤枉兄弟的黑材料，则按着铁证，当堂投入火盆，化为灰烬。这两股因果，泾渭分明，绝不能混作一团，强行让时光倒流。

庄承裕那笔拉皮条的黑金，连同另一半还没挖出来的赃款，依旧像毒蛇般盘踞在追魂簿上。张榜的黄底黑字，死死留着这几处要命的气口。陈驰替自己扛下的这半局收官终于落子，但他手里的那支狼毫，绝没有替任何一个还在流血的苦主，画上那个代表恩怨两清的红圈。

天色完全黑透，寒星寥落。周慎衡独自一人，挑灯重新去盘下季度的粮草。破阵堂的私库里，实打实地被生剜了两万两，再加上刑堂过堂的火耗，下半年能挥霍的阵仗，只能生生往回缩。这几笔带着血痕的烂账，不是旁人能替他们拿块遮羞布捂上的丑疮，只能由他们自己，一刀一刀，将腐肉剔除干净。

城南的陋巷里，吴秀榕就着一盏豆大的油灯，将那张写着“尚欠贰佰两”的追魂帖，和刚拿到的钱庄底单，小心翼翼地叠好，死死塞进了同一个油纸包里。两张带血的凭证，一张都没扔。

她终于能花那笔从鬼门关抢回来的买命钱了。

但同时，她那双因为长久熬夜而布满血丝的眼睛，仍死死盯着那个还在漏风的死门，一定要让天下人看清，那里，还欠着她一笔还不完的血债。
