# 第5章：三局盈亏

朔风如刀，正一下下剐着破阵堂工坊门楣上那块“秋季誓师”的烫金招牌。木屑与剥落的金箔混在寒气里，劈头盖脸地打下来，像一场迟来的嘲讽。

陆文渊提着他的独脚紫檀木算盘，立在廊庑的阴影下，看那几个伙计手忙脚乱地拆解着半月前的豪言壮语。他没有半分冷嘲热讽的心情，那风刮在他脸上，也像在刮他心里的账本。他自己回崇远商行要交的那份请罪书，怕也得推倒重写。秋季发了三路大军，一路血战险胜，两路无功而返。他亲手批下去、砸进这无底洞里的六万两雪花银，究竟是如何在刀山火海里滚了一遭，又剩下几两骨渣，必须得有个说法。一个铜板都不能含糊。

堂内，一盆炭火烧得半死不活，根本驱不散这如冰窖般的寒意。周慎衡就坐在那盆半明半暗的火光旁，一张脸比门外的北风还要冷硬。他面前那张宽大的黑胡桃木桌上，没有茶，只有一摞摞码放整齐的银锭，和三卷用牛筋绳捆扎的账簿。

“‘秋声回望’一役，”周慎衡的声音没有起伏，像在宣读一份判词，“出门时，崇远商行拨银两万两。中途截杀，劫回现银六万两。总计入账，八万两。”

他伸手，将一摞银锭推到桌子中央。那银子在昏暗中泛着沉闷的死光。

“开销：购置军械，两万两。阵前花红，赏给三百刀客，两万四千两。点将联络，各路香火钱，四千两。”他每说一笔，便从那银堆里分出一份，动作不大，却带着千钧之重。“按出兵前画押的死契：崇远商行先收回本金两万两，再分润利钱四千两，此为刀口舔血的彩头。余下八千两，归破阵堂，留作底金。”

一笔笔银子被分拨开，壁垒分明。出门时的两万两本金，与后来劫回的六万两，在账目上泾渭分明，绝无混淆。那两万两老本，既没有被偷梁换柱，挪作他用，也没被厚颜无耻地粉饰成战功。它只是在时光的漏斗里走了一遭，又原封不动地回到了原处，冰冷，诚实。

陆文渊一言不发，走上前，放下算盘。他修长的手指在算珠上疾走，只听得一片清脆的“噼啪”声，如急雨敲窗。片刻，他停下来，点了点头。账，是对的。但这八千两，仅仅是“秋声回望”这一隅之地侥幸做活的一块棋，绝不代表破阵堂这满盘死活，已然由黑转红。日常的流水、新打磨的机括暗器，连同那些深不见底的旧账血窟窿，依旧死死钉在总账的耻辱柱上。

“第二局，‘南桥护镖’。”周慎衡拿起第二卷账簿，解开牛筋绳，摊在陆文渊面前。那纸页上，透着一股未干的墨迹与无功而返的萧索。“预算两万，实拨两万。探路、打点、买通沿途关隘，共支八千两。后军令忽至，中途撤回。余下一万两千两，已悉数退还崇远账房。”

陆文渊的目光落在那“支八千两”的墨迹上，瞳孔微微收缩。这八千两，如同投入江心的一块石头，连个水花都没见着。

“按规矩，各自认命。”周慎衡的语气不容置喙，“探路的兄弟淌过的汗，买通关节烧掉的香火钱，一文不能少。不能因为刀没见血，就当弟兄们是在耍猴。”

南桥那张残局，就这么半死不活地摆在那里。探路的人，没权把别人铺好的路强行炸毁重来，也休想拿这没打起来的残局去冒领战功。烧掉的香火钱是实打实的，但没真正过刀，就是没过刀。这是两根绝不能混淆的骨头。

“第三局，‘北岭夺营’。”周慎衡将最后一卷账簿推了过来，它甚至没被解开。“兵马未动，粮草先行。两万两军饷原封不动，早已归账。”

陆文渊的手指在三卷账簿上缓缓划过，像是在抚摸三块墓碑。他抬起头，目光如炬，直刺周慎衡：“一局小胜四千，一局折损八千。崇远商行前后拨银六万两，如今归账五万六千两，里外里，亏了四千。周堂主，这还不算，南桥一役半途而废，江湖上都说破阵堂虎头蛇尾，信誉扫地。这笔无形的折损，又该如何算？这八千两的窟窿，破阵堂不该多担待一些么？”

他这是在收官阶段，试图靠一个“打劫”来搅乱盘面。

周慎衡的脸沉得像要滴下水来，他没有动怒，只是冷冷地反问：“陆先生，请指明，破阵堂究竟违了哪条门规？若有，你即刻写明，我交刑堂自裁。若无，便请按白纸黑字的死契结清。休想因为盘口炸了，就把黑锅全扣在离得最近的人头上。”

他的话，如武当心法，渊渟岳峙，守得滴水不漏。任你千般算计，我只守我中宫一隅。

陆文渊的算盘珠子捏在手里，几乎要被指力碾碎。他盯着周慎衡看了半晌，最终从牙缝里迸出两个字：“画押。”

他黑着脸在分账的契书上签下自己的名字，保留了回去拍桌子骂娘的权利，但终究没有下作到把亏空的窟窿，强行转嫁给底下卖命的弟兄。

他将分账死契揣进怀里，那纸张的棱角硌着胸口，生疼。当初歃血为盟，说好同上刀山，如今分道扬镳，至少还肯硬着头皮，各自认下自己的死账。这草莽江湖里最后的一点规矩，有时竟脆弱得只剩下这点担当。

堂外，一个断了半截耳朵的喽啰忍不住高声质问：“既然说好大碗喝酒、大块分肉，凭什么‘秋声’那趟，弟兄们拿命换来八千两，你们这些坐堂的金主，就能舒舒服服地赚走四千两？”

话音未落，程砚舟的身影已如鬼魅般出现在那人面前，反手将一份过堂的红契甩在他脸上，纸锋刮得他脸颊生疼。“当初押上桌的是白花花的真金！若是打了水漂，流干的也是真血！你只看到那四千两的彩头，怎么没看到南桥这八千两的窟窿？这两笔账，本就是拴在一根绳上的蚂蚱！你可以不签这份生死状，另寻高就。但绝不能等刀客把命换来的钱劫回来了，你才红着眼，要撕当初说好的分赃规矩！”

那喽啰被喝得满脸通红，满心怨毒，却只能把不甘死死咽进肚里。旧的门规，没有在这一声吵闹中被当场撕毁。拿了暴利，自然要说清是抢了哪个堂口的肥羊，但绝不能仅仅因为彩头比喽啰丰厚，就成了天理难容的死罪。反过来说，哪怕你这趟镖赔得血本无归，也洗不净你当初靠阴谋算计、拔刀逼人滚蛋的肮脏手段。

陆文渊收起算盘，一言不发地转身离去。他只字未提下半年的粮草，却也无人开口去求。他依旧肯坐在暗处，如一个最苛刻的棋手，端详每一局的残谱，死死逼问以后每一笔赌注可能陷入的最大死门，更要冷眼看看这群不要命的，下次再跌进血坑时，究竟要怎么往外爬。

程砚舟横剑于门前，权当送客。他没有搬出“义气大过天”这种虚伪的套话，去骗陆文渊再往这火坑里砸一分钱。

夜深了，海岬战区那边贴出了“秋声回望”的后续告示。那晚冒死运进暗港的一批火器，已在三日前炸开了官军的围剿，为一条生路开了道。那几个拼过命的刀客，也早就换了别的山头，赏金一笔不落，全数打进了各人的行囊。江湖还在受用他们当年拿命铺出来的路，但这绝不代表他们就能千秋万代地坐在路口收买路钱，更不代表砸钱的金主能永远像吸血鬼一样，趴在这条道上抽成。

堂内，那三卷带血的生死簿被周慎衡重重合上，发出沉闷的响声。封皮上没有写什么“江湖同心、天下太平”的粉饰鬼话。

一局劫后余生，一局撞破南墙，一局勒马悬崖。

这三步跌宕起伏的残棋，已经用最冷酷的笔触，向天下人描摹清楚，那六万两带血的真金，究竟经历了一场怎样抽筋剥皮的浩劫。
