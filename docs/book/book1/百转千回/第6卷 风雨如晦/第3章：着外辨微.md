# 第3章：着外辨微

第二次刑堂过堂，潘俊棠从那件洗得发白的粗布棉袄里，掏出了一方破旧的桦木小算盘。算盘的边角被摩挲得油光锃亮，每一颗枣木珠子都像是浸透了人世的油汗与血泪。

九万六千，减一万八千。

他枯瘦的手指在算盘上拨动，珠子与横梁撞击，发出“啪嗒、啪嗒”的闷响，在这死寂的公堂上，清晰得像是渐行渐近的索命足音。得数是七万八千，与堂上判官卷宗里那笔冰冷的死账，分毫不差。可他依旧咬着牙，像是不信邪，将那几颗珠子拨回去，又重新算了一遍。

上一次，就是那些记在云端、花里胡哨的电子账本，像桃花岛的奇门阵法，步步皆是生门，踏进去却处处都是死路。这一次，他打死也不愿再把自己那两千六百块的活命钱，闭着眼睛，交到别人手里任其宰割。

他拨算盘的声音极轻，动作却慢得像是暮年的棋手在复盘一局生死劫。每一颗珠子落下，他都要死死盯上半天，仿佛要从那光滑的木纹里，看出藏匿的杀机。旁人早已不耐烦地将那些死活气口讲了千百遍，他却偏要像个最笨拙的初学者，亲手把十九路棋盘上这一着，落到下一着的前面，用指尖的触感确认，这两手之间，没有被那只看不见的黑手，抽走任何一寸赖以活命的实地。

高坐堂上的判官面沉如水，声音里听不出一丝波澜，他将每一笔带血的账目来路当众展开，犹如刽子手在展示行刑的利刃。潘俊棠自家垫付的冤枉钱，被一笔劈掉；那些诱他入局的香甜诱饵，被逐个抵扣。公堂那张宽大的黑胡桃木桌面上，只留下一串串冰冷的刺客代号，而真金白银的最终去向，则被死死锁进了一个个不便见光的暗盒里。

吴秀榕与潘俊棠，各掏了两千六百块的命钱，至今未见半个子儿的回头钱。但这黑市上画出的两个所谓“三千元”的画饼，绝无可能在刑堂上一过，就凭空变成大豪岑绍庭新欠下的一笔六千元血债。江湖恩怨，一码归一码。

潘俊棠双眼熬得通红，布满血丝，却仍像一头被逼入绝境的孤狼，死死咬住骗子当初在死契上画押的那个数字。判官看了他一眼，目光冷冽，却并未呵斥，只是取过一张新卷，将他这带着血泪的贪念另立一案，批注：此番升堂，只追本金；此笔妄念，不阻其讼。这便是刑堂的规矩，不替你判断何为妄念，但也不让你挟着妄念，来污了这追讨本金的公道。

堂鼓三通，轮到审判那道要命的放行昏令时，许知妍的脸色已是一片煞白。她默默从旁听席上站起，走到堂中央那条专为受审者设下的冷板凳上，缓缓坐下。那凳子像是万年寒铁所铸，一股刺骨的寒意顺着脊椎直冲天灵盖。

判官的诘问如刀，一刀刀割在她身上：
“为何一笔无从查考的烂账，却能挂上‘北辰’的将旗？”
“为何示警的狼烟既已点燃，却只敢如鼠辈般，在虚文上偷偷摸摸涂改几句？”
“为何盘口炸裂，血流成河之际，迟迟找不出一个该为此事掉脑袋的人？”

她咬着下唇，唇上渗出一丝血腥。铡刀就悬在头顶，她迎着那冰冷的锋芒，一字一句地挨着刀。黑市盗用“北辰”名号行骗，确是铁打的事实，但她也绝无可能借此洗白，自己那面被挂错的帅旗，没有在那场屠杀中，成为招引冤魂的幌子。

平生第一次，许知妍尝到了自己的名号被钉在耻辱柱上，受千刀万剐的滋味。那是一种深入骨髓的寒意，比这刑堂的冬日更冷。她没有为自己辩解半句，没有搬出过去替人仗义执言的老资历来做挡箭牌，只是将身下的冷板凳，硬生生往前拖了半寸。冰冷的剑锋已经刺穿了喉咙，她必须让天下人看清自己的伤口，看清这伤口有多深，流出的血，又是什么颜色。

“不对！”一名苦主猛地站起，像一头暴怒的狮子，他戳开当初交钱时的旧盘口光影，“这里！这里根本没有后来才心虚补上的泣血警告！”

众人哗然。判官手中的底档，竟也错引了那份被洗白过的新案卷。

顾承安的面庞冷硬如铁，他一言不发，亲自上前，当堂查验旧档。片刻之后，他从一沓封存的卷宗中，劈出了一份带血的原始凭据。那上面，没有警告，只有引人入局的颂歌。

程砚舟的目光死死钉在许知妍身上，他咬着后槽牙，腮边的肌肉绷成一块坚硬的石头。但他没有动，没有替她挡下这致命的一刀。两人有过命的交情，可在这森严如铁的门规面前，在天下人的公审之下，任何私情，都必须退避三舍。

海岬战区那几道砍人的军令，也在这周，重新在死囚牢里过了堂。

一名刀客，在掩护军令下达后，依旧贪功冒进，致使侧翼空门大开。那道杀威棒，继续死死打在他身上，虽不夺其性命，却褫夺了他下次带兵冲杀的虎符。另一名弟兄，明明早已在血战中完成了交接，却被那帮瞎了眼的督战官，指着一张过时的旧沙盘，骂作逃兵。这道天大的冤狱，被当堂劈碎，清白与名号，一并还给了他。

判官的声音响彻大堂：“同在一个烂透了的战区里，绝不能让主将闭着眼睛，将二人一并拖出去斩了！功是功，过是过，一笔是一笔！”

老关那魁梧的身形如一座铁塔，他横刀而出，声若洪钟：“这冤狱平反了，以前看过他逃兵骂名的人，该怎么想？那些唾沫星子，难道就白挨了？”

“洗冤的判词，必须用赤金铆钉，死死钉在这份旧档案上！”判官回应，“连带着当初是谁瞎了眼，如今又为何翻案，一字一句，昭告天下！绝不能只在账本上偷偷把黑钱抹平，却任由那张带血的黑字报，继续挡住我等弟兄日后拿命去求的封赏！”

这一轮复盘，又在刀尖上挑出了一笔黑心的克扣。司号兵，本就得死守在战位上，等待前方九死一生传来的飞鸽信书。那等待的每一秒，心头都在滴血。原先的算盘先生，竟把这没敲击信号的几分钟，判成了临阵脱逃，克扣了军饷。刑堂按着当时的铁律，硬生生将这几段活命的时间夺了回来，重新分赃。判官更当堂立下规矩：若是将来要立新章程，也得先到江湖上广撒英雄帖，议定了再说。绝不许这帮拿笔杆子的，用新铸的铡刀，去砍旧人的脑袋！

这一刀切下去，靠的是早先白纸黑字的死契，绝不是高坐堂上的老爷们，临时发了什么菩萨心肠。冰冷的铁算盘和活人的判官，各有各的用场。算盘能算出更漏的时差，却算不出人心。它绝不能仅凭棋盘上几分钟没落子，就污蔑一个棋手，已在修罗场上丢了魂。

堂下，庄承裕杀猪般地叫着屈，赌咒发誓，死活不认自己从一开始就在挖坑埋人。刑堂的判官冷着脸，既留下了他带血的罪证，也一字不漏地记下了他说不圆的谎。没有为了让堂下苦主听个痛快，就草草给他定个凌迟的死罪。平台挂错帅旗的罪过，也毫无保留地甩给各方，该放多少血，另行上桌谈判。谁赔了钱，谁拿了钱，全都在追魂簿上一一画押，绝不容许哪头饿狼，拿着同一个血窟窿，来重复讨债。

散堂的钟声敲响，余音在梁柱间回荡。潘俊棠小心翼翼地把那只破算盘，和自己的带血底档一并卷起，揣进怀里。吴秀榕跟在他身后，脸上依旧带着惧色，怕这案子遥遥无期。但这一次，她终于能指着怀里那堆卷宗，分毫不差地说出，每耽误的一天，究竟在流谁的血；哪一份死契还没拼齐；又有哪些连篇的鬼话，已经再也当不成推诿塞责的挡箭牌。

顾承安吹熄了堂前的最后一盏灯火。幽暗中，那面冰冷的墙壁上，同时挂着刚刚洗净的清白、死咬不放的斩首令，以及那些依旧悬在半空、还未砸下的重锤。

它们没有像过去那样，被粉饰成一句热血沸腾的口号。

却比那种一刀把全盘杀个精光的大屠杀，更真切地刻下了每个人在这场浩劫里，究竟留下了哪一道属于自己的刀痕。
