# 第6章：还君明珠

第三次。

许嘉榕的靴底踏上刑堂门槛那块被岁月磨出凹陷的青石板时，心里默数。寒气顺着石板的纹路，蛇一般钻透厚实的靴底，直刺骨髓。她怀里死死抱着那本用油布反复包裹的阵中日记，书角已磨损，浸透着“归雁”战区司号兵的血汗与风霜。

那九百两带血的花红，像一具悬在城头的枯骨，从九月底一直吊到如今，北风刮过，便在许嘉榕的心里发出空洞的响声。她并非全指望这笔钱吊命，可那副日思夜想的听风竹简，那几吊能让人在寒冬里睡个安稳觉的盘缠，全都寄托在这具枯骨之上。判官那句冷得像铁的“尚在查验”，便是一把钝刀，每一次都将她这点活命的指望，往后生生割退一寸。

“这一回，”她走进那片沉沉的阴影，声音不大，却像一颗投在死水里的石子，带着不容置疑的决心，“总能把那本死账上究竟还漏着哪个气口，给我点透了吧？”

林静薇端坐于堂前，面沉如水，视线未曾从许嘉榕脸上挪开半分。她没有立刻答话，只是伸出两根修长的手指，将一份卷宗推过冰冷的黑胡桃木桌面。追魂簿上，墨迹森然。

“第一桩，驿站延误，此为过错，单立一案，死罪。”她的声音没有起伏，像在宣读一道早已刻好的碑文。“第二桩，刑堂接手，限期千礁商会交出底档。他们交了，却是一张画皮。”

她将那张所谓的“卖身契”在烛火下展开。烛光摇曳，映着她毫无表情的脸。她取来一枚琉璃镜，将那伪造的接缝处一寸寸放大。许嘉榕凑上前，只觉一股陈腐的纸臭和血腥气扑面而来。

“看这里。”林静薇的手指点在一条细微的撕裂痕上，那痕迹在琉璃镜下赫然暴露，像是地壳深处一道狰狞的伤疤。“这是两张红契的断口，被他们用秘法强行拼凑粘合。就像一柄借了上古名剑铭文的赝品，就算名字刻得再像，也接不住当初那份拿命换来的军功。”

她的话语，一字一顿，仿佛不是在解释，而是在用言语为这桩罪孽钉下棺钉。每一个漏洞，每一个破绽，都被她一笔一划地钉死在许嘉窝心头，让她看得清清楚楚，明明白白。

“邱庭舟那份烂账，用的是他早年间在旧堂口的通关铁牌。他当初的口令，只准旁人借他在那场血战里修过桥的资历去充个门面，这放行的号令，却被人移花接木，接到了另一张生死状上，凭空捏造出一份典当未来全副身家的卖身契。”林静薇收起琉璃镜，眼中闪过一丝鄙夷，“他退出旧山门时，早就换了新的号牌。就算恶狼手里死死攥着那张旧底牌，也休想凭空生出砍他脑袋的军令。”

另一侧，一直沉默不语的顾承安起身，取过新旧两份带血的红契，用两枚铁钉，“铛”、“铛”两声，并排钉在刑堂那面挂满陈年兵刃的墙上。

“旧榜单，留作铁证，查清这帮伥鬼是如何设的迷魂阵。”他沉声道，“但绝不能再冒充今天过关的虎符。这张，”他指着那张字迹宛若鸡肠的画押，“判官断案，不看谁的字写得好看，只死咬三件事：当时如何接的剑、堂口有谁作保、拿回了哪张底单。至于要找谁来递刀，得由苦主自己定夺，休想让那个冒名顶替的千老，替不相干的人来招魂。”

刑堂的惊堂木终于落下，声音沉闷，却仿佛带着千钧之力，将这几个月的阴霾一击而碎。

“判词已定：此六千两军功，厮杀为实，铁证如山。应分红利与被克扣之烂账，件件确凿。所谓典当卖身，纯属子虚乌有，一派胡言！”林静薇的声音陡然拔高，回荡在空旷的刑堂之内，“击鼓鸣冤的过场已走完，原主花红，即刻发还！至于造假一案，另立新卷追凶，绝不拿那些八竿子打不着的弥天大案作挡箭牌，把弟兄们的活命钱扣到地老天荒！”

一只沉甸甸的钱袋被推到许嘉榕面前。她没有立刻去拿，而是抬起头，目光如炬。

“许嘉榕，九百两。邱庭舟，九百两。其余几人，合计四千二百两。”林静薇的语气恢复了冰冷，像是在清点账目，“此款，从‘归雁’战区军资处封存的预备粮草中支取。我再说一遍，这笔钱，绝不是那九万六千两黑市赃款的一部分，也绝不从破阵堂为平旧账、自断臂膀割下的那七万二千两肉里出。更不会在你们拿走花红后，去替任何一个被坑的冤大头，抹平追魂簿上的半分亏空。一码归一码。”

许嘉榕的手指终于触碰到那冰凉的钱袋，她死死攥住，指节发白，却咬着牙先问了另一件事：“我背上那道莫名其妙的卖身典当刺青，何时能洗白？我还要去别的堂口扛旗，绝不能让下家主顾，继续把我当成一个连身家性命都卖尽了的奴隶！”

林静薇从卷宗里抽出另一份文书。“洗冤令。连同当年那份假的卖身契、翻案的铁证和当下的清白文书，一并存档。凡是以前瞎了眼收过那份黑材料的主顾，三日之内，刑堂会悉数送达平反公文。若要再往大街上张榜昭告天下，须由你本人亲自画押，绝不容许破阵堂为了证明自己断案如神，就把你私底下的伤疤，再撕开给街边的看客们当笑料。”

“好。”许嘉榕点头，心中的一块巨石终于落地。但她没有松懈，提着刀，向前一步，刀尖几乎触到桌沿。“生生拖了这么久，我误了工，折了本，这被耽搁的账，又怎么算？”

林静薇眼中竟闪过一丝赞许。她甩给许嘉榕一叠单独记下的文书，上面罗列着拖延的罪状和继续往上申诉的门路。“把本钱连本带利吐出来，绝抵不掉耽误战机的罪名。这些因此受损的烂账，仍旧一笔一划在刀尖上核对，休想拿几张无用的破礼券，就换回一句轻飘飘的恩怨两清。”

许嘉榕收好所有文书和钱袋，深深看了一眼堂上二人，转身离去。

邱庭舟拄着一把无鞘的阔刀，沉默地等在刑堂外。两人并肩走下那满是刀痕的台阶，冬日的阳光惨白，照在他们身上，却毫无暖意。

他侧过脸，沙哑地问她：“以后……还做这听声辨位的刀头舔血活儿吗？”

“做。”许嘉榕的回答干脆利落，“但得先摸清是谁挑的头，这旗，究竟怎么个交接法。”

她将那本带血的阵中日记死死合上，发出“啪”的一声轻响。这场浩劫并没有让她学会算尽十九路棋盘上的每一处劫争死活，只是往后，她再往棋盘上落子前，必定会死盯着身后的断点，多看一眼。这一眼，虽保不了她招招做活，却总能让她不再仅凭一个看似金光闪闪的帅旗，就闭着眼往前猛冲，将自己的大龙置于死地。

她依然向往在刀光剑影中去听那破阵的鼓角争鸣，但再也不会因为一面绣着金线的将旗，就把自己的性命，闭着眼睛交出去。

这种清醒，让破阵堂试图借此案洗白名声的盘口冷得像冰。可程砚舟依旧死咬着没松口，绝没有把这区区一桩洗冤的案子，涂脂抹粉成天下群雄重新归心的虚假画皮。他宁愿承受这份冷，也要守住这份实。这是弃子争先，舍弃一隅的虚名，换取全局的信誉。

午后，许嘉榕在城南的暗器铺里，反复掂量了数副听风竹简。最终，她挑中最顺手的一副，竹节温润，机簧清脆。她付了钱，将剩下的几块碎银小心地收进贴身的口袋里。

回到落脚的客栈，她点开一段不涉机密的旧战报残片。在那片光影交错的残影里，她看到自己声嘶力竭地报出阵眼方位，然后死死熬着，直到前锋营的回号传来，这才如释重负地松下一口冷气，几乎虚脱在地。

风中的声音依然凌厉，可那九百两带血的花红，终于完完全全落进了由她自己做主的口袋。

她稳稳地戴上新的听风竹简，推开窗，冷雨夹杂着雪沫扑面而来。她没有回头，再没有看一眼那张悬在江湖人心头，若有若无的封神榜。那些拼尽全力淌过的血海，早就该随风散去，绝不必永远被挂在别人的死牢簿上，等着被一次又一次地招魂。
