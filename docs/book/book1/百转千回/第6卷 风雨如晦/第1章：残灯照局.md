# 第1章：残灯照局

十一月，第一场浸透骨血的冷雨，毫无征兆地砸穿了京城上空铅灰色的愁云。工坊区那扇沉重的铁门前，新挂上一方未经打磨的胡桃木牌，上面只用狼毫蘸着浓墨，写下本周刑堂开案的冰冷时辰。除此之外，再无半句招兵买马、许诺青天的虚妄口号。木牌边缘的墨迹被雨水洇开，像一道蜿蜒的血痕。

堂内，陈驰用一块粗麻布，将那张能并坐十二人的花梨木长案擦得一尘不染，动作沉稳得如同入定老僧。空气里弥漫着潮湿木头与旧纸张的霉味，混杂着一丝若有若无的铁锈气息。

一个女人跪在案前，面色煞白如纸。她的信物，一枚刻着家族徽记的玉佩，在逃亡中被砸得粉碎；而那张证明她投入身家的买命钱底档，竟也未能留下任何备份。她以为自己会被当成空口白牙、前来滋事的流寇，连人带骨头一起被轰出这道最后的门槛。

“去钱庄。”陈驰的声音没有一丝温度，像机房里恒温的冷气，“调取底单，全程用你自己的印信过账。刑堂的人，绝不会沾手半点你的身家秘钥。”他顿了顿，目光落在女人抖个不停的手上，“少一张带血的红契，不代表那场屠杀没发生过。但单凭一张嘴报出的银两，也绝过不了判官手里的铁算盘。”

另一头，吴秀榕咬着青紫的嘴唇，颤巍巍地呈上了她在黑市里招徕人头的所有暗语记录。那是一本皮质封面的小册子，每一页都写满了见不得光的交易和承诺。其中一页，赫然记录着她曾对潘俊棠拍着胸脯保证的那句要命把柄：“查过底细，包赚不赔。”

“这句……这句能不能剐掉？”她哆嗦着，像溺水者抓住最后一根稻草。

坐在她对面的林静薇，连眼皮都未曾抬一下。她伸出两根手指，将那本册子推回原位，动作精准得如同收官阶段的一记“尖”。“不行。”声音冷硬如铁。“刑堂要留存的，是完整的因果链。绝不许任何人断章取义，将旁人的一句蠢话，放大成全盘的死罪。”她的目光终于落在吴秀榕脸上，“带血的罪证如何得来，将用在何处，都会按门规写明。张榜示众时，只会遮住那些不便见光的私密家事。但在这里，在局内，每一个落子，都必须清清楚楚。”

长案一角，死死压着那本千疮百孔的旧门规。书页泛黄，边缘卷曲，上面布满了不同时期的朱笔批注和墨迹污痕。有人试图绕开它，只拿后来缝补得严丝合缝的新法典来断今日之案。顾承安“啪”地一声，将一只还在滴漏着猩红液体的更漏顿在桌上，震得所有人的心都跟着一跳。

“赌徒掏钱下注时，看到的究竟是什么诱饵，就必须死盯着当时那个千疮百孔的旧盘口去查！”他的声音不大，却字字如刀，“修罗场上，一道送命的军令到底能不能打，也必须顺着那个先锋官当时被血雾蒙蔽的视线去看！用今日之棋规，去复盘昨日之死局，那是对死人的第二次谋杀！”

话音未落，另一桩要案的复盘已在刑堂的另一侧展开——海岬防线布防图泄密案。

一面巨大的留影石被激活，幽蓝的光芒投射在墙壁上，显现出沙盘般的战场。罗启锋的视角被忠实地还原出来，能清晰听见从四面八方传来的、兄弟们临死前的哀嚎与求救。然而，那条唯一能通往生路的指令，却被一股无形的力量生生卡了十几秒。十几秒，在棋盘上，足以让一条大龙从“活形”变成“死棋”。

后来，一位高高在上的督战官，俯瞰着全局封锁阵型，站着说话不腰疼地痛骂他：“西面明明有活口，为何不早点拔刀向西冲杀？”

可此刻，当所有人的视线被迫切回到罗启锋当时那被血雾与硝烟遮蔽的半张残图上时，那个所谓的“西路活口”，分明还是一片沉寂的黑暗，一个尚未被点亮的、充满未知的“星位”。

老关伸出一只枯瘦但稳如山岳的手掌，一掌拍在留影石的基座上。光影瞬间定格在那致命的、万籁俱寂的十几秒。

“十九路棋盘上，最忌讳的，就是多出这么一双事后诸葛亮的‘上帝之眼’。”他的声音苍老而沙哑，仿佛裹着风沙，“仿佛你早早把屠龙的杀招摆在天元，再去嘲笑当时身在局中、为‘劫争’耗尽心血的棋手，是个瞎子。”他冷冷地扫视全场判官，下令道：“先把这要命的十几秒死寂，原原本本地给老夫熬完。谁也不准快进。”

他亲自将两根更漏并排钉在墙上，一根代表他拿到外围血书的时刻，另一根，则是他发出撤退鸣镝的时刻。两股猩红的液体，以肉眼可见的速度，拉开了触目惊心的差距。

“被耽搁的战机，该拿谁的脑袋来祭旗；收到情报后，这盘棋还能不能强行续命，这些都可以拿刀逼问。”老关的目光如鹰隼般锐利，“但绝不能因为满盘皆输的结局已经摆在眼前，就硬要逼着罗启锋，在那片无尽的黑暗里未卜先知。”

刑堂的沙盘推演终究只是一场幻梦。纵然阵亡的兵卒可以在盘上换一百种死法供人剖析，但真实战场上流干的鲜血，绝不会因此倒流一滴。这场带着锥心悔意的复盘，也绝不可能凭空变出一两凭吊的战功，或是一文钱的安家费。

突然，一位铁面无私的判官像猎犬般嗅到了不对劲，他指出案卷中似乎被人抽走了一份内堂争吵的底稿。陈驰面无表情地从自己袖中取出一份蜡封的卷宗，当众拆开。那滴血的原件上，既有他当年劈头盖脸的示警，字迹力透纸背；也有程砚舟那句自负到愚蠢的昏令：“区区流言，一张布告足以平息风暴。”

控辩双方，拿到了内容一模一样的补丁。陈驰的眼神在说，绝不容许因为某句带血的口供会让掌门人颜面扫地，就偷偷将它压在卷宗的最底下。

岑绍庭带来了九月那场血战的阵亡名录，每一页都按着牺牲者的红指印，像一朵朵绽开的血梅。其中一个连算盘都不会拨的粗豪汉子，在上面画押认领了自己驻守的死关与时辰。但这纸本血书上记录的时辰，竟与武备库里记的档期，足足差了一整天。判官用朱笔冷冷圈出这个漏风的“气口”，将两份证据双规保留，并列存盘。而另一处模糊不清、对不上号的残印，更是被他用一枚铁钉死死扣住，下令彻查底细。他绝不会因为这本册子大半都是铁骨铮铮的战史，就对这一处可疑的暗门闭眼放行。

“漏了一处气口，总不至于让这满篇的血泪，都成了废纸吧？”岑绍庭冷眼相问，语气中带着一丝不平。

“自然不会。”判官头也不抬地回答，“但也绝不能因为满篇大半都是真血，那漏风的一处死门，刑堂就可以不去拿刀追问。否则，千里之堤，便是由此溃穴。”

隔壁厢房，方婉音正在交割“风雷原声社”的全部底档。她冷硬地定下门规：“只准截取那帮恶狼冒名顶替的铁证，剩下的带血母盘，必须用三重火漆死死封在铁匣之内。”

直到主事之人在交割的“死状”上画了押，她才将那只沉重的、记录着无数人声名生死的铁匣，重重搁在桌上。她把贴着封条的那一面死死护在怀里，只用一把小刀，精准地割出过了明路的那块“血肉”，递了出去。这手法，既有桃花岛主人的精妙算计，又有天山折梅手的收发自如。她深知江湖规矩，递刀给别人前，必得先验清刀鞘；既要让验尸的判官看清刀刃上的血，也得死死盯住究竟是谁接了刀、何时还刀。弃子，是为了争先。这份在刀尖上舔血的谨慎，在面对一群不相干的看客时，更是半点都省不得。

那场浸透骨血的冷雨，一直没有停歇。

那位摔烂了信物的苦主，终于从钱庄的铁柜里，讨来了那张带血的底单。陈驰冷着脸，用最好的油纸拓了两份，让她凑在灯下，死死看清每一笔烂账的来龙去脉后，将其中一份塞进她贴身的口袋。

她把那份判词般的纸页，小心翼翼地塞进油纸伞下。跨出刑堂那高高的门槛前，她又怔怔地回望了一眼那块在风雨中显得愈发冷硬的新招牌。

堂内，依旧堆满了没找到真凶的死账，还有被黑洞吞噬、至今未归的黑金。刑堂发出的那些冷冰冰的回执，绝没有尚方宝剑那般一亮就能天下太平的威力。

但至少，它像暗夜里的一盏残灯。

一盏能让那些被推下火坑、在黑暗中摸索的人看清，下一步，该提着刀，去哪座山头，找谁讨命。

以及，那一桩桩带血的冤案，究竟得拿出什么样的铁证，才能真正在这十九路棋盘上，翻盘。
