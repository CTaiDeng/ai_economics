# 第2章：穿花寻路

庄承裕硬着头皮，独自一人走进刑堂那间没有窗户的静室时，空气冷得像刀子。他不敢带任何一个昔日跟班，那些人如今见了他，眼神躲闪得比见了索命的阴差还快。

静室里只点了一盏鲸油灯，光晕昏黄，勉强照亮黑胡桃木长桌的一角。他小心翼翼地从账本最隐秘的夹层里，拈出那张单独记着拉皮条黑钱的薄纸。纸页边缘已被他指尖的冷汗浸得微微发皱。

整整四千块现洋。

这笔钱，死死地嵌在那笔早已被六扇门查实的、总额一万六千块的黑市买路钱里，像一块剔不掉的烂肉。他将那张纸推过桌面，声音干涩地为自己辩解：“判官大人，我……我只是个引路的暗桩，替人吆喝几声，牵个线搭个桥。钱庄的钥匙、银库的封条，没一样从我手上过。这骗人卖命的血债，凭什么全往我一个人头上扣？”

桌对面的判官，脸上戴着一张遮去眉眼的铁面，只露出一个刀刻般冷峭的下巴。他没有说话，只是将一叠黑底白字的供状，像一沓冰冷的铁片，哗啦一声摔在庄承裕面前。供状按着时辰的先后，钉死了他挣扎的每一寸空间。

“起初，你套取那些退隐刀客的真实战绩，拿去给黑市的骗局做画皮，可有此事？”判官的声音没有温度。

庄承裕的喉结滚动了一下。

“紧接着，便有苦主报出，用以抵押的虎符被一女两嫁，你却仗着堂主的威风，把要账的人强压在堂下，不许声张外扬，可有此事？”

“再后来，”判官的手指，重重地敲在最后一份供状上，那一句用朱笔圈出的“钱庄自有安排”，墨迹狰狞如血，“这句包藏祸心的迷魂阵，是你亲自点头，亲口放出。在那个要命的当口，你既没去钱庄查过一页底账，也没找大豪岑绍庭对过半句口供。你是在赌，赌这盘棋不会崩。”

庄承裕的脸色已是一片死灰。他确实不是在幕后画下这座奇门遁甲般迷魂大阵的主谋，钱庄的钥匙也不全挂在他腰上，刑堂的卷宗自然会记下这笔公道。但他在棋盘上清清楚楚看见死门之后，非但没有抽身，反而主动做了哪些引人入局的伥鬼勾当，那四千块染血的现洋又是如何从层层盘剥中落进他私囊的，判官的铁笔同样一字不漏地刻在案卷上。

“要吐多少黑钱，该挨几记杀威棒，全按门规过堂。”判官的声音如同最后的宣判，“休想靠一句轻飘飘的‘我只是个拉纤的’，就想金蝉脱壳，全身而退。”

从静室出来，庄承裕浑身虚脱，在刑堂外的夹道上，他像抓住最后一根救命稻草般死死拽住了邱庭舟的袖子。凛冽的穿堂风刮过，吹得他牙齿都在打颤。

“庭舟，邱兄弟！你给句公道话，四海堂……四海堂昔日确实是打过真刀真枪的硬仗的！你得替我证明！”

邱庭舟的目光比这冬日的寒风更冷。他的手稳稳地按在腰间的刀柄上，仿佛那才是他唯一的倚仗。他看着庄承裕，一字一句，掷地有声：“真打过。我这一身修桥铺路、勘探地脉的本事，就是在那里练出来的，是拿命换的真功夫。但这沾着汗水的过去，绝不可能替今天这卖人血馒头的勾当去作保。”

他顿了顿，眼神里没有半分动摇：“我会向刑堂交出我所知所见的、干干净净的供状。但要我为某个从根上已经烂透的招牌，去写什么非黑即白的荒唐诔文，恕难从命。”

邱庭舟说完，冷着脸，从夹道侧边让开一步，动作不大，却像划开了一道不可逾越的深渊。哪怕早已退出了旧山门，他依旧敢认当年受过的恩惠，也敢认后来亲眼见过的烂疮。恩是恩，债是债。若是为了证明自己早就跟那帮恶狼划清了界限，就硬把当年拼过的命也说成是假的，那他拼死带出来、至今仍在阴雨天隐隐作痛的一身刀疤，也就成了一张虚伪的画皮。

追赃的那条暗线，终于咬出了活口。

一间密室里，周慎衡的目光在一卷长长的账目上缓缓移动。烛火在他深邃的眼眸里跳动，映出的却是一盘十九路的围棋残局。早先被卷入各路销金窟的两万两千块黑钱，经过六扇门高手不眠不休的追索，已有一万两千块被硬生生从恶狼嘴里撬了出来，吐回了指定的铁库。

可剩下的一万块，依旧沉在深不见底的黑洞里。

他用指节轻轻叩着桌面，像是在棋盘上落下一子。好不容易在腹地做活了一块孤棋，但别处被绞杀的断点却依然在淌血。这区区一个胜负手，还远远不够替这满盘皆输的血战收官。他死死地在那笔烂账旁留着一处空白的气口，绝不能拿刚缴获的真金去强行粉饰太平，否则只会让整条大龙死得更快。

被官府贴了封条的四万两，加上新追回来的一万两千两，总计五万两千两真金白银，仍得按着门规排队过堂，一笔一笔核对血契，验明正身。

吴秀榕哆嗦着嘴唇，在公堂外拦住了一名女官，声音里带着哭腔：“大人，能不能……能不能今天就把我的命钱领回去？我家里……已经揭不开锅了……”

那女官正是林静薇，她面若冰霜，从袖中取出一张印着规矩的宣纸，冷冰冰地塞进吴秀榕的手里，却没有再赏她一句遥遥无期的“很快”。

吴秀榕的眼泪滚了下来：“我怕……我怕这钱，又是拿后面那些替死鬼的血汗钱来填的……”

“这回，是你自己的钱。”林静薇冷硬地斩断了她的妄念，声音不大，却字字清晰，“左边这笔，是死死护住的底账；右边这笔，是从狗嘴里抢回的残渣。每一两银子的来路，都一笔一划全钉在铁板上，绝不再沾任何一个新赌徒的半滴血。”

堂内，另一场争论已然沸腾。

二十二个苦主，当初总计砸进黑市九万六千两。经过刑堂的彻查，其中有一万八千两，曾被骗子当成诱饵，分批吐回给了部分早期入局的人。账目挨个厘清后，仍有七万八千两的真金白银，彻底化成了灰。至于当初骗子画下的那张能让石头开花、包赚不赔的虚妄暴利大饼，必须另起炉灶去告，绝不容许混进这笔保命的血汗债里来搅浑水。

有眼红的苦主拍着桌子，想把那些早期拿到过回头钱的人，全打成骗子的帮凶。

陈驰反手从卷宗里抽出一份死状，摔在桌上：“睁开眼看看！这位，前后砸了六千两，最后只捡回一千两的碎骨，净亏五千两的命！拿过诱饵，绝不等于跟这帮千门骗子是一丘之貉。而那些被吐回来的诱饵，也绝不能再厚着脸皮，算进被骗的死账里！”

海岬泄密案的追魂索，也在同时一寸寸收紧。

判官的朱笔在另一份卷宗上游走，笔锋冷静得不带一丝烟火气。偷偷将海防布防图卖给黑市的内鬼，和在堂前拉客的牙子，并不完全是同一拨人；而被蛊惑入局的赌徒，也不是各个都偷看过那份绝密的舆图。刑堂的判官，只顺着实际踏过的暗道、传递过的黑信和落下的刀痕去锁定罪人，绝不搞株连，也绝不把挤在同一个贼窝里的看客，全当成开了天眼的山大王。

被无辜褫夺兵权的摇旗兵，终于等来了一纸解禁的公文。那些还没落锤的斩首令，仍被押在死牢里，等候最后的复核。死死守住过军机要密的人，绝不需要替整个腐烂的堂口去顶罪背锅；而那些趴在泄密图上喝过血的秃鹫，也休想因为自己没在黑市买过一张红契，就能躲过刑堂的铡刀。

深夜，陈驰的房间里，只有屏幕的冷光照亮他疲惫的脸。他刚刚给自己的催命房贷上好了这个月的响马。屏幕右下角，吴秀榕的头像在闪动，带着血泪的叩问跳了出来：当初我们怎么就瞎了眼，看不穿这迷魂阵？

他叹了口气，指尖在键盘上悬停。他敲下几句“别太自责”、“都会过去”的宽慰废话，又冷着脸，逐字删光。最后，只留下了一句冰冷的军令：

“把你当时被蒙蔽时，对方给你看过的所有画皮、许过的所有诺言，按顺序一一钉死，存好。别因为恨自己蠢，就把那些能要了骗子命的刀痕给亲手抹了。”

另一间更深、更静的密室里，顾承安正在一张巨大的宣纸上，用朱砂墨线绘制一张错综复杂的关系网。金主的过手银、刀客的花红、拉皮条的赏金、空头死契和被层层转走的黑钱，像一条条索命的锁链，被他一环一环地套在具体的、活生生的人名脖子上。

程砚舟端着一杯热茶走进来，脚步很轻。他的目光落在图上，顺着其中一条最粗的血色墨线追溯。那条线，代表着最大一笔黑钱的流转。它蜿蜒曲折，穿过无数个名字，最后，竟死死地连着一个他再熟悉不过的印鉴——那是当年，他亲手画押的一张放行令。

他站在那里，一动不动。手中的茶水，氤氲的热气模糊了他的视线，但他却看得无比清晰。那道带血的铁链，仿佛有了实质，正一圈一圈地勒紧他的脖颈，让他呼吸困难。

他没有伸手，没有试图将那条线挪开哪怕半寸。

在这盘错综复杂的残局上追溯死手，并不总能抓出一个可以完美背下所有黑锅的替死鬼。有些滴血的因果线，在江湖的棋盘上绕了千万里，打过无数个劫，最后竟又像宿命般，以一个最匪夷所思的角度，一个看似早已跳出三界外的单官，死死绕回了他们自己的天元。
