# 尾声：十三道门

小溪把最后一颗黑子从棋盘上拿起来，又轻轻放回原位。

“六点九目，大吗？”她问。

“在有些棋里很大，在有些棋里，只够证明一件事。”

“什么事？”

程砚舟望向玻璃墙外。十三个腔室的运行灯依次亮着：城北的结算节点刚完成一笔付款；锦川的地方议事会驳回了一项越权请求；南离有人提交新的母带授权；一个从未见过程砚舟的年轻维护者，正在独立处理申诉。没有哪一盏灯需要先等他的许可。

“证明不必把所有人变成自己的人，也能让规则成立。”他说。

小溪又看了看盘上仍然活着的白棋：“那白棋以后还可以下吗？”

“当然。它们可以在自己的地方活，可以重新签约，可以换一条路，也可以下一盘赢回来。只是不能再拿一处的权力，悄悄替另外十二处作决定。”

她似懂非懂地点点头，把棋子一颗颗收入棋罐。黑白落入木罐时发出清脆的碰撞声，没有哪一种颜色被单独留下。

程砚舟关掉棋谱，却没有关闭十三腔室的运行界面。第一百四十手之后，系统仍在继续接收新的路径、新的争议和新的选择。

他牵起女儿的手，走出机房。

长廊尽头，十三道门各自开向不同的灯火。门后的人知道怎样核验自己的账，怎样拒绝不属于自己的命令，也知道在需要合作时，怎样带着完整的责任穿过那条横贯全局的主干。

棋谱已经收官。

生活没有。

而这一次，再也没有一个人能够替所有人落子。
