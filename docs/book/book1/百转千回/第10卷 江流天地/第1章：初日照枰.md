# 第1章：初日照枰

六月，凌晨四点。

百炼工坊这头吞吐着两万个节点、永不眠的巨兽，比城中任何一只雄鸡都醒得更早。程砚舟站在十九楼的露台上，能感到脚下整栋楼沉雄的搏动，那是十六个机柜、一百二十台服务器在地下冷库中发出的心跳，混杂着冷却系统嘶嘶的吐纳，如同一头蛰伏的巨龙。空气里有雨后青草的潮气，也有一丝从服务器散热口逸出的、独有的臭氧的金属腥味。

楼下大堂的巨幅全息光幕上，数据流如瀑布般滚落。岑绍庭新开的护镖死局——“海岬防御阵列完整性验证”，标着血红色的“危”字，倒计时冷酷地跳动着：167:59:59。南离那头的听音场，正实时监控着全网1.2Tbps的异常流量，像一张无形的天罗地网。另一侧，不设任何彩头、只供新丁磨刀的白场子，是模拟攻防的沙盘，代码的刀光剑影无声地交错，败者的数据体被瞬间抹除，下一秒又重新生成，周而复始。

接镖的时限、悬赏的花红、贡献值决定的座次、乃至最后折算成生态奉献激励金的汤药费，每一条都由冰冷的智能合约锁定，镌刻在不可篡改的区块之上。没人会婆婆妈妈地劝那些新来的极客该选哪条路，是去安稳的白场子磨炼技艺，还是直接踏入那片随时可能被清零的血色沙场。有人只肯花基本参与份额五百元在圈外旁观，有人偏要一头撞上那块最硬的磨刀石，也有人冷眼扫过光幕上的数字，沉默地转身，没入城市的夜色。

就在三个小时前，海岬战区的外围武库——编号Alpha-7的服务器集群，被人生生撕开了一道口子，数据洪流的獠牙咬穿了防火墙。新接班的运维刀客脸色铁青，双眼布满血丝，逐行清点着没被污染的火线、阵亡节点的残骸和被截断的备份链路。上一更退下来的主将并未离去，他死死盯着原子钟，直到交接时间精确到纳秒，双方的数字密匙在交错的瞬间完成授权交割。那些顶着分布式拒绝服务攻击（DDoS）硬撑到最后一刻的木人傀儡——自动防御脚本，它们挥出的每一刀、格挡的每一次入侵，都化作一行行冰冷的日志，刻在案底，绝不容许任何一个活人贪天之功，将算法的死斗算作自己的斩获。

陈驰的八仙桌，是一张巨大的黑胡桃木整板。他没看光幕，而是死死盯着桌面上展开的一卷宣纸，上面是用朱砂笔手书的账目。快要到期的买路钱——“潮汐站”项目的结算款项。已经验尸画押、等着划账的，是那些ID后标着绿色“已确认”的贡献者；还在过堂盘问、等待代码审查的，标着黄色的“待审核”；而那些只在社区频道里摇旗呐喊、未曾贡献一行代码的看客，他们的名字则根本没资格出现在这张纸上。账簿分得泾渭分明，绝没有图省事点一盏绿灯全混成一锅粥。沙盘上的机巧阵盘依旧有走眼的时候，所以拿提交记录（commit history）对峙、单拎出来公开鸣冤的仲裁通道、以及查验托管钱包实底的铁律，绝没因此就废了半条。

魏泽安在财务室的铁窗外站着，直到扩音器里传来他的名字。他将身份卡贴在感应器上，看着最后一笔六十两白银——或者说，等值的稳定币——从他的账户划走，打回债主的底账。三期，不多不少，凑齐了二百二十两。冰冷的机器女声在他耳边念出最终审计结果：一百四十两，填平了他在“瀚海”项目中因错误预判而垫付的服务器租赁费；八十两，退回了东瀚资本在那场短命的投资局里没烧完的本金。至于冯至成替他还上的那六十两，依旧只在招兵买马的抽水里抹平，记作“坏账核销”。每一文钱，都顺着它的来路，沿着智能合约的轨迹，分毫不差地滚了回去。半个子儿，也没敢厚着脸皮，写成六月里新开张的油水。

五月里那两轮带着悬赏的杀局算是熬到了头，但这绝不意味着魏泽安能平白捞到一个在香堂里永远占座的铁交椅——一个永久的治理席位。他只能拿着恢复了初始权限的腰牌，回到白场子里，从零开始积累贡献度。想重新接镖，就得跟全天下的光棍一样，去蹚同样的火海，守同样的死规矩。冯至成没再替他往任何一份电子合约上代签。两人在工坊的山门前撞见，冯至成正和几个新人讲解着什么，看到他，话音停顿了一下，只冷冷地点了下头，便各自走向了不同的赛博杀阵。

程砚舟背着手，从十九楼下来，一路行过，并未在任何一个堂口前指点江山。他那双看透了太多代码起落、资本生死的眼睛，如今更像一位静观棋局的国手，轻易不肯落子。

他在那张海岬战区的残局光幕前驻足了半盏茶。Alpha-7那一角，确实已经被人生生啃食殆尽，成了一片无法挽回的死棋。可紧挨着的Beta-3和Gamma-5两个集群，却像两枚棋子，在阵盘上死死咬着对方的缺口，互为犄角，守住了最后的几口“气”。换作从前，他早会急赤白脸地冲进作战室，亲自下场，在十九路盘上强行补棋。可如今，他那只习惯于在键盘上翻云覆雨的手，只是静静垂在身侧，冷眼听着接防的主将自己盘清这局棋里最致命的死门，寻找着弃子争先的胜机。

极轴堂口，凌拓刚认下了一笔不起眼的碎银子——一个小型社区的漏洞赏金，他没去插手海岬的死局，转头去审查另一拨提交了入伙申请的散客。罗振业仍梗着脖子，在为他的项目争一个首页上更显眼的字号排场。坐堂的判官，AI“铁面”，只收下了他那一半符合规范的展示请求，冷面驳回了那些会遮挡血色战报（高危预警）、或是坏了死契规矩（夸大宣传）的非分之想。你掏过银子，不代表你每次来都能在香堂里横着走；也不等于你以后就非得死气白赖地一直掏这买路钱。每一次曝光，都需重新博弈。

周慎衡在盘这期的铁账。几条营生里抠出来的真金，已经填平了这阵子开堂和过堂的嚼谷——运营成本，但早年间天使轮融资失败留下的那口大窟窿，依旧单开一页血账，挂在加密的子账本里，谁也没敢敲锣打鼓地吹嘘起家的老底已经全赚回来了。各凭死契按着江湖规矩分到的花红，必须优先结算。绝不能因为总堂还要关起门来打磨新兵刃——研发新产品，就厚颜无耻地克扣底下刀客们拿命换来的汤药费。

下一期的生死簿——项目路线图，没敢写得太长。先死死护住那些已经画了押的欠债——对社区承诺的既定功能，再去盘算那些八字还没一撇的新门路。垫底的棺材本（储备金）、朝廷的救济粮（孵化器补贴）和真刀真枪做买卖换来的银子（项目收入），三笔钱在账上被三道红线切割得清清楚楚，再没敢被糊涂账房揉成一个看似油水十足的大数目。

方婉音跟新来的匠人——一位独立UI设计师，只谈拢了一半的切口。匠人不情愿在自己的作品集首页，生硬地刻上金主“百炼工坊”的字号。方婉音没强求，指尖在平板上轻轻一点，将合约中的品牌露出条款挪到了次要位置，利落地说：“要么换个位置，要么，我们可以完全移除这一条，对应的费用会下调百分之十五。”她绝不先假惺惺地哄骗人家“没事，咱们先进场”，等签了死契再翻脸，露出“行走江湖总得挨刀”的狰狞嘴脸。情愿赏钱少拿些，但这剑该往哪儿指，必须在落笔前画得清清楚楚。

新匠人面无表情地看着条款变更，沉默了片刻，将没肯画押的那页电子合约存为草稿。方婉音也顺势收回了触控笔。八仙桌两头，谁也没装出那副仗义疏财的酸腐派头。各自手里都死死攥着一寸不肯退让的锋芒，唯有如此，那点真切交出来的底牌，才不至于在日后化作扎进彼此心窝里的毒刺。这是一场安静的“手谈”，每一寸的进退，都是在寻找彼此都能接受的“目”。

山门外，李惠兰只站在街口的咖啡馆，结清了当月的生态奉献激励金。她压根没踏进工坊的门槛。这笔钱，全凭着开源社区贡献者的公开名录和定例发放，绝没被那些算计人头的账房先生偷偷塞进扩充香火的功劳簿里。兜底的活命粮和卖命换来的花红，就算在同一条长街上交割，也依旧是两股水火不容的源头。

辰时的钟声一响，开堂训话刚起，就有个生瓜蛋子梗着脖子问：“只要下场，就一定能见着回头钱吗？”

陈驰冷着脸，拿马鞭——一根伸缩式的激光笔——在光幕上划出三个入口：“只要你签了带赏金的死契，活着把定好的差事办了，那差异池里七千元打底的汤药费就跑不了；若是立了头功，按贡献度另算花红。这打底的钱，绝不能因为你功夫不到家、排名在末尾就黑掉。至于你是在白场子里瞎转悠、站在旁边看热闹、还是光报了个空名字，那绝不等于你已经接下了那张阎王帖。这三条道你随便挑，但提刀前，先撒泡尿照照自己选的到底是条什么路。”

生瓜蛋子不死心，又追问一句：“要是咱们这伙人输了呢？”

陈驰面沉如水，直接调出了“潮汐站”那本已经结清的生死簿，将那些败军之将的名字和一笔笔实打实的转账记录甩在他脸上，其中一笔赫然写着：扣除公摊的七十二元五角电费，实付四万七千九百二十七元五角。“总堂绝不会因为你尽力了，就大包大揽地保证下个更漏里永远有金主肯当冤大头；但只要你履行完这一更事前约定的责任，哪怕最后阵地失守、战区单位尽损，也绝没人敢拿一句‘败军之将’，就抹黑你付出的心力，克扣你应得的银子。”

长窗外的朝阳一点点撕开夜色，化作一道金线，打在办公室里那尊黄杨木雕的十九路棋盘上。那座半夜里丢掉的武库，依然被死敌死死咬在嘴里，化作棋盘上一块无法挽回的黑地。而眼前这笔到期的买路钱，也照常一分不少地发了下去。

新的一天，这江湖根本不需要把一处败局，生生涂脂抹粉地扮成另一桩虚妄的大捷。

棋盘上，输了，便是输了。

那就从这里，再落一子。
