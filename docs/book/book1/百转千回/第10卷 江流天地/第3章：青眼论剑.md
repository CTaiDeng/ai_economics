# 第3章：青眼论剑

那张八仙桌，是用一整块未经拼接的北美黑胡桃木制成的，木纹深邃，如凝固的墨色河流。八个人，八张太师椅，围着这张桌子，像八颗钉死了自身方位的星。周慎衡一抬手，掌心温润，将那把养得油光水滑的紫砂茶壶，从摊开在桌子中央的《霁岳堂创始股东暨治理章程》上挪开。壶底与皮面封套接触，发出一声沉闷的轻响，像是一记落下的槌音。

那本章程，他们私下里叫它“生死簿”。

程砚舟的目光，缓缓扫过在座的每一张脸。五个歃血为盟的旧同袍，从一无所有杀到今天，还有后来入伙的陈驰和方婉音。他心里原本熬着一锅滚烫的话，什么“咱们自古就是八大金刚”，什么“兄弟齐心其利断金”，此刻却一句也倒不出来。话语像冰块，堵在喉咙里。因为他知道，那是假的。最初是六个人，在城中村的露天烧烤摊上，用三块钱一瓶的啤酒斩了鸡头，创下“霁岳堂”。后来八个人齐心，结成一座数据与代码的剑阵，去破“星原计划”那个号称千古无解的杀局。五个人砸锅卖铁凑出的两百万现金，和另外三人凭着一身代码神功、满脑构架奇思折算的技术股，各自都有各自的来路，各自都带着血与火的温度。绝不该为了给这草莽传奇捏造一个更光鲜的彩头，就随便在这本皮面已经磨出包浆的生死簿上，轻描淡写地涂改。

顾承安的手指，像一把精准的卡尺，一笔一笔地核对着打印稿上的条款。当年画押时约定的“基本参与份额五百元”这个象征性的初始单位，后来攻下“千礁”项目后资产包的归属权，以及眼下八人各自执掌的业务山头与一票否决权。他念得极慢，像是在宣读一份判决书。绝没因为谁要退隐回家照顾重病的妻子，就无中生有地加高他早就跨过的下山门槛；也没混蛋到把早期技术入股的“唱段”、处理紧急故障的“汤药费”和未来才有分红可能的“干股”，全绞在一块，熬成一锅逼着人家往后还得无限卖命的连环死债。

“杜启航，”顾承安的目光落在那个沉默的男人脸上，“关于‘生态奉献激励金’的追认，你上次提出的异议，现在复议。”

杜启航的脸颊削瘦，透着一股长期被服务器机房冷风吹出的苍白。他冷着脸，像是回忆起自家幼子染上重疾，躺在ICU里，每日费用清单如雪片般飞来的时候。那时，最难张开的嘴，不是向兄弟们开口借那笔救命钱，而是怕自己一旦撂了挑子，这座以他为核心节点的“杀阵”——整个霁岳堂的底层数据架构，就要跟着崩盘。

“我坚持，”他声音沙哑，却字字如铁，“离岗交接，必须有明确的‘信托处分’流程。股权可以托管，责任必须交割。做完的买卖就像抹了血的刀，必须干干净净地收进鞘里。我不能在我儿子床前守着，还得担心公司的服务器集群是不是会因为我的一个思路没交接清而雪崩。这不该是一辈子都挣不脱的活鬼。”

陈驰，那个永远穿着连帽衫，头发乱得像鸟窝的技术鬼才，也硬邦邦地交了底：“我不管你们的星辰大海。我每个月一万八的房贷，银行的催缴短信比闹钟还准。总堂休想拿那张八字还没一撇的分红期权，去抵我今天就该到账的季度奖金。财务报表上写明了，差异池里还有七千元，扣除本季度核算的72.5元电费，我个人账户实付应该是47927.5元，一分不能少。”

方婉音，那个唯一穿着高级定制西装裙的女人，气质清冷如月。她“啪”地一声，将一沓文件甩在桌上。那不是纸，是打印在薄金属片上的核心算法架构图，是霁岳堂赖以成名的几样独门兵器的“铁券原件”。她分毫没为自己攥着这几样不肯开源的绝活而显出半分局促。

“我的研发部门，需要绝对的‘闭门磨剑’时间。任何跨部门的需求，必须提前两周提交，由我来判断优先级。谁也不能仗着江湖交情，一个电话就想让我的人放下手里正在攻关的活儿，去给你修补一个无关痛痒的前端bug。”她环视众人，目光锐利，“能冷下脸明明白白说‘不给’，才护得住那些我们情愿交出来的兵器。否则，今天你来讨，明天他来要，我的桃花岛，就成了任人进出的菜园子。”

话题，终于还是翻到了那卷带着霉味与血腥味的“千礁旧案”。

许知妍，一直沉默寡言，像个影子，此刻却面无表情地开了口：“是我。我当年错信了第三方提供的假阵图——那份伪造的API文档，导致数据库侧门洞开，被‘化功大法’侵蚀，核心用户数据泄露。我认罪。”

程砚舟梗着脖子，喉结滚动，咽下了那份屈辱的苦果。“我也有责。是我为了抢占市场，在安全协议没有完全闭环的情况下，就拍板半开城门，提前放了一万个内测用户进来，给了对方可乘之机。这苦果，我吞。”

林静薇，财务的铁娘子，推了推鼻梁上的金丝眼镜，指着投影幕布上的一串串数字，声音比机房里的制冷风扇还冷：“砸进那个天坑里的两百万市场推广费，是本钱；遇诈被劫走的五十万个付费用户数据，是镖；看走眼签下的那个废物供应商，是漏子；后来我们拼死拼活，一万一万节点地优化，一个客户一个客户地磕回来，才是赚来的真金。这几笔账，必须一笔一笔劈开，记在不同的账本上。绝不能因为公司眼下要喘口气，就把这些全搅成一笔烂账，一笔能被龙头随便挪用来粉饰太平的死人账。一句‘交了学费’，抹不掉资产负债表上那个鲜红的窟窿。”

整张桌上，没人去装什么“相逢一笑泯恩仇”的江湖洒脱。错了就是错了，败了就是败了，血淋淋的伤口剜开，用酒精和律法来消毒，才能结出坚硬的疤。

八名同袍，在这张桌上，各自划下了后半局的道道。顾承安要在自己的运营堂口里，有对预算和人事“说一不二的兵权”；杜启航不愿再跟着没头的苍蝇，为了一个临时的市场需求就去瞎改核心“阵眼”；陈驰死咬着，交班的“更漏”必须精确到分钟，到点就断开权限，天塌下来也和他无关；方婉音则死死攥着她可以不受打扰，闭门磨剑的“清净时辰”。

接着搭伙过日子，绝不是要签下一张永世不得翻身的卖身契。更没人敢逼着大伙儿，在这条刀口舔血的道上，非得埋进同一座坟。

程砚舟越听到后头，越发现自己早先在肚子里熬好的那锅，关于梦想、情怀与未来的迷魂汤，此刻竟半句也倒不出来。青眼相看，论剑江湖，也得容这帮兄弟把各自压箱底的剑路演完。倘若只凭一句“生死同袍”，就要逼着所有人都终身走一套由他规定的、一模一样的“武当太极剑”，那这张聚义的八仙桌，就又生生变成他们当年拼死也要逃离的那座——吞噬一切个性的、吃人的山门了。

会议结束，这伙人并未散去。他们走进了一间密闭的“白场子”——公司的网络攻防实验室。四壁是吸音的灰色材料，空气中只有服务器低沉的轰鸣。他们要复盘当年那局功败垂成的“双桥试阵”。

一台孤零零的控制台前，程砚舟下意识就想伸手去握那枚象征着最高权限的根管理员（Root Admin）令牌。

顾承安却不知何时站在他身后，用一根冰冷的伸缩教鞭，敲了敲他的腰牌和今天演练的座次表，嘴角挂着一丝冷笑。“程总，今天，你只负责赶大车的粗活。你是‘节点运维工程师07号’。”

满室皆是压抑不住的低笑声。

手里捏着总堂的开天阵盘，也休想在这场实操演练里，就顺杆爬成大权独揽的霸主。

“倒计时167:59:59，”陈驰看了一眼墙上的原子钟，设定了演练时长，“我只参与前八个小时的班次。”

方婉音懒得下场，只站在观察室的单向玻璃后，盯着主屏幕上被授权展示的战局残影。

拔刀的人，心里都跟明镜似的：这是一局不带真金花红的白场子，一次纯粹的压力测试。谁也别想把这帮老伙计的切磋，回头又虚报成总堂花钱雇人的另一门好汉买卖，列入什么“加班工时”去邀功。

演练开始。程砚舟负责的那辆“辎重车”——一个高达1.2Tbps的数据迁移任务，在虚拟网络的险峰拐角，卡住了，进度条死活不动。

杜启航的声音从后方的通讯频道里传来，带着电流的嘶嘶声，却吼得震耳欲聋：“07号！前头的‘轻骑’——侦测脚本还没把所有的‘雷’蹚完！你敢强行刷新数据流，整个通道都会被污染！”

林静薇，作为此次演练的总协调，破天荒地没有急着递上解决方案。她只冷眼看着程砚舟的屏幕，看着他自己去翻那一沓厚厚的电子版军令——应急处理预案。

他耐着性子，手悬在键盘上，盯着屏幕上代表侦测脚本的绿灯一个个亮起，直熬到前方的网络通道全线飘绿，才敢敲下执行指令。

直到真坐在这个死门里，他才惊觉，那些在架构图上，他自以为不过是眨眼就过的几毫秒停顿，搁在一个一线运维人员身上，竟熬得像半辈子那么长。

那辆“镖车”，在漫无边际的阵图上不过是一粒微尘。可真把这微尘塞进他手里，前后的死活间距，都化作了切肤的刀锋。以前他站在高处看全局战报，总爱皱着眉骂底下人：“这个‘应手’为何不赶紧接死？这么简单的‘单官收气’都不会吗？”

此刻，他才真真切切地尝到了，被前后路死死夹住，动弹不得的迟滞感。那种棋盘上所谓的“气紧”，化作了服务器风扇的尖啸和CPU占用率100%的红色警报。他按着回车键的指尖一直虚悬着，到底没敢像个愣头青似的，去下一个打破规则的“抢手”，去冒险破局。

八小时的漏水滴尽，警报声准时响起。陈驰按着规矩，将自己负责的“阵眼”——防火墙规则集的控制权，无缝交接给了守场的“木人傀儡”，一个预设的自动化脚本。他摘下耳机，扭头便走，离开了实验室。

满场没一个人上前去假意挽留，没人说“再熬一会儿，把这个关键节点扛过去”，没人逼他再用半个时辰来证明什么“歃血情分”。

傀儡机巧顺着原有的阵势接着往下演算，留下的人若是还没杀过瘾，也得自己去想下一步该怎么蹚雷。绝不能偷偷摸摸地，让已经下山的人，还在背后无声无息地扛着干系。

八仙桌上，空出了一把太师椅，可桌底下的盟约，却没散架。

那些大伙儿彼此心知肚明的野心、恐惧和底线，终于在这张桌上，找着了能重新讨价还价的切口。这盘还没杀完的十九路局，再也不用强逼着所有弟兄，非得把一整个带血的寒夜，全押在同一颗星位上。

程砚舟看着屏幕上缓缓前进的进度条，第一次觉得，慢，原来也是一种快。弃子，原来是为了争先。
