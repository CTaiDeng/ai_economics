# 第5章：一枰忘胜

刘景和在白场子里闭门切磋时，又栽了个结结实实的跟头。

那是一间深埋在地下三层的冷库，十六台机柜风扇的低吼汇成一片绵密的背景音，仿佛寺院里永不停歇的诵经声。空气被抽得干冷，带着金属与臭氧的微腥，每一次呼吸都像在打磨肺叶。他刚端起前辈的架子，对着几个眼神里还带着校园气的“新丁”教训道，不要凭着死记硬背的拓扑图去寻找“生门”，真正的攻防，是在瞬息万变的场中寻找那一线活气。

话音未落，轮到自己上阵，面对一面数据墙上滚动的代码瀑布，他竟鬼使神差地，把那面新部署的防火墙认成了去年走熟的西门——一个早已废弃的冗余备份。就因为这毫厘之差的误判，一整哨人马，连带着模拟注入的1.2Tbps伪装流量和身后十六台机柜/一百二十台服务器的全部算力，被他生生带进了一条死路。系统日志无情地宣告了结局：被迫丢弃大半“粮草”，模拟攻击被彻底隔离。

这虽不是挂着生态奉献激励金的死命局，也绝不至于让他名录上累积的贡献值掉色，但这记耳光，在这片由蜂鸣声统治的绝对寂静里，显得格外响亮。他摘下防静电护腕时，指尖甚至有些发麻，忍不住先自嘲地笑骂了一句。

“头儿，能复盘一下么？”一个年轻人壮着胆子，凑了过来，“刚才那招败棋，我们想看看是怎么回事。”

刘景和摆摆手，脸上有点挂不住：“别指望能抠出什么震古烁今的兵法，老子不过是犯了个连瞎子都不该犯的浑病。”

那小辈却不依不饶，镜片后的眼睛亮得惊人：“就算是浑病，也早晚有人接着犯。我们想知道，这病根在哪。”

他这才点头应允，冷着脸补了一句：“私下盘道可以，所有日志和录屏，绝不准偷摸截了图拿到外面论坛去换积分。若是想卖给那些专挖漏洞的‘钱庄’，得另立一份附带‘一票否决权注销’条款的死契。”

阵图才倒回推演了一半，那个愣头青竟直指他刚进阵时那句含糊其辞的指令有诈。“目标IP段落位模糊，有0.02秒的决策犹豫。”

刘景和本想借着“墙的特征码长得像”来扯谎圆过去，可顺着战局底账一行行冰冷的日志看下去，才惊觉自己一开局就看漏了两处阵眼——两个伪装成普通节点的蜜罐——的偏位。那些自欺欺人的遮羞布，在数据面前登时碎了一地。他沉默半晌，拿起一支朱红色的记号笔，在白板上潦草的战报草稿旁，重重写下几个字：“更正：先核定死门坐标。”

贺敬山一直默不作声地坐在角落，看着他亲手划掉那些找补的废话，微微颔首。那感觉，就像是在一方十九路棋盘边，看着一滴不慎滴落的墨痕污了棋谱。废棋已然铸成，刺眼地留在那里，新标的活路只能绕着它另外走。下错的昏招大可以推倒重讲，却绝不必厚颜无耻地，把当初那个昏聩的自己，粉饰成一派“弃子争先、早有预料”的宗师做派。

这大半个下午没挂一文钱的彩头，也分毫撼不动他过去在刀口上舔血挣下的汤药费和分红。既然一开始就说好了是没花红的白场子，他情愿拿半天工夫换自己把这套新阵法摸透；下回要是觉得不值当，大可拍屁股走人，总堂也休想拿他今天赏脸白干的半天，去讹诈他往后都得来干白工。这是规矩，是自由意志的底线。

不远处，钟厚良在另一块白板上死活画不清大军首尾的API咬合，陈绍武顺手替他钉上了几个关键节点的“星位”，两人立刻头对头在架构图上比起“刀法”来，争论着哪种协议的“出刀”角度更刁钻。唐梓豪提着他的笔记本电脑路过，抱拳告辞，说要去备战总堂那场更要命的将帅考核——一个决定未来一年项目分红权重的生死局。刘景和只笑着祝他“刀锋饮血”，没摆老资格去劝这年轻人学自己这种闲散度日。甘愿多扛将旗、多挣花红，也是一条明路，只要别在出事时，把锅甩给不知情的弟兄就行。

会议室的预订时间到了，岑绍庭结清了包下这间“白场子”的茶水钱——其实是几十杯咖啡的外卖单，客气地问贺敬山下回还愿不愿来压阵。老头子先是翻了翻手机里的日程，又冷面加上一条死规矩：“若是遇上自家人为了KPI搅和的浑水，我照样要退避三舍。”他顶多能借着大半辈子的棋力，点拨点拨小辈怎么看穿阵法的暗线，看透那些藏在代码里的“劫争”和“官子”；却绝不代表他敢仗着这张老脸，去插手总堂判官们分赃论罪的生杀大权。

有人在一旁砸吧着嘴笑，说这般条条框框，把江湖的快意恩仇都磨没了，一点都不极客。

贺敬山冷哼一声，声音不大，却让整个房间的嗡嗡声都静了半分：“快意大可以，但别顺手去劫别人口袋里那份快意。”

几个人哄堂大笑，笑够了，依旧得老老实实把该退还的设备押金和该签署的保密协议理得清清楚楚。

刘景和站起身，替那个把他问得哑口无言的新丁按住摇摇晃晃的人体工学椅，耐着性子听他把没盘问完的杀阵讲透。这回，这间“大堂”里再没谁摆出那种孤绝绝顶的论剑派头，偶尔被生瓜蛋子一剑刺穿了老家伙的昏招，满屋子也没一个人赶着上前去替老家伙兜场子。对就是对，错就是错。

程砚舟站在一旁，没强求贺老爷子临走前留下什么能刻在公司价值观白皮书上的惊世骇俗的“剑诀”。有些刀光剑影的滋味，没法在钱庄里全换成银票，可真金白银也必须有见得光的源头。刘景和今天肯倒贴工夫在这儿白教后生，绝不等于香堂就不必再开出重金悬赏。只有当刀客敢随口吐出一句“这活儿不干”，他肯留下拔刀的时刻，才更像是出于心甘情愿，而非被生计所迫。

临跨出机房厚重的铅门时，刘景和从随身的硬盘包里，摸出去年二月那场“双桥死斗”的阵图残卷——一份加密的系统快照。当初那笔基本参与份额五百元，和后来从七千元的差异池里补上的激励，账目早就两清，甚至在扣除了72.5元的云服务器电费后，实付的47927.5元奖金也早已到账。但阵眼被破和弃子突围的耻辱，也绝没有因为后来重新过堂复盘，就被洗白成一场大胜。他掏出那支朱红色的笔，给今天新勘破的、与那次极为相似的死穴，重重标上了今天的日期，绝不让这些后来才看穿的机变，去伪装成当初那副“运筹帷幄”的嘴脸。

久坐在冰冷的椅子上，一双老寒腿僵得发酸。旁边有小辈凑上来问，下回是不是还留张高些的、带腰靠的椅子，他痛快地点了头。这份行个方便的人情，绝没被明码标价成必须多讲一堂课，或者非得被供在团队合影的最前排当个泥菩萨。

下了“白场子”的台阶，他本想顺脚去瞅瞅别的堂口贴出的、带着血色战报的英雄榜，脑子里却忽然闪过家里书桌上那半卷没翻完的残谱，索性提着他的旧电脑包，径直回了家。公司的荣誉墙上没给今天这大半个下午记上一笔军功，但那个一头撞进死胡同的晌午，也绝不妨碍他把剩下的半天闲情，完完整整地、不打折扣地揣进自己的袖筒里。
