# 第4章：然诺如山

黄昏的流光，将小溪那间学塾染成一片温热的琥珀色。木屑与松节油的气味在空气中浮动，像一首无声的歌。程砚舟破天荒地提早了半个时辰，像个初入阵地的斥候，悄无声息地倚在门框上，渊渟岳峙，收敛了江湖里带来的一切杀伐气。

九岁的闺女正与一名同窗埋首于一具半成品的木牛流马。那不是孩童的玩具，而是一座微缩的、遵循着墨家古法的机括阵。一处榫卯死死卡着传动的机括，像是棋盘上一个顽固的劫，任凭如何腾挪，都无法消解。

程砚舟的指尖下意识地抽动了一下，换作从前，他早已上前，三两下便能拆解这死结。可小溪没有像惯常那样，一见他便立刻把手里的墨斗和凿子塞过来。她的小脸绷得紧紧的，额上渗出细密的汗珠，先是将自己试过的三路破阵之法，一步步演示给父亲看，指着图纸上的废线，条理清晰地讲解为何此路不通。她的逻辑，竟隐隐有了几分桃花岛主推演奇门遁甲的影子，虽稚嫩，却章法俨然。

直到确认自己的算路已尽，她才抬起头，板着脸，用一种近乎命令的口吻，请他帮忙死死按住底阵的基座。

“爹，用力，别让它晃。”

他依言俯身，双掌如铁钳，稳稳压住那块浸了桐油的底木。机括在他掌下发出细微的“咔”一声，应手而解，顺着滑轨流畅地冲了过去。小溪脸上瞬间绽放出光彩，她没多看他一眼，更没把这破阵的头功归于他，而是兴高采烈地转身去唤同窗来看，仿佛这最后的致胜一击，与旁边这个身形高大的男人全无干系。

收摊时，程砚舟顺手拿起几张画废的阵图，想一并扔进火盆。小溪却像护犊的母兽，一把抢了过去，死命护在怀里，字字铿锵：“不行！要留着复盘的！”

他伸出的手僵在半空，随即缓缓收回。他老老实实地从墙上解下一个牛皮囊，将那些画着叉线、墨迹斑驳的废图一张张仔细卷好，妥帖收藏。他没敢越俎代庖，去替这位小小的刀客断言，哪一步落子才算废棋，哪一步又是通往死地的歧途。更没有借着这桩小事，端起总堂里那副令人作呕的架子，去灌输“复盘定生死，错步即是冢”的腐臭门规。

一碗凉水递到唇边，带着井水的寒意。沈婉衡不知何时站在了他身后，神色淡得像一张未着笔墨的宣纸，眼神里没有半分波澜。从去年七月，他将所有底牌——那些信托处分的文书、一票否决权的注销契约、乃至生态奉献激励金的流向账目——全数交割清楚，到今天，整整七个月。两人之间，有时谈柴米油盐，更多时候，只对着缝补闺女的嚼谷用度和前程规划。她死死护住自己独处的那方气口，也护住了随时可以翻脸掀桌的退路。他便老老实实按着更漏上的刻度现身，再不敢将这种为人父的本分，偷偷记进哪本妄图“换取招安”的功劳簿里。

他曾极度迷恋十九路棋盘上的神机妙算，只要对方抛出一个星位，他脑中便能瞬间连环推出后续百般变化的应手。可如今，听见她的话音悬在半空，只一句“水凉，慢点喝”，他终于学会了死死按住剑柄，没急着去抢那步自以为是的后手。有些交锋，招式只能喂到这里，剩下的留白与死门，必须由她自己去点。这盘棋，他已无权主导。

学塾的考校比预定晚了半个时辰。百炼工坊那头的“千里音”嗡嗡震动起来，有心腹探子用加密的信道飞鸽传书，催问一桩关于网络负载的紧急军情。程砚舟只扫了一眼那道“1.2Tbps流量洪峰预警”的军令，冷着脸，按既定的兵权交接规程，将处置权限转给了副将。他绝没敢再像从前那样，理直气壮地从这间小小的屋子里，“借”走这带血的半个更漏。

小溪见他把那枚不断闪烁着幽光的千里音倒扣在桌面上，这才放下心来，继续兴致勃勃地比划着，刚才那个同窗是如何独辟蹊径，摸到了那处机括的阵眼。这小刀客精明得很，一眼就能分辨出亲爹是在敷衍塞责，还是在真心听讲，并以此来拿捏，下一剑该刺得多深，话该说得多重。

提到休沐日的盘算，他也没敢像过去那样大手一挥，打包票说“万事大吉，爹都安排好了”。他老老实实地从怀里摸出自己的行事录，亮出上面已经画了押、推脱不掉的几条死契，抠出仅剩的空档时辰。一家三口，像三个最严谨的账房先生，头碰头地对着账，这才拍板定下一个不算宽裕、但绝对不会被临阵放鸽子的下半天。

城南的另一处宅邸，灯火同样温柔。

许知妍正陪着快四岁的独子，收拾满地散落的小木人。那些木人，有的扮作将军，有的扮作走卒，散落一地，像一场战役的残局。这半大的孩子心里有笔谁也抹不掉的明白账，他清清楚楚地记得，谁许诺过要来看他，也死死记着那些趴在门槛上等爹，等到月上中天、寒露浸湿衣衫的夜晚。他压根摸不透大人们在江湖上拼杀出的那些带血的裂痕，更不该被强逼着，去充当糊这烂摊子的泥瓦匠。

前夫斜倚在门框边，神情是一贯的冷峻。他正跟她对着下个月接送孩子的档期表，语气公事公办，像是在交割一笔再寻常不过的买卖。两人心知肚明，这条裂痕已是天堑，各自都得去盘算后半辈子的生路，绝没有谁会厚颜无耻地把这难得能和气说话的半刻钟，当成什么“破镜重圆”的台阶。

孩子忽然扬起脸，用最清澈的童音问：“为什么爹爹和娘，有时候不住在一个屋檐下？”

她蹲下身，尽量用不带血腥味的软话，一字一句地解释：“因为大人……遇上了自己也解不开的残局，需要花很长很长的时间去破阵。但我们绝不会丢下你不管，也绝不会逼着我们的小刀客，去选站在谁那一边。”

门边的男人，微不可察地点了一下头。

这一点默契，虽算不上歃血为盟的和解，却也成了这盘死棋之上，两人唯一还肯共同护住的一处气口。

入夜，工坊的暗哨群里，不知是谁忽然翻出几张陈年旧档。那是当年大伙儿为了某个项目，歃血结阵、在机房里通宵破局的旧日残卷。照片上，年轻的程砚舟和她并肩坐在16台机柜/120台服务器的轰鸣声中，背后是代表着两万个在线节点的瀑布流数据，眼神里是如出一辙的疲惫与燃烧的火焰。

许知妍冷眼扫过，心底那股熟悉的冲动如暗流涌动，但她死死按住了单戳程砚舟的念头，没去回味那种只有他俩才懂的、背靠背的孤独。合伙抢地盘的买卖，是“化功大法”，侵蚀市场，可以接着干。可越过雷池的那份生死相托，却必须在寻常的柴米油盐里，生生勒住缰绳。绝不能仗着缅怀当年一起舔过刀口的情分，就暗搓搓地想把旧账翻出来，重演一出早已落幕的戏。

她关掉讯息，拿出纸笔，将明早该带的行囊，以及要交割给学塾的一笔“基本参与份额五百元”的款项，一笔一笔写清。哪怕军令下得再周详，明早，也必须是她亲手在门口牵起孩子的手。一条冷冰冰的千里音，一句“差异池里还有七千元，扣除72.5元电费实付47927.5元已到账”的语音，绝代不了活人的体温。

她把那传音的机巧远远扔到沙发另一头，静静坐在小床边，直到听见那均匀的呼吸声彻底平稳，像深海的潮汐。从前在江湖上听评书，总以为那句“然诺如山”，非得是在腥风血雨里替人拔剑挡煞、或是千军万马前一言退敌，才配得上这四个字的分量。

真到了自己身上才知道，那不过是明早一段极寻常的送学路，绝不能再被一句轻飘飘的“总堂告急”，就生生拦腰斩断。

城南的饭桌上，小溪已把那具木牛流马拆了个稀巴烂，零件分门别类地码放整齐。她嘟囔着，下回不想再弄这些机括暗器了，想画一棵很大很大的树。

“好。”程砚舟痛快地点头应下，没有问为什么，也没有说画树比造机关简单。

沈婉衡连一个眼神都没分过来，径直上楼去理自己的账本。父女俩各占着半面八仙桌，一个在拆解，一个在旁观，没人非要在这份沉默里，硬凹出什么“天伦之乐，合家团圆”的腐儒排场。

闺女很快铺开宣纸，攥着笔锋，向外扫出一根嶙峋的枯枝。他便伸出手，死死用手掌替她镇住那不听话的、微微卷翘的纸角。直到这小刀客自己画累了，将一支紫毫狠狠摔进笔洗里，溅起一圈墨花，他才收回手。

阵盘里那些坐堂听审的重担，那些关于市场份额的生死劫，大可以交托给副将去代劳。

可眼前这镇纸的丁点功夫，这如山般沉重的、一寸都不能挪开的承诺，却必须逼着他这个亲爹，老老实实地、一动不动地，死钉在这张椅子上。
