# 第2章：闲敲棋子

许嘉榕拒了一封飞鸽传书，是当着屏幕上那串血红的倒计时数字，亲手摁下的。

那不是一卷绑在鸟爪上的蜡丸密信，而是一道冰冷的系统指令，在她的“腰牌”，一方温润如玉、实则幽光流转的墨色终端上，以一种不容置喙的口吻闪烁着。任务代号“长夜”，目标区域网络吞吐量峰值要求不低于1.2Tbps，预计动用16台机柜共120台服务器，协调至少两万个节点，报酬是……一个让她心跳漏了一拍的数字。而此刻，那串数字上方，【167:59:59】的猩红倒计时，正像一颗被悬丝吊着的血珠，一秒一秒，无声滴落。

她点了“拒绝”。没有丝毫犹豫，就像在棋盘上弃掉一块看似至关重要的大龙，只为争得一个无关生死的“先手”。

于是，她生生给自己抠出了一个无事可做的下半天。

她绝不是突然发了什么横财。账目上，上一笔“军功”结算的流水还清晰可见：一笔来自“差异池”的七千元奖金，加上基础报酬，扣除托管机房分摊的72.5元电费，实付47927.5元。数字冰冷，精确到分。这些卖唱段——用声音和逻辑编织罗网，和刀口舔血——在数据的洪流中冲杀搏命，换来的赏银依旧时多时少。该掏的房钱和米面钱，照样得在这块墨玉腰牌的账簿界面上，用指尖一笔一笔扒拉清楚。

只是，没接下“长夜”这道催命符，并不会叫她原先落袋的花红被金主追缴回去，更不会顺手抹去她早已在“总堂”的功勋簿上用代码刻下的战绩。金主那边，一个叫“信托处分”的权限被她激活，那份邀约便成了死棋，再无转圜余地。隔了半个时辰，联络人换了个客气的口吻发来讯息：“下月可有档期？”

她指尖悬停，最后只敲了四个字：“到时再说。”

那边沉默了。谁也没在这档口上，用一堆假惺惺的江湖客套，来磨平这句硬邦邦的、几乎带着金属摩擦声的“谢绝”。

她将腰牌翻过去，屏幕朝下倒扣在老旧的黑胡桃木桌案上，动作里透着一股天山折梅手般的收发自如。可过了一阵，又忍不住瞥一眼那方静默的墨玉。骨子里那种一旦闲下来，就仿佛能听见身后无数饿狼追赶的脚步声，那种生怕被人一脚踩死的恐慌，依然阴魂不散。门规——那些由代码和共识写就的铁律——虽然改了几条，废止了不人道的“一票否决权注销”条款，可经年累月在刀尖上绷紧的那根心弦，绝不会因为几句轻飘飘的安抚就痛快地松开。

走到江边时，她没带那套吃饭的家伙。腰牌收进了夹层，隔绝了所有讯息的蜂鸣。那些曾在虚拟世界的两岸空谷里撞出赫赫回响的“浪头”，今天便老老实实只做这物理世界江上的浪头，浑浊，缓慢，拍打着水泥堤岸。她没必要碰见任何一个顺耳的动静，就非得在脑子里连夜编成一套能换酒钱的戏文。

有看客认出了她的脸，一个戴着黑框眼镜的年轻人，激动地追上来，非要盘问上一折“风陵渡”残局里，她是如何通过一次精妙的“弃子争先”反败为胜的。她破天荒地抬手挡了回去，声音比江风还淡：“今天不说这些江湖恩怨。”

那看客愣了片刻，眼里的光彩黯淡下去，倒也识趣，抱拳作揖，退开了。

在江湖上混出名头，确实能叫往后的买卖好做些。但也逼着你无论走到哪儿，身上都像背着个必须时刻张嘴唱曲的铁壳子。她终于学会了，用一道无形的真气，一刀劈开界限：死契上画押过的事、茶馆里无关痛痒的闲扯，还有那份大可闭嘴不管的冷漠，分得清清楚楚。绝不拿别人施舍的几个好脸色，就逼着自己非要绞尽脑汁，去凑一局投桃报李的虚伪应酬。

旧书摊上摆着一卷她惦记了很久的野史，纸页泛黄，墨香混着尘土气。她利落地从那笔四万七千多的赏银里划出几十块钱买下，半句也不必跟那些砸钱的金主交代，这笔银子究竟花到了哪家勾栏，还是哪座书坊。转身又去花房，盯着几盆造型奇诡、筋骨嶙峋的盆景看了半晌，分文没掏。那掌柜的只顾埋头修剪，也没因此就死气白赖地追出来，非要让她为这多看的三两眼，交一份“生态奉献激励金”。

“千里音”的公共频道里，一条人事变更的铁帖悄无声息地刷了出来：原来她推掉的“长夜”那把交椅，总堂已经指派了一个生面孔去坐镇。新来的判官，ID叫“孤云”，头像是一枚黑白分明的围棋子。新人自然有他自己的一套刀法，未必肯沿用她以前惯使的那套切口。她冷眼扫过，确认交接文档里没留下什么能扯皮的烂账，便划开了屏幕，没多事隔空飞传将令，去对别人的棋局指手画脚。

她太认得那条刀口舔血的熟路了，也太认得自己嗓子眼里那股非要跳出去指点江山的冲动。就好像隔着矮墙听见外头有人在拆解一套自己烂熟于心的剑法，而且拆得破绽百出，握刀的手已经下意识按在了剑柄上，指节发白，到底还是硬生生松开了五指。

这盘残局，既然已经轮到了别人上阵摸子，就用不着她还像个老鬼似的，处处留下阴魂不散的指纹。

一把已经让出去的堂主交椅，往后或许再也复刻不出她当年的排场。但这绝不是总堂卸磨杀驴的重罚，而是那个叫“孤云”的后生，也到了该在功勋簿上，刻下自己血印的时候了。

钟厚良卷着一张线路拓扑图路过，上头的桥梁依旧画得歪三扭四，却比早先那软脚虾的模样硬气了些。他没把春天里凭运气捞着的那三百六十两彩头，当成往后每个月都能闭着眼领的皇粮；依旧老老实实掐着手里的碎银子去赴场，实在分不开身便干脆弃一局。朝廷发的赈灾粮——那些公共的悬赏任务——自有别的判官来审，哪笔是细水长流，哪笔是砸完拉倒，全死死按着战前报备的切口来断。

江岸边还蹲着个春季里一起听过墙角的修图匠，捏着两张旧票根来换马扎。一个账房先生模样的人正在对他进行例行的用户画像访谈。

“卷宗核对，”账房先生的声音毫无波澜，“春季分红，三千；夏季激励，三百。合计三千三百两。扣除‘基本参与份额’五百元，净入两千八百两。对是不对？”

“对。”修图匠有些局促。

“档案显示，你的‘享乐性支出’，主要是购买‘弈理沙龙’的入场券，春季是三十元一场，夏季未涨价，你却连续两次支付了六十元，连包两场。支出翻了一倍。而你的净入，仅增长了百分之十。这个数据偏好，已经录入卷宗。”账房先生的目光像手术刀一样精准，“旁边另一份卷宗，同等收入增长，享乐性支出为零。你解释一下动机。”

许嘉榕翻着书，耳朵却像雷达一样捕捉着每一个字。

“是不是因为沙龙解盘能帮你破阵？”账房先生追问。

那修图匠挠了挠头，说：“旧账簿……那些公开的棋谱，就算白送我也能翻。我……我就是想跟一帮刀口舔血的同路人凑在一块儿，听听风声，感觉……感觉不那么孤单。”

这句大实话，没敢大包大揽地替全江湖打包票，说什么天下人的享乐钱一定涨得比身价快。却让那份薄如蝉翼的、由数据构成的死契上，总算多了一个肯心甘情愿自己掏腰包的、有血有肉的真看客。

她依然低头翻着手里的野史，没因为自己也曾被圈进过这张巨网，就非得凑上去瞎起哄。

“往后就死磕这听声辩位的买卖了？”钟厚良隔着丈许问她，目光落在她手里的书卷上。

她眼皮都没抬，冷冷回了句：“难说。”

今天不拔刀，绝不等于昨天挑落的仇家就能起死回生。她留下的字号、画押的死契和分到手的地盘，自有香堂——那个自动化的信托系统——管着。哪怕闭关歇上十天半月，也用不着把自己从整张十九路盘上，剔骨剜肉般地剜出去。

后来方婉音的飞鸽传书到了，是一段新谱的曲调，让她得空过耳。她硬邦邦地回了个“明日”，只讨回一个清脆的“好”字，和一个笑脸的表情符。她挪回江边，继续翻那本野史，没急赤白脸地非要从字里行间找一句光宗耀祖的切口，来标榜自己现在究竟算个什么东西。

江风翻动了书页，哗哗作响。她伸出两根修长的指头，轻轻在粗糙的卷沿上敲了一下。

嗒。

像一枚棋子，落在了无形的棋盘上。

换作从前，她活像个守着生死劫的疯子，只要瞥见十九路盘上有一丝可争之处，一个“单官”，都恨不得连扑带抢地把子落死，好证明自己没在这个更漏里白喘气。可这会儿，书页留白的残局上，只倒映着岸边梧桐斑驳的树影。她任凭那光影如水般晃荡，耐着性子，慢吞吞地，把眼前这一行关于前朝旧事的字，给嚼碎，咽下。

远处，百炼工坊的轰鸣隐约传来。那里，有人在拍出真金白银、有人在交接服务器的印把子、有人为了几两碎银争得面红耳赤。也正有亡命徒，靠着刀尖上的硬功夫，去生抢更大的地盘。

她今天没下这趟浑水，腰牌上也没亮起半点分红的火光。可这白白晃过去的半天，照样能名正言顺地活在她的命数里。不是每个不用去卖命的更漏，都非得在总堂的铁账上报备成一次“见血的军功”，才配算作是她许嘉榕自己活过的时辰。

天色泼墨般暗下来，她合上书卷，转身往回走。那片带着硝烟与血腥味的江湖长夜，自有别的守夜人去扛那面“1.2Tbps”的死旗。

而她自家灶台上那锅等米的晚饭，也正等着她自己，去慢火熬熟。
