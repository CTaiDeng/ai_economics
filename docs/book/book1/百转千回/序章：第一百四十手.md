# 序章：第一百四十手

雨停以后，城北工坊的玻璃顶棚还挂着细密的水珠。夜已经很深，机房里只剩散热风扇持续不断的低鸣，像一片看不见的潮水，在墙后缓慢起伏。

程砚舟没有坐在主控台前。他和小溪隔着一张榧木棋盘相对而坐，盘上黑七十子、白六十一子，棋形横贯中腹，左右两翼却都还留着并未死尽的白棋。显示器右上角只有一行极短的结果：黑胜六点九目。

小溪已经九岁，学棋不久，仍习惯先数被提走的棋子。她用手指沿着盘边一点点划过去，最后困惑地抬起头：“白棋明明还有这么多块活着，为什么输了？”

程砚舟没有立即回答。

这盘棋走到第八十手时，公开估值仍是白方领先五点五七三七。黑棋没有一块足以让所有人惊呼的大模样，最大的集团也没有越过那个最容易被机器识别的集中度门槛。它只是在边角、中腹和两翼留下分散的锚点，像一些彼此无关的人，各自在风雨里守着一间灯火微弱的屋子。

真正改变棋局的，不是哪一手横空出世的屠龙妙着。

白棋每一次试图救援、连接、反攻，都会暴露一条真实的跨区路径。黑棋不需要预先占满所有地方，也不需要同时封死十三道门。它只在白棋把路走出来之后，选择那一处恰好能够命中路径的截断面：有时合并两块旧棋，有时三块相接，有时只收回一枚一百零七手以前埋下的旧子。于是，中腹那条原本断续的黑色主干一点点闭合，白棋的局部仍能安定，全盘协同却一层层失去。

小溪又问了一遍：“所以，是把白棋都杀掉了吗？”

“不是。”程砚舟摇头，“能各自活下来的，仍然可以活。真正失去的是替所有地方一起发号施令的路。”

“那十三个金色圈呢？”

她指的是旁边屏幕上的结构图。十三个腔室被分成六个主干、四个次级和三个终端，每个腔室只有一扇门。那些门不是领地标记，更不是谁的私产，只是当某条跨区路径经过时，必须留下授权、结算、证据与责任的接口。

程砚舟看了很久，才轻声说：“那是这一年里，我们学会不再替所有人落子的地方。”

棋盘上的第一百四十手已经结束。可在他的记忆里，真正的第一手，并不是落在木盘上的黑子。

那是一百八十六个名字，被整整齐齐地印在一份裁员名单上。
