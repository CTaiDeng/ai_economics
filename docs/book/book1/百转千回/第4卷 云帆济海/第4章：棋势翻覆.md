# 第4章：棋势翻覆

九月初的天气，秋意已带着一丝不易察觉的凉，从窗棂的缝隙里渗入会议室。空气中浮动着咖啡因的焦香和一丝若有若无的烟草味，黑胡桃木的长桌上，几只烟蒂在水晶烟灰缸里无声地死去。罗振业站在投影幕布前，手中遥控器发出的微弱红光，像一滴悬而未落的血，点在冰冷的数据之上。他送来了八月的复盘报告，开口的第一句话，却引着所有人的目光，坠入了一场刚刚结束的血战。

“开始之前，先看一段撤离。”

幕布上，画面瞬间切换。那是“东瀚”在海岬新开的盘口，一场模拟巷战的沙盘推演，却打出了真实战争的质感。镜头剧烈摇晃，跟随着罗启锋的死士小队，他们如同楔入铁板的一根钢钉，强行突入了仓库的底层。几乎在他们身影消失的瞬间，外围的守军火力网便如铁闸轰然落下，彻底锁死了东面的生门。观战室里，战役总指挥的瞳孔在沙盘的电子光影中猛然收缩，他看见那片代表封锁火力的密集红点，声音嘶哑地对着麦克风急令：“地下残阵，放弃东口，从西侧突围！重复，从西侧突围！”

将令穿过电波，抵达了那片钢铁与混凝土构成的地狱。可对于被困在死地里的人而言，命令不过是远方的雷声。他们还得亲手，一寸寸地咬牙搬开倒塌的辎重，拖着肋骨断裂、血流不止的同袍，在伸手不见五指的黑暗中，用身体去蹚出那条理论上的生路。

屏幕前的看客们，安坐于上帝视角的延迟画面之上，可以轻易拼凑出全局的生死脉络。然而，对于亲临火线的刀客而言，每个人手里都只攥着一张残缺的盲牌。罗启锋的耳机里只有四面八方传来的杀机与轰鸣，他根本摸不清敌军狙击手的精准暗哨究竟藏在哪一扇破窗之后；而高居明堂、俯瞰全局的上层，虽知东口已是重兵压境的绝路，却也无法替他点破，楼下那个黑暗的拐角处，是否正藏着一支能瞬间夺命的冷枪。

主持人蒋克己，这位一向以煽动情绪、追求节目效果为己任的男人，此刻却破天荒地沉默了。他没有去催促那些挣扎在死亡线上的战士早一点赴死，而是示意导播掐断了所有花哨的口播，用沉默邀请所有看客，把那些轻率傲慢的质问先咽回肚里。

直到血战终了，屏幕上打出“战损结算”的字样，罗启锋与另一支小队的指挥麦振铮，才各自掀开那张获准公开的底牌。一个双眼通红，声音沙哑地解释着当时为何判断东口尚有一线生机，死咬着没撤；另一个脸色冷峻如冰，一字一顿地剖白，为何自己在生门之外徘徊，硬是没敢踏出那至关重要的、却也可能要命的半步。

两人隔着血迹斑斑的回放画面，开始了激烈的撕咬与追问。谁也不肯在复盘时，让出半寸自己用命换来的判断。那场景，就像两名绝代剑客于电光火石间交锋之后，各自收剑入鞘，才在冰冷的后怕里，看清对方那本可封喉的半步为何没有刺出。而留在死局地砖上的那道极深的剑痕，究竟该被命名为“犹豫”还是“审慎”，绝不能只凭活下来的某一方来强行定义。

最终的记录冰冷而客观：内部核心人员没有被隔着层级直接击伤。第一名存活者真正抵达西口、重返地面时，外围的伏击火力才成为他面前的现实。老关调来的烟幕弹为后续人员创造了转瞬即逝的窗口，一名负责殿后掩护的队员，仍在出口附近阵亡。他的名字，没有因为系统中的重新登录而改变。

那场胜利并不圆满。但人们却沿着那段粗粝的原始视角，反复诘问了很久，直到彻底弄清等待、掩护、牺牲与最终的损失，是如何像一条沾满血污的绳索，环环相扣地连在一起。蒋克己终于没有把这些沉重的间隙，都用聒噪的商品介绍塞满。

罗振业按下了暂停，画面定格在那名阵亡队员最后的背影上。他转过身，会议室的光线让他眯了眯眼。

“八月，极轴投入三万元。增加的，就是这种可自愿进入的解释场次、完整的战斗回放，以及不会被广告打断的深度问答。”他的声音不带感情，像在宣读一份验尸报告。“凌拓投入一万二千元，继续选择较小的展示窗口，微调了时段，并撤去了一项回报率极差的静态展示。两家各自的参与池均已先期锁定并如期结算，没有等键盘卖得好不好，才决定给那些普通参与者发他们的基本份额。”

他切换到下一页，两排冰冷的数字并列。

“商品规格、定价、保修条款完全一致。非注意力成本、退货率与消费者比较窗口，按同一口径核对，任何可识别的其他促销活动均另列表格。”罗振业的手指在屏幕上划过，“根据现有可比样本估算，极轴的增量毛收益为四万二千元，扣除三万元投入，净增一万二千元。凌拓的毛收益为两万一千元，扣除一万二千元投入，净增九千元。”

周慎衡一直沉默地坐着，眼神如古井无波。直到此刻，他才缓缓伸出一根手指，轻轻敲了敲桌面。他没有合上这份看似已经完结的账目。

“罗生，把底账翻出来。”

罗振业点点头，又按了一下遥控器。一张更复杂的财务表单占据了整个屏幕。

“极轴，这一产品窗口期，实收五十万元。产品、交付、售后等完整归属成本，四十万元。那三万元的营销合同，已完全包列本次制作、展示与回访的所有费用，没有另藏任何门店人员的配套支出。所以，实际净利润，七万元。”他顿了顿，目光扫过另一列，“凌拓，实收三十万元，相应成本二十四万元，完整营销成本一万二千元，净利润四万八千元。必须说明，先前那两个‘净增数’，比较的是‘假如不做本次营销’的估计结果，绝不能再加到这七万和四万八之上，当成第二份利润来吹嘘。”

周慎衡的目光，像一把外科手术刀，精准地切割着每一个数字背后的逻辑。他要的是“实地”，是围棋棋盘上清点出来的、一子一目都无可争议的疆域。

罗振业再翻一页，是两张资金用途授权页，上面有财务部门红色的印泥，血色般醒目。

“极轴的七万元利润里，四万五千元已有明确的设备更新与到期债务偿付安排，可供灵活调用的资金，是二万五千元。凌拓的四万八千元里，三万元已有既定用途，可另用一万八千元。”他指向两份新的授权书，“两家公司董事会分别批准，把其中的二万元和一万二千元，投向九月上旬的护送与复盘项目。余款各自保留，作为风险储备。批准页上写得很清楚，动用的是已到账的现金，没有把应收货款当成现款，银行的回执也证明，资金不是从参与者尚未领取的份额里临时借出来的。”

一周后，这个新窗口的结果出来了。一张更小的表，却同样严谨。

“新窗实收三万二千元。其中，明示成本八千元、固定组织成本三千元、风险储备金一千元。最终注入参与池的总额，是二万元。二十个已接受岗位的参与者，每人各获得一百元基本份额，剩余的差异池为一万八千元。结算回执，已通过加密邮件逐一发送到人。”

报告里附了一段匿名视频，邱庭舟领到自己的那份数字凭证，没有片刻停留，转身就在一个线上平台，结清了一笔早已到期的家用账单。罗振业坦诚道：“我当时很想问他，这笔钱最终买了哪家的商品，但话到嘴边，还是收住了。”他看着在座的每一个人，眼神锐利，“钱走过了我们这一圈，就必须允许它在任何一家门前转弯，哪怕是对手的门前。”

“那么，谁赢了？”杜启航终于问出了那个所有人都悬在心头的问题。

罗振业指了指屏幕上的绝对净增额，一万二对九千。而他身旁的宋振峰则指了指另一组数据，低声道：“投入回报比例。”随后，两人都克制地笑了一下。极轴的净增额更高，是百分之四十的回报；凌拓的净增额虽低，回报率却是惊人的百分之七十五。不同的口径，回答着截然不同的问题，你不能等棋下完了，再去挑一条对自己最有利的规则来宣布胜利。

周慎衡听见这句夹杂着试探与机锋的笑声，依然面不改色。他伸出双手，将桌上那两张代表着八月战果的、仿佛还带着血腥味的旧账表，轻轻拍平，动作沉稳，如同棋手在落子前抚平棋盘的褶皱。十九路棋盘之上，辛苦抠出来的“实地”与着眼于未来的“厚势”，各有其沉甸甸的分量。换一种拷问的眼光，先前的生死得失，就可能翻转出截然不同的底色。但你手里这把剑，究竟想切开哪一面，总得在拔剑之前，就把规矩立得明明白白。

他身旁，还静静地躺着一张六月份的战报，上面极轴亏空六千元的赤字，依旧冰冷刺骨。真金白银砸下去可以成事，囊中羞涩也同样会满盘皆输。左右这残酷结局的法则，绝不能被虚伪地简化为“花钱越少越显高尚”。贴在同质工业品上的那一纸脆弱的商标偏好，必须经由刀光剑影里实打实的感官血拼才能铸就，甚至可能在消费者掏出钱包的前一秒，被另一个横空出世的悬念彻底斩断。

“基于回报率和用户反馈，”罗振业的声音再次响起，果决如刀，“我砍掉了一项颇得叫好的夜谈环节。数据很清楚，看客们固然喜欢这种风花雪月的调剂，但极少有人会因此去为极轴的键盘多付一分钱。这种场子，大可以另寻愿意掏钱的闲人去办。那些只看不买的白嫖看客，根本没资格逼着极轴，永远为他们的免费偏好买单。”这是弃子争先，舍弃一块看似活泛的孤棋，是为了抢占更重要的全局大场。

另一侧的岑绍庭，一直沉默地读着战报，此刻也抬起头，声音同样没有半分犹豫：“我们复盘了上次的险胜，我砍掉了自己下一轮方案里两处已经露出疲态的气口。上次侥幸得手的杀招，绝不会因为赢了一阵，便成了不败的秘籍。”就像在棋盘上，一旦被对手看破了那记石破天惊的“妙手”，若是原封不动地再走一遍，便注定会沦为任人宰割的致命缓手。

这一次，逻辑的链条被严丝合缝地扣上了：八月的实收款项，扣清所有既定用途后的可用利润，支撑了九月的新合同，新合同带来了新一轮的支付。两项增量效果的数据旁边，仍带着无法消除的估计区间，下一期，也仍要用同样残酷的方式重新检验。程砚舟看着桌上摊开的四张不同日期的纸，终于肯让那根代表因果的箭头，依次经过每一道狭窄的关隘，而不是像过去那样，轻飘飘地从一笔大收入，直接跨越到另一次华丽的开场。

当天晚些时候，海岬西出口的那支伏击部队，悄然撤向了另一处关键道路。沙盘上的战役，又换了一副全新的局面。

程砚舟将新旧报告并排收好，手指抚过那张六月的亏损页，没有将它抽掉。她把所有的纸张，无论荣辱，都悉心归入同一个档案夹。棋盘上的每一步，包括那些输掉的劫争，都是棋谱的一部分。
