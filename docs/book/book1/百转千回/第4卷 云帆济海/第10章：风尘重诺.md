# 第10章：风尘重诺

九月底的空气，已然淬着刀锋般的寒意。陆文渊孤身一人，步入城北那间灯火通明的议事厅，带来的已不再是那份轻飘飘的意向页，而是一份沉甸甸、用崇远资本的印信烙下了血色封印的战表。

黑胡桃木的长桌上，烟灰缸里堆满了捻灭的烟蒂，像一座座小小的坟。程砚舟、林静薇、周慎衡、陈驰、许知妍、杜启航，星原六位核心围桌而坐，神情肃杀，仿佛在等待一场决定山门存亡的棋局。

陆文渊将一份文件推到桌子中央，指尖叩击着封面，发出枯寂的声响。

“崇远资本，为下一季的三场搏杀，备下六万元的生死赌本。”他的声音没有半分暖意，像冰块在玻璃上刮过，“每场死卡两万的红线，专作招兵买马与排兵布阵的开拔费。”

他顿了顿，目光如鹰隼般扫过在场每一个人：“这笔钱，买不走诸位的帅印，也吞不掉刀客们已凭血汗落袋的卖命钱。我崇远资本，更无意借此在大帐里强占一把交椅。”

林静薇的指节攥着一支笔，几乎要将笔杆捏碎。她俯身向前，视线死死钉在那份契约上，一字一句地审视，仿佛要从墨迹里榨出淬毒的陷阱。

“陆先生快人快语，那我也把丑话说在前面。”她抬起头，眼神清冷如冰，“一场若打了败仗，没花出去的银子，原路退回；已经流血折进去的粮草，按画押的生死契，各安天命。这笔烂账，绝不能变成一根绳索，逼着全军将士去卖命填补一个无底洞。”

她的每一个字，都像是在棋盘上落下的一颗冷硬的石子，封死了所有可能的腾挪之处。

陆文渊嘴角勾起一抹冷笑，非但没有退缩，反而悍然反击，身子微微前倾，气势如出鞘的利剑：“林律师说得好。那么我也请各位听清：一旦凯旋，我崇远资本，必须按原契约，切走最肥的那块战利品。绝不容许等打下了江山，再翻脸说我这出资人只该扛着死伤的黑锅，吃些残羹剩饭。”

他的声音陡然拔高，如同金石交击：“粮草底薪、刀客的保底银两、拔尖的重赏，以及我崇远的抽成——所有分赃的位次，必须在战前用刀劈开，一清二楚！战后论功行赏时，谁敢在桌子底下暗中挪动分毫，就是与我崇远为敌！”

这番话，已不是商议，而是最后通牒。议事厅内的空气仿佛凝固了。

良久，林静薇缓缓将笔递了过去。直到陆文渊在那一栏代表着“刀尖滴血，无怨无悔”的条款下，重重按下自己的手印，那鲜红的印泥如同凝固的血滴，林静薇才冷着脸，将下一重关卡的卷宗递到他面前。

同蹚一滩浑水，大可各有图谋。星原的剑客们图的是扬名立万，是竖起一面不倒的旗；而陆文渊这般的行商，算的永远是真金白银。这世上最难的，不是一时意气相投，而是在血雨腥风里杀过一轮后，这帮背景各异的人，还肯咬死启程时发过的毒誓。

六万元现银入库，周慎衡像一头护食的狼，立刻将这笔钱按照三场战役，死死地切成三块，分别锁入不同的账房。这笔钱绝没被粉饰成虚浮的声望进项，更没把崇远资本的入局吹嘘成已经凭空捏造出的战果。在他的账本上，这只是押在赌桌上的筹码，在翻牌之前，一文钱也不能算作自己的。在刀客们签下生死状、接下任务之前，真刀真枪的现银与白纸黑字的血契必须反复勘验，至于那些空口白牙许下的虚头赞助，半个铜板也不准提前算进犒军的赏池里。

当晚的会议一直开到深夜。山门的组织架构在扩张，随之而来的接管、授权、核验与争议也如同疯长的藤蔓，缠绕着每一个人。杜启航开发的自动工具能像个忠实的史官，整理所有往来记录，却不能替他们决定当时的命令是否可行，私人间的密谈是否同意公开，以及一笔刚刚达成的新交易，到底卖的是什么，是割肉饲虎，还是弃子争先。

“我建议，建立一套统一的、所有人都可复算的事件记录。”杜启航的脸上带着一丝技术人员特有的执拗，“所有动作，无论大小，都应留下不可篡改的痕迹，如同一盘棋的棋谱。”

“同意。”林静薇点头，“标准化可以减少重复的内耗。但要警惕一点，总处理量增加后，即便单位成本下降，总成本仍可能急剧上升。我们不能只盯着那一栏‘单位费用下降’的数字弹冠相庆，却忽略了整个后勤体系正在被活活累垮。”

许知妍推了推眼镜，补充道：“可以让更多组织自行登记。比如普通游玩、切磋武艺，不必八个人逐场批准。但凡带有参与收入、资金转移和可交易权利的业务，则必须通过相应的门槛，验明正身，画下押金。”她顿了顿，声音里透着一丝疲惫，“登记，只负责说明是谁在做什么。绝不意味着，只因他在此处挂了个名字，山门便已核准了他将来所有的承诺。”

然而，麻烦来得比预想中更快。

山门初开不过两日，名录里便如蝗灾般涌入了几十份形似克隆的拜帖。有宵小之徒，将同一段木偶扛活的残影，生生套上三个不同的山头反复呈堂，企图一鱼三吃；还有人漫天撒网，批量贴上“曾在粮道上卖命”的空话，追问细节，既掏不出交割的虎符，也说不清究竟是在哪年哪月哪场战役中流过血。

这帮人虽没能直接套走赏银，却像一群苍蝇，把刑堂验伤的队伍挤得水泄不通。真正想开堂讲武的一家本分社团，就因为被这群无赖堵在门外，文书勘验足足等了两天，生生错过了约好的演武场。

杜启航的脸冷得像一块铁。他亲自坐镇，先将那些如同一个模子刻出来的残影与背后的黑手，用一道刺目的红线死死并列示众，昭告天下。随后，为了赶在有限开城的死线前清出道路，他启动了一套沙盘阵法，自动将这些疑似串供的口供折叠、压缩，尽数打入待审的“天牢”。

这道防线，如同一招凌厉的“天山折梅手”，收发自如，暂时逼退了攻势，却无法一劳永逸。它只能逼迫那些人重新对质，却无法直接一刀切地宣判每张相似的脸谱都属于同一个细作。他们还未来得及用战阵交割时的生死暗号，来检验这道粗筛的成色。

许知妍面沉如水，将这平白多出的验伤时辰，一笔一笔记入清理门户的折损账上。她心中明镜似的：山门的门槛放低，固然免了新刀客的奔波之苦，却也让那些造假虚声的江湖油子，能用一文不值的代价，疯狂榨干刑堂的心血。

最致命的，是那本新造的花名册。

在那上面，两道生死门面被画得难以分辨。已经闯过刀山火海、拿到赏格的英雄帖，与那些仅仅在此挂了个名号、来历不明的游医野狐，竟然都挂着同样刺眼的星原大旗。尽管大旗下方藏着几行蝇头小字辩白，可一旦拿到江湖上招摇撞骗，那些匆匆一瞥的看客们，眼里往往只剩下那面虎虎生威的大旗。

“开城之前，必须修改！”陈驰一掌拍在桌上，如同拔剑出鞘，“这等于我们把自己的印信借给了骗子！”

许知妍虽同意必须将生死状态顶在每个名号的脑门上，却固执地指着墙上的倒计时：“时辰不能改！这是我们对所有人立下的军令状。”

争执不下，所有目光都投向了程砚舟。

程砚舟最终咬牙，在“有限放行”的帅印上盖了章。他自以为重兵把守住了库房的银门，却惨痛地低估了，在这片血肉横飞的江湖之外，那些旁观的看客，会将这面“星原”的招牌，当成多大多重的生死担保。

夜深人静，他独自看着那份花名册，星原的图腾排列得如同刀阵般森严，他的目光却死死钉在那行苍白无力的小字上。

十九路盘上，他以为自己只是顺手在薄弱的边角补了一记，自以为是手筋，便可抽身向前，去争夺更大的“大场”。他却没有痛心追问，自己这自作聪明的一手，在旁人的眼里，究竟被吹嘘成了多大多硬的一块“厚势”。这看似不起眼的一步，或许已为未来的“生死劫”埋下了伏笔。

就在这时，庄承裕提交了一份名为“参与经历凭证”的议案。它拟记录成员真实的履职经历与获得的公开荣誉，便于成员在山门之外介绍自己。

林静薇的书面意见如同一盆冰水，兜头浇下：“履历可以核验，勋章不等于现金请求权。任何带有付款义务的凭据，必须明确指向原始合同、债务人和未清偿金额。交易更需另行准入，不能借一个新名称，就想跨过我们用血立下的规矩。”

庄承裕此前诱导成员续留的问题已经整改，山门并未因此禁止他所有新申请，但这份“前科”，让他后续的每一次抽查都变得格外严苛。他沉默地签收了林静薇的意见。

没过几日，一张飞扬跋扈的招募令，被陈驰在江湖外的暗桩处截获了。

在那与官方花名册如出一辙的星原图腾旁，赫然多了一句血淋淋的蛊惑：“把今日流的血，换成明日能变现的黄金！”

那句口号下方，更是大剌剌地挂着一枚高阶虎符的幻影，以示其正统，却根本没敢列出哪怕一笔白纸黑字画押的现银账单。

陈驰看到这张招募令时，只是冷笑了一声。

他当即将那份原先规规矩矩的拜帖，与这张带毒的新门面一并封存钉死，厉声下令刑堂彻查这越界的妖言。对方闻讯，立刻辩解说这不过是画在纸上的愿景，尚未在堂口里公然贩卖。

陈驰非但没把这根刺从肉里拔出来，反而将那句狡辩的鬼话，当成认罪的画押，死死扣在了卷宗的首页。这已不是简单的违规，而是对星原根基的侵蚀，如同“化功大法”，无声无息，却能废人根骨。

九月绝杀的最后一夜，山城里，一位战功赫赫的指挥使按规矩将帅印交割给副将，准备卸甲归田。那枚染过无数次血的虎符，依旧堂堂正正地挂在他的腰间。

那原本只是一段被铁证夯实的生死经历，是他此生荣耀的见证。

而那张飞散在暗处的招募令，却已经妄图扒下这身英雄的血衣，去替一笔根本不存在的烂账，作伪证。
