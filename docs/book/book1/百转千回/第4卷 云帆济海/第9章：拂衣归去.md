# 第9章：拂衣归去

本草堂取消秋场的消息，是在山城集散区的银杏树将一身青衣尽数换作黄金甲时，传开的。

寒意已顺着长江的江风刺入骨髓。沈培棠坐在黑胡桃木的长桌前，窗外那棵高大的银杏，每一片叶子都像精心锻打的金箔，在铅灰色的天幕下凄美地燃烧。他原本的构想，是借着这满城秋色，办一场关于花草与城镇记忆的清谈。不卖一味药，不许诺半点疗效，只将那些根植于泥土与砖瓦间的枯荣，说给有缘人听。他深知，自己钟爱的东西，未必能在这江湖中找到足够多的知音，愿意为这份虚无缥缈的情怀解囊。

屏幕上，冷光映着他毫无血色的脸，数字像一排排冰冷的墓碑，森然罗列：

预售票三十张，单价四十元，合计一千二百元。
企业预付支持款三千元。

两笔预收款项，总计四千二百元，正静静地躺在专用项下的账户里，如同被戒律封印的真气，分毫未动。合同里白纸黑字写得清楚，最低开场条件未曾达到，这笔钱便绝不能作为已成立的战场参与承诺，投入到那片尚未燃起烽火的阵地中去。

“已经准备了这么久，再开一回，再多吆喝几声，也许……也许就成了。”朋友在通讯器那头叹息着劝他，话语里的暖意被电流切割得支离破碎。

沈培棠的目光却死死钉在那棵窗外的银杏树上，仿佛要将那绚烂的死气看穿。最终，他缓缓抬手，像一位决意自断经脉的武者，挥刀斩断了心中最后一丝杂念。为了这场未竟的雅集，他亲手砸下五百元置办的布景与心血，如同沉入寒潭的石子；为了获得这片场地的使用许可，两份画过押、印着红泥的文书上，清清楚楚地写着六百元的许可费。这两笔总计一千一百元的开销，如今只能由他自己那点薄薄的家底硬扛。所有为此出过力的匠人、画师，他都按着江湖上最讲究的规矩，一文不少地结清了酬劳。至于那笔四千二百元的预收款，则像一道不容亵渎的铁律，被他原路、分毫不差地退了回去。他没有半分颜面，去逼迫那些已经表示过善意的看客，来分摊这盘注定要推倒的败局；更没有让那些交过底、出过力的手艺人，反过来倒贴自己的血汗。

他的手指，在那个刺眼的“取消”键上空悬滞了许久，久到指尖都有些发凉。这方寸屏幕，此刻在他眼中，就是一张杀机四伏的十九路棋盘。那些已经砸进去的几记“恶手”，正像鬼魅般在耳边低语，蛊惑着他再去“倒贴一子”。它们说，只要再狠下血本，再多压上一些筹码，那层看似一捅就破的窗户纸，就能硬生生撑成一片无懈可击的厚势。

他惨然一笑，笑声嘶哑。目光掠过那页尚未对任何香客许下誓言的空白残局，他终于用尽全身力气，死死抠住了自己那份不甘的欲念，没有再往那个无底洞里，填上哪怕最后一枚棋子。

一千一百元的放血，虽不至于让他流落街头当场讨饭，却也足以痛彻骨髓。这痛，并非来自账本上那个冰冷的赤字，而是来自那些在刀光剑影般的市场里精心挑选过的树影，那些他亲自登门拜访过的门客，那些心血与期盼……它们绝不可能因为会计系统里一句轻飘飘的“风险折损”，就真能从心尖上被彻底抹去。

程砚舟见不得兄弟受此折辱，动了心思，想从别处几个尚有盈余的盘口里，暗中抽调些粮草辎重，来为沈培棠粉饰这场败局，至少让账面看起来不那么狼狈。

周慎衡却闻讯而至，他一言不发，只是将每一笔沾着血与汗的账权，冷酷地摊开在深夜办公室的灯光下。他的脸庞如万年寒冰，手指敲击在虚拟账簿上，发出金石之声。

“这一笔，是欠前线那些刀口舔血的兄弟们的卖命钱，动它，就是断他们的归路。”
“那一笔，被铁律死死锁在储备库里，那是我们过冬的口粮，是整个大营的‘气’，谁也休想动。”

他的声音不高，却字字如刀，在寂静的空气中划出裂痕：“想救急，可以。你程砚舟大可另立旗号，擂鼓聚将，或者干脆自掏腰包，砸锅卖铁，我周慎衡敬你是条汉子。但绝容不得你像个三流的毛贼，偷偷摸摸去挪用别路弟兄的军饷，只为了给这场败局画上一张假意不败的画皮！那是对所有人的侮辱！”

沈培棠摆了摆手，谢绝了程砚舟的好意。他只想先静一静。

比徒手掰断帅印更煎熬的，是收拾这片狼藉的交割。本草堂租借的这方虚拟残阵，并非孤岛，它的底层还死死连着一条正在流血运转的庞大“粮道”——那是整个生态系统的核心网络。堂口虽然关了，却绝不能像个撒泼的莽夫般，一键毁了那条路，把正在上面拼命的其他镖局的车队逼入万劫不复的死地。沈培棠设下的阵眼尚未激活，那些沾染了军机要务的铁壁铜关，依旧死死攥在原驻军的手里；租来的场地一旦解了契约，哪怕只剩下一地鸡毛，也得按照最严苛的规矩，老老实实地交还给那只看不见的、掌控着整个棋局的巨手。

邱庭舟提着一把冰冷的电子标尺前来查验，他神情严肃，如同刑部的执事。什么“虚景”能拆，什么“死阵”绝不许乱动，他辨得一清二楚。

“那棵银杏，”他指着沈培棠心血所凝的虚拟造物，“不过是这集散地里撑场面的花架子，卷铺盖带走，没人拦你。”他顿了顿，目光变得锐利，“但战区里那座核心数据交换石桥，它基座上还染着上次攻防战的血。它绝不会因为你沈培棠曾在桥头摆过几天茶摊，就跟着你改了姓。更休想把它当作抵债的破铜烂铁，拆解变卖！”

散伙的银两、被永久封死的交易通道、那些带着心血烙印的作品卷宗……所有的一切，都被分门别类，用冰冷的数字标签钉死在归档记录里。尚未到期的契约，咬着牙硬挺着履行完最后的义务；已经到期的布告，被冷酷无情地从告示墙上扯下。每一个曾为此付出过心力的人，他们用命换来的履历，都被堂堂正正地拓印、加密、发还本人。向天下张榜的告示里，白纸黑字写清了关门的死线与退银的通道，绝没有走漏半点那些曾购票的看客们的私密行踪。

当最后一笔还清的尾款落下鲜红如血的电子印章时，沈培棠亲手在后台捏碎了那棵他钟爱无比的虚拟银杏树。数据流如金色的烟尘，消散于无形。那些原本眼巴巴等着听曲的看客们，大可以痛骂他言而无信，骂他扫了所有人的兴，却绝不会在人走茶凉之后，发现自己手里连一张可以讨债的残契都摸不到。

这残局的收官，远比起势时的意气风发要死寂得多，也艰难得多。沈培棠将那些生死契与还款的回执一张张码平，存档，加密。他就好像一个在江湖上萍水相逢的孤客，在离开借宿的寺庙时，恭恭敬敬地吹熄了借来的灯火，一丝不苟地点清了别人寄放的行囊，最后将钥匙原封不动地还给了主人。

真正傲骨的侠客，拂衣而去之时，两袖清风，绝不能暗藏半点带血的赃物。

几天后，他买了一张票，去了风雷原声社。场子里人声鼎沸，没人围上来要他先解释本草堂为何办不下去，更没人把他当成一个走投无路回来讨岗位的落魄户。散场时，灯火阑珊，许嘉榕走到他身边，轻声问：“将来，还讲那些花花草草的故事吗？”

他说，也许吧，但可能会先写一些短小的手札，别一上来就痴心妄想地准备整个季节。

“我想听那棵树。”她看着他的眼睛，认真地说。

沈培棠没有立刻承诺会重新开场，只是将这句话，这片刻的温暖，牢牢记在了心里。

在系统的另一端，陈驰调出了本草堂的档案。他在项目状态栏里，没有选择“商业失败”或“违规处分”，而是平静地将其标注为“依约结束”。他知道，商业失败、兴趣变化、家庭照护……每一个选择退出的背影背后，都有各自的缘由，不能把所有中途离场，都简单粗暴地当作背叛。为了一个虚假的留存数字，而将一个已经体面终结的项目继续标作“活跃”，那是对缔造者最后的侮辱。

深夜，另一支装备精良的队伍，接过了那条山路运输任务的权限。他们的车队轰鸣着，经过了本草堂原计划中作为集合点的那个虚拟坐标。

道路，仍在那里。
曾有一场没能办成的秋场，也静静地留在了它自己的记录里，不曾被抹去。
