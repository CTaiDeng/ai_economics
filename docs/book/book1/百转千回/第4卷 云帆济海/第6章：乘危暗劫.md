# 第6章：乘危暗劫

三更残月，寒霜凝于窗棱。四海行会的夜班窗口上线不过三日，子时后的山城竟比白日里更为喧嚣，无数幽灵般的ID在虚拟的街巷间奔走，如扑火的飞蛾。深夜的在线人数，已然压过了白昼。

庄承裕坐在他的黑胡桃木长桌后，指尖在泛着冷光的屏幕上轻轻划过，如同拨弄琴弦的乐师，弹奏的却是他人心底最深沉的疲惫与贪欲。他恶毒而精准地给每一个连续熬夜的刀客挂上了累积展示的虚衔——“奔雷校尉”、“破阵都尉”、“镇关将军”。那头衔在屏幕一角熠熠生辉，仿佛唾手可得的荣耀。但一旦断了一晚，前几夜呕出的心血便会化为泡影，这无声的惩罚如一柄达摩克利斯之剑，悬在每个人的头顶。

那招魂幡般的页面，绝口不提这些虚衔能否变现成哪怕一文铜钱，却用血红的倒计时和不断滚动的虚幻预期赏金，将刀客们的神经死死绑在战车上。哪怕白纸黑字签下的战功绝无可能被系统抹杀，但行会精心编织的这套新门面，却在每一个像素、每一声系统提示音里阴沉地暗示：你敢离开火线半步，前几夜熬出的血，就全都白流了。

第一道带血的鸣冤帖，如一道惊雷，劈开了这虚假的繁荣。发帖的是一名累脱了形的运输刀客，双眼熬得如同死鱼，连撑了数个不眠之夜。按照契约，今夜子时，他本该交割虎符，卸下重担，然后沉入一场久违的酣眠。然而，就在他准备下线的那一刻，一道催命符从天而降，冰冷的系统指令砸在他的脸上：再强行押送一批辎重，否则，按临阵脱逃的死罪论处，信誉清零。

这要命的加码，根本不在他当初画押的生死契之内。那条新增的路线，更是毒蛇般蜿蜒着越过了火线接管的红线。他早已按照规矩，提前一个时辰递交了退路申请，行会却无耻地将前来接应的NPC木偶死死锁在关隘之外。冠冕堂皇的系统回复冷得像铁：“为保证战场沉浸感，NPC接应机制暂不启动。”一句轻飘飘的“不够真实”，逼着一个活生生的人，继续在刀尖上泣血硬扛。

那条本该全身而退的生路，被一只看不见的手强行掐断。他惊恐地发现，前面每往火海里多蹚一程，身后那扇保命的门，便像是被钉死了一重又一重。这名刀客死死盯着屏幕上那催命的倒计时，分秒流逝的声音仿佛是他生命的倒数。他终于彻骨地察觉，这堂皇的招募令里藏着的，是怎样一种阴毒的连环杀招：这根本不是一盘棋，而是一张沾满了胶水的棋盘。只要你落下第一颗子，就被死死黏住，逼着你拿自己的血肉去填下一个、再下一个无底的劫争。

许知妍的初审报告还带着墨水的余温。她曾像个冷酷的账房先生，只冷眼核对了账面上的粮草、辎重与每一笔分成，确保数字的平衡。然而，她致命地遗漏了棋盘之外的人心。她算尽了局中的得失，却没算到终局收官，人在交还虎符的那一步，究竟会踩中怎样一个不见血的陷阱。当她切开那些被刻意屏蔽的暗页，后台数据如瀑布般倾泻而下，她才触目惊心地发现：那些保障刀客权益的护身条款，被死死折叠在需要点击七八次的隐藏角落；而那血红色的“战功清零”警告，却像地府判官的朱笔，狰狞地占满了整个视野。原本用来排兵布阵、调度人手的作息情报，此刻竟沦为庄承裕这位刺客手里的刀，专挑人最疲软、最无力挣脱的气口，一刀狠过一刀，刀刀见血。

“他可以不接。”会议室里，庄承裕的声音平静无波，仿佛在评论一盘与己无关的棋局。

林静薇的眼神骤然变冷，她将一部平板电脑“啪”地一声拍在桌上，屏幕上正是那刀客的鸣冤帖和后台的规则截图，光芒如出鞘的利剑。“依据呢？”她的声音清冽如冰，“让他赴死的将令，依据何在？真正能调兵遣将的军规，必须有分明的虎符为凭，有保命的辎重为继，有不可越界的红线为限，更要有刀客本人白纸黑字的画押确认！而不是用这种虚张声势的军令状，去给榨取血汗的黑合同盖上一个伪造的官印！堂堂正正的交接，力战不支的败报，与弃阵逃脱的死罪，三者泾渭分明，岂能仅凭一个冷冰冰的离线印记，就混为一谈，乱杀一气！”

话音未落，另一份带血的战报被呈了上来。一名仍在死线时辰内的刀客，接到了不可抗拒的死守军令，却在战局最胶着时，为贪墨个人战功，悍然放弃侧翼掩护，擅自追击一股残敌，致使整个防线的生门被敌军撕开，阵脚大乱。这笔血债，同样必须算清。绝不能因为行会门规腌臜，就任由江湖规矩崩坏，让投机者逍遥法外。

判决如刀，迅速落下：先褫夺此人调兵的虎符，当堂拍出他擅离职守的行军记录作为铁证，并留足三日申诉的生门。但，绝不牵连没收他此前用命换来的、每一笔干净的赏银。

这两桩恩怨，一桩冤，一桩罪，被并排钉在了虚拟的刑堂之上，昭告天下。谁也休想再靠一句轻飘飘的“自愿”或是“抗命”，把这盆脏水搅浑，糊弄过去。

许知妍站在巨大的电子沙盘前，伸出手指，在两个截然不同的时间点上，死死圈出两个拔剑退场的时辰。她没有将它们混为一谈。同样是弃守一处死地，十九路棋盘上的前后手，却有着天壤之别。她对众人缓缓道：“一方，是拼尽全力，仁至义尽之后，光明正大地卸下重担，这是厚势；另一方，却是为了自己的‘目’，把同袍的后背留给了屠刀，这是恶手。落子的地方看似一模一样，但棋盘的死活、气脉的流转已是云泥之别。我们绝不能把两张黑白分明的棋谱，强行揉成一团烂账。”

紧接着，又有几名被当成牲口般长期排班查夜的苦役，拍案而起。他们被固定的夜班时间表压得喘不过气，仿佛被钉死在磨盘上的驴。林静薇果断抽刀，将整理好的法律文书和后台数据铁证递到他们手里，一路护送他们杀向衙门，击响了那面数字世界的登闻鼓。当堂，她便越过行会，直接动用信托基金，结清了他们每一笔没有争议的血汗钱。究竟是平台雇佣的死士，还是协议下的闲散门客，必须按刀口舔血的实证来算，绝容不得平台用一个虚浮的“玩家”身份，就想强行抹平这天下不平事。

风暴之下，相关诱导功能被即刻暂停，但合法的基本参与份额，依旧按期支付。许知妍在公开的备忘录中，一笔一划写明了自己的审阅遗漏。四海行会收到的正式整改要求，措辞冰冷而精确：误导性界面展示、超范围使用个人作息资料、以及恶意阻碍正常任务交接。每一项指控之后，都附有精确到秒的时间戳和不可辩驳的操作记录，同时也允许行会提出复核。

有人建议，为免再生事端，不如一刀切，关闭所有夜间活动。老关第一个站出来反对。他摘下老花镜，声音沙哑却有力：“我和在座的各位，都已通过成年核验。平台也没有向未成年人开放夜班入口。我白天要照顾家人，分身乏术，夜深人静，反而是我能挤出来的最完整的‘大场’。要改的，是那种让人停不下来的‘劫争’设计，而不是替我们所有人选择睡觉的钟点。”

调整后的规则很快上线。刀客们已经完成的战功记录，不再因正常离开而消失，那柄悬顶之剑终于被撤去；下一段岗位的具体内容、报酬和限制条件，必须弹出独立窗口，重新确认；当真人玩家选择结束任务时，NPC木偶会按照约定时间精准接续，其后产生的所有贡献，不再与真人强行捆绑。必要的安全交接流程仍须履行，但被严格限定在十五分钟内，绝不能被无限拖长，变成另一种留人的借口。

七日后，那虚火般燃烧的深夜在线时辰，如冬雪遇骄阳，轰然雪崩。许知妍面不改色，将这份惨淡的战报，连同庄承裕那些上不得台面的手段罪证，一并甩在金主的桌案上。她的眼神没有丝毫退缩：“剜去腐肉，必然会流血，会留下伤疤，但这才是保命的正道。我们绝不容许再用下作的手段，去粉饰太平，填补账面上的窟窿。”行会必须自己打落牙齿和血吞，承担起重修门规的代价和那笔带血的赔款。休想从刀客们已经落袋的卖命钱里，再抽走一分一毫。

风波平息后，那名第一个敲响登闻鼓的运输刀客，再次留信。信中只有短短一行字：“今夜，我终于可以在交出虎符后，堂堂正正地转身离开。待到明日拔剑再战时，那份浸血的功勋，依旧会刻在石碑上，等着我。”

程砚舟死死盯着这行字，反复读了两遍。他没有天真地用这句惨胜后的宽慰，去抵消那名刀客在这片泥沼里熬干的血泪与心神。他只是默默地将这封信存档，作为这场战争中，一枚沉重而宝贵的官子。

夜漏九响，山城的镖车依旧在行进，只是车夫换成了不知疲倦的NPC木偶。它们在死寂的涵洞中缓缓碾过，冰冷的机械轮轴声取代了昔日的人声鼎沸。战报的卷宗上，清清楚楚地烙下了一个交割完成的朱印。

卸下重担的真人，早已抽身退出了这片江湖，回到现实中，或酣然入梦，或陪伴家人。而沙盘上的战区，依旧在冷冰冰地运转，分秒不差。这两件曾经被庄承裕用恶毒的手段死死绑在一起、互相要挟的事，终于在连绵的刀光剑影中，被彻底斩断。

一刀两断，泾渭分明。
