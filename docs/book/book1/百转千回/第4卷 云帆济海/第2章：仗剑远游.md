# 第2章：仗剑远游

当南离那封烫金的英雄帖递到手上时，许嘉榕知道，自己最难面对的一关，是方婉音。

她应下了山城通信席的邀约，也答应为那支在枪林弹雨中穿行的运输队做夜行记录。这意味着，她将彻底错过原声社新一期的筹备。尽管上一期的合同早已履行完毕，可一想到要离开那间最初接纳自己的、仅能容纳十几个听众的小厅，她便觉得五脏六腑都纠着一团无形的债，沉甸甸，还不清。

推开那扇熟悉的、转轴会发出轻微悲鸣的门，方婉音正坐在调音台后，指间夹着一支燃了半截的细长香烟，烟雾缭绕，模糊了她平日里刀锋般锐利的轮廓。

“要带哪些材料？”方婉音没有抬头，声音像是被烟雾浸透，听不出喜怒。

许嘉榕深吸一口气，压下心头的翻涌，将早已拟好的清单递过去。个人作品集，履职记录的副本，至于那些与原声社成员共同创作的版本，她注明了需另行征求授权。而海岬防线上那些尚未解密的坐标，以及与队友在生死关头的私聊，则被她像埋藏最深的剑谱一样，一字不提。

“去试。”方-婉音终于抬眼，目光穿透烟雾，落在她脸上，带着一种勘破棋局的平静，“别因为是熟人牵的线，就忘了把合同上的每个字都看进眼里。”

场面话说得干净利落，像武当宗师推手，一招一式都无懈可击。可当许嘉榕的身影消失在门外，那方小小的堂口重归凄冷后，方婉音却久久地坐在原地。她掐灭了烟，冰凉的指尖捏着鼠标，点开了一个尘封的音频文件。那是一段带血的旧节目，进度条被她用一种近乎自虐的执拗，死死卡在许嘉榕第一次在炮火中拔剑报点的时刻。

那声音，清脆，紧张，带着一丝初上战场的颤抖，却又有着不容置疑的决绝。引新人拜山门时，长辈们总爱云淡风轻地说一句“愿你有出息”；可等到这把亲手开刃、亲手磨亮的剑真要负起行囊去远游，去闯一片更广阔的江湖时，留守山门的人才感到一种剜心般的惊觉。原来自己心里，也有一道看不见的关隘，一道名为“不舍”的生死劫，根本，放不下。

许嘉榕在南离度过的第一个夜晚，便撞了个头破血流。

这里的江湖，有另一套规矩。草莽出身的当地刀客们，将地图上的三道关键岔路，用祖辈传下的土话喊作“上口”、“后口”、“老口”。而沙盘的军用坐标系里，它们的正式名称却是冷冰冰的“北坡”、“涵洞”和“石坪”。许嘉榕仗着在海岬练就的一身烂熟于心的黑话，自以为是地强行省略了地名，一道“从后面绕”的指令，如离弦之箭，带着不容置喙的杀气，传达给了一辆满载辎重的运输车。

那指令，在海岬的棋盘上，是妙手，是捷径。可在这张全新的十九路巨盘上，它却是一步致命的恶手。

NPC驾驶员忠实地执行了命令，重型卡车咆哮着一头扎进了那条被称为“后口”的便道。直到车头灯的光柱刺破黑暗，照亮前方断崖般的损毁边界时，他才猛地一脚踩死刹车。轮胎在碎石路上发出令人牙酸的尖啸，车头在离深渊不足半米的地方堪堪停住。驾驶员脸色惨白，一身冷汗瞬间湿透了作训服。整个车队，就这么被死死钉在了原地，分秒流逝，如同失血。

陆宏远那张黑铁般的脸孔在通讯屏幕上跳出，背景是机房服务器冷酷的轰鸣。“复述你给出的气口位置！”他的声音里没有温度。

许嘉榕张口结舌，脑中一片空白。那些自以为刻在骨子里的海岬暗语，此刻全变成了毫无意义的废纸。她感觉自己像一个固执的棋手，试图将一张烂熟于心的旧谱，强行搬到一张气口、星位、大场全都截然不同的巨盘上。落子哪怕只错偏了半寸，整盘棋的脉络、眼位与生死照应，便会瞬间全盘崩溃。

冷汗刷地打湿了她的额发，顺着鬓角滑落。她咬破了嘴唇，铁锈味的血腥气在口腔里弥漫开来。她放弃了所有自作聪明的简练，用最笨、最慢、最原始的一句剑法，重新起势，将省略的地名一个字、一个字地重新补全。

“原来的通信记录不是很好吗？为什么要换？”一名队员在频道里低声质疑，像一根针，扎在她紧绷的神经上。

她没有反驳。经验让她知道如何去听懂每一句话里的潜台词，却没有让她自动获得勘破另一方天地里每一条路径的神通。她只是沉默地，重新报出地图编号，然后用最谦卑的语气，请本地队员确认每一个坐标对应的俗称。

接下来的“鬼门关”，是一条仅能容一辆车贴着悬崖死线碾过的窄道。前车尚未从那道死亡隘口探出头来，后车只能像一条被扼住咽喉的巨蟒，憋屈地趴在后方的安全区死等。沙盘上，代表大军的红色箭头停滞不前，像凝固的血。上层指挥的主将眼看战机流逝，立刻红着眼在主频道厉声质问：“是否在故意拖延，消极抗命？”

那一刻，许嘉榕死死盯着屏幕上跳动的损耗数据和倒计时，感觉全身的血液都冲上了头顶。她没有辩解，没有求饶，而是将损毁路段的结构报告、等待的战术必要性、以及预计破局的倒计时，用一连串不带任何感情色彩的数据，一口气砸了回去。她的声音冷静得像冰，每一个字节都敲在关节上，精准、有力，如同一套收发自如、变幻莫测的“天山折梅手”。频道里死寂了数秒，终于换回一句同样冰冷的“确认”。那令人窒息的几分钟，再也不是一段无人敢于认领的战术空白。

就在这场惨烈的战役即将落幕收官之际，后方，她的“家”里，一通电话如催命符般打了进来。朋友急需她回去救场，是足以影响整个生态的紧急事态。

她没有丝毫犹豫，按江湖规矩，在指挥系统里提交了撤退申请，交出了象征指挥权的虎符。副将尚未抵达火线，在她离席的瞬间，系统便自动授权了一个毫无感情的NPC木偶，接管了她尚未下完的死局。她卸下指挥权的那一刻，被战报系统以精确到毫秒的时间戳，冷冰冰地钉死在记录上。此后，她还能像个局外人般围观沙盘的演变，却绝不能再厚着脸皮，将NPC后来用数据和逻辑蹚平的那条血路，继续算进自己领赏的时辰里。

功过赏罚，自有铁律。她已在刀山火海里挣到的那份赏银，按着事前画押的生死契，分文不少地划入她的账户；而“临阵脱逃”的代价，也化作铁笔，如实地、永久地刻在了她的履历上。那次险些断送整支车队的致命误判，并没有将她前半夜拼死坚守的功劳一笔清零；同样，后半夜她为大军保住的粮草辎重，也绝无可能替她洗刷掉最初那句致命误导所带来的耻辱。

回到那间熟悉的小厅，她试着将这惊心动魄的一晚编成声音稿。她原本想讲述的是异乡山城的风景，是金戈铁马的豪情，可当她开口时，却发现整个故事的核心，变成了几个人如何反复确认同一条道路的过程。一名参与过那次行动的本地队员，坚持要在稿子里保留“老口”这个叫法，那是他们血脉里的印记。许嘉榕没有删，只是请他在后面加上一句解释，好让后来的人，那些不懂此地江湖规矩的远游客，也能听懂。

正式演出那天，厅里稀稀拉拉坐着几个人。她得到的份额，甚至没有超过以往任何一次旧作。方婉音买了一张票，独自坐在最后一排的阴影里，没有像往常一样发动朋友替她撑场。

散场时，冷清的空气几乎能结出冰来。许嘉榕垂着头，走到方婉音面前，声音颤抖得不成样子：“我是不是……做了辜负原声社的叛徒？”

方婉音看着她，眼神复杂。她坦然承认，最初听到许嘉榕接了南离那封英雄帖时，心里确实像被一根刺狠狠扎过。但她随即又冷冷地补上了一句，那话语像冬日海岸边的礁石，坚硬而冰冷：“那只是我护短的私心，不是你在江湖上违了约。”

两人并肩走在集散区那片潮湿凄冷的海岸线上，海风卷着咸腥的气息扑面而来。许嘉榕在南离山城的履历，正在带着一道道血痕，一寸寸地加厚；而她在海岬那份拼过命的旧战报，也依旧清晰地镌刻在所有人的记忆石碑上。

她忽然明白了。在这片苍茫无尽的江湖里，她不必像个签了死契的家奴，被永久地拴在某一个山门死守到底。她依然有资格，堂堂正正地保留下当年与旧主并肩拔剑、同生共死的那段岁月。那不是背叛，而是成长。每一道伤疤，每一次迷途，都将成为她剑刃上新的寒光。
