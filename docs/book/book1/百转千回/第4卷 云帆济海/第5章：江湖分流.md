# 第5章：江湖分流

会议室的空调开得极低，寒气顺着黑胡桃木长桌的光滑表面无声漫溢，像冬日里结在刀刃上的薄冰。沈婉衡的指尖在面前那份采访提纲上轻轻一点，动作轻缓，却带着千钧之力，正点在“星原带动全城消费复苏”那一行字上。她没有抬头，声音平直得听不出一丝波澜，却让整个房间的温度又降了几分。

“全城的证据，在哪里？”

许知妍的心猛地一沉。这句话像一根淬了毒的银针，精准地刺破了她精心编织的逻辑链条。那个故事，在她自己的脑海里曾经是如此天衣无缝：玩家在沙盘里搏杀，换来真金白银的赏格；他们拿着钱，走进现实的市集，购入所需的货物；商号的流水因此活泛，便有了底气回头支持下一场更盛大的江湖争霸。故事里的每一环，都曾真实发生过。可当沈婉衡用这冰冷的一问，将它们串联起来时，许知妍才惊觉，那看似顺理成章的叙事之间，横亘着多少未经勘测、深不见底的鸿沟。

她带着厚厚一叠分类资料，像一个即将接受门派长老盘问的弟子，走进了基金会的会议室。沈婉衡并未以投资人的姿态施压，她只是像个最纯粹的棋手，冷静地落下一子，直击要害。

“一个本来就要买键盘的人，”沈婉衡缓缓抬眼，目光锐利如鹰，“他只是把选择从极轴，改成了凌拓。告诉我，这对整个键盘市场的存量，是否真的多出了一单生意？”

这一问，如武当剑法中的“黏”字诀，不带杀气，却让人避无可避。许知妍感到喉咙一阵发干。

“……不一定。”她艰涩地吐出三个字。

“很好。”沈婉衡的语气没有丝毫嘉许，仿佛只是确认了一个早已算定的结果。“刘景和，拿到了你们的参与款，买了一副凌拓耳机。这笔交易真实不虚。但你不能只凭这一人之功，就将所有合作品牌的成交额，都算作星原凭空创造的新增需求。”

这番话语，步步紧逼，如同天山折梅手，看似轻描淡写，实则已封死了所有花巧的腾挪空间。许知妍咬紧牙关，指尖因用力而泛白，翻开了那叠带着血腥气味的授权回访记录。那些刀口舔血的汉子们，拿命换来的赏银，每一笔的去向都刺痛着她的眼睛。有人像守财奴一样死死捂在钱庄的户头里，数字冰冷地增长，却未在江湖上激起半点涟漪；有人拿去填了旧日的窟窿，偿还积欠的赌债或是陈年的药费，那是一笔抹平过去的账，而非开启未来的消费；更有甚者，只是冷着一张脸，对回访者拒不透露半个字。

那并非是星原缺了一道严刑拷打的门规，而是这群卖命之徒，在这片虚拟江湖之外，有着他们绝不容许任何山门染指的、红尘俗世里的私生活。

沈婉衡的追问没有停歇，她像一个算无遗策的刺客，在对手心神最乱的刹那，递出了最致命的一剑：“键盘这种东西，随便找个地方就能拉起一条产线，增产不难。但你们的沙盘，难道还能在现实里，凭空造出安身立命的房子？造出续命的汤药？造出那些卡着天下咽喉的玄铁利器？”

许知妍的视线穿过巨大的落地窗，望向窗外真实世界里，起重机正艰难地吊起集装箱，那些沉重的辎重，每移动一寸都耗费着巨大的能量。她颓然地摇了摇头。沙盘棋局之上，无论模拟出怎样花团锦簇、堆积如山的虚拟粮仓，也变不出红尘俗世里，一粒能填饱肚子的活生生的米。

她像个惨败的将军，退回了灯火通明的工坊。机房里服务器的轰鸣声如同不绝的鼓点，敲打着她混乱的思绪。她没有丝毫犹豫，手起刀落，将报告里那句吹嘘“全城”的狂言彻底斩断。只留下那些被铁证焊死的冰冷事实：精确到街道的商品地界、记录到秒的搏杀时辰、经过身份勘验的卖命群体，和验明正身的交割法子。

程砚舟看着那份被修改得面目全非的战报，忧心忡忡：“知妍，这拔了牙的老虎，还怎么去唬住外面的那些金主？”

“唬不住也得认！”许知妍的声音冷硬如铁，“再冠冕堂皇的招牌，也不可能凭空替血淋淋的现实，走完那段根本无人蹚过的死路！”

她毫不留情地删到了最后一刻。原本丰满华丽的战报上，被她亲手剜出了一大块触目惊心的空白。她曾经天真地以为，在十九路棋盘上，只要在星位和小目布下几颗孤零零的落子，就能虚张声势地围成一片无懈可击的庞大外势。可如今，当她亲手拔掉那些自欺欺人的幻想应手，她才彻骨地看清，在那些看似相连的棋子之间，到底还横亘着多少步根本无人敢走的死地。

就在这时，运输玩家赵庆源带来了一次意料之外的自愿回访。他是个寡言的汉子，几个月里，他像一头老黄牛，认真完成了每一次沙盘上的接管任务。从最初基本参与份额五百元，到后来凭借经验获得的专业奖励，他逐渐积攒起一笔不算丰厚、却至关重要的补充收入。

这笔钱，他用来换掉了家里那台运转时发出垂死哀鸣的旧冰箱。

他没有选择星原的赞助品牌。他先用卷尺仔仔细细量过自家厨房预留的尺寸，然后在网上反复比较了不同品牌的能耗与售后服务。

团队里立刻有人兴奋地想将这个案例归入“品牌转化”的功劳簿。许知妍却拿起红笔，将它划到了另一类。

“这个案例，”她对众人说，语气不容置喙，“它只能支持‘收入增加后的一次性自主消费’这个论点，不支持‘哪家键盘的广告投放更有效’。而且，我们还必须区分，这台冰箱是他本来就计划购买，还是因为我们这笔钱才带来的增量。不能只听到一个‘买了’，就把所有功劳都揽到自己身上。”

另一条线索则更为幽微。一个从未领取过任何参与款的匿名用户，只是以一个纯粹看客的身份，旁观了海岬几次惨烈的攻防战。他极为欣赏极轴品牌在危急关头，那种从不打断玩家解释、默默承担责任的安排。不久后，当他自己的键盘寿终正寝时，他毫不犹豫地选择了那个印着极轴商标的盒子。

这是另一条路径，一条关于注意力与情感偏好的隐秘路径。它真实存在，并不因他没有领取一文钱的赏银而消失。

但许知妍清醒地知道，这两条路，也都随时可能中断。关注未必导向购买，所得可以化为储蓄，企业随时可以削减投入，而这边增加的消费，也极有可能只是挤掉了另一处本该发生的支出。这盘棋的变数，远比想象中更多。

韩知衡在视频会议里，用他那惯有的、仿佛置身事外的冷静语调，要求他们：“提前固定下一期的比较基准与停止条件。要让‘失败’这个结果，同样在你们的报告里，有一个堂堂正正的位置。”

在另一间会议室，沈婉衡的手指，又一次翻回了出资那一页，目光落在了罗振业和宋振峰的名字上。

“罗总说，没有星原这项赞助，这笔钱本来会转去另一处广告投放。”她的声音在空气中回响，“而宋总的备选方案，却是将这笔资金留存一半，另一半则按原定安排，向他的出资者进行分配。”

许知妍瞬间感到一股寒意从背脊升起。沈婉衡的目光仿佛穿透了纸张，看到了资金流动的全部脉络。

“这两笔钱，一旦离开它们原本的用途，同样会改变另一些人的所得与购买行为。你们只追着玩家问他们多买了什么，却看不见被你们从棋盘另一端移走的那颗棋子，它原本能做什么。”

这句话，如同一记当头棒喝，彻底击碎了许知妍最后的侥幸。

她回到工坊，脸色冷峻得像个即将行刑的刽子手。她再也不敢用刀客们兜里那点沾着血沫的总赏银，去粉饰太平，去吹嘘整个江湖因此多出了同样多的油水。她先用最无情的笔法，将星原山门内部左手倒右手的门票、过路费和堂口抽成统统斩断、抵销；随后，她将两位金主那笔赞助背后隐藏的机会成本，像剥皮剔骨一样，单独拎出来示众；最后，她才拔出那支最锋利的笔尖，死死挑开这笔流入市场的净银子，追问它究竟是从谁的骨头缝里刮出，又最终落入了谁的钱袋。

报告的末尾，多出了血淋淋的一栏：若这场看似繁花似锦的作秀，挤掉的是一笔原本更能稳住大局、救人于水火的救命投资，那么眼下这一切热闹，甚至可能反咬一口，让现实中真正的营生饿死街头。

那几行字，让罗振业在审阅时如芒在背，却也让他头一次感到一种凛然的心惊。他明白了，这场刀刀见血的盘道，并非只是在算计金主该多掏几两碎银。

“在这片吃人的江湖里，”韩知衡冷冷地为这份报告掷下了结语，“你得给铁打的事实，留一条敢于翻脸说‘不’的退路。”

采访当天，聚光灯打在海岬基地的指挥台上，镜头对准了程砚舟。他沉稳地解释着，星原的架构如何由上层的战略目标，精密地延伸到一支运输队的每一次具体行动。

记者却抛出了一个极具诱导性的问题：“这是否已经证明，每个人只要来玩这个游戏，都能挣到钱？”

程砚舟没有直接回答。他拿出了一张清晰的图表，在镜头前划出了一条明确的界线——一边是“有偿任务窗口”，另一边是“玩家自主游戏”。

“有偿名额，必须先有外部的真实资金与商业合同作为支撑。”他解释道，“这个世界里的每一步，并不会自动产生现实中的现金。”

说完，他做了一个让所有人都感到意外的举动。他将话筒递给了身后阴影里的一个人，那是团队专门请来的一位已经退出的前玩家。

“我让他来回答你的问题。”

那位玩家走到光线下，表情有些不自在，但眼神很坦诚：“我觉得这里值得一试，但它的黄金时段和我现实里的工作冲突了。所以我完成了最后的交接和结算，就离开了。”

这段直白甚至有些“扫兴”的话，最终被原封不动地保留在了报道里。

程砚舟默默地看着那个背影，自己主动退入了更加黯淡的阴影之中。他用这个动作表明了一种态度：一个已经决定拔剑出门的人，本就没义务再回头替旧日山门粉饰太平。而能咬碎牙关，容忍一句扎耳的实话刺在当面，远比花重金请十个相熟的托儿来扯起虎皮唱大戏，更需要常人难及的胆气。

最终放出的那部带血的成片里，并没有把沙盘上的残酷搏杀，强行剪辑成一曲整座城市太平盛世的虚伪赞歌。江湖上的回声，比预想中冷清了许多。但一些真正的底层看客，开始较真地在留言区查问，那些拿命跑镖的草根是否真的拿到了足额的赏银；也有老辣的行家一针见血地指出，那套精密的算法里，可能漏掉了另一场看不见的暗处截杀。

许知妍面不改色地将这些刺耳的战书，一条条收入下一期死斗的卷宗。她绝不再为了保全一时的面子，去替一个千疮百孔的结局，提前砌起一道密不透风的防风墙。

她心里像明镜般清楚，自己与沈婉衡之间那道因理念而产生的裂痕，还远未愈合。

但这片沙盘上，至少这份要向天下公开的投名状，绝不能再用一句轻飘飘的漂亮场面话，去妄图掩盖那一笔依旧散发着血腥味、必须在十九路棋盘上拼死算清的烂账。
