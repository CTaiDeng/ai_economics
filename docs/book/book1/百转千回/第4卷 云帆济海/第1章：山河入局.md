# 第1章：山河入局

八月的风，自城北的钢铁森林穿过，已带上了一丝凛冽的秋意。程砚舟办公室里那张巨大的黑胡桃木长桌，如同一方沉寂的十九路棋盘，桌面的反光里，映着窗外灰蒙蒙的天。

门被推开，陆宏远走了进来，身后没有随从，只提着一个磨损了边角的公文箱。他将箱子放在桌上，发出“嗒”的一声轻响，像一枚落在天元之位的棋子，瞬间锁定了整个房间的气场。他坐下，没有理会那杯冒着热气的茶，开门见山。

“程总，我今天来，不是为了补三年前那通你打给我，而我没有接的电话。”

话音不高，却像一柄淬了冰的锥子，精准地刺向记忆的旧伤。三年前，霁岳山门在一场资本的血洗中轰然倾覆，门徒星散。程砚舟收拾残局，另起炉灶，曾广发英雄帖，其中一封就递到了陆宏远手上。但他如泥牛入海，杳无音信。

如今，他终于来了。不是来投奔，而是来立约。他从公文箱里取出的那份方案，每一页都透着刺骨的清醒与戒备。他要在城北构建的这个庞大沙盘上，单辟一处名为“山城运输”的盘口，所有风险、所有画押的生死契，由他的南离工坊独自扛下。更重要的是，他在契约的末尾，用加粗的黑体字，为自己保留了一条随时可以卷铺盖走人、投奔别处山门的退路。一票否决权的注销，信托处分的豁免，写得清清楚楚。

“那时候，我信不过您的人品。”陆宏远直视着程砚舟，目光里没有半分遮掩，“我不想刚被前任掌门当做弃子扔出门外，转身又瞎着眼，迈进同一批刽子手开的另一扇黑店。”

程砚舟的面色如古井无波。他渊渟岳峙般地端坐着，任由那尖锐的指控在空气中回荡，然后才缓缓开口：“那么现在，你敢把身家性命都押上来，是信了？”

“不，”陆宏远摇头，唇角勾起一抹冷峭的弧度，“现在，有些底牌能掀开来查，有些账目能摆在阳光下验。比如，南离工坊的基本参与份额是五百元起，每一笔进项，都必须有据可查。我们不必再拿命，去赌你们的良心。”

程砚舟默然。他终于将那通石沉大海的旧电话，从自己内心的恩怨簿上彻底抹去。眼前这个人，不是来重归门下的旧部，只是一个同走一段险路的刀客，从未许诺过任何忠诚。

陆宏远将那份厚重的生死契翻到权责最重的一页，冰冷的指尖点在一个条款上，等着程砚舟的印章。那姿态，仿佛在棋盘的劫争处落下致命一子，逼着对手不得不应。

南离工坊申请接入的，是内陆牌桌上一条被遗忘的山路。这条路上，已经有了被摘要算法固化的历史：上个月的洪水冲毁了一段涵洞，驻守的NPC守备队因此将一号仓库紧急迁往了地势更高的B点。区域一旦激活，这些浸透着数据流的历史就必须成为玩家眼前能走、能看、能交互的现场。陆宏远绝不接受为了开场漂亮，凭空捏造一张完美无损的地图。

他带来了详尽的计划：工程队负责修复模拟，侦察兵负责勘探新路，运输单位负责承接NPC留下的烂摊子，甚至还有一支团队专门负责采集当地环境的背景声。他要让参战者的体验与这片土地的“讲述”无缝相接。但他同样明确表示，不会把所有作品的发行权独家授予城北，更不承诺所有观众都会喜欢山路上这种枯燥而缓慢的节奏。

契约的附件里，南离工坊的登记主体、经营范围和独立的银行结算账户信息一应俱全。售票与赞助合同由谁签，报酬与税款由谁承担，全部归于南离名下。支付服务将直接委托给持牌银行或第三方支付机构，城北作为平台方，只能按约收取固定的服务费，绝不能将各路诸侯的资金先行汇入一个总钱包，形成资金池。陆宏远反复核对了三遍，确认平台系统能查阅每一笔收付凭据的哈希值，却绝无权限随意划拨他账上的一分一毫。

林静薇的团队花了整整两天，对这份滴水不漏的方案进行审核。资金流向、授权范围、岗位设置、收益分配和复核机制，每一项都像在拆解桃花岛的奇门遁甲，繁复而精妙。战役指挥权限需要另行考核，组织者不能仅凭一张入场券就控制千军万马。陆宏远亲自参加了线上指挥资格考核，第一次，他因为在下达撤走路障的指令后，未在规定时间内收到下级单位的确认回执，被系统判定为“指挥链路中断”，考核失败。第二次，他补上了所有交接确认的冗余步骤，才取得了限定范围的战场委任。

程砚舟看过南离提交的一段测试样片，一段卡车在深夜泥泞的山路上颠簸前行的影像。他觉得节奏太慢了，缺乏戏剧冲突。他提出了修改意见，陆宏远只是回复了一句“收到”，却没有全盘采纳。

但这并不是拒绝接入的理由。程砚舟在平台接入审核的后台界面，亲手点下了“通过”。出版运营的权限仍在已获批准的产品范围内，至于新增场次可能涉及的现实经营许可，则由责任主体自行核办。这是规矩。

一石激起千层浪。

四海行会嗅到了血腥味，紧随其后，以一种更为狂暴的姿态叩关而来。其魁首庄承裕的胃口大得惊人，他企图在“海岬”与“山城”这两处规则迥异、互不连通的死地同时开辟战线。他不仅想用重金砸下最显眼的推荐位，更异想天开地要求，他从旧平台招募来的那些亡命徒，可以把他们在旧营盘里的兵甲、辎重、等级和历史战绩，一并带入这个新世界。

“痴心妄想。”

顾承安如一柄出鞘的利剑，挡在了庄承裕的野心面前。他的声音比机房里恒温的冷气还要冰冷：“两张牌桌，两段截然不同的杀戮历史，各有其不可逾越的兵力死线。拔剑的活人，可以跳槽过来，接管一个虚位以待的空壳。但那些带血的军火与补给，是那片土地的数据沉淀，绝不可能凭空捏造，更不可能跨沙盘传送。如果未来想在两处死地间打通粮道，可以，请在十九路棋盘上另开一局，用真金白银和人命去一公里一公里地铺设，去一枪一弹地实耗。眼下这盘棋，没有这种手眼通天的捷径。”

庄承裕碰了一鼻子灰，退而求其次。他企图用赏银买下特权，要求在搜索排序和推荐流中，将其他所有中小型门派强行压进暗无天日的末尾。

双方的法务与运营团队在会议室里剑拔弩张地厮杀了一整个下午，烟灰缸里的烟蒂堆成了小山。最终，庄承裕只拿到了明码标价的广告位、轮换展示和独立检索入口的购买权。顾承安守得滴水不漏：钱，可以为你买来江湖上的名声，但在这片沙盘上，绝对买不到一句话就能让旁人灰飞烟灭的霸权。

新秩序的阵痛，最先反噬的，竟是城北的旧部。南离工坊高薪挖走了几个最熟练的战地通信员；四海行会申请的黄金时段，正好与元老岑绍庭的直播计划迎头相撞；海岬那处原本默认留给“原声社”录制节目的公共设施，如今也被排进了公共预约池。

那张密不透风的排期表，像一块被迅速侵占的棋盘，每一个气口，很快都被各路诸侯的刀枪剑戟塞满。程砚舟恍然间想起，这十九路棋盘上，自己用外势围出的宏大模样，终究还只是虚浮的阵势，远远算不得能变现的实地。过去那些习惯了由自己只手遮天、肆意落子的咽喉要道，如今，别路枭雄也有了名正言顺砸下棋子的资格。他必须咬着牙，强迫自己学会，不把这种分庭抗礼的局面，称之为“失地”。

杜启航盯着那张令人窒息的排期表，自嘲地对程砚舟说：“砚舟，这山门开得太张狂，倒把我们自家人挤得无路可走了。”

“只有让外面的群狼也杀得进来，撕得开皮肉，这山门，才算真正开了。”顾承安的声音硬邦邦地顶了回去，不留一丝情面。

程砚舟沉默着。他转过身，在自己的权限后台，亲手撤下了那块一直授予自己团队、打着“开山鼻祖”特权印记的免死金牌。然后，像一个籍籍无名的散人，按照江湖规矩，重新提交排期申请，静静地等待系统分配。

没有人因为这理所应当的退让去赞颂他的胸襟。那个本就无法在阳光下存在的虚伪特权，只是终于从这片残酷而公平的沙盘上，被无声地抹平了而已。

南离工坊首场推演的前夜，陆宏远发来了最后的交接确认函。在山城服务器那片漆黑的虚拟地图上，第一支由真人玩家组成的运输队，从NPC手中接过了记录着剩余油量、货物清单与道路损毁标记的电子终端。紧接着，一束，两束，三束车灯，如星辰般，沿着那条狭窄而危险的盘山路，一点一点地亮了起来。

他们没有回到程砚舟的队伍。

但他们，终究是从同一套可查的边界里，走向了另一条属于自己的路。
