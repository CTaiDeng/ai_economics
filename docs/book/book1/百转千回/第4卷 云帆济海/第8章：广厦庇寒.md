# 第8章：广厦庇寒

九月中旬，秋意已带上了刀锋般的寒气。会议室里恒温的空气，却被严知敏甩在黑胡桃木长桌上的那份文件，砸出了一片冰原。

那不是一份报告，而是一张清单。纸页单薄，上面的铅字却有千钧之重。它没有血，纸面上干净得像雪地，因为它记录的不是沙场上的功勋，而是泥沼里的苟延。它没有战功栏，只有一行行被压缩到极致的条目：吃穿用度、求医问药，每一笔数字都被核算到了骨头里，仿佛再削去一分，人的脊梁就会应声而断。

这张表上，死死钉着二十户草根居民的名字。他们是这座钢铁丛林战争棋盘之外的人，是那些甚至没资格被当作棋子，只能在棋盘的阴影里躲避碾压的蝼蚁。榨干了所有微薄的进项后，这张表冷酷地量化了他们吊住最后一口气，还需要多少粮草与柴米。

“二十户，这是第一批核查清楚的。”严知敏的声音没有温度，像手术刀划过玻璃，“在泥里熬着，连星原这个江湖的门槛都没踏过半步。”

程砚舟的目光扫过那份凄苦的名单，一种熟悉的冲动瞬间涌上喉头。他几乎是本能地张开嘴，想问是否可以招募他们入局，用星原的体系给他们一条出路——

“不。”

严知敏甚至没等他把话说完，便冷冷地摇了摇头，那眼神像两把淬了冰的锥子，直刺程砚舟的肺腑。“先让他们有口吊命的饭吃，有条路能寻到亲人。至于愿不愿意进你们这血雨腥风的江湖，那是活下来，能自己站直了之后的事。”

程砚舟生生收住话头，后背惊出一层细密的冷汗。

就在那一瞬间，他才猛然发觉，不知从何时起，自己已习惯性地将世间所有的苦难，都看作了往山门里拉壮丁的筹码，看作了可以撬动战局的“势”。他在这张十九路的巨盘上殚精竭虑，算计着每一个大场，每一个星位，每一次劫争的转换，却险些忘了，棋道之本，始于人。他恍然记起，多年前在街角那间破旧的棋社里收残局，老板递来的那口滚烫热茶，也照样会分给那些没钱落座、只在旁围观取暖的苦命看客。

自己煞费苦心圈了这么久的杀伐大局，倒险些连棋枰之外，那把供人喘息的残椅，都忘了留下。

那份名单最终没有被迫填入海岬生态的死士名册。

李惠兰大半辈子都在码头上出苦力，一身被湿气和重担压垮的病骨，再也接不住江湖上任何一件脏活累活。社区发放的几文补贴，根本填不平求医问药的窟窿。当她被通知来签领一笔救济款时，那双布满老茧的手抖得几乎握不住笔。她在电子签名板上战战兢兢地按下指印，怯懦地抬起头，浑浊的眼睛里满是惶恐。

“领了……领了这笔钱，是不是……是不是得出去替你们吆喝？还是说，要去给哪家金主的东西……冲销量？”

坐在她对面的管事，声音温和却带着不容置疑的坚定，轻轻将她的手从签名板上扶开。“您什么都不用做。不用替谁卖命，不用去买谁的东西，更不需要去那片修罗场里替谁杀出一条血路。这笔钱，就是让您能喘口气，活下去。”

救命的粮草，已斩钉截铁地砸在了账上。

极轴、凌拓和海港重工，这三大在星原棋局中杀得眼红的诸侯，按照白纸黑字的契约，各自从榨出的血汗钱里，硬生生抠出三万元交了“岁贡”。另外三万元，则从生态的公共基金——那片理论上属于所有人的“公家庄园”的净水中强制划拨。

整整十二万现银，被重兵看守般单独封存在一个独立的信托账户铁柜中。它既不是收买人心的花哨封口费，也绝不允许流入战区那口沸腾着欲望与仇恨的赏金库。因此，那帮在棋盘上挥金如土、手眼通天的金主，甚至连看一眼受助者花名册的资格都没有。

这笔钱的用途，被周慎衡用戒尺一般精准的条款死死框住。

“首期目标，保住查明的二十户，吊命三个月。”他在内部会议上，声音冷得像铁，“每个月的生存缺口，核算为两万五千元。查验和发放的人力成本，三千元。三个月总计八万四千元。账户结余三万六千元，必须死死压在两万元的熔断红线之上。”

账本被他当众展示，每一笔都清晰得如同刻在碑上。哪怕有一毫的变动，都必须通过风控部门的复核，如同过一遍刑堂。

“我把话说清楚，”周慎衡的目光扫过每一个人，“绝不许拿虚无缥缈的未来收益，去掩盖眼下正在流血的窟窿；更不许把同一笔残羹冷炙，无耻地在账上虚报两遍，玩左手倒右手的财技。这笔活命钱，与战区的带血开销，必须死死劈成两半。一旦账户余额触及两万红线，必须立刻停止发放，在大庭广众之下重新筹措粮草。我们绝不拿空头支票，去给第四个月画饼。”

他最后补充的一句，让整个房间的空气都凝固了：“领救济的苦命人，若是遭了任何克扣，大可直接通过社区司法接口击鼓鸣冤。他们不需要先去那个修罗场里，积累一分一毫虚伪的信誉。”

宋振峰推了推眼镜，提出了一个技术层面却无比现实的问题：“我们这样做，会不会……让一些原本打算参与生态的人，因为得到了支持，反而不再急于参加了？我希望真实的参与度是增加的，这个担忧很直接。”

严知敏没有直接回答，而是调出了李惠兰的资料，指着其中一行：“看这里，她的电话，下周停机。一个连联系家人的二十块钱话费都凑不齐的人，就算你把参与窗口的邀请函推到她眼前，她看到的也不是机会，而是另一个她无力支付的账单。你说，她有真实的选择吗？”

她顿了顿，语气稍微放缓：“恢复联络之后，她可能来，也可能因为终于能和家人说上话而感到满足，始终不来。但无论如何，那才是她自己的选择。”

宋振峰沉默了。最终，这个救济计划的条款里，没有加上任何与星原生态报名或参与挂钩的条件。

---

这天下午，社区服务大厅里，呈现出一幕奇异的割裂景象。

大厅左侧，唐梓豪正襟危坐，双眼死死盯着面前的全息沙盘。屏幕上刀光剑影，喊杀震天，他正杀气腾腾地演练着新一轮的“虎符”权限交接流程。刚刚在一次模拟大考中折了面子，他心里正窝着一团火，指尖在虚拟键盘上敲得噼啪作响。

大厅右侧，李惠兰瑟缩在一角的柜台前，在工作人员的指导下，笨拙地学习使用触屏画押，领取这个月的救济粮。她连鼠标都握不稳，指尖在屏幕上划了几次都对不准签名框，急得额头冒汗。

那笨拙的动静，终于搅扰了唐梓豪的“修行”。他烦躁地抬起头，瞥见那妇人畏畏缩缩的模样，一股莫名的优越感混着火气冲上头，带着几分少年人的傲慢，冷冷地刺了一句：

“喂，阿姨，连这个都不会用，以后怎么跟得上全城一统的战役号令？”

话音未落，柜台后的管事抬起头，一道比他沙盘里的刀光更冷的视线射了过来：“这儿是救命的堂口，没人逼她去接你们那套要命的任务。”

唐梓豪猛地愣在当场，脸上瞬间青红交加。那句话像一记无形的耳光，抽得他头皮发麻。他讪讪地站起身，手脚都不知道该往哪儿放，最终还是磨磨蹭蹭地走过去，俯下身，替李惠兰把屏幕上的字号调到最大，又默默地走回自己的座位，将自己那边刀剑相击的音量死死掐灭。

他颓然地靠回椅背，忽然觉得刚才自己脱口而出的那句“规矩”，刻薄得令人作呕。他从小在话本里、在影像里崇拜的那些路见不平、拔刀相助的侠客，也从来不会在施舍几个救命铜板之前，先去拷问对方能不能接得住自己手里那把带血的剑。

屏幕上，那冷酷的军考沙盘依旧在无声地流血，推演着复杂的攻防。但在这一刻，他终于把那江湖上的杀伐，与这人世间的苦难，清清楚楚地劈成了两半。

几天后，许嘉榕陪着一个朋友前来询问。对方的情况同样艰难，却不在首批核查确认的二十户覆盖范围内。工作人员没有用“我们未来会扩展”之类的话术来敷衍，而是坦诚地解释了现有资金和人力的限制，然后耐心地帮她查找了其他几个可用的社会救助渠道，最后将她的需求和联系方式郑重地留在待办记录里。

二十户不是整座城市，一个试点也不能靠一句空洞的善意，就自称无所遗漏。

月底，李惠兰收到了十月生活费用的支付到账通知。她做的第一件事，就是去营业厅给停机许久的手机充满了五十元话费，然后拨通了那个很久未曾联系的亲人的号码。电话接通的那一刻，她苍老的脸上，泪水纵横。

唐梓豪在同一天，通过了新的“限定副席”考核。这意味着他将承担更复杂的职责，去争取那份数额高达七千元的差异池收益。

那张没有战功栏的表格，依旧安静地躺在社区的册子里。它没有削减唐梓豪为前途奋力拼杀的半分价值，也从不要求李惠兰先去证明，自己能在他那张浴血的功勋表上，排到第几。
