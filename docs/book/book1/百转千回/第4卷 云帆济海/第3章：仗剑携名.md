# 第3章：仗剑携名

四海行会那间永远弥漫着二手烟与制冷剂味道的办公室里，邱庭舟的目光像两把淬过火的锥子，死死钉在全息光幕上。他的工兵履历，那份用命换来的卷宗，如今只剩下一个冰冷而空洞的团体名称。

光幕上，淡蓝色的数据流无声淌过，将他过往的血与火冲刷得一干二净。他曾冒死在三个火力窗口里抢修过逃生通道，那是在炮火将钢梁融化成铁水的绝境中，为袍泽们撬开的一线生机。其中两期的卖命钱，早已化作他身上几道狰狞的伤疤和银行账户里一串冰冷的数字；但第三期的赏银，至今还悬在账上，像一滴凝固的血。

旧日的宗卷里，每一个字都曾是他亲手刻下：岗位、接管的死线时辰、行动的每一个细节，甚至连每一次负伤的医疗评价，都清晰如昨。可如今，这张被篡改过的新页上，所有细节都被抹去，只剩一句轻飘飘的“行会工程支援”。属于他邱庭舟个人的名刺，他用命搏来的名号，被彻底封死。

行会的管事庄承裕，正隔着一张黑胡桃木长桌，用指甲慢条斯理地剔着烟丝，仿佛在欣赏一件与己无关的艺术品。他甚至没有抬头，声音里透着一股居高临下的傲慢：“队伍既然散了，就休想把行会养出的荣誉私自带走。这盘棋是我们四海行会布的局，你不过是其中一颗棋子。棋子离了盘，还谈什么星位和目数？”

邱庭舟冷着脸，没有去争辩那辆沾过他血、至今仍停在机库里的工程战车。那东西是死的，是行会的资产。但他要讨回的，是活的，是他自己的魂。他要的，是那些能证明每一次断桥、每一条绝路是由他邱庭舟亲手续上的铁证，以及，那一笔带血的尾款，究竟该由谁来结清。

“前两回的赏银都已经喂给你了，还差这几个虚名的字？”庄承裕终于抬起眼，嘴角勾起一抹淬了冰的弧度，像是欣赏着一只笼中困兽的徒劳挣扎。

“给了卖命钱，也绝不能把老子流血做过的事，抹杀成没做过。”

邱庭舟的声音没有拔高半寸，却像一块沉铁砸在桌面上。他将一份用防水密封袋装着的原始战报“啪”地一声拍在桌上，那牛皮纸的边缘早已被汗水和血渍浸得发黑发硬。他来讨的，不是一块从库房里强分走的虚伪金字招牌，也不是要争什么山头字号。他的手艺曾在哪座生死桥上试过剑，那剑痕就应当能跟着他堂堂正正地走入江湖，绝不能被这般无耻地扣在山门之内，连名字都被改了姓。这不啻于废掉一个剑客的武功，再将他的佩剑熔掉，铸成自家的门匾。

僵持间，门被推开。顾承安走了进来，他像一把出鞘的古剑，带着法庭般的冰冷与森然。他没有理会庄承裕的眼色，径直走到光幕前，手指在虚拟键盘上疾点，调出了后台的追加记录。

“原始接管虎符，序列号7B-4A，邱庭舟签收，无误。旧功劳簿，三笔高危任务记录，归档完整，无误。”顾承安的声音没有一丝波澜，像是在宣读判决，“被暗下毒手抹掉的，只是新页面通向真相的超级链接路径。釜底抽薪，做得倒也干净。”

他冷眼看着庄承裕：“行会固然有权重修门面，整理这盘大棋的棋谱，却绝不容许仗着重修山门，卑劣地抹去当年替你们挡过刀的人。江湖规矩，欠债还钱，欠名还名。”

复核并未蛮横地要求行会掀开整张绝密的工兵阵图。毕竟，那些邱庭舟曾经浴血奋战过的设施，至今仍是这盘残酷战局中的“大龙”，它们的生死罩门，对别路诸侯和死敌都有着生死的保密红线。邱庭舟也从未想过做那种弃子构陷的龌龊事。他只需带着被铁印重新验证过的个人战功录全身而退，在改投明主时，能让对方堂堂正正地查验他剑上的每一道豁口与血痕即可。他根本不必为了证明自己的手腕，去强行拓印整张前任掌门的私有沙盘。

“第三期悬在账上的赏银，照旧按白纸黑字的死线结清。”顾承安的目光转向财务终端，“拔剑出门，不是克扣粮草的借口。”

在顾承安的注视下，庄承裕面色铁青，却只能眼睁睁看着技术员恢复了邱庭舟名刺的署名，并将那道无耻的“离会即失效”的霸王门规吞回肚里。资本当然可以为了将来的卖命，抛出更重的赏金来“做势”；却休想用“化功大法”，将过去早已结清的血汗钱，强行篡改成捆绑自由的忠诚狗粮。

---

离开四海行会，邱庭舟到了南离。这里是山城，空气里都带着一股湿漉漉的、属于岩石与钢铁的凛冽。他又遇到另一道门，一道更难的门。

凭借在四海行会那段带血的临时工程指挥经历，他希望直接取得山城工程总席的位子。陆宏远，南离的当家人，亲自接待了他。这位中年人身上有种渊渟岳峙的气度，像个弈棋多年的国手。他认可邱庭舟那段记录的含金量，却没有立刻应允。

他只是领着邱庭舟走到一幅巨大的沙盘前，上面是南离错综复杂的地理模型。“邱先生，请看这里的涵洞、警戒洪水线，以及最重要的，我们的战时运输任务。”陆宏远的手指在沙盘上划过，留下一道虚拟的光痕，“您过往的经验，是您坐在这张桌前的资格依据。但本次任命，我们仍要确认您的能力与我们的棋路是否相合，以及我们能给您的授权边界。”

“那带过来有什么用？”邱庭舟的声音里压着一丝傲气。他像一个携带着屠龙绝技的武者，却被要求先去劈柴挑水。

“用处很大。”陆宏远温和但坚定地回答，“它让我们知道，您不是一个空谈阔论之辈，您见过血。它也让您那些旧日的功劳簿仍有凭有据，不会因为换了山头就作废。但我们同样不能让另一张桌子，为我们这里的战功凭空再给您一次钱，或者，把这里已经有人负责的‘大场’，直接送给您占了。”

邱庭舟沉默了半晌，山城的风从窗缝里灌进来，带着刺骨的寒意。他最终咽下了那口傲气，像是弈者在布局阶段，为了争得先手，不得不忍痛弃掉一颗无关大局的棋子。他选择先屈尊接下那处受限的工程末席。

第一场接管，是在暴雨将至的悬崖上加固一座临时便桥。他那双老辣的眼，几乎在瞬间就死死盯出了桥身悬臂梁的结构罩门，那是一处致命的“断点”，必须立刻补强。然而，他致命地低估了山路运送辎重的泥泞与漫长。他只算了桥身的薄弱，那是棋盘上一个局部的“劫争”，却没算准运送加固材料一路的生死距离——那是关乎全局的“厚味”与“实地”的转换。

当预定的加固钢缆因为塌方而迟迟未到，湍急的洪水已经开始舔舐桥墩时，邱庭舟的额头渗出了冷汗。是他的副手，一个本地出身的年轻人，在悬崖边及时扯住了他的袖子，嘶吼着提出了一个用本地绞索和岩钉的替代方案。两人惊险地变阵，带着工程队在洪峰抵达前的最后一刻，堪堪打通了活路。

那一夜，他带来的一身硬功夫确实见了血，但在这新盘口上暴露出的致命破绽，也像刀子一样，一笔不落地刻进了他在南离的第一份履历里。

回到营地，邱庭舟在案头的材料边，用笔死死记下副手那句救命的提点。他原先那手“断点补强”的一招，气口根本没看错，错就错在他只看到了棋盘的十九路，却没看到棋盘之外的天时地利。当棋形彻底换了骨血，曾经最引以为傲的夺命一手，也必须在悬崖边重新称量分量。

---

陈驰在后台接收这份履历材料时，一个四海行会过来的老熟人发来私信，请他把邱庭舟的申请往前排一排，给个方便。

他看了一眼那份惊心动魄的便桥加固报告，然后平静地回复：“抱歉，不行。”

登记者掌握的材料提交顺序、信息的完整性和后台的可见范围，本身就是机会的一部分。他不能一边声称评价体系是独立的，一边却私下开后门，让某些人的材料永远到不了评审的面前。这盘棋的规矩，必须对所有棋手一视同仁。

夜间结算时，邱庭舟坐在自己的终端前，再次检查个人名下的行动记录。他设定了查阅权限，可以让新东家查见他在四海行会的旧日荣誉，却没有将原来的单位经验粗暴地打包移植到南离的履历上。那辆已经多处损伤的工程车，它的资产归属也仍属于原来的战区。

履历、装备、任命、所得，四条线，各自沿着自己的因果关系清晰地延续着，互不纠缠，却又彼此印证。

数月后，方婉音在内网的知识库里，偶然听到了邱庭舟为新晋工程队录的一段技术讲解。他的声音沙哑而沉稳，像被山风打磨过的岩石。

他说：“……修桥的人离开后，桥可以继续由别人用，但技术档案上，应该还能看见是谁，在哪一天，用什么方法，接上了那一截。这不是为了邀功，是为了让后来人知道，这一手棋是怎么下的，万一将来出了问题，他们才知道该从哪里复盘。”

方婉音心中一动，把讲解音频的来源点开，顺着数据索引一路回溯，最终，她找到了那份来自四海行会的、被恢复了署名的原始战功记录。

那条路，那座桥，那个名字，没有因为人换了一扇门，就被从江湖的地图上彻底擦去。剑已出鞘，名亦随行。
