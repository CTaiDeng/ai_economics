# 第5章：雁阵惊寒

三天之后，周五下午四点，霁岳大厦三十四层的走廊比往常更加空旷。

一百七十九份签了字的解除劳动合同协议书，整整齐齐地码在人力资源部的保险柜里。还有七份死死压在长桌一角，那七名资深员工拒绝接受任何形式的调解，已经正式向市劳动人事争议仲裁委员会递交了立案申请。

程砚舟坐在办公桌前，电脑屏幕上是人力资源管理系统导出的离职生效名单。

鼠标滑过，每一个名字被点亮，又被关掉。没有哪个名字会因为他多看两眼而起死回生。

下午五点，信息安全和系统运维负责人顾承安敲响了门。三十三岁的顾承安，曾在江岑大学学习公共政策，毕业后长期从事系统工程，拥有信息安全与运维的丰富经验。此刻，他戴着一副黑框眼镜，眼底布满了血丝，手中紧攥着一份打印出来的系统权限注销执行单。

“程总，按照人力资源部的交接节点，下午五点半，这批员工的企业微信、域账号、VPN远程访问权限以及内部代码仓库权限，必须准时批量回收。其中有四个人的分支PR还挂着上个月的记录，另外还有两个人的公会管理员特权在晨港那边还没有转移……”，顾承安的声音有些发紧。

“照章执行！别让他们在代码库里留下不合规的提交记录，法务部门正在盯着。”程砚舟的声音毫无波澜。

顾承安的嘴唇微微翕动，似乎想说什么，但最终只是重重地叹气到：“程总，陈驰他们私人账号在晨港旧城区还有两座自建屋，那是去年测试期他们通宵一个月亲手搭的……，社区那边问，要不要连带他们的游戏资产一起封存？”

程砚舟猛地抬起头问道：“资产是他们在游戏里自己建的，凭什么封存？谁下的指令？”

“机构董事委派的运营副总监。对方说，被裁员工带着对公司的负面情绪，留在高阶社区容易煽动群体对立，甚至引发服内抗议，建议作为‘潜在不稳定因素’做静默降权与资产没收处理。”顾承安低声道。

“荒唐！”程砚舟一掌拍在桌上，震得咖啡杯嗡嗡作响，“那是玩家的合法财产！在晨港里，他们不是霁岳的员工，是拓荒者，是居民！通知社区运营，谁敢动他们的一间瓦房，我就停了他的权限！”

顾承安指了指屏幕，苦笑着说：“程总，但现在他们只要拿走了后台的权限，我们连自己留下的旧账都看不见了。谁做了什么，欠了谁的，到时候还不是留下来的人自己去解释。”

程砚舟盯着那些名字，忽然想起了那些空荡的工位。人走了，记录也要跟着消散，仿佛他们从未曾在这里熬过不眠之夜。他们需要的筹码，不能只藏在老板的抽屉里；账目必须让参与者每人留档一份，一旦起了争议，还需要有地方能把原始证据摆出来，让双方能摊开来对话。否则，所谓的公平，不过是主人心情好时，对客人随口许下的一个空头承诺。

五点半一到，系统的自动流程准时启动。三十四层研发区内，数十台显示器上的终端连接如同潮水般同时中断。原本显示着流畅“编译成功”的绿色光标，瞬间骤变为刺眼的红色，错误提示如同瀑布般接连弹出，显示“权限不足：密钥无效”。那是一场无声的缴械。在数字的江湖里，剥夺一个工匠的利器，甚至不需要走近他，仅仅一道指令，就能让多年心血付诸东流，化为乌有。

顾承安站在机房入口，看着那些熄灭的屏幕，眼底尽是难以掩饰的鄙夷——这种死守着中心化权威，靠着剥夺参与者的权利来维持体面的做法，与武侠世界里那些虚伪做作的正派高手，根本没有两样。

程砚舟走出办公室，来到三十四层。放眼望去，成排成排的工位已经空了出来。桌上散落着没带走的便签纸、枯萎的小多肉植物、喝空的速溶咖啡罐，还有几张写满架构演算草图的白板，擦得斑斑驳驳。几个小时前，这里还是激烈讨论并发锁和渲染管线的工场，现在却安静得像一座数字荒冢。

在拐角处，二十五岁的独立音效师方婉音正蹲在地上，默默把她带来的几只专业拾音器和防震架装进巨大的黑色器材包。

她是外包合同工，连N+2的遣散待遇都没有，只有一张结算单。大厂上了最新的音频生成工具，输入几句文字提示词，十秒钟就能生成一段风雨声与金属碰撞音，精度虽糙，但胜在成本几乎为零。

“方婉音。”程砚舟停下脚步。

方婉音背起沉重的器材包，回身看着程砚舟说到：“程总，机器用十秒做出来的声音，没必要叫我再熬一夜去重做。”

她抬手按住器材包侧面，里面装着她多年录制的母带。接着说道：“可这些声音如何被选中，配上什么样的故事，最后又让谁愿意停下来细听，就是另一回事了。我的授权和结算还没有说清楚，不能跟着工牌一起注销。”

她侧身让开走廊另一端拖动的纸箱，才继续说道：“街上的音像店、乐器行接连关门，大家都在等下一份活。我也在等。但往后总不能只剩下跟机器比谁更省钱这一条出路。”

程砚舟看着她，一时没有接上话。

她背着包，踩着空旷走廊的地胶，一步一步走进了下行的电梯。

电梯门合上的刹那，财务总监周慎衡快步走了过来。他手里拿着最新的清算账目表，五指如天龙寺一阳指般死死捏着报表边缘，骨节发白，脸色阴沉如水：“砚舟，第一批补偿金实际打款一千八百二十万元，本季度的研发预算缺口勉强被填平。但是——”

“但是什么？”程砚舟追问道。

“机构董事刚才发起紧急动议，下周二下午召开临时董事会，议题是：第二轮组织架构精简，以及启动晨港项目的海外全权独家商业化授权招募。”

周慎衡把文件递过来，声音里带着刺骨的寒意，叹道：“这帮人练的是星宿派的化功大法！抽干了一百八十六个底层弟子的血肉还不够，他们现在盯上的，是晨港这只还能生金蛋的本命母鸡！他们要连皮带骨，把它彻底拆碎卖给那帮野蛮人！”
