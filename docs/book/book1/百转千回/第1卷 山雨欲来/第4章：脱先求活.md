# 第4章：脱先求活

第三天清晨，薄雾尚未散尽。城西那栋建于上世纪九十年代的高干家属楼前，两株老槐树垂着光秃秃的枯枝。

程砚舟和许知妍穿过略显昏暗的门厅，走上四楼。防盗门虚掩着，里面飘出一股陈年普洱与旧书纸张混合的干燥香气。

客厅朝南，冬日的朝阳透过没有擦拭干净的双层玻璃，斜切在靠窗的一张圆木桌上。桌上摆着一副古旧厚重的榧木十九路围棋盘，棋罐由黑檀木车制而成，盖子掀开着，棋盘上零散落着几十颗云子，黑白纠缠，正是一盘尚未解开的中盘残局。

七十一岁的贺敬山坐在圈椅里，穿着一件洗得褪色的藏青色夹克衫，戴着老花镜，正在看一份宏观战略与产业研究院的内部季刊。

他曾是省技术创新引导基金与产业规划的掌舵人，也是当年霁岳科技在高校孵化器破土时，最早给予政策引导与宏观战略视野的引路人。退休七年，他不问政事，不见闲客，唯独程砚舟和许知妍每逢关乎生死的关口，总会心照不宣地来到这里。

“敲钟上市的时候，送来的喜糖我尝了一颗，太甜，齁嗓子。”贺敬山没抬头，翻过一页刊物，声音带着老烟枪特有的粗粝，“今天大清早两手空空跑来，眼眶青黑，满身烟味——怎么，山门守不住了，当了刽子手，心里过不去，来我这儿讨安魂药？”

程砚舟在桌对面的方凳上坐下，双手搭在膝头，背脊僵硬如生铁：“贺老，第一批一百八十六个人，昨天谈了一整天，签了一百三十五个。”

“剩下五十一个呢？”

“有的还在僵持，有的要申请劳动仲裁。”许知妍在侧面坐下，声音透着彻骨的疲惫，“法务和人力的意思是，依法应诉，按最高赔偿标准打到底，绝不妥协让步，免得在行业里坏了合规的口径。”

“好一个合规的口径。”贺敬山冷哼了一声，把老花镜摘下，重重扔在棋盘旁，“下令开除弟子的是你们，算尽机关逼人画押的也是你们。大厂的刀，比绿林悍匪的刀快得多，不见血，不留痕，还能让法务洗得干干净净。”

程砚舟垂下头，看着榧木盘上的纠缠黑白，指尖微微泛白。

“棋盘上的这颗黑子，”贺敬山指了指中腹被白棋重重合围的一块死活不明的孤子，“你若是执黑，此时作何抉择？”

程砚舟审视片刻，低声道：“我会考虑弃掉外围的三子，先去边角争实地。白棋如果来提，再借外势压它的边路。”

“这就是你们在三十六层做出的决定？”贺敬山语气平静，却如同一柄沉重的玄铁重锤，狠狠砸在程砚舟胸口，“你们以为自己是坐在棋盘边的弈者？放屁！在那些嗜血的并购基金和跨国资本眼里，你们两个，跟昨天被你们赶出大门的陈驰，没有任何本质区别！”

老人站起身，走到窗前，指向窗外冷清萧瑟的城市街景：“你们只看着霁岳裁了一百八十六个人。你们抬头看看这全省、全国的宏观报表！AI把生产效率拉得极高，算力几乎不眠不休，可荒谬的是写字楼却在裁员！白领却面临失业、工匠却被AI替代，工薪阶层手里的钱少了。虽然商品越来越便宜、产能极其过剩，可街边的铺子却在快速易手，老百姓变得不敢花钱！这是什么？这是通缩！你们一家大厂裁员算账保净利润，如果千千万万家大厂跟着也裁，那么最后谁来买你们的游戏？谁来买实体工厂的产品？宏观大循环一旦陷入通缩，社会大环境就会低迷，你们那点期权和分红，会贬的废纸不如！”

许知妍神色微变，指尖微蜷：“贺老，霁岳的管理权还在我们手里，董事会虽然有九席，但我和砚舟有一票否决权……”

“一票否决权？”贺敬山嘴角泛起一丝冷峻的嘲讽，“知妍，你也是名校经济学出身，资本借壳入局的三步定式，你难道看不懂？先借着上市稀释创始团队的绝对表决权；再用对赌协议与季度财报指标逼迫你们自断羽翼、裁撤核心研发；等到团队离心离德、底层架构停滞，他们就会借着做空报告与独立调查委员会，以‘重大经营决策失误’为由，顺理成章把你们扫地出门！”

老人走回桌边，枯瘦的指节重重叩击在榧木棋盘上，笃笃作响：“武侠书里那些名门大派，少林武当的掌门人，看似威风凛凛、执掌号令，其实身上绑满了门规、戒律与朝廷的暗索！遇到风吹草动，第一件事就是将最具反骨、最敢破局的弟子当成妖邪逐出门去，给武林盟奉上血淋淋的投名状！可交了投名状的名门，最后哪一个没被拆骨毁寺？”

程砚舟的手指深扣进木凳边缘，深吸了一口气，语气带着被时代逼至绝境的苍凉与困惑：“贺老，如果活儿都被机器干完了，那人……以后究竟凭什么领钱？”

贺敬山没有立刻回答。他从凌乱的旧书堆下抽出一本泛黄起毛的古旧棋谱，指尖抚平卷起的折角，将它推到两人面前：“这盘棋，你还记得？”

程砚舟低头翻开。那是八十年代某届国际围棋擂台赛的决胜名局，胜负早已封存在历史尘埃里，但他指尖抚过那些手抄的落子序数时，仍能感到当年围棋大师孤身对决超一流九段时、近乎凝固生死的呼吸。

“交给机器，这些变化半秒钟就能穷尽。”贺敬山指着边沿密密麻麻的朱红批注，“可普天下的弈者想看的，仅仅是一道冷冰冰的正确答案吗？”

程砚舟怔住了，手指停留在泛黄的脆纸上。那些年，人们为谁的胜负彻夜欢呼，为谁的误算扼腕长叹，哪怕隔了近四十年，纸页间激荡的人性执念与血肉温度，依然扑面而来。

“人们想看的，是另一个人怎么赢，怎么输。”许知妍轻声打破了沉默。

老人微微颔首，目光深邃如潭：“还有陪他们下棋的人，讲得明白的人，把一场比赛张罗起来的人。十九道横竖经纬，自己长不出这些血肉。是规则一代代传下来，人们的悲喜、本事与血汗，才在上面留下了不可磨灭的分量。”

“那钱呢？”许知妍追问，眼神锐利如刀锋，“大众肯看、肯共情，但距离真金白银的流通，还隔着一层资本筑起的厚墙。”

贺敬山将棋谱翻到封底，指着两家并排印着的赞助老字号：“设想两家制造厂卖的是同一规格的棋钟，材质、机芯、走时分秒不差，造一只的工本一样，印了不同的招牌，卖同一个价。它们为什么争着出钱赞助棋赛？”

许知妍放下茶杯，眸光微动：“我记得幼时父亲带我看哪场决赛，也记得场边悬挂着哪家的钟牌。日后再去百货柜台买棋具，两件东西即便一模一样，我也绝不会随手挑选。”

“这就叫人心偏好，这就叫真实价值。”贺敬山翻过一页，“办赛的人有本事，搭好台子，讲清门道，让看客听懂转折、记住了牌子，企业才肯拿出真金白银买单。可过去在大厂平台眼里，这笔钱全被吸进了垄断资本的黑箱，平民和玩家只是财报上任人宰割的活跃数字！”

“那就把这笔账，从头重开。”老人的声音骤然低沉而坚决，“赞助资金来自实体需求，成本有着落。谁凭真本事把棋下得惊心动魄，谁手把手把后生领进山门，谁把精微的棋道拆解得通俗透亮，事先立下透明契约，事后就按真凭实据分润！”

“下得好、讲得好、贡献真实的，理应多得；空耗时长、制造垃圾的，一文不取。而你们这些设计规则、构筑场域、分担风险的架构师，自然也享有该得的那一份‘设计红利’——不能一句空泛的天下为公，就抹了开山者的心血。”

“拿到分润的人，手里有了活钱，才能去买柴米油盐。”许知妍顺着老人的推演，呼吸微微急促，“企业获得了真实的品牌偏好，劳动者获得了活命的购买力；买卖一旦接通，通缩的坚冰才会被撕开一条缝隙！”

她抬手将茶杯移开，在光秃秃的木桌上让出了一块空地，仿佛原本纠缠死结的天下棋势，终于在此刻被理出了水落石出的通路。

“可万一有人棋艺平庸、干不得重活，一时分不到多少呢？”程砚舟忍不住追问。

“所以，绝不能把一个活人的立锥饭碗，全押在一时的输赢胜负上！”贺敬山目光如炬，直视着程砚舟的眼睛，“最底层的生存底线与进门通道，必须有另外可靠的制度托底；进了门槛之后，才各凭本事共享参与红利。你们要想破局，就得先在人间办一场干干净净的试验——看看钱是不是真能流进普通人的口袋，看看失业的人是不是真能挺直脊梁站起来！”

“记住：别以为赶跑了旧庄家，自己就能坐上龙椅替天下人派活、定价、定生死！那不是新路，那是换个法子当恶霸！”

话音未落，老人枯瘦的食指与中指倏然探入棋罐，夹起一颗乌黑温润的云子，啪的一声脆响，没有落在那团死活纠缠的泥潭，而是径直点在了中腹之外的一片辽阔虚空！

落子声不大，却如一道惊雷，震得程砚舟浑身一颤，霍然抬头。

“脱先求活。”

贺敬山缓缓收回手，神情沉静如深山古刹：“大厦将倾，你们还守在那间三十六层的玻璃笼子里互撕，不过是坐以待毙。跳出旧谱，天元自辟——在别人算尽的死局之外落下一子，才是生机所在。”

日光终于穿透了双层玻璃的斑驳尘埃，化作一道明亮澄澈的光柱，斜斜照亮了那颗孤悬在荒原中央的黑色云子，将四壁略显昏暗的客厅映得一片清朗。

虚室生白，吉祥止止。

那一处广袤的空白，并没有因为一颗孤子的落下就立刻化作活地，后手尚有千难万险、万重棋劫；但程砚舟死扣在木凳上的五指，终于一寸一寸松开了。

他站起身，迎着那道晨光，朝着眼前的老人，郑重地长揖到底。
