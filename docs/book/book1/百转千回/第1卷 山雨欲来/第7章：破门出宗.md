# 第7章：破门出宗

纸终究包不住火。

不到四十八小时，裁员三百人、晨港即将被那帮野蛮人吞并的消息，像一场瘟疫，迅速在霁岳这座大楼里蔓延开来。平日里，原本通宵达旦的研发区，此刻彻底死寂了。没人再去盯着实时监控大屏上跳动的并发曲线，也没人争论图形管线该如何更完美。连代码库的提交记录里，都充斥着带着黑色幽默的告别注释：“修复：执行前的最后一次提交”；“功能：向晨港说再见”。

周四深夜，大雨倾盆。

雨水狠狠砸在三十六层的落地窗上，水痕蜿蜒如泪。

“咚、咚。”敲门声打破了死寂。走进来的是核心架构师林静薇和底层网络负责人杜启航。林静薇，三十岁，拥有计算机和法律的双专业背景，自从入职以来，她便长期深耕于系统研发领域，并逐渐肩负起了核心架构的职责；她对于权责边界的认知，近乎于一种执念的坚守。她素面朝天，怀里抱着一个牛皮纸箱；杜启航眼圈发黑，身上的格子衬衫也沾满了褶皱。

“砚舟，知妍，不用等到下周五董事会动手了。”林静薇将纸箱放在茶几上，里面装着她的机械键盘、两本翻得起了毛边的分布式系统论文集，以及一枚霁岳成立两周年时颁发的创世员工铜质纪念章。那枚纪念章，已经陪伴了她六年。

“静薇……”许知妍起身，眼眶泛着水光。

“我们不等他们来裁，我们自己走。我和启航今天下午把所有技术交割文档都写完了。足足一百四十八页，就算是一个刚毕业的实习生，拿着这些文档也能把整个服务重新拉起来。我们对得起这份技术，对得起晨港，唯独对不起的，是把这把利剑交到了一帮商人手里。”林静薇的神情异常平静，但那双清澈的眼眸深处，却透着一股不容置疑的决绝。

杜启航也从怀里掏出工牌，啪的一声按在桌上：“程总，当年你说，代码是有灵魂的，技术应当让每一个人挺直脊梁。我们信了！我们通宵两年敲出来的每一行并发逻辑，如今却成了他们拿去资本市场质押套现、反向清退工程师的绞索。留在这座大楼里，每天看着自己的心血被当成吸金工具，甚至要去迎合那些剥夺玩家资产的下三滥勾当，不如早点拔剑割席！”

程砚舟的目光依次掠过林静薇、杜启航，最后停留在身旁的许知妍身上。周慎衡和顾承安也随之推门而入，并一同站在桌边。八年前，正是他们六个人一起创立了霁岳。从最初并肩熬过的长夜，到上市敲钟时的意气风发，他们曾坚信，只要能将手中的事业做至精妙，攀登到足够的高度，便能为更多人开辟一片安身立命的净土。然而，如今他们站立的，本该是荣耀的巅峰，却成了斩杀同袍的断头台。程砚舟的视线一一扫过每一张熟悉的面孔。没有人率先催促，六人只是沉默地伫立着，等待着那句本该早已说出口的决断之言。

“贺老说得对。在资本的旧棋盘里，我们永远只是一颗被算计的子。只要我们还恋栈这三十六层的沙发、红酒和虚浮的创始人头衔，我们就只能任由他们借我们的手，去斩杀我们的同袍。”程砚舟缓缓站起身，声音在昏暗的办公室里回荡，带着一种如释重负的苍凉与旷达。

许知妍抬起头，看着程砚舟：“砚舟，你想好了？”

“想好了。”程砚舟拉开抽屉，取出一张白纸，拿起万宝龙钢笔，手腕沉稳如山，在纸上笔走龙蛇写下四个大字：

辞职报告。

放弃全部未归属期权，辞去总裁与执行董事职务，自愿放弃竞业禁止补偿金，申请即刻解除劳动合同！

许知妍看着那张纸，眼底最后一丝犹疑彻底褪去。她从大衣口袋里掏出自己的金笔，在程砚舟的名字旁，同样利落决绝地签下了自己的名字：

“算我一个。”

周慎衡笑了，笑得眼泪都流了出来，他也抽出笔：“做假账和看他们卖儿卖女的事，老子早就受够了！算我一个！”

顾承安二话不说，将自己的工牌摘下，拍在桌上：“算我一个。”

六个人，六枚工牌，排成一列。

在武侠的道统里，这叫“破门出宗”。

脱下名门正派华丽的道袍，折断门派赐予的虚浮宝剑。杜启航如刚猛沙弥怒碎戒刀，林静薇宛如峨眉剑侠割袍断义，周慎衡如天龙寺俗家弟子拂袖脱尘，顾承安不羁如逍遥慕容散尽虚华，许知妍如桃花岛门人孤高超然，而程砚舟则如当年张三丰离开少林别开天地——将虚名、期权与不洁俸禄全数奉还，从此下山入世，不问庙堂高远，只求心中一口未凉的人间正道！

午夜十二点，大雨没有停。

六个人昂首挺胸，穿过空无一人的三十六层走廊，乘着客梯直达一楼大厅。

保安认出了他们，惊讶地站直身子想行礼，但看着六人平静从容的面容与未佩戴工牌的前襟，他只是张了张嘴，最终默默替他们推开了沉重的玻璃旋转门。

刺骨的寒风夹着冰冷的雨丝迎面扑来。

三十六层大厦的霓虹在雨雾中模糊成一片惨淡的血色。

程砚舟没有回头。他深吸了一口潮湿冰冷的夜空空气，转过身，看着并肩而立的战友们，沉稳而有力地说道：

“走！去城北！既然旧山门已经腐朽，我们就去建立一个规则透明、天下参与者共享红利的新天地！”
