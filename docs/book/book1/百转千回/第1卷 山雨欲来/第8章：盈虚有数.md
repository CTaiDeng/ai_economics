# 第8章：盈虚有数

走出三十六层大厦的那一夜，风雨如晦，每个人胸膛里都滚烫得像揣着一团烈火。

但真正的严峻考验，绝非一时意气用事的决裂，而是摆在眼前的时代现实。

辞职第十四天，清晨七点半。

城南别墅的餐厅里，阳光透过百叶窗，洒在一张白橡木长桌上。程砚舟坐在桌前，面前摊着几份关于全省宏观经济运行指标的产业简报，以及团队新项目的启动预算梳理表。

主动离职意味着放弃了未归属的期权，但凭程砚舟和沈婉衡的家庭积淀与合法积蓄，随手拿出几百甚至上千万的现金来支撑团队在相当长的时间内从容研发，并非难事。家庭生活更无需为几斗米折腰，保姆在厨房里热着有机燕麦奶，女儿小溪的笑声从楼上隐隐传来。

然而，摆在程砚舟眼前的，却是一份沉重得令人窒息的社会大账本。

简报上的曲线触目惊心：全省第三产业新增就业人数同比暴跌四成，写字楼空置率突破新高，居民边际消费倾向跌入冰点。AI与高度自动化的算力，已经像瀑布泻地般接管了基础研发、设计、财税与法务工作；生产端极其过剩，商品价格一跌再跌，然而大众却因失去劳动收入而紧捂钱包。整个社会正滑向的通缩的螺旋。

楼梯上传来轻微的脚步声。沈婉衡穿着一身居家的米白色针织衫走下楼来。

她在程砚舟对面坐下，端起温热的红茶，目光掠过丈夫手边那份宏观简报，语气清冷而平静：“昨天沈氏产业基金的例会上，投决会刚通过了一项全面收缩制造业与文娱投资的决议。下游订单萎缩，全产业链都在回笼资金，持币观望。”

她看着程砚舟，眼神如同天山折梅手般剔透而深邃：“砚舟，以沈家的底蕴和你手头的个人储备，即便再大的风暴，也保得住我们这间屋子的体面，保得住小溪衣食无忧。你仅辞职半个月，整夜整夜在书房里推演模型，你到底在怕什么？”

程砚舟抬起头，迎着妻子的目光，声音低沉而沙哑：“婉衡，我怕的是‘坐吃山空’。”

沈婉衡微微挑了挑眉。

“我说的不是我们这个小家的账本，而是整个社会的生机。”程砚舟走到落地窗前，指向远处灰蒙蒙的天际线，“资本以为只要掌握了最先进的AI、把所有人工成本压到零，就能躺在资产上千秋万代。可这是最大的妄想！如果千千万万普通人失去了工资性分配的入口，没有收入、没有尊严、没有购买力，生产出来的海量物资卖给谁？谁来维系市场繁荣？整个社会的流动性一旦被冻结，所有的存量资产不过是一座正在坍塌的冰山，谁都在坐吃山空！”

程砚舟将启动预算推向妻子：“机器能做的，就让它做得更快。我们想试试，人愿意聚在一起较量、讲解和创造，能不能产生不靠熬工时的收入。”

沈婉衡看着他。十多年前大学里那个执意另辟蹊径的青年，如今已是三十五岁的父亲，问道：“有人看，不代表一定有人买。企业愿意把钱投进来，图的是什么？愿意再投第二次，又凭什么？”

“请几家销售同等商品的企业，各自争取品牌被记住、被选择。商品本身、标价都一样，这样才能追问人究竟为什么选择了某个商标。再计算销售收入扣除全部投入后，剩下多少利润。活动如何组织，也需要有人负责。另一头，则是实收款根据公开规则分到谁的手里，他们后续购买了什么，又存下了多少。”程砚舟在预算表边留了两栏说到。

“两栏不能互相顶账。”沈婉衡叩了叩纸面，“更不能领了奖就非得买赞助商的东西。”她把杯子放稳，“我给你六个月。沈家的产业基金有董事会，不能拿来填这场试验。家里的事务我来分管，小溪由我照顾。到时候，我要看企业为什么会再次投入，也要看参与者拿到钱以后究竟怎样过日子。那些热闹的照片，和你自己补进去的钱，都交不了这个账。六个月，没接上的环节也要如实摆出来。”

楼上又传来女儿的笑声。程砚舟点点头，沈婉衡将他手边的冷茶换掉，没有再做任何劝说。

九点半，城北数字创意工坊的落地窗洒着冬日清冷的微光。顾承安和杜启航正陪着工程人员，小心翼翼地将八台服务器安置到位；林静薇则在工作台上，细致地铺开着厚厚的资料。

周慎衡走到程砚舟身边，从公文包里取出一张银行回单，递了过去：“您、知妍、承安、静薇和我，五个人投入项目的两百万，都到账了。”程砚舟接过回单，仔细核对了一番，才将它整整齐齐地夹进了初始资金的那一页账目里。

周慎衡将账目一一写在了白板上：“租赁和托管一万二，专线接入八千五，水电环境三千二，伙伴津贴与社保一万五，研发备用一万。总计每月四万八千七百元。”他终于放下手中的笔：“这笔预留的资金足够支撑十八个月。硬件和日常开销都有了着落，接下来的任务，就是证明我们所做的事情，被人需要，并且能将真实所得的收入，实实在在地送到每一位参与者手中。”

程砚舟凝视着那张清晰的预算表。这笔资金让他们有了从容起步的余地，却不足以证明，脚下这条路就是通往未来的唯一道路。

六个人围坐在宽大的会议桌前，阳光照进来，室内温暖如春，咖啡机散发着浓郁的烘焙香气。

这绝非一群被逼上梁山的英雄好汉，而是一支脱离了资本缰绳、携深厚底蕴与顶尖技术下山入世的极客宗师战队！转战到这里，虽然没有了写字楼的豪华，却有了宽敞的享受。

程砚舟走到白板中央，擦去旧的指标公式，用黑色油性笔在白板正中郑重画出十九路的纵横方格，并在正中心点重重地画下一个圆点：

“先把局布起来。”程砚舟在棋盘两侧各落下一点，“一头是企业为什么愿意来，另一头是人凭什么得到收入。我们不能只是把机器接走的活重新搬回来，让大家换个地方继续熬。”他放下笔。

周慎衡翻开空白账页，写下了“盈虚有数”四个字。
