# 第2章：水波不兴

在深夜那场三十六层的风暴席卷开来之前，城南的天色还泛着一层青灰。

下午六点十分，三十四岁的沈婉衡端坐在听涛古雅饭庄顶层的茶室里。她身着剪裁极利落的深墨绿羊绒大衣，长发一丝不苟地挽在脑后，没有多余的珠翠，只腕间佩戴着一只极素的百达翡丽白金方表。

她是程砚舟结褵十一年的妻子，出身经营大型产业基金与并购重组的沈家。二十八岁以前，她在投行亲手操盘过四起跨国并购，见过太多在谈判桌上被拆骨吸髓的实业家。白瓷壶里的龙井已经续过第二道水，但她面前的杯子，却一口未动。

窗外最后一抹残阳悬在仿古铜窗棱上，迟迟不肯落下去。

这间酒店见证过两家太多盘根错节的宿命。十一年前的世家联姻定亲宴，六年前霁岳险些因研发断流而崩塌时的紧急过桥贷款，三年前上市敲钟前夕那场长达七小时的股东表决与董事席位争夺——每一桩关乎生死的契约，都是在这条走廊两侧的暗红地毯上签下的。

服务员轻手轻脚推门进来，问要不要上茶点，沈婉衡只微微颔首，示意不用。

门再次被推开，叶舒倩匆匆走进来，将手袋和风衣随意搭在对面的酸枝木圈椅上。她与沈婉衡是初中同窗，见过沈婉衡拿全额奖学金时的清冷，也见过她穿上定制婚纱时的明艳。但此刻，叶舒倩脸上没有半点叙旧的闲情，直截了当地把手机倒扣在桌上。

两人的女儿在同一所私立双语小学同班，明晚的年级家长会，班主任已经在群里发了三次置顶通知。

“下午四点半，我去霁岳大厦见商务中心改造的甲方。”叶舒倩盯着沈婉衡，声音压得极低，却字字带着逼人的冷硬，“电梯厅里，我看见程砚舟了。许知妍隔着三四个人走在他身后，两个人连一个眼神都没交汇，却在一分钟之内，先后进了西侧那部直达三十六层高管区的专属电梯。”

沈婉衡抬手提起茶壶，水线极稳地注入对面的青瓷杯中，甚至连半滴水珠都没有溅出杯沿。

“他们两个人，在同一栋楼里共事了八年。”沈婉衡的声音平静得没有一丝波澜。

“婉衡，你知道我指的绝不是工作。”叶舒倩没有碰茶杯，眉头紧锁，“那个眼神……不是上下级，甚至不是寻常合伙人。太避嫌了，避嫌到近乎刻意。一前一后，步速完全一致。作为女人，你别告诉我你真的一点感觉都没有。”

“我知道的，已经足够了。”沈婉衡放下茶壶，瓷器与木托相碰，发出一声清脆的轻响。

“什么叫足够？他们到底有没有——”

“舒倩。”沈婉衡抬起眼，那双极明亮的丹凤眼里没有愤怒，只有一种常年在资本深水区磨砺出来的审慎与冷肃，“知道多少是一回事，必须做什么又是另一回事。我不是侦探，没有兴趣去搜集每一个肮脏的细节来刺痛自己。”

叶舒倩愣愣地看着她，像是第一次看清这位相识二十年的挚友。

“那是你的丈夫，是你们十一年的婚姻！”叶舒倩有些急了。

“这我当然知道。”沈婉衡转动了一下微凉的茶杯，“如果我想查，他的行程单、私人账单、专属电梯的刷卡记录，还有他在霁岳持股信托里的每一笔异动，沈家的法务团队可以在四十八小时内列出三份无懈可击的调查报告。但我为什么要去查？拿到证据之后呢？像泼妇一样冲上三十六层掀翻他的会议桌，还是在财经头条上买下三个板块，宣告霁岳科技创始团队的婚内丑闻，然后因此导致控制权易手？”

她摇了摇头，唇边泛起一丝极淡的清冷：“做企业重组的人，永远不会在局势未明的时候提前摊牌。商战如弈棋，十九路棋盘上，你若是被对方随手点了一颗孤子就乱了阵脚，满盘的厚势和实地，瞬间就会被屠得干干净净。”

“你管这叫下棋？”叶舒倩难以置信。

“不然呢？当成苦情戏演给外人看吗？”沈婉衡的视线投向窗外的苍茫暮色，“女儿今年八岁。她出生那年，程砚舟睡在书房，说怕半夜接海外投资人的电话吵醒孩子。后来出差、路演、抢版号、建架构，那扇书房的门便再也没有真正打开过。我们已经好久没有在一起了。”

“那你图什么？沈家的资产和底蕴，够你和小溪衣食无忧过几辈子！”

“图我付出的十一年，不能被一把火烧成灰烬。”沈婉衡的声音骤然沉了下来，带着金石般的冷冽。

“六年前，霁岳第一款分布式游戏引擎因资金链断裂濒临夭折，程砚舟被几个野蛮人资本逼得在这间茶室里连抽了两整盒烟，嗓子全哑，几乎要跪下签卖身契。是我拿沈家的过桥资金替他兜底，逼退了那帮吃人不吐骨头的对赌方。回程的车上，他握着我的手，掌心全都是冷汗，说一辈子不会负我。”

沈婉衡停顿了片刻，端起微苦的茶水饮了一口：“商人嘴里的誓言有多廉价，我比谁都清楚。但他那声‘谢谢’是真的，我拿真金白银和沈家信誉替他撑起的底气也是真的。现在的霁岳，有我沈家两道担保、一个独立董事席位，还有我个人信托持有的百分之四点五的优先清算权。更重要的是，现在整条实体产业链都在承受AI替代的剧痛——沈家控股的制造厂，下游订货量腰斩，商场里门可罗雀。商品造得再快再便宜，老百姓失了业、没了薪水，谁来消费？整个经济都在滑向通缩冰川。如果我现在掀桌子，霁岳的股价明天就会腰斩，做空机构会群起撕咬，两家的资产全面承压——我的女儿，也会成为名利场里被指指点点的牺牲品。”

“所以你就这么忍着？”叶舒倩眼眶发红。

“不是忍，是守势。”沈婉衡字字如刀。她在并购深水区操盘百亿资金，手段恰如天山缥缈峰灵鹫宫的至高绝学“天山折梅手”——任凭对手招数如何变化莫测、狂浪滔天，她自以万法归宗的极寒守势，将所有违约风险与财务破绽化解得滴水不漏：“我守着这盘棋的边界。程砚舟很清楚我的底线在哪里：不准动用上市公司的公款替私人关系平账，不准把许知妍带进沈家的社交圈，不准在女儿面前露出一丝破绽。该回家的时候他必须回家，老人有需要时他必须到场，小溪成长的重要时刻他必须出席。守住这些规矩，他依然是体面的程总，依然是霁岳的主心骨。”

“可如果他跨过了那条线呢？”叶舒倩追问。

沈婉衡放下茶杯，窗外的霓虹刚好映在她的瞳孔深处，冷得像出鞘的霜刃。

“真到了棋局死活难保的那一天，我会亲自执黑落子，断了他的大龙。”沈婉衡神色自若，“沈家的刀，从来不怕沾血；灵鹫宫的折梅手，既能化尽万法，也能凝水成冰化作生死符寸寸锁喉。但在他彻底变成恶手之前，我绝不会替别人的错误，砸碎我自己的盘子。”

叶舒倩沉默了良久，终于叹了一口气：“明晚小溪的家长会，他会来吗？”

沈婉衡看着手机里女儿拼好的积木桥，目光终于掠过一丝不易察觉的柔软：“我会去问他。来不来，是他自己的劫数；接不接，是我必须给他留下的活路。”
