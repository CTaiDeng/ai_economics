# 第1章：溪云初起

2026年一月初，夜里十一点四十七分，霁岳科技在主板敲钟上市已满三年。

总部大楼三十六层，整条西侧走廊只剩最后一盏冷白筒灯亮着。程砚舟的联合创始人办公室占据了最好的西南角，两百多平方米，巨大的曲面落地窗将整座城市的流光夜景尽收眼底。这里宽敞得近乎空旷，甚至能听见中央空调出风口微弱的吸气声。

黑胡桃木办公桌没有一丝拼接的缝隙，如同一块打磨极深的长方大印，压在整间屋子的正中。桌上摊着那份刚刚盖上保密印章的文件——《组织结构优化与人员分流最终执行表》。

总计一百八十六人。

按围棋的说法，这一百八十六个名字，就是霁岳这盘大棋行至中盘时，必须弃掉的子。没有死活的余地，甚至算不上打劫时的劫材。董事会要的是压缩成本率，财务要的是现金流净额，机构股东要的是环比提升的净利润；于是，棋盘边上的手轻轻一挥，这一百八十六颗棋子便被拔出了盘面，连一声叹息都落不进财报。

程砚舟站在桌边，指间夹着一支点燃的香烟。烟雾直直升起，又被头顶的风扯成凌乱的细丝。另一位联合创始人许知妍坐在落地窗前的深灰皮沙发上，同样指间燃着一支细支烟。

屋子里有种近乎窒息的沉寂。十分钟前，他们刚刚在这张宽大的黑胡桃木桌后发生了不该发生的事。那场仓促、压抑且带着绝望意味的越界，非但没能替他们卸下心头哪怕一克的重负，反倒像是在本就亏空的账目上，又添了一笔无论如何也无法平账的私债。

两个在商场与技术架构上最懂得维持秩序的人，此刻连目光都不知道该落在何处。

程砚舟垂下眼，盯着踩在脚下那块纯手工织造的羊毛地毯。那是上市那年，一家只接待预约客户的工坊送来的高档奢侈品。他与许知妍的家庭底蕴皆极为殷实，从海外名校归国创业至今，从未受过半点生计窘迫的委屈；可越是衣食无忧，越是站在行业算力的最巅峰，心底那一层冰冷的寒意就越发刺骨。

落地窗外的整座都会，看似霓虹璀璨，实则正在大洋两岸掀起的AI海啸中剧烈失血。生产能力的物理约束全面松弛，机器与大模型以近乎零边际成本的效率疯狂吐出代码、图纸与文案；然而走下写字楼，街角商铺成片熄灯，中产家庭的资产缩水，传统雇佣链条被渐渐斩断。社会正在滑落“机器生产一切，大众失去收入，商品过剩却无人买得起”的通缩深渊。

许知妍的手机屏幕在茶几上亮起微光，是她丈夫发来的消息。两岁半的儿子烧退了，丈夫问她：“会议结束了吗？几点能到家？”

许知妍的手指在冰凉的玻璃屏上悬了很久，最终只回了四个字：“还在收尾。”

四个字发送出去，手机暗了下去。她抬起头，透过青白色的烟雾看着程砚舟。

“名单上的字，董事会已经锁死了。”许知妍的声音很轻，却干脆得像刀锋掠过薄纸。她名校经济学出身，深谙数理推演与机制设计，心性中本带着几分桃花岛奇门遁甲心算法般的机敏与通透。昨夜在董事会那场九票死局中，正是她以近乎算筹定星盘的周密博弈，在机构嗜血的算盘下，硬生生为这些被抛弃的外门弟子争出了N+2与大病医保的喘息生机：“九票表决，八票赞成，一票弃权。机构代表似乎并不关心这批人做过什么，他们眼里更多的是人均产出比。新模型上线后，宣发物料的生产周期从三天压到两个小时，测试用例自动覆盖率提升到七成——在股东眼里，多养一个人，就是在棋盘上多留一口无用的气。”

“气尽子亡。”程砚舟扯起唇角，露出一抹极尽苍凉的冷笑。他本在江岑大学学习计算机，曾将编写游戏底层分布式架构视为铸剑的技艺。少年时沉迷武侠，最向往的是武当张三丰一脉的太极道统，那讲究纯阳无极、气脉连绵，意在用至高无上的“大巧若拙”架构来包容世间万物。直到自己带着好友，合计六人创立霁岳，使其成为行业标杆，走上万众瞩目的红毯，他才惊觉，这个当代商业江湖，根本容不下行侠仗义的纯阳正道。资本是最大的名门，而财报，则是最无情的戒律，其掠夺之狠，堪比抽干人骨血的化功大法。任何名门要拓山门、保基业，第一件事便是将那些无权无势的外门弟子逐下山去，任其自生自灭。“一百八十六人，平均年龄二十九岁。”程砚舟掐灭了烟头，指尖在名单上轻轻划过，“其中有六十三人是全家唯一的收入来源，二十九人去年才在高位背负了房贷，十七个家庭的孩子尚未上幼儿园，还有九个家庭每月都在为大额的慢性病账单买单……在纸面上，不过是几行姓名、职级和赔偿金的计算公式，可一旦挪到各自的屋檐下，全是一座座摇摇欲坠的顶梁柱。”

“我们能争取的，我都争了。”许知妍掐灭了手中的烟蒂，站起身来，“补偿标准提了整整一档，按N+2结算；有直系亲属重大疾病的，保留商业补充保险至年底；四十七个入职不满一年的管培生，年终基准绩效全额补足。如果这些不写进决议，我今天不会在表决书上签字。”

“但是……”程砚舟顿了一下，“不还是签了？”他意味深长的叹道。

“即便我们争下了补偿，走出这栋大厦，他们又能去哪？如今满城都在裁员，各行各业的雇佣通道都在关闭。没有了工资性分配，普通人靠什么在这场通缩寒冬里活下去？我们在这里锦衣玉食，可覆巢之下，安有完卵？”程砚舟感慨着。

“知妍，皮之不存，毛将焉附？我们若守着这套把人当耗材的旧模式，哪怕分得再多期权分红，也是坐在火山口上数金子。”

许知妍眼眶微红，迎上他的目光：“我何尝不知这是饮鸩止渴？可如果不签，明天开盘，股价继续被做空机构按在跌停板上。机构已经准备好临时提案，要求罢免管理层，启动第三方托管清算。真到了那一步，连这N+2的补偿款，他们都拿不到！”

窗外，夜幕低垂。繁华的商业区如同铺开的十九路巨盘，纵横交错的街道是经纬棋线，车辆的尾灯拉成猩红与惨白的流光，像极了正在搏杀纠缠的黑白棋子。

程砚舟走到落地窗前，俯瞰着整座城市。

在楼下街角二十四小时便利店的惨白光影里，一辆冷链卡车刚停稳。穿着反光背心的装卸工正喘着粗气，将一箱箱牛奶和切片面包卸上板车。而在大楼三十五层和三十四层，那几个通宵运转的研发部门里，不知还有多少毫无觉察的年轻工程师，正一边嚼着冷掉的便当，一边盯着多智能体模拟调优的实时曲线，幻想着新版本上线后的全员奖金。

内线电话的指示灯无声闪烁。秘书没有转入语音，只发来一条加急备忘录：

是人力总监发来的，“人力资源部与法务部已完成全部解约沟通脚本与会议室排期。明早九点整，从三十四层测试组开始，按每组十二人、每人二十分钟分批谈话。请程总、许总确认统一口径。”

“统一口径……”程砚舟低声重复着这四个字，一股无名火涌上心头。“什么时候开始，连亲手把并肩作战的同袍赶出山门，都要先对齐一套滴水不漏的官样说辞？”

他拿起内线话筒，直接拨回给人力总监：“不用统一口径，明早九点，第一场谈话，我和许总亲自参加。”

话筒那头的人力总监明显愣了一下：“程总，按照危机应对常规规程，联合创始人不宜出现在第一轮面谈现场，容易激化被动情绪……”

“人是我们决定裁的，字是我们亲手签的。”程砚舟打断了他，声音里透着不容置疑的寒意，“至少要让他们看清楚，是谁亲手把他们推下悬崖。”

挂断电话，办公室里重归死寂。

程砚舟的手机也在这时震动起来。屏幕上跳出妻子沈婉衡的名字，还附带了一张女儿今天在学校拼好的积木桥照片：

“小溪说明晚的家长会，她想让你第一个看她的作品。能回来吗？”

程砚舟看着屏幕，戴着婚戒的手指微颤，最终将手机扣在桌面上，没有回音。

窗外，寒风卷着枯叶掠过三十六层的高空玻璃，发出极细碎的摩挲声。这盘大局刚刚落下最狠的一子，而棋盘边缘的深渊，才刚刚睁开眼睛。
