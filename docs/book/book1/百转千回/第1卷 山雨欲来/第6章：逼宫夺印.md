# 第6章：逼宫夺印

周二下午两点半，三十六层一号董事会议室的隔音重门彻底合死。

九个席位座无虚席。厚重的长桌中央没有摆放任何鲜花，只有九台打开的笔记本电脑，屏幕泛着冷冽的蓝光。空气中弥漫着高档速溶胶囊咖啡的微酸气味，与中央空调吹出的干燥冷风混在一起。

机构投资者代表赵董事坐在右侧上首，翻开了投影屏幕上的第一张幻灯片。

大标题触目惊心——《霁岳科技二期组织效能重塑与晨港资产价值最大化议案》。

副页的人员精简预案里，赫然列着三百一十二人。

比第一期多了近七成。这一次，刀口直接对准了霁岳最核心的资产——晨港虚拟协作空间的底层系统架构组、图形算法组，以及整个主策与生态设计团队。

许知妍手中的笔停在半空：“三百一十二人，这是霁岳的大动脉，这些人在这里耕耘过，他们积累的经验，该由谁来承载？过去立下的约定，该由谁来坚守？受影响的伙伴，该向谁来对接求助？”

赵董事并未看她，而是翻开了手中的测算报告，语气带着一种冰冷的、无可辩驳的逻辑：“自动化的流程配合离岸维护，每年可以削减六千四百万元的人力成本，税息折旧及摊销前利润率甚至能提升十三个百分点。机器能够完成的任务，理应由机器来承担。”

“机器能接任务，这一点我承认。”周慎衡的声音平静得出奇，却带着一股不容置疑的力道。“但这些节省下来的钱，最终归谁？原团队应得的授权和未结的报酬，该如何安置？那些玩家们倾注心血、共同创造的价值，难道也可以连人带账地，一次性卖掉？”他缓缓抬起眼，目光落在那些冰冷至极、只列出成本的数字群组上，神色中带着一丝不忍：“晨港的建设者们，一旦失去了收入，也就失去了选择的权利。您所谓的‘繁荣’，如果缺乏了支撑的根基，将如何延续下去？”

赵董事的嘴角不易察觉地勾起一丝弧度，那笑容里，是资本世界最淡漠的傲慢：“周总，按您的设想，‘退一万步’，就算晨港在一年后空置，又如何？”

整间会议室陷入了死一般的冰封。程砚舟猛地抬起眼，目光如两道凌厉的剑锋直刺赵董事。

“只要下个季度我们把晨港的海外商业化独家运营权打包卖出去，签约预付款预计就有三亿多美金。”赵董事毫不避讳地迎着程砚舟的目光，字字诛心，“加上财报扭亏的估值修复，公司股价能在三个月内重回百元大关。到时候，机构基金获利解套，中小股民看到亮眼财报追高买单——程总，许总，你们手里质押的股权也能顺利赎回，甚至套现离场，何乐而不为？”

“典卖山门，欺师灭祖。”程砚舟声音极其低沉，喉咙深处仿佛压着千钧雷霆。

“赵董事，你们只算自己的退出通道，可曾看过一眼窗外的现实？”许知妍冷声道，“全社会各行各业都在裁员，失业率在飙升，居民购买力在显著下降，整个宏观经济正在滑向通缩的螺旋！你们把人当成纯成本砍掉，商品造得再快，价格卷再便宜，全社会大众没了收入，到头来谁来消费你们的数字资产？你们以为资本能脱离大众生存变成孤岛吗？”

“通缩是经济周期，我们管不了天下人的饭碗，我们只管资本的投资回报率！”赵董事神色倨傲，“资本的逻辑就是顺势而为、套利交易！”

许知妍心中冷笑：“这不正是武侠旧书里最荒诞也最残酷的戏码吗？宛如金庸笔下嵩山派左冷禅与华山岳不群同坐密室，商量的不是如何传承祖师爷留下的浩然剑道，而是如何打着‘为了全五岳同盟大计’的伪善幌子，将山门大殿、历代灵位和外门弟子一起打包卖给朝廷和富商，自宫练剑，换取长老们在财报红毯上的锦衣玉食。门派从来不是死在敌人的明刀明枪下，门派总是死在自家长老的算盘珠子与辟邪自残里。”

许知妍暗暗咬紧银牙，她以桃花岛奇门遁甲心算之术，一眼便看穿赵董事所谓的EBITDA利润修复，不过是西域白驼山庄放出的毒饵，用断子绝孙式的账面扭亏，诱杀全盘长生之根！

“程总，十九路围棋，下到这个地步，为了保大龙，断尾弃子是必然的定式。你若是硬要保那三百多号人，现金流撑不过两个季度，整条大龙都被做空资本屠光，你拿什么给所有股东交代？”另一位独立董事清了清嗓子说道。

“这哪是下棋，这是掀翻棋盘抢夺木料！围棋三千年，之所以博大精深，是因为设计者立下规则，千千万万棋手在盘上倾注心力，共享棋道的繁荣！你们现在却想把棋手全杀了，把棋盘拆碎当柴火烧！别忘了我手中的一票否决权！”程砚舟一字一顿地说道。

“程总，你可以反对这笔交易。但机构股东将依法提请召开临时股东会，提出董事改选议案。你手中的否决安排能覆盖哪些事项，我们会逐条争。”赵董事合上了电脑，说完嘴角露出一抹胜券在握的笑容。

“你们在逼宫。”许知妍脸色白得吓人。

“不，我们是在给这艘快要沉的船找一条出路。下周五之前，如果两位创始人不能给出同等规模的有效现金流填补方案，我们就推动召开临时股东会，依法审议交易和董事改选提案。程总，时代变了，收起你的武侠梦吧，代码只是一串字符，不值得你赔上身家性命。”赵董事站起身，整理了一下西装下摆。

隔音的重门再次打开，又合上。会议室里只剩下程砚舟、许知妍和周慎衡三个人。

周慎衡瘫坐在椅子上，抹了一把脸上的冷汗：“砚舟，知妍……他们这不是在开玩笑。离岸外包和接管团队的尽职调查，看样子他们早就秘密启动了。”

程砚舟没有说话。他走到窗边，看着楼下如蚁群般穿梭的车流。

三十六层的高空，风声呼啸。

他曾经以为，只要把技术做到了极致，敲了钟、上了市，就能在这座残酷的江湖里为兄弟们打下一块不灭的根据地。

可直到今天他才彻悟：在资本的棋盘上，你只要坐上了它的庄，就必须按它的规则杀人。若不肯与资本同流合污，唯一的出路，就是跳出旧棋盘，以代码为剑、以不可篡改的契约为盾，在天地间开辟出：让天下人共享红利的新江湖！
