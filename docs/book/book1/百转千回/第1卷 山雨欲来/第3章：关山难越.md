# 第3章：关山难越

第二天上午九点，三十四楼二号会议室的百叶窗紧紧合着。晨光从叶片的缝隙间透进来，在长桌上落下几道窄窄的光痕。门外的办公区已经坐满了人，往日的招呼声和笑语却迟迟没有响起。零星的键盘声断断续续，衬得四周愈发安静。年轻的工程师们各自坐在工位前，身体微微前倾，但谁也没有率先打破这层凝滞的空气。

程砚舟和许知妍并肩坐在会议桌的一侧，眼底残留着连日不眠的青黑倦意。张总监在不远处，早已将一叠叠的解约协议和补偿清单摆放整齐，黑色签字笔靠着红色的印泥，每一份文件都排列得一丝不苟，规矩得像是一场冷酷的仪式。门外，不知何时，脚步声停了下来。程砚舟抬起了头，目光沉静地望向门口，等待着第一位要进入这“审判场”的人。

门被推开了，走进来的是二十八岁的高级测试工程师陈驰。

陈驰穿着洗得有些褪色的连帽卫衣，肩上的双肩包磨起了毛边。看见程砚舟和许知妍都在，他在门口停了一下。桌上那几份解约协议，比昨夜收到的会议通知说明得更清楚。

“陈驰，坐。”许知妍的声音比平时低。

他把背包放在椅边，拉开椅子坐下。张总监翻开文件：“陈工，鉴于公司当前研发业务线的战略收缩与自动化效能提升，经过管理层与各部门审慎评估……”

“让我来说！”程砚舟抬手，张总监猛然怔住，然后看了他一眼，将翻到一半的文件轻轻放平。

程砚舟看着对面的年轻人。他记得陈驰，去年核心引擎攻坚阶段，陈驰连续三周通宵抓底层并发死锁的Bug，最后在晨港节点压力测试上线前一刻找到了内存泄漏的根源。当时程砚舟拍着他的肩膀，亲手递给他一杯热咖啡，说陈驰是霁岳最敏锐的哨兵。

如今，AI大模型接管了自动测试和用例生成。屏幕上滚动的结果快而准，程砚舟找不到任何能让机器停下的理由。可坐在对面的陈驰，也并未做错什么。涌上来的念头总是逼得人无处可退：倘若下一份工作依然要求这个年轻人证明自己比机器更廉价、更耐用，今天的谈话，迟早会在另一间会议室重演。

“陈驰，公司决定裁撤整个专项测试组……”程砚舟没有拐弯抹角，字字如同钝刀割肉，“你的岗位在裁撤名单里。这不是你能力的问题，是公司在资本和财报压力下做出的收缩决议。”

陈驰的手停在了背包拉链上。“整个组？”他等程砚舟点头，才接着问，“那我手里的多智能体并发测试工具链呢？上周刚跑通第一阶段，剩下的问题还没交代完。”

“项目会被封存，逻辑转由自动化大模型接管。”许知妍将文件推到他面前，“这是离职方案。我们争取到了N+2的补偿基数，你的年终绩效按全额折算，未休的十二天年假按三倍工资结算。”

陈驰接过文件，从第一页往后看。看到交接一栏，他用指尖压住了那一行：“未解决的问题我会列出来。交给谁，请给我一个名字，别等出了差错，又说离职的人没有说清。”张总监在一旁记录，翻出交接安排与他核对。

“裁撤是什么时候定的？”陈驰抬起头，“上周还在催进度，我们还在安排后面的测试。如果那时已有打算，至少应该让我们早一点知道。”程砚舟没有立即回答。陈驰把文件放回桌上，等着他，会议室里只剩翻纸的声音。

“程总，许总，前年秋招宣讲会上，你们站在学校的大礼堂里说，霁岳不是那些只顾赚快钱的换皮作坊，霁岳要做的是属于我们自己的硬核游戏底层，要把每一个敲代码的工程师当成患难与共的兄弟。”

“我当时是认这件事的，所以推了另外两家外企的意向书。”陈驰望着两人，“在霁岳做过的东西，我没觉得白做。但今天你们只告诉我，岗位没有了。那些承诺变了，但至少该由作决定的人把原因说明白。”他顿了一下，伸手去拿桌上的水杯，杯沿碰到牙齿，发出很轻的一声。他将杯子放下。

“我上个月刚在城北交了首付，积蓄基本填进去了。每个月一万多的房贷，生活开销另算。这笔钱也就撑几个月，现在回想，买房可以算作我考虑不周。”陈驰重新翻开补偿清单，“可外面也在用AI缩减岗位。换家公司继续等下一次裁撤，这条路还能走多远，我找不到答案。”

陈驰已经在问岗位之外的出路，程砚舟却连眼前的裁撤安排也没能及早告诉他。程砚舟看着桌上那份递过去的协议，一时接不上话。棋谱上的弃子，几笔就能写完；可桌子另一边的人，还要还贷，还要找工作，还得设法把已经排好的生活重新衔接上。

“没能让你们早一点知道，是我们没有做好。”程砚舟说，“往后的事，我现在给不了你保证。今天列在这里的补偿和交接，我们先逐项说清。”许知妍把明细推到陈驰面前，张总监也停下了说辞，开始按他的询问核对各项结算和付款安排。

陈驰读完协议，又将几项金额与清单对了一遍。他仍不满意程砚舟的回答，但离开这家公司以后该怎样生活，终究还得由自己安排。他确认了交接对象和付款日期，拿起笔，在签字栏写下名字，按下指印，将自己留存的一份折好放进背包。

“交接我会做完。”他站起身，将工牌轻轻放在桌角的印泥旁，“至于以后的事，等我想清楚了再说。”他的手在工牌上停了片刻，才松开。

陈驰转身拉开门，走了出去，关门时仍下意识地放轻了动作。走廊里的脚步声停了片刻，随后便渐渐远去。

张总监松了一口气，伸手去收那份签好的协议：“第一场还算顺利，比预想的耗时短了五分钟。下一场是前端渲染组的……”

“这也算顺利？”程砚舟猛地转过头，眼神冷冽得像要择人而噬。

张总监吓得手一抖，协议险些掉在地上，心里嘀咕着自己成了出气筒。

程砚舟没有理他，转头看向窗外。玻璃窗倒映着会议室里清冷的陈设，那一枚被遗留在桌角、染着鲜红印泥的工牌，在惨白的日光灯下，泛着寒刀般的冷光。

这只是第一场。门外，还有整整一百八十五个人在排着队，等待受刑。而整座城市，不知还有多少这样的会议室，正在将成千上万的大脑剥离出时代的棋盘。
