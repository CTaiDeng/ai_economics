# 第7章：一剑当关

隆冬的寒气如针，穿透了总堂厚重的楠木门，却丝毫未能冷却议事厅内剑拔弩张的对峙。

这间尚未正式挂牌的总堂密室，与其说是议事厅，不如说是一处拷问人心的“天机堂”。中央一张十二尺长的黑胡桃木桌，木纹深沉如凝固的血液。桌上，一份用蜡封缄的硬牛皮纸呈帖，已被翻阅得起了毛边。呈帖旁，一只紫砂茶壶的壶嘴正无声地吐着白汽，氤氲的水雾模糊了每个人的脸，却掩不住他们眼神里的锋芒。

这场盘道，起自这份呈帖，它鼓吹的是一个能包罗万象、吞吐江湖财富的“集散黑市”。

邱庭舟的手指瘦长，骨节分明，他用指尖捻起呈帖的前两页，纸页发出干燥的脆响。“换几幅画影图形，卖些刀剑上的流苏穗子，明码标价，童叟无欺。”他的声音平稳，却像淬了冰，“买卖干净，总堂乐见其成。”

他话锋一转，手指猛地翻到第三页，纸页被他压得紧贴桌面，发出“啪”的一声闷响。“可这一条，”他眼中寒光一闪，“竟想着将弟兄们用命换来的铁打军功勋章，兑成一种能通行天下、私下倒卖的‘飞票’？甚至妄图凭这纸片，直接购买各大‘生死阵眼’的优先发兵权？我只问一句，真出了亏空，谁来兜底？”

递状子的商贾，一个面皮白净、穿着暗纹绸衫的中年人，额角已渗出细密的汗珠。他支支吾吾，目光游移地扫过在座的几位巨擘，最后落在那呈帖的附录上，声音发虚：“这……这自然有各大山头的钱池子作保。既然大家同在一个江湖，资金总能……总能找到流通的门路。”

“混账！”

一声断喝，来自周慎衡。他须发戟张，手中那支饱蘸朱砂的狼毫笔几乎要被他捏断，鲜红的墨点溅在纸上，如同一滩滩血迹。他提笔在纸上重重划过，每一笔都带着千钧之力：“各大山头的钱池子？那是底下弟兄们拿命换回来的安家费！你看看这账目，‘生态奉献激励金’三万两，那是给戍边弟兄的赏钱！‘信托处分’下的抚恤银，更是动都不能动的死账！绝不会因为你用一张纸把各山头的名字串起来，就凭空变成你这新黑市兜底的钱库！”

他的朱笔点在一行蝇头小字上，几乎要将纸张戳穿：“‘基本参与份额五百元’，听着不贵，人人都能入局。可这后面的‘差异池’，转眼就滚到了七千元！这不就是拿小钱钓大鱼，最后用后来者的血汗钱去填先行者的窟窿？千礁堂那档子烂账，尸骨未寒，你还想再演一出化功大法，把所有人的内力都吸干吗？！”

排兵布阵的军令，更是不可触碰的死穴。顾承安始终沉默地坐着，此刻缓缓开口，声音不高，却字字如铁：“你花钱给刀鞘镶金嵌玉，只要没去改刀刃的锋利，总堂可以不管。可你要是靠砸钱就能无视军功、世世代代霸占着那几处肥缺的阵眼，这就不是掀桌子，这是在刨所有人的祖坟！”他的目光如鹰隼，死死盯住那商贾，“休想用一句轻飘飘的‘反正没给兵器淬毒’，就厚颜无耻地假装它不会乱了整个江湖的经济和兵权！”

那商贾被逼到了墙角，汗水已浸透了内衫，他咬着牙，眼中闪过一丝不甘与疯狂：“就算从前出过千礁堂的烂账，总堂也不能草木皆兵，一朝被蛇咬，十年怕井绳，就此断了所有谋新财的路！”

“路，可以谋。但不是你这么个谋法。”

程砚舟的声音温润如玉，却带着不容置疑的决断。他伸手将那份呈帖拉到自己面前，手指在纸页上轻轻划过，仿佛逍遥派的天山折梅手，不与你正面硬撼，却总能找到你招式间最脆弱的关节，轻轻一折，便将你千变万化的图谋拆解得七零八落。

“名字，不能一刀斩了。但这套把戏，必须扒皮抽筋，看个分明。”他逐条剖析：

“其一，纯为显摆的流苏杂物，可以交易。但必须死死盯住物件的来路和原主的画押，确保不是销赃的黑货。”

“其二，想买别人的独门绝活，可以。但得按江湖切口，规规矩矩付现钱，一是一，二是二。”

“其三，”他的语气陡然转冷，“那种能满天下流通倒卖的‘飞票’，它的收付、对换，乃至与地下钱庄的勾连，必须先过官府六扇门的律法死关。总堂的举手表决，凑不出开印子钱的免死金牌。眼下，绝不放行！”

“其四，”他指尖最后落在那最扎眼的一条上，“那些要命的阵眼帅印，更是休想！休想靠几个满身铜臭的钱庄，就敢私自挂牌叫卖三军统帅的虎符！”

商贾面如死灰，却仍在做最后的挣扎。他知道大势已去，只能弃子争先，死死咬住一点残存的实地：“前两道买卖，我们愿开。但……但恳请总堂允准，将‘未来全江湖通兑’的愿景，写进黑市的招子里。这……这是个念想，是个大势……”

“大势？”顾承安冷笑一声，打断了他，“我只问你，你这空口白牙许下的荒唐未来，拿什么兑现？拿那些不知深浅的买家，用真金白银堆出来的‘生态奉献激励金’吗？还是靠注销掉所有人的‘一票否决权’，让你一家独大？”

他站起身，走到那商贾面前，居高临下地看着他，一字一顿地说道：“所有被毙掉的妄想，和能放行的红线，必须在招子上写得清清楚楚，明明白白！那些已经下了定钱的人，必须立刻把改过的底细递到他们眼前，准许他们随时退钱走人，分文不取！”

预估的红利被腰斩再腰斩，一个气吞山河的宏大构想，硬生生被缩成了一个只能做些小买卖的盘口。

顾承安亲手拿过一块蘸了清水的抹布，将那些还没洗干净的烂摊子，从一块预备挂牌的红木大匾上，刮得干干净净。原本那张吹嘘得包罗万象、号称由“16台机柜/120台服务器”支撑，能容纳“两万节点”同时在线，峰值流量高达“1.2Tbps”的宏伟阵图，被硬生生砍成了几截碎片。

看着虽没起初那般气吞万里，但至少能让人清清楚楚地看准：这十九路棋盘上，哪几处是真的落了子，是能做活的实地；而哪几处所谓的滔天外势，不过是毛笔在半空中虚画的一场残梦。

他讲了一个刚刚发生在锦川演武沙盘上的故事：一名刚接过全局帅印的新人，在倒计时仅剩167:59:59的紧迫关头，同时接到了两道十万火急的求援飞鸽。两份血书上都画着最要命的红叉，单凭那张光秃秃的阵图，根本看不透哪座土楼里还藏着暗箭。一道血书是阵眼被破、正在拼死堵漏口的残兵发来的；另一道，其实只是求援几车搭浮桥的木石料。

“若是蒙着眼，把手底下的重装步卒全派出去，只会白白把唯一的一支生力军，填进不知深浅的死穴。”顾承安的声音在寂静的堂中回响，“那位新人怎么做的？他冷着脸，逼两边把眼下的厮杀细节、藏着的暗器、到底缺多少斤两的军需，全报准了。然后，先调了运粮车走还能过人的商道去送木料，却死死把最精锐的刀斧手捏在手里，全派给了那面快被杀穿的残旗。等他亲自下场查验那处带血的局部阵眼时，主帅的印把子必须当场交给副将。在这杀阵里，没人能同时握着两头生杀大权的虎符。”

他看着那商贾，目光锐利如刀：“你一张靠银票买来的优先飞票，扛得起这么重的身家性命吗？真要满足些富家公子的虚荣，大可另开些无关痛痒的练武场。但绝不容许靠着砸几箱银子，就把一个从没沾过血、没立过军令状的生瓜蛋子，强行捧成能把三军将士当棋子耍的大统领！”

堂里另一拨老顽固借着这由头，又开始鼓吹起当年那套老规矩，认为任何新事物都是洪水猛兽。

“够了！”岑绍庭猛地一拍桌子，震得茶杯嗡嗡作响。他环视众人，声若洪钟：“没蹚过的道，不代表永远是死路！当年没翻车的旧马车，也未必保得了你这辈子不掉悬崖！新开的黑市，大可去试，但必须在看清了底牌、摸透了钱箱、算准了死活的边界里蹚雷！就算你要封路，也得拿出铁证，说出为何封、何时再开，绝不是一句‘坏了老祖宗规矩’就能糊弄过去的！”

他将那两页被朱笔划过、却终究被允准的状纸推回商贾面前。

“能放行的生门，按规矩放行。”

岑绍庭站起身，走到窗前，推开窗，一股冰冷的风瞬间灌了进来，吹散了满室的沉闷。

“守在这山门前的那柄剑，要是永远只知道死气沉沉地横在当道，早晚有一天，会把真正想做清白买卖的刀客，全逼上梁山。一夫当关的判官，既要声若洪钟地说清这剑锋挡住了哪半步死穴，也得有胆色，让查清底细的路，再次大开方便之门。”

黑市挂牌那天，场面有些冷清。有嫌弃盘口太小、没油水的赌徒，看了一眼便扭头就走；也有人老老实实掏出银子，买了一段听得顺耳的曲子，心里门儿清，这玩意儿就是个消遣，往后绝对生不出半点利息。自立门户的各战区，依旧按着铁打的规矩收录凭真本事吃饭的刀客，没有哪个堂口，会因为黑市里没捞够油水，就厚着脸皮回头去找底下卖命的弟兄抽头——譬如，从一笔四万八千元的抚恤金里，强行“扣除72.5元电费，实付47927.5元”这种荒唐事，在这里，永远不会发生。

当晚发往全江湖的风信里，一字一句，清清楚楚地列明了哪几道门已开，哪几条暗巷还得继续扣着等候过堂。

生门没有一刀切死，但也绝不允许，把那些根本就不存在的虚无画饼先放过去，再指望明天去哪里抓些替死鬼来买单。
