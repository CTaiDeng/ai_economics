# 第5章：劫残鸿影

那最后一笔填坑的赎命本金，竟比总堂新发榜的投名状，还先一步沉沉地拍在了刑堂那张油光发亮的八仙桌上。

钱箱是两口，樟木的，包着铁角，落地时发出的闷响，让整座肃杀的大堂都为之一颤。庄承裕的脸色比堂外铅灰色的天还难看，他硬生生从齿缝里挤出了四个字：“四千，现银。”

这四千两引路茶水钱，是他刮地三尺，几乎是跪在地上求来的。顺着这根藤，他又从几处早已废弃的暗桩里，像饿狼刨食一般，抠出了另外两千两。统共六千两，银锭上还带着地窖的阴湿寒气。

刑堂的老判官，一个枯瘦得仿佛只剩骨架的老者，眼皮都未曾抬一下。他身后的算盘珠子拨得如同疾风骤雨，每一声清脆的撞击，都像一记重锤敲在庄承裕的心口。这六千两赃款，与早先退回密库的那七万两千两，分头核着铁账，每一笔的来路、去向，都得用血淋淋的原始票根来对。半个铜板都不许算重，更不能是从底下那些刚把卖命钱捂热的苦哈哈手里抽血，拆了东墙补西墙，好让同一块黑招牌下的小喽啰，去替真正的罪魁祸首顶那要命的缸。

“新进赃银六千两，”老判官的声音嘶哑如铁器摩擦，“核对出处、苦主名录、前期汤药费，按开仓放粮例，即刻发还。”

这六千两，堪堪补足了那二十二个刀客还没填上的本金窟窿。上一回的七万两千两，加上这一回的六千两，共计七万八千两。老判官的算盘打到最后一颗珠子，猛地一停，堂上死寂。

“七万八千两，”他缓缓抬头，浑浊的眼睛里没有一丝温度，“恰与当初砸进花红池的九万六千两，刨去一万八千两旧账后，所余死亏，一文不差。”

吴秀榕、潘俊棠各自手里最后那两百两救命钱，终于落了袋。沉甸甸的，却像是烙铁，烫得人掌心发痛。没人凭空捞着那张“包赚三千”的画饼，也绝没人能拿原来的死契舔着脸再领第二回。破阵堂为了给自己犯的瞎眼错失买单、生生放出的那两万两血，依旧像一道狰狞的伤疤，死死钉在总堂的亏空账上。想找人分摊这笔血债？可以，另拿铁证来过堂。休想因为贼赃追回了，就顺手牵羊，把自己那份赔款也悄悄摸回腰包。

至于那些要上枷锁、蹲大狱的官司，自有六扇门去按律问斩。别的花销，也得一码归一码地过秤。总堂的黑榜上，只用朱砂笔，在苦主实打实砸进去的本金条目下，冷酷地勾了一笔——“两清”。

同一个更漏里送回的另一笔追赃，却被泾渭分明地隔绝在这六千两的池子外。

“魏泽安，”老判官念出这个名字，如同吐出一口冰渣，“三月，退赃六十两。本月，追缴一百两。尚欠六十两。”
“冯至成，退回拉人头赏钱，六十两。”

东瀚那头在短图死局里多砸的冤枉钱、底下刀客补的亏空、请人验尸的开销，都有各自独立的字号。谁也休想拿四海堂追回来的这笔带血贼赃去替他们平账，更不准把退回来的赃款，厚颜无耻地算成新搂的油水。

判官最终拍板，法槌落下，声音不大，却震得梁上尘埃簌簌而下。

“魏、冯二人，明知故犯，以假人头冒领花红，罪证确凿。原两轮禁令，不得接榜拿赏，继续执行。”他又转向冯至成，“剥夺验尸官腰牌。至于寻常的镖，接与不接，看局，看人，看天意。”

目光最后落在魏泽安的案卷上：“仍准许其在白场子练手、击鼓鸣冤。然，所欠总堂六十两，连同封禁时辰，白纸黑字，刻入案底，永不磨灭。”

追杀赃款的铁律，只认那几招下流刀法，狠则狠矣，却终究没有丧心病狂到，要将他们在江湖里谋生的活路与所有后手，一并赶尽杀绝。这收放之间的分寸，正是天山折梅手般的精妙，既断其作恶之臂，又留其残喘之命。

潘俊棠的飞鸽传书送到吴秀榕手里时，信纸还带着一丝山风的凉意。上面只有寥寥几个字：休沐日，江边走走？

她回了一个“可”字。可真到了江边，看着灰蒙蒙的江水缓缓东流，两人并肩而行，却不知该从哪句切口，接起旧日并肩作战时的那份从容。

百炼工坊里，喧嚣未散。有闲汉喝高了，瞎起哄，扯着嗓子要大伙儿画押表态，给四海堂重新敞开所有的生门。“赃银都吐干净了，冤有头债有主，还揪着不放作甚？冰释前嫌，重摆擂台嘛！”

顾承安坐在角落里，用一块麂皮慢条斯理地擦拭着他的佩刀，闻言，头也不抬，声音却像淬了冰：“恢复什么？”

他终于抬起眼，目光如刀锋般扫过众人：“寻常刀客应得的赏金，是账；私底下的交情，是人情；那些带血买卖的过所，是罪。这三者，本就是三股不相干的道。你们再大度，也休想让那些没盖总堂大印的黑市买卖借尸还魂。你们谁又能拿出铁证，证明他们那些见不得光的暗盘，已经洗心革面，从根子上断了？”

话音一落，满室皆静。

而在另一处堂上，庄承裕正死命分辩，声泪俱下。“我……我闻到腥风后，已在极力安抚那些买单的苦主！我庄承裕对天发誓，往后只干干干净净、盖了总堂大印的正经差事，求总堂给条活路！”

他话音未落，一直沉默旁听的邱庭舟，脸色猛然一白。那句话，像一根毒针，精准地刺中了他当年遭人暗算、家破人亡的旧疤。他霍然起身，太师椅在地上划出刺耳的声响。

“总堂主，”他对着上首一拱手，声音沉稳却带着压抑的颤抖，“属下邱庭舟，曾为类似暗盘所害，与本案有涉。为避瓜田李下之嫌，按门规，自请退到堂下，回避此案终审。”

他大可以把当年的铁证血书狠狠砸在那张八仙桌上，但他绝不容许自己，仗着眼下坐的这把太师椅，去亲自给自己受过的天大委屈，下最后一道判词。这是他身为棋手的骄傲，棋盘上的公道，绝不能沾染半分私人的血腥味。

最终的裁决，冷酷而精准，如围棋收官，寸土必争，却又留有活眼。

那些没沾过腥的四海堂清白喽啰，只要底子干净，验明正身，大可以另投明主，去接新的悬赏，或是新开香堂。从前在刀尖上舔血攒下的军功和赏钱，一律作数，分毫不差。

但原来那个引人入彀、拉客收黑钱的局盘，继续被死死钉在死牢里，永不超生。庄承裕这颗项上人头和他的腰牌，还得按着刑堂的规矩，一步步过堂问审，休想换个马甲就能逃出生天。但这雷霆之怒，也绝不至于一杆子打翻一船人，把那个堂口下的所有人，无论清浊，永远钉死在耻辱柱上。

一个早年在四海堂干过押镖苦力的汉子，壮着胆子跑来盘道，问自己能不能去顶海岬战区空出的那个肥缺。

老判官翻开他的卷宗，一字一句地念：“周阿牛，四海堂马夫，后晋镖师。入堂五年，未沾染半分卖黑名额的荤腥。腰牌验讫，清白。”

“按此次打擂规矩，准其下场。”

可另一个被揪出借着暗线情报吃独食的贼骨头，卷宗上的朱笔批注依旧刺眼：禁令未解。他头上的紧箍咒，依然死死念着，绝不能因为总堂追回了本金，就提前放他下山。兜里的赃款和江湖上的信义，本就是两本必须各算各的铁账。谁也休想拿一边的血，去洗白另一边的污。

底下有人忍不住嘟囔：“这么麻烦作甚？不如一刀切，把他们全家斩草除根，图个清静！”

岑绍庭一直冷眼旁观，听到这句，目光陡然射了过去，森寒如冰。“那些没动过半点歪心思的弟兄，被你们一刀砍了脑袋，他们的抚恤银子，由谁来出？”

他一字一顿地逼问，声如金石，硬生生忍住了拿自己当年被人借尸还魂、鸠占鹊巢的惨状来拔高调门。他比这世上任何人都清楚，被无辜地按在案板上，任人宰割是什么滋味。所以，他才更不能为了自己挥剑那一瞬间的嗜血痛快，连带把同一面大旗底下，那些甚至连刀都没拔过的无辜弟兄，给活活劈了。

过堂的铁律之所以没完没了地折腾，绝不是要故意把白菜豆腐说成满汉全席，而是必须，也只能，把每一刀的血，死死地、精准地，放干在真正该死的人脖子上。

江风猎猎，吹乱了吴秀榕的鬓发。她画押认清了追回的本金，冷着脸拒了堂口执事那种假惺惺举着大红花照影留念的烂戏，依旧将那份复核的字据，郑重地揣进了怀里。

潘俊棠在山门外候着她。两人顺着江风，先是有一搭没一搭地扯着天色，最后，还是潘俊棠先咬了牙。

“有些时候，”他看着江面，声音有些发涩，“我真他娘的不想去揭你的伤疤。”

吴秀榕沉默了片刻，低声道：“我……也是。”

钱能填上的黑洞，算是填平了。可那些在油锅里备受煎熬的时辰，那些被逼到悬崖绝路、夜夜惊醒的惶恐，根本没有一个能一笔勾销的死契。

吴秀榕停下脚步，迎着风，细细地把那纸字据叠得四四方方，像是在收殓一件遗物。潘俊棠就那么静静地站在一旁，死死地等着，等她妥帖地将那方寸之物收进贴身的暗囊，这才重新迈开步子，与她并肩继续往前蹚。

就像一局熬得呕心沥血的残棋，终于在某个惨烈的死角，点清了劫材的得失。棋局是终了，可坐在十九路棋盘两边的两个人，早已精疲力竭，还得重新学着，怎么咽下满嘴的苦水，再开口说话。

他们谁也没拿那个“钱已两清”的破印戳，去逼着对方当场拔剑四顾、相逢一笑。有些江湖，是回不去的。

总堂张榜的黑头字，只冷冰冰地新刻上一笔：“赃款入库，计六千两。”

剩下的烂账，全都单开一页，另案处置。绝没有半个字，敢吹嘘什么“江湖信义已重见天日”。程砚舟冷眼扫过初稿，亲自划掉了底下人添油加醋补上的一句“同舟共济”。

到了夜半，海岬战区交接阵眼的秘本上，果然浮现出那个叫周阿牛的旧日押镖汉子的新代号。而在他的代号旁边，明晃晃地留着他从前效命的山头——“原属：四海堂”，以及这回新挂的帅印。

一个在刀尖上讨生活的人，大可以继续往下蹚，用不着非得先把过去的底子全泼上白灰，涂成一张白纸。但也绝不该，替旧主子身上所有的血债，去背一辈子的黑锅。
