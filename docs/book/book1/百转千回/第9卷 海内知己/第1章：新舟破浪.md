# 第1章：新舟破浪

四月的风还带着刺骨的寒意，吹过香堂高阔的门楣，卷起一缕若有若无的檀香。许嘉榕从那张坐了数年的紫檀木交椅上退了下来，挪到了下首旁听的冷板凳上。硬木的凉意透过衣衫渗入骨髓，一如她此刻的心境。面前不再是那方能定人生死的朱红令旗，只剩下一沓沓码放整齐的卷宗，纸页边缘因反复翻阅而微微起毛，上面用蝇头小楷记录着拔营交割的最后一道道手续——那曾是她的生死簿，如今是别人的。

堂上，六把雕花太师椅已按着新签的死契重排了座次，冰冷的木纹在昏暗的光线下泛着幽光，像极了棋盘上刚刚落停的棋子。顾承安依旧稳坐中宫，替总堂掌着那面纹丝不动的帅旗。岑绍庭的脸膛在跳动的烛火下显得有些亢奋，他顶替了陆宏远留下的那个专管外八路山头的交椅，眼神里是压不住的野火。底下那些在刀口上舔血的刀客们，则合力将邱庭舟与苏怀青二人推上了这权力的棋盘。剩下的两个席位，仍由号脉的老郎中坐着，只是其中一张换了新面孔。

拜帖里的人情香火，拿命换来的汤药钱，以及那些必须摆在明面上避嫌的恩怨情仇，都在这敞开天窗的香堂里，一笔一划地清算。虎符交接的年限被一枚狼牙钉死死钉在文书上：六月底，分毫不差。

苏怀青的身影并未出现在堂中。她的人远在千里之外，却仿佛在每个人的背后投下一道清冷的影子。她的决断，全凭飞鸽传书与千里眼送来的密报。过堂的卷宗早已一式两份送至她手边，连香堂议事中留给她辨认加密口令的时辰，都用特制的更漏一格一格地刻进了流程里。众人急着翻篇，将旧日的烂账一笔勾销时，她那封从天而降的信笺，却总能冷不丁地用朱笔圈出一处看似不起眼的破绽。于是，整个香堂的议程便如同一队冲锋的铁骑，被一道无形的缰绳猛地勒住，人仰马翻。谁也休想拿“黑榜上已经刻了苏怀青的名号”这种虚文来糊弄，当成她已经点了头。

第一把出鞘的刀，就猝不及防地横在了岑绍庭的脖颈前。

他粗着嗓门，嫌每开一次小香堂，就得把旗下的人马从头到脚重验一回正身、搜一回身家，太过繁琐。“都是在江湖上滚了多年的老字号，”他拍着桌子，震得茶碗盖当啷作响，“那些陈年拜帖，墨迹都还没干透，直接拿来充数，省下的灯油钱，够弟兄们多喝几顿了！”

“省灯油钱？”一个清冷的声音响起，不响，却像一根冰针扎进每个人的耳膜。邱庭舟不知何时已站起身，他并未拔剑，只是将那柄连鞘的长剑轻轻横置在黑胡桃木的长桌上，剑鞘与桌面发出一声沉闷的“咚”，压下了所有的嘈杂。“岑堂主，你偷懒省掉的，究竟是查验重复卷宗的功夫，还是连人家新开盘的花红真假，都不打算验了？”

岑绍庭一张脸瞬间涨成了猪肝色，正欲拍案而起，脑子里却猛地炸开一道惊雷——那是去年九月份的惨痛记忆，一个笑面虎用一纸空头文书，就从他手里套走了整整三千两血汗钱，那钱至今还是一笔烂账。他攥紧的拳头青筋暴起，手上的力道却像被抽了筋，不甘不愿地松了下来。

邱庭舟的目光如刀，一寸寸刮过他的脸：“旧的字号、没过期的腰牌和未曾变更的死契，自然可以沿用。但只要接新镖、收新赏银、签新契，就必须把底裤扒下来，放在这香堂的灯火下，让所有人重新过目！若察觉出半点邪风，立刻打入刑堂大狱重审！”他的声音陡然拔高，“江湖上倚老卖老的资历，休想替后世的每一条歪门邪道盖上免死金牌！能省的，只是跑腿的功夫，绝不是守擂的命！”

岑绍庭硬生生将那口恶气咽回肚里，视线重新死死盯住邱庭舟用剑鞘尖端挑出来的那一行蝇头小字。他感觉自己像个刚学棋的雏儿，被人一子点在了天元。在棋馆里，他大可仗着早年记熟的几个定式，对新人指手画脚；可一坐上这过堂的太师椅，便绝不能因为自己早年在刀尖上滚过一遭，就狂妄地把这十九路棋盘上后来的千般变化，都当成一盘算死了的老局。

风波未平，又一份声称能省下判官验尸费的新套路被送来试水。堂口的判官们按着老规矩的准星一探，递上来的两百份悬赏案卷，竟瞎了足足二十二份，错漏之处，生生踩破了一成的红线。可笑的是，若是让这套路自己查自己，却次次都能滴水不漏地蒙混过关。岑绍庭本想仗着一股蛮劲，赶在休沐日强行开香堂通过，可苏怀青的朱笔批注随着信鸽一同抵达，信笺上只圈出了两处颠倒黑白的死案，便让他自己黑着脸撤了出兵的令箭。那些已经拔刀上阵的活计，总堂只好动用库里备好的真金白银，请回德高望重的老判官去一一结清。在阵上流血的弟兄，绝不能为了总堂想省两个铜板的瞎折腾，去吞那颗粒无收的零报酬苦果。

火器营的人只得捏着鼻子，去外头寻了几个毫无牵连的验尸官，又重新搜刮了两百份无人碰过的生案卷来考校。这一次，总算只错判了四份，堪堪挨着及服线。即便如此，也只准许它半遮半掩地重新下场试水。陈驰更是冷着脸，亲自撕了那张吹嘘“一朝神功大成、永不退转”的膏药大旗，另立了规矩：能吃下多少盘口、漏算几刀算是破功、以及随时准备接盘的老判官名册，全都白纸黑字写明，贴在榜上。只要敢越过红线半寸，立刻叫停封杀。

这一番中途勒马和重新开堂，烧掉了整整两千两银子，一文不少地记在了春季清理门户的带血铁账上，休想从那些报废的卷宗里偷偷抹掉。

堂前再起波澜。一道跋扈的请战帖被呈了上来：一支杀老了的死士营，妄图凭借赫赫战功，永远霸占海岬战区过江渡口的头把交椅。邱庭舟一言不发，只是将总堂的粮草底账和各路人马的换防军令甩在他们面前。“往日在刀光血影里攒下的军功，确实能当你们竞镖的筹码，”他的声音没有一丝温度，“但这绝不意味着，后来提刀的后生们，就得一辈子坐在冷板凳上等死。更不容许那些连活人都不剩几个的空头名号，像个死劫一样，死死卡住所有人的生门！”他环视四周，“我们这些过堂判官，审的是天下人入局的铁律，不是来当越俎代庖的阎王，直接下令把哪支杀红了眼的队伍强行褫夺兵权，赶下前线！”

话音刚落，轮到一份与岑绍庭自家山头相关的买卖。他脸色一变，立刻站起身，对着众人一抱拳，识趣地自报家门，退到堂外避嫌。旁边的候补判官随即上前，顶上了他的位子。他不能因为自己曾经被贼人摸了营寨，如今一坐上太师椅，就大喇喇地免了别人上堂应诉时，必须挨的那一百记杀威棒。

角落里，许嘉榕正低头整理着交割的最后文书。她交出去的，绝不是一句拍着胸脯的“我已经干了多少”。那些悬而未决的死结，每一个都用朱笔钉死了攥在手里的把柄、当下的死活状态、下次过堂的时辰，以及新接手判官的名号。那些击鼓鸣冤的苦主，也同步收到了用火漆封缄的原样复刻字条。

吴秀榕冷着脸，目光如炬地追问：“账上那笔二百两的抚恤银，还在不在？”

新接手的账房先生不慌不忙，从铁皮柜里扒出旧日的画押回执，高声答道：“吴堂主请看，死契未变，银子分文未动！还有那二十二个刀客被黑掉的六千两血汗钱，也一并在此，绝没有因为跨了年、换了当家人，就凭空蒸发！”

那道斩钉截铁的飞鸽传书，本就是交割兵权的一环。休想只在密阁的黑榜上偷偷画个押，就大言不惭地通告天下，说所有人都已有了着落。

陆宏远的身影早已消失在江湖的另一端，他一门心思去盘算南离自己山头的新棋局，不再来蹚这口天下人共用的水井。但他自立门户开香堂的腰牌，却没被摘去。有人不解，向程砚舟盘道，为何不让他身兼两职。程砚舟只是冷声回道：“既然钱庄里已经有龙头坐了那把交椅，他自己大可去递战帖、递案卷。绝不能因为他对这个江湖的暗道门清，就活生生凭空多出一张永远不死的护身符。”

邱庭舟在一旁冷耳旁听，思绪却猛然被拉回了许多年前。他想起自己当年在风雨飘摇中，为了保住一块小小的招牌，不得不咬碎牙根去和四海堂死磕的日子。如今，这柄能断旁人生死状的判官笔就捏在自己手里，他绝不能只把那些跟自己流过一样血的冤屈，才当成是值得抬手一管的正经事。他提笔，给手下第一道生杀令批注了铁证如山的门规，然后敞开大门，准许对方逐字逐句地登堂击鼓，当面对质。

那支判官笔，入手冰凉，竟比当年只敢在墙角偷偷刻下自己名字时，还要沉重几分。邱庭舟曾无数次在绝境里，眼巴巴地盼着能有一位大侠从天而降，一脚踹开那扇密不透风的死牢大门。如今，他自己披甲按剑，守在了这道生门之前，才恍然大悟：在拔出那把威风凛凛的镇堂一剑前，必须先硬着头皮，听完来访者嘶哑的哭诉，问清他究竟想要过哪一关。

日头偏西，金色的余晖穿过窗棂，在地上投下斑驳的光影。许嘉榕妥帖地收好了移交虎符的最后一张回执，转身离去，去谱写她那支尚未唱完的残局悲歌。卸下这身发号施令的行头，抹不去她当年在阵前流过的血，却也不容她继续攥着一把藏在暗处、能操纵江湖生死的黑钥匙。

正此时，堂外传来一阵金鼓齐鸣，那是十九路棋盘上传来的帅旗交接的轰鸣。老元帅搏命留下的伤疤，将永远镌刻在卷宗之上；但下一道能调动千军万马的带血军令，已经裹挟着新墨的清香，实打实地从新接印的帅帐里，扔了出来。
