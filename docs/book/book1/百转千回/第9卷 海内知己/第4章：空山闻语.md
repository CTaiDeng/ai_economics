# 第4章：空山闻语

苏怀青递上那份判词的时候，堂上正燃着三支手臂粗的牛油巨烛，烛火却被穿堂的寒风压得几乎要舔舐到微温的烛泪。那份卷宗很薄，只有一页纸，搁在三寸厚的黑胡桃木卷宗堆上，像一片随时会被吹走的枯叶。

然而，就是这片枯叶，承载着千钧之重。

她的笔迹清瘦却遒劲，如同在冰上刻痕。上面没有冗长的陈情，只有几句见血封喉的质问。

“有的英雄帖，帖上明明写着‘山门洞开，好汉请进’，可真接了镖，却要逼着人立下死誓，不眠不休熬上七天七夜，心血耗干方才作数。这究竟是招揽，还是索命？”

“有的鸣冤鼓，只认千里之外飞鸽传书送来的画影图形，说这是铁证如山；转过头，另一份状纸又死咬着苦主必须亲自过堂，验明正身，少一道疤痕都不算数。这规矩，究竟是为验明真伪，还是为了拒人于千里之外？”

苏怀青的目光扫过堂上几位面色各异的执事，声音不高，却字字清晰地砸在每个人的心上。“我们那本号称人丁兴旺的生死簿，上面记满了名字，却从未记下过那些摸到山门前，又因这重重矛盾的门槛而无奈扭头，消失在风雪里的孤魂野鬼。从死契上除名的人，极少留下临终遗言，因为在他们咽气之前，早已被我们当成了无名之辈。”

她伸出一根手指，轻轻点在那页纸的留白处，那里用朱砂小字，钉死了几处吃人的死穴。

“总堂的铁账，算得太精，也算得太绝。就像一个围棋国手，只盯着十九路棋盘上那些已经做出两个真眼的活棋，然后就敢拍着胸脯打包票，说这盘棋大势已定，还能再容纳多少人马进来做活。可那些在风雪里奔波数月，始终找不到一处气口落子的弃子，他们的死活，他们是如何在棋盘外咽下最后一口气的，竟连被写进结案陈词的资格都没有。”

这番话，如同一记无声的耳光。

邱庭舟得了准许，拿着那份薄薄的判词，像是捧着一道滚烫的军令。他不再枯坐堂中，而是亲自去听那些被视作“杂音”的风声。他听到一个中年刀客沙哑的嗓音，说家有老母幼儿吊着命，他只能接三日内往返的短途镖，那种动辄封锁半月的阵仗，给座金山他也不敢去。他见到一个脸上带着狰狞烙印的汉子，那人武功极高，却不愿在人前露脸，他说自有法子能用信物和暗号验明正身，可总堂的规矩却非要他摘下面具，任人评头论足。他还收到过几封信，信里的人对这种步步为营的杀局毫无兴趣，却被总堂的暗探三番五次地递上帖子，那口气仿佛是天大的恩赐。

“这些人，”邱庭舟在议事堂上将一沓访录拍在桌上，发出沉闷的响声，“绝不能用一句‘怯懦避战，不愿卖命’就轻飘飘地盖棺定论。我们更不能天真地以为，只要把英雄帖的烫金字做得再花哨些，全天下的好汉就会像飞蛾扑火一样，自己往里钻。”

负责布阵的总管，一个名叫季衡的男人，脸色冷得像数九寒天的铁。他驳斥道：“有些阵势，必须在同一个更漏的鼓点上同时发难，差一分一秒，满盘皆输。难道要容许有人躲在后面，等先锋营分出生死胜负了，再去放马后炮收渔人之利？验明正身的铁律，更不会因为谁蒙着脸就网开一面。要为那些杂门偏道铺设专门的接引路数，哪一条不要拿真金白银去铺？我们总共就16台机柜、120台服务器的算力，每秒钟要处理1.2Tbps的讯息洪流，那些底子薄的小香堂，能敞开几扇门就不错了！”

苏怀青与邱庭舟对视一眼，不再多言。两人索性拔出鞘中之刀，对着满墙的招募贴，开始一刀一刀地削骨剔肉。

“这一条，‘冲阵岗’，”苏怀青的刀尖点在一张榜文上，“必须卡死时辰。榜上要用血字标明，倒计时167:59:59内必须入阵，入阵即交割兵权，不得转圜。这是死地，要让想进来的人看清楚。”

“这一条，”邱庭舟的刀锋划过另一张，“战后收尸、抄写战报的闲差，凭什么要人通宵达旦地守着？改为分段招募，三个时辰一班，谁有空谁来揭榜。”

“能用纸笔画押的状纸，就留下递字条的路数。信物为凭，见字如面。”

“必须凭千里传音、靠暗号认人的死局，就在发榜时把规矩说得死死的，丑话说在前头，别等人来了再关门打狗。”

“吃不下长更漏熬煎的，大可去揭那些切碎了的短途悬赏。但规矩也要跟上：绝不容许一人分饰两角，在同一个时辰里，同时领两份赏钱。这是对那些专心致志者的公平。”

一炷香的功夫，墙上的榜文被划得面目全非，却也脉络清晰。总堂的铁律，从未狂妄到要逼着每个人都成为十八般兵器样样精通的杀神；但也绝不该允许任何一个判官，仅仅因为某人不配提某一类刀，就大笔一挥，断言这汉子在整个江湖里，都不配有一个站脚的坑。

那份号称“广发天下英雄帖”的文书，被苏怀青当堂打了回去，掷地有声。

“这东西，骨子里只认那些能点得起长明灯、能整夜不睡画影图形的阔佬，竟还恬不知知耻地想把全天下还没下场的看客，全都算成迟早要来送钱的肥羊？”她声色俱厉，“我要求你们，把总堂能吃下多少盘口的红线，给我一笔一划地画清楚！那些压根没递过投名状、也从未沾过总堂半点油水的人，绝不能在铁账上被我们强行按着头，替他们领下所谓的‘生态奉献激励金’！这不叫普度众生，这叫强取豪夺！”

程砚舟一直沉默着，此刻他默默提起朱笔，走到一面记录着江湖游侠名录的墙边，将上面一行刺眼的“择机唤回”四个字，一笔笔地涂去，改成了三个字：“死活不知”。

他头也不回地说道：“没有盖过手印授权的飞鸽传书，就是骚扰。绝不能打着探究兵法、切磋武艺的幌子，就对人家死皮赖脸地追魂索命。在江湖上，沉默，本身就是一种懒得搭理的闭门羹。我们得听得懂。”

堂下角落里，一直闷声不响的陈绍武嘟囔了一句：“不露脸过堂，确实能省去不少被当堂喝问的哆嗦。可……可我头一回想进来击鼓鸣冤的时候，那份状纸，硬是让我像个无头苍蝇，在总堂的几道暗门之间绕了足足半个时辰。里头那些黑话切口，什么‘一票否决权注销’、‘信托处分’，我扒着眼皮看上三遍，也是两眼一抹黑。”

一直负责接引新人的顾承安闻言，脸色微微一变。他索性将一份新拟的状纸递给陈绍武：“你，现在就去走一遍流程，从头到尾。”

他死死忍住，没有在旁边提点一句“那块地砖踩了不翻板”，也没有暗示哪个窗口是虚设的。他就这么眼睁睁地看着陈绍武，像一只撞在琉璃墙上的苍蝇，几次三番又绕回了死胡同，额头上渗出细密的汗珠。顾承安几次想伸手替他扒开那道生门，但终究咬着后槽牙忍住了。

一阵彻骨的寒意从他心底升起。他这才惊出一身冷汗：原来自己每天闭着眼都能蹚过去的熟路，在刚摸到山门的雏儿眼里，竟是一座藏在深渊里的八卦阵，每一步都可能是万劫不复。他自己，这守着山门的老狗，只管扯着嗓子对外面喊“大道朝天，只管进来”，却熟稔到连在岔路口插个路标的规矩都忘了。那些从千里之外跋涉而来的刀客，脾气再好，怕也只能被这扇看不见的铁门，活活憋死在山脚下。

这哪里是考验，这分明是筛选，筛选出那些和他们说着同样黑话的“自己人”。

修改过的状纸，被顾承安亲自用最粗糙的市井白话重写了一遍。上面钉死了什么时辰能敲鼓、要备好什么供词、谁会来接状纸、几时能给判词。至于那些盘根错节的生死免责死契，依旧锁在柜子里，可供查阅，但绝不准再用一句轻飘飘的“包教包会包活命”去糊弄人。只为了指出阵图上一处看得见的瞎指挥，总不该逼着人家，先把整套奇门遁甲的创派密卷全背下来。

同一天深夜，议事堂再次开堂。苏怀青靠着飞鸽传书送来的字条，远程过堂画押。眼看更正后的判词还没传到所有人手里，主持议事的大堂龙头就有些不耐，想往下过下一场。

“且慢！”

邱庭舟猛地一拍惊堂木，声音不大，却带着一股不容置疑的决断。他硬是让传令官将一字不差的卷宗副本，分发到在场的每一个人手里，等到所有人都确认无误后，才对龙头拱手道：“可以接头了。”

她那一拍，争来的绝不是什么可怜巴巴的施舍和眼泪，而是一次与桌上所有硬汉平起平坐，能把话说完、把规矩看清的铁血权力。

散堂时，有个一直在下面听壁角的闲汉，也是被暗探劝诱来的，他临走时若有所思地嘟囔了一句：“原来这门规，也是可以靠递字条来讲理的。”

他没有拍着胸脯发毒誓说一定会入伙，总堂的铁算盘上，也没因此多出半个铜板。黑榜的底账上，只冷冷地记下了一笔：“探路风声，一则。”绝不准把收到一句风凉话，就吹嘘成整个江湖都来归顺。这份清醒，带着一丝彻骨的寒意，却也无比真实。

最后，方婉音提笔，亲自走到山门外那面巨大的招募旗前。她用一把锋利的小刀，将旗上那句“百无禁忌、来者不拒”的牛皮，刮得干干净净。然后，她用最朴实的黑墨，老老实实地列清楚了堂口能给几分汤药，能分多少红利——从“基本参与份额五百元”到“差异池七千元”的浮动，再到扣除“72.5元”的电火耗损后实付的账目，都写得明明白白。同时，也列清了几道过不去的死门槛。

这山门，绝不是你拿朱笔在牌匾上写下“迎客”二字，就真的一路坦途了。

“倘若，”她放下笔，对着凛冽的寒风轻声说，“仍有人在门槛外栽了跟头，我们第一件要做的事，是竖起耳朵，听清楚人家骨头折断时的那声脆响。这远比逼着他跪在门前，磕头证明自己对总堂一片忠心，要实在得多。”
