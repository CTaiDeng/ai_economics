# 第3章：无须夺魁

寒风如刀，刮过城北的青石板路，卷起零落的煤灰。钟厚良第二次从这工坊门前走过时，脚步不由自主地黏在了地上。头顶上，一块崭新的黑漆匾额在铅灰色的天幕下沉沉发亮，三个擘窠大字“百炼工坊”，笔力雄浑，隐隐透着一股熔金锻铁的烈火之气。而真正让他挪不动步的，是立在墙根下的一张朱砂红榜，上面招募的，是战区画图评书人。

他这几日刚像老牛清圈般，将几桩急等下锅的杂事一一犁清，脑子里还嗡嗡作响。此刻，眼角余光瞥见红榜前已围了几人，有人正伸出指节粗大的手，隔空比划着某场城战中九曲回肠的攻防路线，钟厚良心中猛地一动。他想起自己有多少次，在那些烂熟于心的街口巷角，被旁人一句似是而非的胡言乱语带进了死胡同，耗费了心神，却离真相愈发遥远。他深知自己没有临阵控局、拔刀杀人的本事，那一身筋骨早已在岁月中磨钝了。但他忽然生出一股执念，想试试看，自己这双旁观者的眼睛，能否将一条旁人死活摸不清的幽深暗道，给一寸寸拆解个明明白白。

这工坊的规矩，透着一股子怪异的磊落。

头一关，是分文不取的死练营。钟厚良揣着七上八下的心思，硬着头皮下场，在那沙盘与旧案卷宗里摸爬滚打了一番，探清了这活计究竟要扛起多重的分量，这才敢将自己的名帖递上去。练手的差事，只许用那些早已尘埃落定、过了气的旧案卷，绝不会硬压着刀客的脖子，逼他们交出一整套能立刻拿去黑市换钱的崭新图谱。这就像学棋，让你拆解的是古谱，而非逼你当场献出独门的飞刀定式。

验明正身的规矩更是奇特。工坊只看你一件事：能否将亲眼所见的真章实据、道听途说的虚言妄语，以及凭空掐算的后手变招，像庖丁解牛一般，清清楚楚地撕搂开，分置于不同的竹篮。他们会暗中核验你的身份来路，但仅此而已。绝没有那些江湖堂口里的恶俗习气，非逼着你解开衣襟，亮出两道见血的旧日刀疤，或是报上一个曾在何处扬名立万的花名。你大可以在这道门槛上失手，狼狈地跌下擂台，但绝不必先卑微地剖开自己，去自证当年曾给哪座山头卖过命。

待到正经发榜，那香堂里只肯留下八个带花红的战报评书位子。钱袋子有多深，能让你摸到第几卷秘藏的底账，接的是什么品阶的差事，几时必须交差，所有条款都在放榜的那一刻，用墨钉死死地钉在了榜文上。验过正身，才准许你上前画押，签下那份死契。绝不搞那套阴损的招数，哄着满山头的应募者把成品的图谱全都呕心沥血地画完，到最后才假惺惺地站出来，说只取前三名封赏。

下场操练、抢位夺旗、登台分金，这步步为营的三道大关，被一道无形的墙死死隔开。任何一步，都休想拿后面那还没见着影儿的军功，倒打一耙，来糊弄眼下这个实实在在的名号。这棋局，开盘、中盘、收官，泾渭分明，绝不容许混淆搅乱。

这回来过堂验身家的，统共有十二号人。红榜挂出之前，规矩便已写死：八个坑位，差事一模一样，只要你的功夫到了那条及格线上，便都是同等挑落的候选。至于谁能坐上那八把交椅，全凭一道大白于天下的抓阄排座次来定夺。倘若哪路阵眼非要动用那些懂得奇门遁甲的偏门异术，必须另设一座打擂的台子，另立一套规矩，绝不准到了开香堂撒钱的时候，再往里头临时塞进几个掌柜的熟面孔。看门的汉子只管按规矩收名刺，外头请来的老判官一双鹰眼，死死盯着人头和那个深不见底的抓阄竹筒。候补的，也只能眼巴巴地按着手里的签号，挨个儿等着顶位。

钟厚良的手伸进竹筒时，指尖冰凉。他摸出来一看，是个“捌”字。他身后一个挎着腰刀的精壮后生，摸着了第九号。

那后生眼尖如隼，一把揪住榜单，死咬着黑榜上有一个名字似乎被墨笔改动过，当场便要击鼓鸣冤，声称有人暗箱操作。堂内的气氛瞬间凝固，空气冷得能拧出水来。账房先生面无表情地从柜子里翻出原始的画押回执，铁证如山地拍在桌上。那纸上清清楚楚，是同一个人在画押时写错了字，自行划掉更正，与名额无涉，半个多余的签号都未曾发出。

这桩公案，在队伍开拔前就已过了堂，判得明明白白。钟厚良和那个九号后生，手里被塞了同一套堂堂正正的判词。落榜的第九号，大可留下死等候补，也可掉头投奔别家，或是就此卷铺盖走人，但有一条：他绝不欠这总堂一幅白嫖的战区地图。

钟厚良攥着那张冰冷的死契，生平头一次，没有把别人跌下擂台，当成是自己刀法更高的军功章。这门里，统共就摆了八把交椅，他抓中一根签，不过是拿到了上桌讨口饭吃的过所。他这偶然的一抓，救不了门外那个汉子的一身饥荒。这盘棋，不是你死我活的对杀，只是争一个入局的先手。

这盘棋的彩头，是实打实的看客茶水钱和买路钱。刨去明面上护院家丁的嚼谷用度，一笔两千四百两的花红池被死死锁进了一个铁箱。八个没把差事办砸的刀客，无论高下，每人先兜底拿走六十两的汤药费，算是安身立命的本钱。剩下那一千九百二十两，全凭放榜时就已亮在明面上的杀敌真章来论功行赏，绝不准任何人在事后临时起意，更改规矩。

钟厚良心里还是不踏实，像个初入江湖的雏儿，小心翼翼地盘道，要是自己这活干砸了，会不会牵连家里从善堂领的那份救济过冬粮？账房先生抬起眼皮，冷着脸给了他一句准话：“绝不会。那是另一笔干干净净的香火钱，用不着拿你这一次下场的脑袋去抵押。”

他领了将令，回到自己那陋室，把战图在桌上铺开，倒腾了两遍。头一回，他生拉硬拽地套了一堆故弄玄虚的武林切口，什么“灵蛇出洞”、“叶底藏花”，企图让图谱显得高深莫测。画完自己一看，只觉心虚气短。第二回，他才像个老实的学徒，顺着探子传回的视线，一笔一划，点破了前面的镖车为何会在一条九曲连环的回头道上摸错了门径，一头撞进了死地。他没在那场血肉横飞的杀阵里滚过，就老老实实扛着“局外评书人”的名头，把铁打的眼见之实、刀客嘴里吐出的带血供词，和他自己瞎琢磨的后手变招，用三种不同的颜色，死死分开。他绝不再拿自己从街头巷尾混来的那点脚力，去假充在战场上喝过人血的行家里手。

钟厚良咬着牙，用指甲把那几个花里胡哨的空把式划掉，重新勾出镖车冲锋的箭头，那笔直的线条像一道绝望的伤口。他悟了，学一门新的杀招，与其急吼吼地去吹嘘自己看透了整盘十九路棋局的通天机变，远不如先死死钉稳眼前这三两颗阵眼的死活。他终于能稳稳地伸出手指，指着图上那个逼仄的死角，用最朴素的言语，道破这个地方究竟为何能让成名高手也栽了跟头。

过堂分赃那日，气氛肃穆如法场。前三张帖子的赏钱，被高声唱出：一千二百两、五百四十两、三百六十两。这三笔钱里，都包着那打底的六十两汤药费。剩下那五个汉子，每人只领走了六十两。八个人，不多不少，分毫不差地将那两千四百两花红吞得干干净净。

钟厚良的手里攥着三百六十两沉甸甸的银子。六十两，是旱涝保收的安家费，是棋盘上的“眼”位，确保不死。剩下那三百两，则是刀头舔血、绞尽脑汁挣来的额外悬赏。他看着底下那五个汉子，他们也绝没因为没挤进前三，就被判官从花红簿上一笔抹去了名号。

这份分赃铁账上的筹码，死死钉着十九、八、五三个数，剩下的全吃零蛋，统共三十二份。那一千九百二十两池子里的活水，被这三十二份筹码劈开，每一份，都实打实地兑出了六十两真金白银。钟厚良得了五份。那五份只捞着底薪的帖子，也本本分分画完了图，只是在挑错漏、拆解套路和引旁人验看这几项硬功夫上，连半点见血的铁证都拿不出来，自然只能捏着那点汤药费，算是收了官子。这排名，是算盘珠子一粒粒打到底，才硬生生抠出来的。规矩里写得明白：要是第四张帖子里真能杀出一记带血的变招，整个池子里的算盘和八个人兜里的赏钱，都得当场推翻重算。绝不能因为台阶上只站了三个人，这花红池里的水，就被他们几个全数鲸吞。

他攥着赏钱，心里头高兴，却又憋着一股子邪火。他死活觉得，自己在某个阵眼的拆解上，那一步棋的妙手，绝不比第二名那个汉子来得软弱。他犹豫了半晌，最终还是一横心，硬着头皮去敲了判官的登闻鼓。

老判官竟真的升堂，给了批语。账面上的筹码一分没涨，但也绝没因此就断了他下次接镖的路数。判词里说，他那一手虽有巧思，却失了全局的势，是妙手，却非胜手。敢于上堂盘道，绝非贪得无厌；判官没给他涨钱，也绝不意味着他这面鼓敲得毫无道理。

钟厚良把那份批语揣进怀里，那点邪火还在烧，却不像刚踏进这工坊大门时那样，连个屁都不敢放。他头一次明白，原来拔剑问理，压根不需要你先成了什么天下第一。只要你敢把这口不平之气，有理有据地拍在八仙桌上，而对方也肯规规矩矩地按着门规接你的招，那么这一趟登门，便没算白折腾。

他转头又去了善堂，问这笔新搂的横财该怎么记账。管事的回话依旧是那副公事公办的腔调：这个季度已经发到手里的过冬粮，绝不会反过来倒扣一文；下回过堂时，自然会按着明面上的铁律，去查哪些是细水长流的进项，哪些是撞大运的横财，绝不至于脑子发昏，把这三百六十两直接当成他每个月铁打的月钱来算。是亏是赚，白纸黑字，写得明明白白，绝不能让底下人拼死拼活赚了钱，回头才发现自己的底裤，被总堂在暗地里无声无息地扒走了。

在这笔刚焐热的血汗钱里，他抠出一百二十两，买了三张去城中小茶馆里听高手盘道拆解战图的听书票；又留了六十两作防身的盘缠；剩下的一百八十两，被他用油纸包好，死死压在了箱底。他没像个红了眼的赌徒，把所有身家都押上去博那更大的花红；而那百炼工坊，也断没有那个脸面，逼着他掏钱去买什么劳什子的千里传音法器，好假惺惺地吹嘘这门生意如何“生生不息”。

他想起头一回进香堂操练，手底下的功夫生涩得很，画出的一张八仙桌歪斜得像是随时要散架。带路的老把式却没半分不耐烦，捻着胡须，把阵线的虚实、气口的厚薄，拆碎了揉烂了讲给他听，然后让他把图卷回去，接着磨自己的刀。后来，工坊想拿他那份得了三等的帖子去集市上挂榜招摇，被他硬邦邦地挡了回去。他只想把这张图留下来，当成自己房里的沙盘，时时推演。而他掏过真金白银买来的那些过堂指点，也绝没因为他这点藏拙的心思，就被暗中克扣了分毫。

许嘉榕听他盘完这些流水账，指节轻轻叩着温热的茶杯，却没有跟着灌那些“天下英雄，皆能凭手中之剑混得饱饭”的迷魂汤。她看得清楚，这汉子家里那几口锅，还得靠善堂的过冬粮吊着命。这种刀头舐血的赏金，终究是有一搭没一搭，下一局棋，他未必还有胆子再下场。

只是，这十九路盘上，确实硬生生地多出了一道可以落子的气口。

有一招棋，今天，他终于能自己说了算。不为别的，只因他自己想下。而不是必须先扒开胸口的刀疤，向全天下证明，他一定能活着从那片死地里爬出来。
