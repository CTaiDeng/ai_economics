# 第10章：棋外春山

五月末的熏风已经带上了燥热的先声，自窗外涌入，却吹不散程砚舟书案上那份计划书透骨的寒意。

那不是一份寻常的盟约，而是一张妄图鲸吞天下的扩军战帖。洋洋洒洒数十页，用最时髦的西洋打印体，描摹出一幅宏伟蓝图：天下十八路诸侯，要在同一个更漏——精确到一百六十七小时五十九分五十九秒的倒计时结束那一刻——同时拔刀，向旧日秩序发起总攻。军令状上的期限催得紧过索命梵音，招牌上已经用浮夸的图表算好了能揽下多少生意，那些数字鲜红刺眼，像是提前预支的战功。许多八字还没一撇的香堂，连舵主都未定下，便已在这张阵图上被赋予了名号，全指望着他星原这面大旗能先扛起来，去镇住那些心怀鬼胎的金主。

他将那份装订精美的“血书”翻来覆去踅摸了两遍，指尖捻过纸张，仿佛能感到下面虚浮的脉动。握刀的手，仍忍不住微微发热。当年他负气离开霁岳堂，就是看不惯袍泽兄弟被当成棋盘上的弃子，为了所谓的大局，被卖得干干净净。如今，一张更辽阔的阵图铺开，似乎许诺了一个前所未有的愿景：一夜之间，让全天下所有无路可走的刀客，都有一个避风港湾。这股开疆拓土的凛冽杀气，并没有因为四海堂那场倒灶的败局就彻底冷去，反而在心底某个角落死灰复燃。

程砚舟的视线，顺着那张排兵布阵的羊皮卷，一路朝着化外之地摸索。那感觉，就像是面对着一张十九路棋盘，边角星位已定，中腹却留着大片的浩淼空白。他几乎能听见心底的魔音在蛊惑：只需在此处拍下一颗冷子，便能借势连成一片，化作滔天的大阵。

可等他的目光扫过那几个关键的支撑点，那些标记着“生态奉献激励金”和“基本参与份额五百元”的条目时，那股虚火被一盆冰水猛地浇灭，退回了眼前。他看到了几个根本无人镇守的死门空缺，那是阵法的气眼，也是最致命的破绽。他心头一凛，这盘棋若是连自己手边几条赖以活命的气口都护不住，局铺得越散，留给旁人绞杀的断点就越多。

“这三万六千个节点，是怎么点出来的？”

沈婉衡的声音清冷如冰，不带一丝温度。她不知何时已站在他身后，目光同样落在那份计划书上。

他喉头一紧，下意识地想去遮掩，却已来不及。他支吾着，指着纸上那些密密麻麻的名录：“这是……这是各地报名领了腰牌的，这是答应摇旗呐喊、搭了草台班子的，还有这是……满大街撒英雄帖，有意向加盟的……”

可他越算，声音越低，心跳越是擂鼓般惊惶。他发现，自己竟在自欺欺人。为了凑出一个足以震慑投资人的惊人数字，他竟将同一批千余人的散兵游勇，在铁账的不同名目下，连加了三次。一次算作“核心贡献者”，一次算作“社区合伙人”，一次又算作“潜在孵化项目”。

她没有替他拔刀，甚至没有流露出一丝鄙夷。她只是伸出纤细的手指，轻轻点在财务附录的一行小字上：“差异池七千元。预估净利三百万。你用这笔还没影的横财，去为这张空头支票画押作保？”她的声音平静，却字字诛心，“程砚舟，还没真刀真枪落袋的银子，就不是你的。就如同我们之间那道还没磨平的暗沟，也绝不会因为我肯屈尊看一眼你这破阵图，就算一笔勾销。”

程砚舟的脸瞬间涨红，又转为煞白。

回到百炼工坊，那间永远充斥着服务器低沉轰鸣、冷气森然如冰库的机房，他寒着脸，传下了一道铁律。

“推演暂停。”他对一脸错愕的杜启航说。

杜启航正站在一面巨大的全息投影前，那上面是模拟出的“千里江山图”，十路大军齐发的动态光影如水银泻地，壮观无比。他激动地辩解：“砚舟，你看，只要我们同时启动两万个节点，峰值流量可以冲到1.2Tbps！这足以冲垮任何一个对手的防线！”

“那不是我们的节点，是别人的。”程砚舟的声音冷得像机房里的循环冷却液，“我不管沙盘上推演出了什么。现在，立刻，给我挨个堂口查！第一，执旗主将的法人身份，必须验明正身，一票否决权绝不能旁落。第二，香火钱，我要看到银行水单，每一笔基本参与份额五百元都必须是实缴验资。第三，拼刺刀的死伤，也就是压力测试下的SLA（服务等级协议），我要看到极限数据。第四，买路钱，也就是通道和服务器成本，十六台机柜一百二十台服务器的托管合同在哪？第五，撤退的生门，信托处分和清算机制必须写进章程。第六，暗藏的杀招，对方的商业机密保护和反渗透预案是什么？”

他顿了顿，一字一句，如铁钉砸入木板：“非得在漏壶滴尽前，先做一局小盘试阵。能活下来，再谈鲸吞天下的事。”

对方显然被这套抠抠搜搜的查账方式激怒了。他们回信说，这般畏首畏尾，压不住阵脚，更撑不起原来那套哄骗大钱庄往里砸钱的鬼话。几番往来，这份吞天地的狂书，便生生谈崩了。

机巧造出的千里江山图固然能铺满整面墙壁，没有灵魂的虚拟假人也能靠着西洋钟表般精准的程序演练大军过境，但这绝不代表沙盘上真有千军万马的活人来领军令状，更变不出实打实入账的花红和现银。哪怕这套“星原”的造物机巧能变幻出千百种江湖路数，也绝不配替代死契上按压的每一个血指印，和一厘一毫的真金白银。

杜启航仍不死心，独自在沙盘上推演着那虚幻的十路大军。可程砚舟的一双冷眼，却死死盯在阵图上那三个挂着空名的督军大印上。他知道，真到见血拔刀时，上峰的军令、底下人的汤药钱、交接印把子的火线，每一个环节都必须像最精密的齿轮般分毫不差地咬合死。绝不是为了壮胆，把大旗上的名字全换成活人，就算真吞下了这片天下。那是化功大法，吸来的内力驳杂不纯，第一个走火入魔的就是自己。

他们最终只留下了几道能凭真本事互通有无的清白切口，绝不肯把“星原”这块金字招牌，借出去替那些来路不明的黑钱作保。

眼睁睁看着鲸吞天下的时机溜走，滋味确实如鲠在喉。这般守拙，如围棋中的“单官收气”，未必能在铁算盘上扒拉出最多的油水。但他们死死咬住了一条底线：自己绝没有半点权力，抢先把一个还没蹚过雷的杀阵，强行许配给那些信赖他们的无辜弟兄。

判官桌上，照旧飞来几份状纸。有新加入的山头，想把散碎买卖的手续费砍薄些，理由是薄利多销，聚沙成塔。也有老账房冷声示警，说这帮人蚂蚁搬家似的没完没了讨碎银子，早晚会酿出白蚁蚀空的滔天大祸，动摇总堂的根基。

两派的飞鸽传书一并压在八仙桌上，程砚舟既没因为眼下这套门规还算吃得开，就一口把死言路封上；也绝不会因为对方声势浩大，就随便换个切口，把一笔烂账当成从来没过秤的新买卖。

岑绍庭亲手交上来一份砸锅的排兵残卷。一个新来的刺头毫不留情地点破：有些老一辈刀尖舔血总结出的死理，比如“一个节点宕机必须在三十分钟内完成热切换”，根本套不牢眼下这帮年轻小子的野路子，他们宁可用“去中心化”的法子让几个节点一起瘫痪，只要整体算力不受影响就行。休想把前辈趟雷的血泪录，硬按成必须照着画葫芦的死阵图。

早先交了腰牌下山的刘景和，照样敢来总堂击鼓鸣冤，说他之前的贡献没有被公正计算。接状纸的判官同样客客气气递上回执，立案归档。没了那张坐堂的虎皮交椅，他也绝不必从这江湖的生死簿里除名。

严知敏手里的算盘打得劈啪作响，每一颗算珠的碰撞都像金石之声。她死死扣着二季度的中途开销，一笔笔核对，精确到小数点后两位。六月之后的粮草，全凭新打下来的真金白银来定，手头库房里仅剩的那点底子，绝不拿去无底线地广发英雄帖招人头。

许知妍则像个耐心的猎手，把卷宗里那些没捂热的空洞和暗中蛰伏的肥羊分头圈出。每一个摸不准的黑坑旁，都用朱笔死死钉着下一步必须挖出的血证。她绝没有因为卷宗留白看着丢人，就敢拿毛笔硬画几道“大捷”去自欺欺人。她宁可留着那些难看的伤疤，也不愿用谎言的纱布去包裹。

堂上，一个谱曲的匠人正与众人争得面红耳赤。他有一套独门的编曲心法，自视甚高，却死活找不到肯按他开的价码付香火钱的堂口。一怒之下，他索性把自己的绝活锁回了铁匣子里，声称宁为玉碎不为瓦全。

没卖出个好价钱，不代表那套本领就是一文不值的破铜烂铁。但总堂也绝不会因此就大发慈悲，从库房里掏出真金白银，替他把这笔瞎账给圆上。程砚舟看着那匠人倔强的背影，终于按下了自己那只闲不住的手。他想起了自己从前的老毛病，总想给天下所有人都强行塞一把凳子，让他们坐得舒服。如今他明白，有些人，注定是要站着的。

那匠人把心血结晶揣进怀里，抱拳一揖，转身告辞，准备另投明主。

程砚舟只送到山门前便定住了脚步，渊渟岳峙。他没有再假惺惺地给他画一个“有朝一日必当重用”的大饼。一个背井离乡的人，大可揣着一身还没被相中的硬功夫去别处漂泊。这诺大的江湖里，本就该容得下一柄还不屑出鞘的冷剑。

五月的更漏快要见底，总堂的灯火并未彻夜长明，去吹嘘什么“千秋万载，一统江湖”的虚妄。十九路棋盘上，仍留着几处未曾开辟的暗阵，案头上，还压着几分未画押的死契。或许明日，有新的亡命徒会踏破山门，也自然会有人暂且看不上这盘血肉模糊的残局。

那些空白，绝不全是下错了的昏招。有些残缺，本就该留给后来人。

留给他们，按着自己最顺手的那套刀法，去破局。
