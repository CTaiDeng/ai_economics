# 第8章：万里比邻

五月的锦川，暑气像一头刚出笼的凶兽，将整个河谷盆地都烤得滋滋作响。官道两旁的白杨树无精打采地垂着叶，蝉鸣嘶哑，搅得人心烦意乱。就在这片燥热的土地上，一座新开的山门前，并没有高高悬起那面熟悉的、绣着星辰与旷野的“星原总堂”认祖大旗。取而代之的，是一块崭新的黑漆楠木匾额，上面“锦川战区”四个大字，笔力雄健，新刷的桐油在烈日下泛着刺眼的光。

锦川这头的坐馆龙头是个面皮黝黑的汉子，行事却滴水不漏。他早已亲自跑了趟府衙，将地盘和开馆的手续在六扇门的卷宗上过了明路，一应文书烙印齐全，料理得比账房先生的算盘珠子还清楚。此地的阵盘，依旧严丝合缝地连接着总堂那套验明正身的底座，确保每一位刀客的身份都能追根溯源。新添的地方兵刃，也悉数呈报给判官核准，每一柄刀的重量、刃口角度、打磨工艺都记录在案，死死圈在容许的杀伤力范畴之内。至于那些踩着线的偏门火器，则被厚厚的油布包裹，老老实实地锁在武库深处，静候不知何年何月才能下来的批条。

金主的赏钱，和发给旗下刀客的汤药费、安家钱，每一笔都从锦川自家钱庄的底账上真金白银地支取，流水清晰，与总堂的账目各自独立。该上缴总堂的岁供和江湖行走的名册，则按着各自项上的脑袋分别兜揽，绝无半点含糊。

这便是锦川战区头一回明码标价，发榜押镖的开场。

当地两家最大的杂货商贾，是此番的东家。他们从自己仓廪里实打实的盈余中，分别掏出了两千两和一千六百两雪花银子，买的不是虚名，而是实实在在的买路平安。摆在台面上的彩头——两批定制的兵器，从重量、刃口到打磨手艺，都出自同一炉火、同一位匠人之手，全无二致。唯一的分别，只在于刀柄上用错金工艺镌刻的是“恒通”还是“四海”的字号，以及各自对应的这场杀局的排场大小。谁也休想靠着吹嘘自家刀快三分的江湖口舌，来糊弄买家雪亮的青眼。

三千六百两赏钱落袋，铁账上明晃晃地钉着每一笔款项的去向，字迹是新兑的墨，带着一股冰冷的铁锈味：六百两，定为车马费，支付沿途驿站、草料与损耗；四百两，归山堂抽水，用以维持这方堂口的日常运转；二百两，压作箱底，以防途中出现任何意料之外的变数。剩下整整两千四百两，才被悉数注进悬赏的花红池中，成了引得无数亡命徒眼红的血酬。

画了死契的十二个名额里，八人是提刀上阵、直面生死的先锋，四人则留在后方，负责抄写战报、摆弄沙盘推演，维持整个场面的运转。规矩是死的：只要能活着把这趟差事办完，无论功劳大小，每人打底先领五十两辛苦钱。这便去了六百两。余下的那一千八百两彩头，则全凭各人在刀口上舔了多少血、规避了多少风险，按实打实的军功来分。

这笔钱，与数月前辰川钟厚良那场同样标着两千四百两的死局，泾渭分明，毫无干系。它们各自有各自的债主，各自画押的死契，和各自提刀的亡命徒。这是一种铁律，绝不容许任何一方的判官，仗着共用一个沙盘的便利，就私自动用那传说中的“五鬼搬运诀”，将这边的银子挪到那边去填窟窿。

锦川这盘棋，便沿着自己先前布下的气口，一步步往下推演。

头一拨负责打更探路的老弱，已将部分镖车推到了村口。当那些真正负责真刀真枪厮杀的好汉们接手时，第一件事便是过秤点清剩下的粮草和火线，一丝不苟。没有人会厚着脸皮，把前头那段安稳的脚程也算进自己的战功里。远在海岬战区的老关，只是个旁观者，他所看到的，是迟了半个时辰才传来的风声与光影。他休想仗着自己在那边挂着的帅印，就直接来这里越俎代庖，发号施令。

窄渡口的生门，被一场突如其来的漫天箭雨封死。现场的一哨人马在队长的嘶吼下，本能地要先拿装甲最厚重的冲车去硬闯阵线。然而，负责探雷的斥候却在坡顶的土石中，瞥见了一丝濒临崩塌的死相，他声嘶力竭地发出警示：重车一过，巨大的震动必会引发塌方，彻底断绝后路！

执旗的主将，在那一瞬间的生死抉择中，选择了相信斥候的判断。他手势一变，令旗挥下，阵法立时更易。重车原地驻守，轻骑营如离弦之箭，骑士们一手控缰，一手将金创药高高挑起，冒死冲向对岸的伤员。大队则转头就地取材，拼死抢修被箭雨摧毁的栈道。

终究，有两箱不算救命的辎重，被永远地截在了更漏的时辰之外，葬身火海。从结果上看，这趟押镖算不得大获全胜。可是在战报上，斥候那双蹚出暗雷的毒辣眼光，掩护轻骑冲阵时壮烈牺牲的弟兄，他们身上每一道伤口、每一滴鲜血，都被原汁原味地记录下来，留下了无法磨灭的血色痕迹。这一切，绝不会被一句轻飘飘的“未尽全功”就一把抹去。

老关在那延迟的战局倒影里，眼睁睁看着那两箱没能抢出火海的辎重，化为灰烬。他没有急着叹一句妇人之仁的“可惜”。隔着千山万水去看，这十九路棋盘上，仿佛是在收官阶段，被人白白刮去了一角实空，亏了目数。可只有将你真正按在当时那个箭如雨下、土石松动的逼仄死门里，你才会看清：若是多贪那一手“活棋”，试图保全所有，也许整条赖以活命的气口，都会被塌方的巨石生生碾碎。这是弃子争先，是断尾求生，是棋盘上最冷酷，也最慈悲的道理。

杀青复盘时，锦川本地请来的唱曲人，用的是一首早已向官府报备过的旧时小调。那熟悉的旋律，轻易便勾起了乡亲们对往昔岁月的回忆。然而，下发到众人手中的铁券军令，却依旧死守着总堂统一编排的切口与格式。方婉音坐在马车里，透过一面小小的晶石镜看着这一切，本想挑剔那唱词的停顿拖得太长，显得滞涩。可当她瞥见台下的听众，恰恰在那个节骨眼上，全都鸦雀无声，悄悄红了眼眶时，便硬生生将到了嘴边的话咽了回去。她决定先听，听那戏子如何用这“不合规矩”的腔调，圆上这出戏。

而在另一折戏里，同样有人因不耐烦这拖沓的节奏，直接拂袖而去。冷面判官将这两样截然不同的回馈，一并用炭笔刻进了案底的竹简上，不带任何感情色彩。绝不会因为有一段戏催人泪下，就漫天撒谎，吹嘘全场都听得如痴如醉。

那套在总堂用得熟极而流的排兵布阵之法，到了这片生分的土地上，忽然显得有些水土不服，处处滞涩。方婉音索性将那套准备好的修改兵法，暂时按回了剑鞘。过江拜码头，总得容人家把自家的乡音唱完。若是才听了半阕，就急不可耐地拔出自己惯用的、快如闪电的刀法去强行斧正，那所谓的“切磋”，也不过是换个山头，拿着鞭子抽打别人，强逼他们当自己的提线木偶罢了。

场间，一位金主派来的探子，只顾着死催大伙去背诵他家的字号，仿佛多念一句就能凭空生出银子。而另一家的探子，却耐着性子，在摊位前答疑解惑，讲解兵刃的优劣，反倒引来更多的人围着他盘道。大掌柜并没有被这点表面的热闹冲昏头脑，他那双鹰隼般的眼睛，依旧死死盯着账本上真金白银的买卖数额，和每日退换货的折损率。嘴上的几句好奇，绝不能当场变成能入库的真金。更不能因为谁愿意多掏腰包捧场，就在他核算军功的铁账上，平白给哪位刀客多加上三两赏钱。

陈驰从千里之外，隔空帮着验了一处战报上的名头。最初的卷宗上，只大剌剌地盖着一方香堂的大印，却死活翻不出是哪个刀客，在何时何地，挥下了这夺命的一剑。锦川那头的管事倒也上道，接到勘误的飞信后，没有丝毫推诿，老老实实按着死契上的条款，将个人的功劳簿重新补齐，并挨个找到当事的苦主，让他们亲自画押认领。既没敢图省事打个马虎眼，把这笔功劳银子平分了事；也没想过要把这分赃不清的烂摊子，推给那套负责演算沙盘的西洋机巧。

最后，那两千四百两花红彩头，一文不少地，按着验尸过堂般的铁律分发了下去。打底的汤药费，稳稳罩住了十二条好汉的饭碗；而手艺上的高下之分，则各自单开卷宗，列明缘由，清清楚楚。中间甚至还查出了一处批注上的纰漏，照样被一丝不苟地递交给了不相干的第三方铁面判官，进行重申复核。没有哪个人敢因为觉得这场子小，就顺手把那面供人击鼓鸣冤的登闻鼓给砸了。

有人拍着胸脯，唾沫横飞地保证，下回一定自掏腰包买票捧场。也有人一毛不拔，只肯在旁边蹭着金主施舍的白戏看。判官们只将这些，全当成一阵尚未成型的风声，录入卷宗，却不计入考评。坐堂的，绝不会拿这些还未落袋的画饼去摆阔充门面，也并未端起架子，去痛骂那些白看的看客不知江湖规矩。

收兵回营的路上，马车蹚过铁索桥，发出“哐当哐当”的巨响。千里传音的信号，也因这山谷的阻隔，断了一截。方婉音蹙着眉，问身旁的程砚舟：“这排阵的步子，是不是跨得太碎了些？仿佛处处着子，却未成大势。”

程砚舟的目光依旧望着窗外飞速倒退的山岩，声音冷得像淬火的精钢：“能搭起这么个小堂口，只是落成了一桩买卖。这局棋能不能一直摆下去，得另算。”他顿了顿，续道，“要是下一季，寻不到下一个肯心甘情愿掏香火钱的金主，那就干脆卷铺盖停手。总堂，绝不会靠着往里死填银子，去强充什么‘分舵遍天下’的虚假门面。”

马车驶过铁索桥，世界重归平稳。方婉音点开了那段被准许带回总堂的、带着浓重地方口音的旧时唱段，闭上眼，重新静静地听。

两地之间，虽已有了几笔能跨江咬合的买路钱，有了可以通用的腰牌底账，可这并不代表，两边已经连成了一张可以闭着眼睛随便蹚、全天下都恪守同一种规矩的星罗大阵。

这更像是一盘尚未下完的棋。在遥远的对角，各自占了一个星位。万里之遥，看似比邻，却仍隔着无数的变数与劫争。
