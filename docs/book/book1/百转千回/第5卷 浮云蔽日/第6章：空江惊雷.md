# 第6章：空江惊雷

朔风如刀，割过刑堂高耸的檐角，发出鬼哭般的呜咽。

罗振业没有走暗门，他带着极轴那份字字泣血的自证文书，就这么一步步踏进了这片早已被愤怒与绝望烧得滚烫的庭院。他甫一现身，门口一个眼尖的债主便认出了他，那人双目赤红，像一头被困在陷阱里的野兽，嘶吼着扑了上来：“罗振业！黑市那杆招兵大旗上，明明挂着你们极轴的字号！如今盘口崩了，血本无归，你们就想脚底抹油，溜之大吉吗！”

罗振业的步子没有半分迟滞。他渊渟岳峙，任凭那股夹杂着血腥味的怨气扑面而来，身形稳如磐石。他身后的宋振峰，脸色冷得像堂外那尊淋了半夜冰雨的铁狮子，他将一摞用鲸油鞣制过的硬牛皮账册重重拍在院中那张巨大的黑胡桃木判官桌上，发出“砰”的一声闷响，震得桌上笔架嗡嗡作响。

“极轴，确实给真刀真枪的战役捐过粮草，也签过以命相搏的保底死契。”罗振业的声音不高，却像一口沉钟，清晰地压过了所有的嘈杂，“但这，绝不是千礁那伙人用来画饼充饥、吹嘘包赚不赔的金字招牌！”

他与宋振峰，当着所有债主和刑堂执事的面，将那一册册能见光的底账逐页翻开。哪一笔款项画过押，哪一张契约没摁过手印，哪一分银子是战备军资，哪一厘钱是抚恤血酬，一桩桩，一件件，拆解得清清楚楚，明明白白。他们可以认在战场上流尽最后一滴血，但绝不能在这盘口崩塌之后，像个怯懦的鼠辈，只轻飘飘地甩锅一句“我家的帅印是被毛贼偷了去”。

然而，有一笔账，最是棘手，如同一根毒刺，深深扎在所有证据的核心。那便是被千礁剪进黑市通告里，大肆渲染的那一笔十二万元现银。

“这十二万，是二十户在战火里没了营生的苦命人，接下来三个月的安家费。”宋振峰的手指，像一柄冰冷的刻刀，点在账册上那一栏独立的款项上，“它被死死锁在独立的钱库里，每一文钱的去向都有名有姓，与你们在黑市里赌杀空的盘口，没有半分干系！”

千礁那帮吃人不吐骨头的恶狼，竟只截取了这堆白银冰冷的虚数，便对外大肆吹嘘金库里粮草充盈，后盾坚实，引诱着所有杀红了眼的赌客闭着眼睛押上身家性命。那些受助的苦命人，他们甚至不知道自己的名字被编成了一个美丽的谎言，他们从未在任何一张担保契约上画过押，更不可能因为领了一口救命粮，就莫名其妙地背上了替一群赌徒还债的滔天血债。

“放肆！”堂上的严知敏一声怒喝，腰间的佩刀“呛啷”出鞘半寸，寒光一闪，他厉声下令，“刑堂执法，即刻勒令黑市撤榜！混淆视听者，以同谋论处！”

话音未落，一个瘦小的身影从人群后挤了进来，正是刚刚领到头一笔保命钱的李惠兰。她听街坊传言说盘口炸了，吓得魂飞魄散，手里死死攥着那张还带着体温的银票，一路小跑过来，嘴唇哆嗦着，话都说不囫囵：“官爷……这，这钱……是不是得吐出来？我是不是……得拿回去？”她甚至不敢去给自己那双磨烂的膝盖买一副新的护膝，生怕自己多吃一口饭，就少了一块能替那个无底洞还债的肉。

“拿钱的底细、银子的来路与花销的去向，刑堂，全验过了。”严知敏走下堂来，宽厚的手掌轻轻帮她按住那张被汗水浸得发皱的银票，“李大娘，这钱，是你的活命钱。你犯不着为了那帮黑了心的牙行掮客，把自己下锅的米都赔进去。”

他亲自将李惠兰手里那张揉成一团的安家单在桌上铺平，让她用自己的眼睛，死死看清那上面只属于她的那一栏，白纸黑字，清清楚楚。门外那些讨债的狂徒叫唤得再凶，也不能像一群冲错了门的强盗，一见穷苦人家里还点着一盏灯，就非要凶神恶煞地逼着人家把仅有的破锅烂铁也拿出来抵债。

“我的名字……会不会……会不会被挂到城墙上当挡箭牌？”李惠兰颤抖着问。

“绝不张榜。”严知敏的誓言掷地有声，“在刑堂验明正身，是为了厘清公道，绝不是要把苦命人仅剩的里子也扒光了给人看！”

得到这句保证，李惠兰才像是从水里捞出来一样，长长地吁了口气，将那张银票死死捂进怀里，仿佛捂住的是自己的心跳。

工坊的另一侧，一名脸上带着刀疤的汉子走了过来，他刚从血腥的海岬战役里退下来，此刻一张饱经风霜的脸涨得通红。他低声问，自己行囊里还屯着一些军用燃料，能不能拿去折现，替大伙儿抵一部分债。他早先不明就里，糊里糊涂替黑市的人传过几句话，此刻悔恨交加，恨不得剖开自己的肚子来证明心迹。

顾承安走上前，冷硬地回绝了他这份搏命的好意，声音里却带着一丝敬意：“兄弟，心意我们领了。但这批燃料是战区锁死的军用物资，每一滴的用途都有军法盯着，只能由在编的死士在火线上挥霍，烧出一条血路来。它绝不能随手拉到黑市上换成大洋，更不能凭着账面上的几个虚数，就拿去填饱那帮赌徒贪婪的胃口。”

同理。账本上那些用人头换来的杀敌战功、那些还只在图纸上画着的宏伟蓝图，以及那些被层层封印在铁匣里的军机密要，所有这些东西，全加起来，也变不出一分一毫能拿来还债的现洋。

周慎衡挥起他那支浸透了朱砂的判官笔，笔锋如刀，将这些虚无缥缈的幻影从追债簿上一笔一笔地刮掉，发出刺耳的“沙沙”声。

“金主的粮草，必须有带血的死契和白银过手！”他的声音像冬日里的冰凌，“卖命的买卖，必须有真刀真枪的火拼！分赃的权力，必须要有敢拿自己脑袋来抵押的冤大头！那一串串华丽的总数背后，都必须有一个活生生的人来割肉放血！绝不能用另一个更大、更漂亮的虚无泡影，来无底线地填补眼前的死穴！”

角落里，千礁的代表庄承裕还在不知死活地狡辩，他脸色煞白，汗珠沿着鬓角滚落，却依旧妄想着能说服众人：“各位，各位听我说！眼下强行收刀，只会断了我们原本能源源不断流进来的财路！只要……只要下一局我们把盘口开得更大，用新入局者的血，就能轻易填平眼前的血坑！做大做强，才能掩盖一切……”

程砚舟的后槽牙咬得咯咯作响，指关节因为用力而根根发白，但他终究没有当场拔剑。他也曾被这种“做大做强就能掩盖一切死门”的毒药诱惑过，正因为他太懂这种幻觉有多么致命，才绝不容许对方用它来搪塞今天必须用真金白银清算的死账。

他死死盯着庄承裕递来的那张画着更大饼的新阵图，那错综复杂的线条在他眼中，瞬间化作了一张十九路的围棋盘。他一眼便看穿了那上面最贪婪、最愚蠢的一步毒手：总以为只要在别处挑起更大的劫争，杀一条更大的龙，眼前这块漏风的气口就还来得及补。可笑！那下一手屠龙的杀招还虚悬在半空，今日被逼到死角的这块棋，已经陷入不收气的绝境，再退半步，就是棋毁人亡！

程砚舟一把夺过那张阵图，在众人面前，缓缓地、一寸寸地将它撕碎。

“下一局的生死，只能拿下一局的命去赌。”他的声音低沉而危险，如同淬了火的钢，“今天已经撒出去的烂账，今天，就在这里，必须见着真金白银的底！”

庄承裕哑然，面如死灰，他根本拿不出半文能抵命的实洋。

刑堂的算盘被打得震天响，每一声都像是在敲击着在场所有人的心脏。算盘珠子冷酷无情地劈开了那些早期的鱼饵、拉皮条的赏金、早已被秘密转走的赃款和钱库里剩下的那点残血。有人急红了眼，提议让几位在座的大佬先各自割肉凑钱，先把眼下这个随时会炸的火药包给拆了，等风声过去，再慢慢提刀追凶。

“呵。”周慎衡发出一声冷笑，他猛地一拍桌案，斩钉截铁地喝道，“自家的死穴自家扛！谁要是愿意义气千秋去拔刀相助，大可自己从家里掏出干干净净的银子来！但刑堂今日立下规矩：绝不能向江湖上放出话去，说往后所有那些乱七八糟的空头野誓，平台都闭着眼睛来兜底！更不许任何人，动那笔锁死在库里、留给前线拼命弟兄们的安家费！”

一阵冷风从门口灌入，杜启航提着刀，带着一身寒气走了进来。他刚刚在风口处接了孩子的家书，又匆匆写了封回信托人带走，沙哑着嗓子对信使说，今夜还要继续杀人，定了个时辰，说届时会再报平安，不让家里悬着心苦等。

当他带着一身霜雪重新杀回刑堂时，墙上那张巨大的通缉榜上，经过周慎衡的判官笔一一勾决，只剩下几行触目惊心的死签：

谁，拿了见不得光的黑钱。
谁，画了那张弥天大谎的毒饼。
谁，在吸血的死契上摁下了自己的手印。
还有谁，在看见刀口已经崩裂之后，还在昧着良心继续拉人下火海。

远处的沙盘上，代表军用燃料的红色标尺，还在一格一格无情地往下跌。火线上的镖车，必须拿它去烧出一条活路。而在这现实里更冷酷的江湖中，那些带血的银子也早已被吞进了一个不知名的黑洞。

无论是哪个修罗场，都绝不可能凭空变出一个花里胡哨的新名号，就能把已经烧成灰烬的东西，再变回那黄澄澄、沉甸甸的金子。
