# 第3章：借名藏剑

方婉音是在一段被剪得七零八落的视频里，听见自己替千礁说了话。

光线冰冷的显示器前，空气里弥漫着机房冷却系统抽出的、干燥而恒定的低频嗡鸣。那声音穿透墙壁，像是某种蛰伏巨兽的呼吸。她看着屏幕上自己的脸，那是在三月初，二月第二个窗口期的参与款结清之后录下的影像。彼时春寒料峭，她还裹着一件厚呢大衣，对着镜头，逐字逐句地解释一笔四千五百元的款项所对应的创作参与、作品授权与收益分配的具体范围。那是一份严谨的契约说明，每句话都像天平上的砝码，精准，沉重。

而此刻，在新版的视频里，她之前所有关于权责边界的陈述都被一柄无形的剪刀齐根斩断，只剩下一句干枯而笃定的话——“这笔确实到了”。

话音未落，画面便被一只黑手粗暴地切入一张待售凭证的截图，凭证上赫然标着一个三千元的承诺。就这样，她那句对事实的确认，被嫁接成了一场骗局的背书。仿佛她方婉音，也亲手验证过那个虚妄的、稳赚不赔的许诺。

她调出未经腰斩的母带，苍白的手指死死抵在屏幕上，抵在那被剜去血肉的边界誓词上。指尖的寒意，几乎要透过玻璃，刺入骨髓。

方婉音听着那句被断章取义的、自己无比熟稔的声音，忽然间如坠冰窟。那感觉，就像是江湖上一个素未谋面的刺客，悄然借走了她旧日佩在腰间、视若性命的宝剑。她甚至不知道剑是何时离鞘的，再见时，它已饮饱了无辜过客的鲜血。剑柄上，分明还镌刻着她方婉音的名字，那熟悉的纹路与温度犹在，可那见血封喉的杀机，却早已换了主人。

林静薇的办公室里，气氛肃杀得像一座刑堂。她将那滴血的原件、被动过手脚的赝品，以及精准到秒的行刺时辰，三件物证一并锁入档案室厚重的防爆铁柜，发出沉闷的金属撞击声。她眼神冷厉，没有一丝多余的温度，一道封杀与纠错的追杀令随即下达，字字如刀。方婉音在堂上断然否认曾将自己的声誉借给任何钱庄作保，但她也没有仅仅甩出一句“我没拿脏钱”便心安理得地转身，漠视那些被毒箭射中的看客。她知道，这柄剑是她的，无论被谁借去，伤了人，她便有无法推卸的干系。必须追查下去，他们究竟是在哪个视野的死角中了暗算，那欺世盗名的假剑法，究竟是怎样一招一式刺出去的。

刑堂的审问之下，庄承裕终于支撑不住，哆嗦着交出了四海与千礁暗通款曲的那份生死契。纸页上，利益的划分像一条毒蛇，盘根错节。四海负责提供旗下刀客们过往的喋血履历和那些足以勾动人心的幌子，再按拉来的“人头”数量，从千礁的黑金里抽走一笔带血的赏钱。在这明面上的山门之内，他们只供奉着干净的牌位，讲述着荣耀的战绩；却在山门之外的黑市里，干着杀人越货、卖友求荣的勾当。

“那笔黑钱，根本没走你们的关卡。”他脸色煞白，还试图抓住最后一根稻草，强作镇定地狡辩。这是一种最低劣的腾挪之术，妄图在棋盘上划清界限，说这块被屠的大龙与自己毫无干系。

陈驰发出一声冷笑，那笑声里淬着钢。他一把将那份伪造的水塔战报——一份吹嘘着虚假战功的引流文案——狠狠拍在庄承裕的脸上。纸张碎裂，像一记清脆的耳光。“在江湖上吹嘘某人杀过几个人，和他妈的借着他这张人皮去黑市上倒卖包赚不赔的假银票，后果是天壤之别！”陈驰的声音不大，却字字千钧，“你以为换个分赃的堂口，就能厚颜无耻地说这事与你四海清清白白？”

刑堂的探子们顺着这条线，挖出了更深、更毒的一刀。四海的一个细作，竟将海岬平台严控在手的核心数据——那份详尽的出口布防图——偷运进私设的黑市，大言不惭地向那些被贪婪烧昏了头的香客们叫嚣：只要花钱买路，便可以优先挤进“包赚不赔的打劫大军”。

那笔黑钱，虽然没能买到什么绝世的神兵利器，却被妄口许诺能买到大帐里的军机，以及一场早就被内定好的凯旋。

消息传到顾承安耳中时，他正在沙盘前推演。他甚至没有抬头，只是伸出手，在沙盘上一处节点猛地一按，仿佛斩断了一条毒蛇的七寸。“断。”他只说了一个字，一刀切断了那条泄密的暗脉，并将险情以最高加密等级飞报给镇守核心战区的统兵大将。往后的排兵布阵，大可按着军规重布，这是弃子争先，是为求大局而必须付出的代价。可那些已经被玷污的战果和细作的罪责，必须重新过堂问斩。绝不能为了粉饰太平，为了抹平这块难看的伤疤，就悍然让整个战区倒退回没挨这一刀之前的那个虚假的、看似完美却暗藏溃堤之蚁穴的模样。

更何况，在这十九路棋盘上，从来就没有什么“包赚不赔”。杀赢了的人，也绝不是天生就能多吃一口肉；哪怕是力战而死的败军，只要对得起那纸生死契，照样能领到足额的安家费，至于斩将夺旗的重赏，另有铁律。那句包藏祸心的“包赚不赔”，在同一瞬间，将沙场上铁与血的搏杀，与山门里分毫不差的规矩，一并玷污了。

雷霆之击接踵而至。四海那几张用于拉客的门面与所有引流的暗道被当即查封，服务器端口被物理拔线，只给底下的普通刀客们留了一条仅供查验功劳和击鼓鸣冤的窄门。被坑了钱的苦主们怒火中烧，杀向官府报案。破阵毫不手软，将所有未经脱敏的原始罪证悉数呈堂，死死捏住了衙门盖了红印的回执。那些在大街上公然兜售空头银票的线索，被一并捅进了专办金融重案的官办刑部。究竟是江湖骗局，还是豪赌出千，只等衙门的杀威棒落下。

凡是系统里能联络上的金主与看客，都在第一时间收到了一封白纸黑字的警告帖，措辞严厉，不留任何幻想。可江湖的暗地里，浊流更甚。那些伪造的旧图非但没有死绝，竟还有人在带节奏，将刑堂的封杀令吹嘘成“即将绝版”的最后疯狂，像个输红了眼的赌徒，声嘶力竭地怂恿着那些被称为“韭菜”的人们，再往火坑里填上最后一笔血汗钱。

吴秀榕就是在手机上看到这句话时，才终于懂得自己前一天为何迟迟不愿回复陈驰的问询。她怕错过，更怕承认自己刚刚作出的决定可能错了。人就是这样，宁愿给一个坏消息再找一个看似合理的解释，也不愿直面一剑封喉的真相。

“我还转给潘俊棠了。”她的声音细若蚊蚋，把手机递过来，屏幕上是她和另一个朋友的聊天记录。“他问我，你们以前是不是都按时付，我说是。”

陈驰看着那行字，没有一丝责备。那句“以前按时付”，正是他们几个月来用无数个日夜的辛劳和汗水铸就的信誉。这信誉，本是抵御风浪的厚重船板，如今却被人拆下来，铺成了通往地狱的最后一截、也是最令人信服的路。

罗振业与宋振峰，两位在江湖上足以一言九鼎的大佬，分别发出措辞强硬的江湖通告，死死咬定，从未以个人或机构名义，为任何第三方产品画押签过什么保本保息的担保，更没有像黑市里吹嘘的那样，准备在下一季砸下任何托底的粮草。

而在公司内部，周慎衡，这位掌管钱粮命脉的“计相”，冷着一张万年不变的脸，直接在总账本上，将那笔与千礁相关的、可能流入也可能永不出现的款项，用朱笔戳上了一个“子虚乌有”的死印。而不是一个暧昧的、留有余地的“尚未入库”。这是定性，是斩断一切痴心妄想。

许知妍重新翻开那本惹出滔天祸事的旧版名册设计稿。屏幕上，那个刺眼的、由四海提供的统视图腾，其嚣张与醒目的程度，比底下那行标明生死状态与风险归属的法律小字，要强盛了十倍不止。四海那帮骗子固然包藏祸心，但这绝不能抹去平台自己在这张皮相上诱人上当的罪状。她在提交给刑堂的口供里，一笔一划，清晰地写明了当初在审批这套界面时，自己留下的所有视觉破绽和逻辑漏洞，绝没有等追杀的捕快替她翻出这页早已带血的旧账。

她死死盯住放大后的旧版名册，终于惨痛地看清，那行微薄如游丝的防卫小字，离那致命的杀招究竟有多远。在十九路盘上，她曾天真地以为，一处漏风的断点，可以靠着旁边威武雄壮的厚势来照应，糊弄过去。直到此刻，那柄淬毒的短剑，正是从那处被她忽视的“气口”狠狠刺入，瞬间绞杀了整片大龙，她才彻骨地发觉，那层所谓的厚实照应，那道看似坚不可摧的防线，从来就没有与那个致命的断点，真正连接上。

那一夜，海岬的灯火彻夜未熄。工程师们重新布下了将来用以杀出重围的死阵，而沙盘上的战火，却未曾有半刻停息。还在火线上搏命的刀客们，继续按照旧的虎符交割着任务；那些被内鬼扒掉底裤的倒霉蛋，正咬着牙等待刑堂给出的补偿方案；而那些已经拿着命换回赏格的功勋者，也绝不会因为一场别处的血案，就短了一分一毫的银袋子。

这些带血的事与干净的事，罪恶与信誉，崩塌与重建，就在同一个江湖里残酷地并存着。这幅景象，远比用一句轻飘飘的“全是真的”或“全盘皆假”来一笔抹平，要惨烈、艰难，也真实得多。
