# 第4章：黑云压城

千礁的雷，是从一声枯寂的系统提示音开始的。

起初，只是星原频道里一句零星的问询，带着周末夜晚特有的疲惫：“我的兑付怎么还没到账？”

如同一颗石子投入寒潭，涟漪并未立刻扩散。几张“处理中”的等待页面截图被贴了出来，有人用惯常的口吻安抚，说周末的清算通道本就拥堵如车马填塞的古道，慢是常态。更有人贴出过往的旧回单，那上面鲜红的印戳和精确到分的数字，像是一剂无效的定心丸。

然后，那些平日里最活跃、最热心解释规则的熟面孔，一个接一个地陷入了死寂。他们的头像暗了下去，仿佛被一只无形的手扼住了咽喉。

一夜之间，星原频道里挤满了咆哮与质问的洪流。恐慌是最好的瘟疫，它无视逻辑，焚烧理智。绝大多数人根本分不清千礁、四海与城北这三座码头的旗号有何分别，他们只认得那个曾在所有港口高高飘扬的、一模一样的图样。如今，那图样在他们眼中，已然成了招魂幡。

岑绍庭端坐于潮汐站的残局前。黑胡桃木的棋桌冰冷如铁，一枚枚云子在灯下泛着幽光。他正在复盘，指尖捻着一枚白子，悬在一处“断”的关隘上，纹丝不动，渊渟岳岳，如武当宗师入定。

冷不防，一柄淬毒的利剑从屏幕那头穿心而过。

那是一句诛心之问，裹挟着千万人的怒火，直指他的眉心：“你过去在潮汐站里杀伐决断，赢下的那些赏金，是不是也沾着我们这些后来者的血？是不是也来自那些被你们骗去买空头借条的替死鬼？”

岑绍庭的指尖猛地一颤，那枚白子险些脱手。一股灼热的怒气自丹田直冲天灵盖，他却硬生生将其压了下去。他强忍着拔剑砍人的冲动，将所有能摊在阳光下的粮草来源、每一笔分赃的账本，悉数亮了出来。每一条流水都清晰如刀刻，每一笔去向都明白如掌纹。

然而，棋盘对面的看客，早已不是能静心手谈的对手。阴阳怪气的嘲讽如寒风中的碎冰，劈头盖脸砸来：“你们这帮做局的，哪个不是账房高手？假账早就做得天衣无缝了吧？”

岑绍庭硬生生掐断了正要讲解的那一手精妙的退守，那本是弃子争先的妙手，此刻却无人关心。他抬起头，目光仿佛穿透了屏幕，迎向那片无形的杀机。他习惯了与另一个顶尖高手在同一张十九路棋盘上，为了一处劫争、为了哪一手更毒辣而呕心沥血，死磕到底。可如今，他甚至需要向一群乱兵反复证明，自己脚下踩的，究竟是不是同一片江湖。昔日刀口舔血、尸山骨海里搏杀出的赫赫凶名，此刻竟连半分威慑也挤不出来。

刘景和听见那句诛心之论，心头猛地一刺。他想起多年前，自己第一次为公道击鼓鸣冤时，是多么渴望能有一张撕不烂、烧不毁、能说清一切黑白的死档。可如今，这片江湖满地都是真假难辨的带血卷宗，杀人的凶器与救人的良方混作一谈，反倒让围观的看客们，连该相信哪一滴血是干净的都分不清了。

“锵！”

陈驰的刀是冷的，也是快的。他面沉如水，一刀劈下，将那些真刀真枪的战报、尚待审核的门面契约，与黑市里流出的贼赃死死劈开，泾渭分明。那些带血的私房口供，那些苦主们不愿公之于众的隐秘，是只留给刑堂主事的判官最后定罪的铁证，绝不能为了自证清白，就将受害者的底裤全扒光了，高高挂在城墙上示众。

另一边，杜启航在巨大的沙盘上推演，追踪着那些如瘟疫般蔓延的妖言。他的手指在无数数据流中疾点，揪出了一堆批量生成的克隆残影和凭空伪造的花名册。但在清扫战场的过程中，他脸色一变，发现了几条带着真血的冤屈，竟被那套冰冷的机关算法误判成了乱兵。他当即下令，撤掉封条，补上官府的红契。

更要命的，在沙盘的另一角。早先为了防住水军冲阵而设下的一套拦截暗器，竟冷血无情地将两名在火线上交接虎符的传令兵，也当成了敌人。他们之间一句按规矩核验的暗语，因包含了某些敏感的字符，被机关判定为克隆的贼赃。万幸的是，他俩保底的五百元基本参与份额没有被褫夺，可那份拿命拼来的、高达七千元的差异池重赏，却被这该死的机关硬生生卡了一整天。其中一人，一份本用来向战友证明自己何时何地替同袍挡下一刀的血誓，也跟着这桩乌龙，一头栽进了乱葬岗般的垃圾数据堆里。

许知妍咬着牙，亲手拔掉了那套机关的封死键。她的声音不大，却带着不容置疑的决断：“从现在起，所有相似度过高的卷宗，只作为查案的血迹存证，再也不准作为直接一刀切断别人生路的依据！”

两条带血的真凭实据，被人从数据废墟里手忙脚乱地捞了回来。该补的赏银，分毫不差，按照铁律重新计算。耽误的时辰和折腾的精力，一笔一笔记在了刑堂的烂账上，日后自有说法。

然而，机关的枷锁一松，刹那间，城墙上又爬满了难以分辨的重复鬼影。验伤的刀锋，被迫慢了下来。他们终究没能炼出一把既能斩尽天下妖魔，又绝不误伤一个凡人的绝世快剑。

“我是真的转给过朋友，别又说我是假人。”

频道里，一个孤零零的声音响起。这一次，没人再删掉那句话。

午后，海岬战场的修罗场里，战况急转直下。正在苦战撤退的阵线上，突然爆发了大规模的逃营。无数刀客被后方的流言吓破了胆，生怕自己用命换来的卖命钱也被那该死的千礁风波连坐封死，纷纷扔下兵器，仓皇逃命。

按照死契规矩，那些不知疲倦、不畏生死的NPC木偶立刻顶上了空缺的阵位。逃兵们此后自然再也分不到半文战功，但阵盘上为他们锁死的粮草依旧分毫不动——他们先前浴血杀出的保底份钱，照样作数。江湖的厮杀，绝不会因为几个人的落跑就停止。

可木偶再怎么死扛，也接不上活人断掉的那口气。一辆满载着重伤员的辎重车，就因为传令兵的断档，没能及时收到撤退的信号，连人带车，被敌方的炮火整个掀翻，折在了火线里。

统领海岬战场的大将面沉如水，亲手将这笔血债一字一顿地刻进了战史。他死死捏着交接的虎符，准备按人头来清算责任，但绝没有图省事，把黑锅一股脑全扣在那帮被恐慌冲昏了头的逃兵头上。江湖上真实的恐慌固然已经毁了一场惨烈的恶战，但这绝不意味着，可以将那些在黑市上被人骗光的烂账，强行塞进这场真刀真枪的赏金池里。

工坊大堂的门被猛地撞开。吴秀榕和潘俊棠红着眼杀将进来，潘俊棠的手里攥着一张皱巴巴的死契，像攥着一柄刀，直直逼到程砚舟面前。

“我不管什么千礁四海！”他咆哮着，唾沫星子横飞，“我就问一句，平台能不能先掏腰包，把我们那笔账垫上！等你们查清了，再去劈了千礁那帮王八蛋的人头！我只要一个今天就能吐出真金白银的活菩萨，不想再听你们那些名目繁多的糊涂账！”

程砚舟的双手死死按着桌沿，手背上青筋暴起，几乎就要脱口而出，将这笔天大的烂账全扛下来。那是一种他深深刻在骨子里的武侠冲动：当所有带血的、绝望的目光全都聚焦于你一身时，拔剑而起，大包大揽，远比低头承认自己护不住所有人要痛快得多。那是一种属于江湖儿女的、豪迈而致命的诱惑。

可他的余光，扫过了身旁周慎衡手边那堆厚厚的卷宗。那上面记录的，是海岬前线每一个刀客的卖命钱，是那辆被焚毁的辎重车里每一个伤兵的抚恤金。

那声已经涌到嘴边的“我担了”，终究被他死死地、一个字一个字地咽了回去。

周慎衡的脸庞冷得像一块冰。他甚至没有看潘俊棠，只是用一种不带任何感情的语调，斩断了那条最容易、也最错误的退路：“早已划拨给拼命弟兄们的粮草，哪怕是一个铜板，也绝不能挪去填黑市上的窟窿。”

他的声音在死寂的大堂里回响，字字如铁：“平台在此事中有失察之责，该担的，当用自己的净水银子出来担。绝不能因为黑钱没过自家的钱庄就推脱得一干二净，但也绝不能不分青红皂白，替这江湖上所有的野誓作保。”

他将一份文件推到潘俊棠面前，上面清晰地列着下一次升堂的时辰、已经掌握的查案血迹，以及追索赃款的每一步进展。

无期的苦等依然能将人逼疯，就算死死咬住了真凶的名字，也变不出那被骗走的两千六百块现大洋。但这死磕出来的答卷，这份带着具体时辰和路径的追凶令，终究比一句轻飘飘的“正在查办”，多了一处可以让刀锋相见的实地。

风暴的余波，开始冲击那些看似毫不相关的领域。南离的预订量应声下跌，原声社按条款退还了后续数个场次的门票。一家已经谈妥、只差落印的企业，也发来消息，暂停了尚未正式签下的合作。

尽管所有已经合法支付的参与款项，因账户隔离而安然无恙，没有一分钱被追回。但真实的信任，却从不会因为账户分开就自动隔离。它像水银，无孔不入。

深夜，庄承裕的电话还在喋喋不休。他在那头死命地画着一张大饼，用一种近乎癫狂的语调吹嘘，只要江湖的大盘稳住，只要信心不失，平掉这点账目不过是时间问题。

许知妍直接把冰冷的刀锋架在了他的脖子上，她的声音穿过电波，像冬夜的寒风：“别跟我扯那些虚的。我就问你，那笔已经到期的死账，究竟是从哪家金主的嘴里抠出来的？又是拿哪一块真金白银垫的底？”

电话那头的庄承裕，仍在疯子般地描绘着未来的海市蜃楼，对那刀口上的质问，死活不敢接招。

凌晨，方婉音黯然掐断了门面上循环播放的演示视频。她提着一桶冰冷的矿泉水，走到山门外，挨个分给那些在寒风中瑟缩、熬红了双眼的讨债人。

她身后的屏幕上，海岬的死斗还在血肉横飞地继续，那辆运伤车烧焦的残骸，像一座漆黑的墓碑，死死钉在阵地中央。

而门外这群同样走投无路的苦命人，他们同样不需要一句虚无缥缈的“江湖还会转下去”。他们只想死死咬住一点：自己口袋里被骗光的那点血汗钱，到底该由谁来偿命。
