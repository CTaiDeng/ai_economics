# 第9章：剑问不平

说明会的主席台撤下了，森然的寒意却未曾从这间改作审判厅的会议室里消退半分。空气里悬浮着劣质香烟燃尽的焦味和某种无形的、属于财富灰烬的铁锈味，冰冷的金属折叠椅围成一圈，像一座角斗场。

后排，一个眼眶深陷、面色枯槁的男人猛地站起，手臂上虬结的青筋像是干涸河床的裂纹。他不是拔出刀，而是将一叠厚厚的、边缘因反复翻看而卷曲的交易凭证狠狠砸在地上，纸页四散，如一群被惊扰的白色蝴蝶。

“九月底！盘口漏风的警讯早已传遍内网，你们的系统后台看得一清二楚！”他的声音嘶哑，像是被砂纸磨过，“为何十月，你们还能眼睁睁看着我们，看着我们这些信了你们鬼话的人，把全家老小活命的钱往那条死路里填！为何？！”

质问如同一柄淬毒的重锤，砸在死寂的空气里。

程砚舟站在圈中，面色沉静得像一口幽深的古井，他没有去看那些散落的纸，目光直视着那个几乎要扑上来的男人。他没有辩解，没有拿后来斩断了多少根毒藤、封堵了多少个缺口来搪塞邀功。他只是伸出手，让助手将一台数据终端置于众人面前，屏幕上幽蓝的光映亮他毫无波澜的脸。

“庚子年，九月廿七，更漏时三刻。后台风险第一次触发阈值。”他语速平稳，像是在复盘一局早已终局的棋，“这是当时的系统日志，这是我们排兵布阵的全部记录。”

铁证如山，却不是为了开脱，而是为了承担。

那毒疮早已被钉死在耻辱柱上，日夜受着所有人的刑讯。他们引以为傲的招牌，那条通往财富自由的迎客大道，被这一刀无情劈断，如今只留下一扇查验刀伤、核对血账的暗门。鸣镝早已射上夜空，警告着后来者此地凶险，可那些早已在黑市里流窜、带着血腥味的旧日舆图，却依旧将无数人引向了深渊。

他与许知妍都记得，在更早那次小规模开闸时，他们是如何明知那份过于简化的“财富英雄榜”会搅乱江湖规矩，却依旧自负地以为，在榜单角落多贴一张蝇头小字的风险布告，就能镇住人心的邪祟。

那面用鎏金大字写就的统视大旗，确实比底下用蚁足小楷写就的保命条文更扎眼。这道昏聩的号令，千真万确，是他二人亲口所下。

“割不割肉来赔？！”又一个声音吼道，带着血本无归的疯狂。

“割。”程砚舟斩钉截铁，声音不大，却压过了全场的嘈杂，“自家阵地漏出的底，拿净水衙门里每一两干净的真金白银来扛。但到底该赔几条命、几两银，须交由刑堂判官来定，绝不能由我程砚舟自个儿在账本上，用自家人的笔墨瞎画。”

顾承安从他身后走出，神情冷厉如出鞘的刀。他没有说一句安抚的话，只是将一份文件投影在墙上，上面的条款像一道道冰冷的军法。

“证据递交死线：七十二小时后。升堂初审：七日后。逾期不至者，视为自动放弃初审对质，一切依刑堂既有证据裁断。”他一字一顿，不带任何感情，“不愿在堂下死等的，大可卷起你们带血的底档，去中立仲裁院击鼓鸣冤。这刑堂的供状，不挟任何人闭嘴，也绝不剥夺任何人此刻就拔刀讨债的底气。”

人群中，一个始终沉默的男人缓缓站起。他穿着一件洗得发白的旧夹克，双肩宽厚，眼神却像鹰隼般锐利。旁人窃窃私语，说此人是从东南亚海岬那边的资金盘血海里真刀真枪杀出来的刀客，手上既有别人的血，也流过自己的血。

“带兵的统领，仗打砸了，要被当阵褫夺虎符，削职为民。”刀客的声音很冷，像金属摩擦，“你们这帮开局做局的，把一盘本该干净的战功，跟黑市里见不得光的分赃，搅成了一锅人人喝了都要肠穿肚烂的毒粥。敢问，又该由谁，来剁了你们的手？”

这一剑，不问赔偿，只问罪责。它绕过了所有繁复的账目和法条，如同一道无声的闪电，直逼程砚舟的咽喉。

修罗场上，断没有让打了败仗的将军自己审判自己的规矩。开山立派的掌门，也绝不能因为门规是他所立，就永远躲在法度之外，逍遥快活。

程砚舟的瞳孔骤然收缩。他原本按在黑胡桃木桌沿上的手，指节已因用力而发白，此刻却一根根缓缓松开。他死死盯着那个提剑逼问的刀客，仿佛在看另一个自己。既然曾在江湖上广发英雄帖，邀天下英雄来此试剑，就必须有胆量看着冰冷的剑锋，一寸寸逼近自己的咽喉。若到了这般生死存亡的关头，还要搬出什么“开山祖师”的招牌来压人，那当初掷地有声的江湖道义，就全成了放屁。

就在这剑拔弩张的死寂中，许知妍排开众人走了上来。她的脸白得像一张宣纸，高跟鞋踩在水泥地上，发出清脆而决绝的声响。

“那笔烂账，我认。”她当众说道，声音里带着一丝无法掩饰的颤抖，“是我，当初贪图门面的气派，迷信‘一俊遮百丑’，没有让那道本该跟招牌一样扎眼的保命刀痕，刻得足够深，足够醒目。”

她从随身的公文包里取出一枚沉甸甸的、刻着公司徽记的黄铜印章——那是她权力的虎符。她没有丝毫犹豫，将其放在了桌上，发出一声闷响。这个动作，意味着她主动避开了对自己罪责的会审，先将权力交出，再以待罪之身接受审判。

“所有相关的邮件、会议纪要、我亲手签下的朱批，以及后来所有打补丁的痕迹，都在这里。”她将一个加密硬盘一同放在印章旁，“原件已封存，交由第三方托管。绝不容许在刑堂验尸时，偷偷换成一本干干净净的假账。”

陈驰也大步上前，将一份文件狠狠拍在桌上，那是一份系统变更申请单，状态栏里，“已挂起，待回音”几个字刺眼如血。

“我当初是示过警，但这绝不等于我后来补上的那一刀，就劈准了要害！”他环视四周，厉声喝止了几个想替他辩解、粉饰成“早已尽忠”的下属，“谁在死等？要等多久？毒疮未消时，该由谁去补那第二刀、第三刀？旧的门规里，确实留着这深不见底的死穴！我陈驰，也是这死穴的看门人之一！”

他仿佛看到了一张十九路的围棋盘。他当初点破一处气口的断点，不过是落下了试探的第一手。那是一步冷静的“刺”，却不是制胜的“挖”。随后该由哪位大将飞兵补救，谁又在该落子时延误了战机，导致大龙被屠，都得拿命去一子一子地复盘。他绝不能厚颜无耻地扯过一块写着“我已警告”的红布，就想盖住后来那段无人扛旗、尸横遍野的死寂。

岑绍庭带来了几位在业界德高望重、且从未沾染过这笔黑钱的清流耆宿作为见证。苦主们也经过一番激烈的争论，选出了几位提刀的代表。他们将一同进入刑堂，旁听过堂。查账与定罪的权柄，彻底交到了跟这盘棋局毫无瓜葛的铁面判官和算盘先生手里。

“办案的粮草，全部公开。”岑绍庭宣布，“由‘破阵’项目自身储备金承担，我们砸锅卖铁，也要扛起这追查死穴的全部开销。绝不让已经流了血的诸位，再凑半文钱的路费。”

“不够！远远不够！”罗启锋杀红了眼，状若疯魔地叫嚣，“我要你们把所有战区的绝密军机，每一笔资金流向，每一次密谈，全都贴上城墙！我要一次扒光底裤的自曝！我要天下人都看看，这底下到底有多脏！”

“疯子！”老关如一堵墙般横刀拦在他面前，“那军机里还藏着其他刀客的私房话，还藏着我们没打完的埋伏圈！你为了给自己洗刷冤屈，就要把另一群还在前线拼命的弟兄，扒光了衣甲，给天下人当猴看吗？！”

他一把夺过罗启锋手中的一份文件：“要害处的卷宗，只能封存于密档，交由铁面判官亲验！验完之后，昭告天下为何定罪，因何赔偿！但绝不能为了一场查账，毁了整片江湖！”

刀光剑影最烈之时，吴秀榕攥着两份能要人命的复刻血契，颤巍巍地站起身。她没有看程砚舟，而是红着眼，死死地盯着人群中的潘俊棠。

“老潘，”她的声音不大，却让整个屋子都安静下来，“你摸着良心说，我吴秀榕，有没有偷拿过半个铜板的拉客赏钱？”

潘俊棠，一个健壮的汉子，此刻却咬着牙，眼眶通红。他看着这个曾经带他入局、让他赚到第一桶金的女人，艰难地从牙缝里挤出几个字：“我知道你没沾那点荤腥……可是，秀榕姐，可是我那给儿子留着娶媳妇的白银，实打实地化成了灰。我一看见你，就仿佛又回到了被一把推下火坑的那一天。”

屋里死一般的寂静。

事实能分清责任，未必能立刻修补关系。程砚舟将那句已经到嘴边的“让我们共同渡过难关”咽了回去。在这样的伤口面前，任何套话都是一种亵渎。

刑堂议事散去，人潮退去，留下一地狼藉。许知妍在血迹斑斑的地上，捡起了一张没有落款的纸条，那是一支飞镖射在墙上留下来的。

上面只有一行字：如果是你们自己走火入魔，这江湖里，究竟谁有胆子，让你们把刀放下？

她将那淬毒的飞镖递给程砚舟。两人死死盯着那条依旧在屏幕上滴血的系统日志，再也没法像从前那样，靠着互相挡刀的默契，就轻飘飘地越过那道生死线。

程砚舟一言不发，走到墙边那张刚刚拟定的“刑堂判官”名单前。他的名字，作为创始人和最终仲裁者，赫然列在榜首。他毫不犹豫地伸出手，用指甲狠狠地将自己的名牌从那张决断生死的榜单上抠下，随手扔在地上，发出一声清脆的碎裂声。

他甩出了一纸自请避嫌的死状，用行动回答了那支飞镖的质问。

那个带血的空座上，没有立刻塞进去某个穿同一条裤子的心腹。接替这把刀的人选与遴选的规矩，全权交由那些挨了刀的苦主们，按着新立的铁律，去重新过堂公选。

修罗场里，一块虎符的交接，都有定死的时辰与规矩；执掌这片江湖的权杖，更不能是一笔糊涂账。

在那个风雨飘摇的夜晚，程砚舟生平第一次，彻骨地看清了自己亲手画押放开的，绝不仅仅是山门外的一块招牌，更是从今往后，天下人都有权提着刀，指着他的鼻子说“不”的一片死地。而他，必须心甘情愿地走进这片死地，才能为这片江湖，求得一线生机。
