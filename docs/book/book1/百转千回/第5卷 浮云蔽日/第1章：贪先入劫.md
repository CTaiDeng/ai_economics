# 第1章：贪先入劫

十月一日，长假伊始，京城的天空被铅灰色的云层压得密不透风，寒意已然刺骨。陈驰没有半分休假的念头。

他所在的“刑堂”，是星原生态的神经中枢与戒律院。这里没有窗，只有服务器机柜指示灯组成的星海，与不间断电源系统（UPS）发出的、如同深海巨兽心跳般的低沉嗡鸣。空气里弥漫着臭氧和制冷剂混合的冰冷味道，足以让任何躁动的心绪瞬间凝固。

四海的拜帖、山门的名录与江湖上散布的招募令，三份文件被合金镇尺并排压在刑堂中央那张巨大的黑胡桃木会议桌上。起初的拜帖，用的是最规矩的宋体字，一笔一划记录着旗下刀客们在“深渊战场”里浴血奋战的功勋，每一笔都对应着可查验的数据库日志。而那份在私密社群里流传的招募令，却赫然将一枚带血的帅印——象征着最高战功的数字徽章——与“包赚不赔”、“稳定收益”的黄金券死死捆绑在一起，字里行间透着一股钱庄票号的油滑与贪婪。

陈驰的目光扫过，眼神冷得像刀锋上的寒光。他没有召集任何人，径直走到主控台前，调出最高权限。一行行代码在他指尖流淌，最终化作一道无形的剑气。只听见系统日志里一连串清脆的确认声，所有堂口的官方引荐牌匾——那些通往外部流量的API接口——被他一刀斩断。他只留下了个人战绩的内部查档暗门，并将一份刚刚拟定的、关于“虚假宣传与资产混同”的待审罪状，用加粗的红色字体死死贴在了所有接口的跳转页上，置顶，锁定。

他深知，若是一刀将整个堂口封死，只会让那些真正想来讨个说法、对证战绩的无辜者，连那段真刀真枪的过去都无处印证。这便是围棋里的“弃子争先”，舍弃一时的便利与流量，是为了抢占清理门户、明正典刑的绝对先手。

内部通讯器的红灯急促地闪烁起来，庄承裕那张惯于打圆场的脸出现在屏幕上。背景是他那间摆满古董、烧着昂贵沉香的办公室，与刑堂的肃杀格格不入。

“陈驰，陈堂主，何必动这么大肝火？”他的声音圆滑得像一块盘了多年的玉石，“盘口还没正式开张，不过是下面的人为了招新，在江湖上吹了几句牛，说了几句虚夸的场面话。为这个就拔刀相向，是不是太……”

陈驰没有坐下，他渊渟岳峙般立在屏幕前，沉默的压迫感透过冰冷的摄像头，让庄承裕后半句话噎在了喉咙里。“交出三样东西，”陈驰的声音没有一丝波澜，却字字千钧，“第一，幕后的黑手是谁，哪个牙行，哪个人。第二，所图的利益是什么，分成的规矩，许诺的画饼。第三，真实的钱庄账本，每一笔进出，每一份流水。”

他微微前倾，盯着屏幕里那双躲闪的眼睛：“我绝不接受用一句轻飘飘的‘改口’，来搪塞已经泼出去的脏水。”

电话在死寂中挂断。

午后，一个叫吴秀榕的女孩瑟缩着走进了刑堂。她穿着洗得发白的工装，手指因为长期敲击键盘而有些变形。她跟着星原的“镖局”干过几趟最苦的活——为大型AI模型进行数据标注和红队测试，报酬是几钱碎银般的“生态奉献激励金”，勉强糊口。

“陈……陈堂主，”她双手递上一张从某个社群里拓印下来的布告，那是一张精心设计的图片，边缘甚至做出了羊皮卷的质感，“这几天，有个牙子……中介，来游说我们。说我们不必再去苦等那些拿命拼的抽成，可以直接买下一份已被证实的‘固定赏钱’。”

陈驰接过那张打印出来的A4纸，指尖的温度似乎都无法将其焐热。布告上，赫然挂着大豪“岑绍庭”的名号，旁边还盖着一枚她再熟悉不过的星原大旗的电子印章。

“他说，这是岑绍庭九月份那场‘夜袭光明顶’战役的收益权凭证，基本参与份额五百元一份，旱涝保收。”

一直沉默在旁的林静薇，指尖在另一块屏幕上轻点。幽蓝色的数据流如瀑布般刷过，她点开一个加密的暗桩接口，顺着布告上留下的一个不起眼的ID顺藤摸瓜，几秒钟内，确实连上了岑绍庭九月那场大战的战报数据库。

“血战是真的，”林静薇的声音冷静而精确，像手术刀，“根据归档日志，那场战役结束后，总计价值三十万的‘生态奉献激励金’确实在九月三十日打入了岑绍庭团队的信托账户。但是，”她话锋一转，调出了那个信托账户当前的流水，“这布告，绝口不提库里现在是否还有余粮——事实上，账户余额为零。它更拿不出半分证据，证明旁边那个卖官鬻爵的牙子，得到了岑绍庭的半句授权。”

“原来……查得到，也可能不是可以买的？”吴秀榕的眼神黯淡下去，声音里带着一丝侥幸被击碎后的迷茫。

林静薇将屏幕转向她，把事实的骨架、契约的死理和库房的账本逐字逐句拆给她看。“一个刀客在修罗场里杀出了名头，这只证明他武功高强，绝不意味着全天下都欠他一笔旱涝保收的供奉。一笔银子曾经存在过，也绝不能被当成一张永远不用兑付的空头支票。你看这里，”她指着一行小字，“这笔激励金的处分权，有‘一票否决权注销’条款，岑绍庭本人都无权将其分割出售。”

吴秀榕死死盯着那两张并列的屏幕。左边，是岑绍庭浴血奋战的战功，那仿佛一封带着江湖大佬亲笔落款的引荐信，原本只是证明这人曾拔过几次刀；右边，是那张诱人的布告，此刻却像一张替一个素未谋面的骗子兜底的生死状。

她虽没当场掏空口袋，却仍旧不甘心地追问：“可是……群里有人晒了截图，白纸黑字的到账回执，说是预付的利息。”

角落里，一直闭目养神的周慎衡冷笑一声，睁开了眼。他的眼神像鹰隼般锐利，仿佛能看穿人心鬼蜮。“钱庄的回单，只能证明确有银子过手，却说不清那笔钱是干净还是带血。小姑娘，你记住，靠真刀真枪拼出来的赏金，与从下一个替死鬼手里骗来的押金，在回执单上看起来一模一样。你若是只盯着那张纸，就天真地以为这座金山挖不空，那你的钱，就是用来填别人窟窿的砖。”

他的话像冰锥，刺破了吴秀榕最后的幻想。

就在这时，刑堂的警报系统弹出一条新的待审记录。又一份挂着四海名号的“精锐杀伐”战报被送了上来。五个ID，宣称在同一夜联手攻克了代号“水塔”的高防服务器集群，战报视频里尽是些不眠不休、刀光剑影的砍杀残影。

负责技术勘验的顾承安，锐利的目光扫过屏幕上飞速滚动的数据。他没有看那些炫目的画面，而是直接调出了后端的网络流量与操作日志。“虎符交割之后，”他冷冷地指出，声音里带着极客特有的精确与不屑，“也就是凌晨三点十七分，这五个账号的生物特征识别全部离线。后半夜，所有攻击流量的发起源，是分布在东欧的16台机柜，合计120台服务器。攻击模式高度一致，是预设脚本驱动的NPC木偶在挥刀，峰值流量1.2Tbps，攻击了两万个节点。绝不能凭这就断定那五个大活人，全程都在刀口舔血。”

这桩猫腻尚未正式分赃，刑堂也不该仅凭几段残影便一棍子打死所有人。查验的指令立刻发下，勒令四海交出究竟是人是鬼的底牌，以及每个ID具体的上阵时辰。对方却像个无赖，只会反复塞来那些剪辑过的、最光鲜的浮影。那些打着“死战不退”旗号的画面，恰恰心虚地躲过了“到底是谁在握刀”这个死穴。

傍晚时分，庄承裕递上了改过名目的降书。那份油滑的招募令，被粉饰成了人畜无害的“经历图鉴”，再三赌咒发誓，绝不贩卖任何虚幻的收益，只做战绩展示。团队里的许知妍心软，念及那些刀客打拼不易，本想保留他们战功的牌位。

陈驰却一步拦在了操作台前，像一尊铁塔。“在外面的烂账没查清之前，在那个‘水塔’的真相水落石出之前，绝不许重开山门的引路牌。”

最终，刑堂只留下了供人查验和鸣冤的窄门，彻底掐断了往外引流的大道。这无异于天山折梅手，收发自如，看似只点中一处穴道，却断了对方全身的真气流转。陈驰绝不给任何一笔不清不楚的新买卖，放行半步。

他死死盯着屏幕中央那个无人作答的死穴。十九路棋盘上，眼前这处致命的“薄味”，绝不能靠在别处虚晃一枪、抢占个无关痛痒的先手就能敷衍过去。此刻若是贪图一时的热闹风光，姑息养奸，来日一旦溃败，必将被逼得四处救火，再也没有从容拔剑、一举清算的机会。此乃“贪先入劫”，一步走错，满盘皆输。

然而，他能封住山门，却封不住江湖上的私相授受。外部的私人转发，并没有随着官方目录的熄灭而停止。

方婉音，一位在星原生态里颇有名望的知识分享者，收到了旧日听众发来的邀请，希望她为一家名为“千礁星云”的新产品出镜站台。对方开出的条件优厚，出售的正是所谓的“参与未来收益组合”，并言之凿凿地宣称，所有收益来源都是星原内部的真实活动。这个合作方，根本不在四海提交的备案名单里，其收款账户也不经过星原的任何官方窗口。

方婉音没有虚与委蛇地回几句客套话。她反手便将那张包装精美、实则带毒的请帖，连同那个暗桩的底细，直接拍到了陈驰的案头。刑堂立刻锁死证据，如同猎犬循着血迹追查，并向那些已经暴露的传信人亮明了法律红线。他们虽能强行封死自家的山门，却无法指望按下一个机关，就能将散落在江湖各处、成千上万份带毒的招募令，瞬间焚毁。

夜深了，机房的嗡鸣声愈发清晰。陈驰又给吴秀榕的内部邮箱发去了一份最新的查验通报，里面详细剖析了“水塔”事件中人与“木偶”的界限。

消息送达，却如泥牛入海，久久没有回音。

陈驰靠在冰冷的机柜上，感受着金属外壳传来的震动。他死守着必须用真金白银、用可验证的劳动结账的底线，就是不肯用虚无缥缈的未来画饼，去抵扣眼前这些年轻人活命的钱。可如今，一种包装得更精致、更具迷惑性的毒药，正诱骗着那些在苦寒中挣扎的苦命人，掏空口袋里最后的散碎银两，去换取一个根本不知是谁在兜底的、虚幻的明天。

他仿佛看到，吴秀榕正盯着那个闪烁的“购买”按钮，而她的账户里，可能只剩下那份“基本参与份额五百元”。
