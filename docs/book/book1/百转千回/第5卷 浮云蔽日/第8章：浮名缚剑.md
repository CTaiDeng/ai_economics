# 第8章：浮名缚剑

秋声回望的系统记录在幽蓝的屏幕上重新打开，会议室里没人鼓掌。空气凝滞如冰，只听得见机柜深处散热风扇永不停歇的、如同深海呼吸般的低鸣。

十月三日那个风雨交加的夜晚，海岬数据洪流中爆发的那场暗夜护镖，是一场真正意义上的喋血攻防。冲锋陷阵的节点工程师、抵御攻击的运维苦力、乃至在各个频道间奔走呼号的传令兵，每一个人的行动权限都来自刑堂批复的数字虎符。此刻，那份混杂着警报嘶鸣与风雷原声社粗粝录音的战报，每一个字节都像是浸透了血，硬生生在围剿中砸开了一条生路。崇远资本砸下的那两千万风险准备金，如同一颗钉死的镇龙石，死死抵住了开局那几乎无可挽回的死门。等到“破阵子”镖局的旗号正式挂出，招募天下刀客时，银库里的粮草与刑堂的门规，早已上了三道密码锁，层层加密，牢不可破。

卷宗的影像在屏幕上无声地流淌。许嘉榕，那个ID名为“惊鸿”的女孩，如何在漆黑一片的网络路径中，连续两次仅凭流量的异常波动就锁定了攻击源的死穴。邱庭舟，又如何在SYN Flood的洪峰冲垮第一道防线时，于乱军之中强行接驳备份线路，为整个阵地续上了一口几乎断绝的气。留档的卷宗里，有杀伐决断时带血的代码，也有过了明路、写入区块链遗嘱协议的刀客留言。有人迷恋这刀头舐血的激烈，反复回放那晚的攻防录像；也有人被那高压下的残酷气息灼伤，中途黯然退场。十九路的棋盘上，不是每一处断点的死寂，都非得填上一手虚伪的应劫。

而今，一张不知从哪个阴暗角落冒出来的黑帖，如同一道淬毒的飞镖，精准地截取了那晚最惨烈的一段残影，用猩红的大字，将所有发到刀客手里的卖命钱，赫然指认为同一场精心策划的杀局。

方婉音的眼睛瞬间就红了，指节捏得发白，险些就要把那晚所有的底层数据包、语音记录、私密频道聊天记录，全都毫无保留地倾倒在整个江湖面前。

“够了。”

邱庭舟的声音不高，却像一柄冰冷的戒尺，敲在了她即将失控的神经上。他伸手，轻轻按住她悬在“发布”键上微微颤抖的手腕。

“那些刀客，只答应授权我们记录他们的刀痕，没答应把家里最后的体面也剥下来，供人赏玩。”

她咬着牙，指甲几乎要嵌进掌心，那股不顾一切的决绝慢慢从眼中褪去，化为一片深不见底的屈辱与悲凉。她松开手，撤下了几段最能博取同情、却也最带血的私房话，只将刑堂审计盖印的财务底账，如同一面磨损却坚实的盾牌，推出去迎向那漫天箭雨。

那份即将公之于众的账目，冰冷而精确：

“破阵子”首战总收益：六万标准份额。
其中，生态建设与品牌价值转换：四万份额；渠道激励与核心贡献者酬劳：二万份额。
前期风险对冲资本（崇远专项）：二万份额，独立封存，不计入本次收益。
参战者酬金池（刀客）：二万四千份额，按贡献度与风险系数结清。
核心指挥团队薪资：四千份额。
运营及硬件损耗成本：二万份额。
项目结余，转入期末分红池：一万二千份额。

陆文渊那边传来一条言简意赅的加密消息，冷硬地拒绝了团队内部有人提出的、将“崇远”字号暂时从案卷上抹去的提议。他既然拿两千万砸开了死门，也贪图这刀口上的厚利，就该像个真正的棋手，坦然地让自己的名字钉在棋谱之上，供天下人评说。他敢拿命去填的死门，同样得留在记录里，但谁也别想往他头上强扣一顶他从没答应过的“保本付息”的高帽。

江湖上的风言风语早已炸开了锅。有人叫嚣着他财大气粗，就该拿钱去填千礁崖那次失败项目的血坑；也有人眼红他打赢了这一仗，就不该再参与分红。陆文渊对此置若罔闻，连眼皮都未曾抬一下，硬是没撤回半张查账的底契。压在死门上的赌本，是一回事；一刀一枪拼回来的真金，是另一回事；至于那些被钓鱼网站骗走真金白银的冤大头，他们的损失又是第三回事。这三笔账，绝不能因为都在这肃杀的秋天见了血，就被一锅烩成一笔谁也算不清的糊涂账。

许嘉榕应得的那份酬劳，就静静地躺在那二万四千份额的资金池里。有相熟的刀客通过加密频道递来私信，劝她暂避风头，先别动用那笔钱，免得落下一个“发死人财”的骂名。

她死死盯着屏幕上那行字，看了足足两遍，指尖冰凉。然后，她冷冷地敲下一行回复：刑堂大可派人来检验我服务器上留下的防御伤疤，但我拿命换回来的安家费，一个子儿也不需要向任何人磕头谢罪。

把消息发出去后，她心里还是闪过一丝后怕。那是一种被污名所缚的恐惧。方婉音很快联系了她，没有让她收回那把出鞘的刀，只隔着电流问她：“你敢不敢把你的操作日志、贡献证明，在隐去核心代码的前提下，提交给刑堂的独立判官审阅？你可以披着‘惊鸿’这件夜行衣，不必暴露真实身份。”

她咬牙，敲下一个字：“敢。”

她随即甩出了自己作为摇旗传令兵的全部权限记录与操作兵符，但面对那些在公共论坛上像疯狗般乱咬的看客，她绝不会扒开自己所有的底裤。

另一头，海岬安全委员会下达了死命令，必须彻查那张被内鬼泄露出去的早期网络布防图，到底直接或间接导致了多少友军节点的覆灭。秋声这边的前锋部队虽然没有走那条要命的暗道，但也绝不能因此就在刑堂的质询中自动脱罪。更不能因为大家都在海岬这个巨大的绞肉机里流过血，就一刀切地废掉所有人拼死换来的战果。判官们的追魂索，只顺着数据流里真刀真枪的血迹往上捋，死死咬住那条区分功过、辨明黑白的底线。

后续的镖单，仍有人在恐慌中退订。风雷原声社的客服们冷着脸，一言不发，按门规退钱，多一个字都不解释。而那些愿意留下死扛的老主顾，也没被挟持着提前掏腰包来给平台续命。下一局的赌本，依旧与这一场的死账劈得干干净净，泾渭分明。

程砚舟曾急红了眼，在视频会议里拍着桌子，想把南离科技那块干净的招牌，强行涂成一面“誓死力挺破阵子”的血色战旗。

话音未落，就被陆宏远一道沉稳的声音斩了回去：“砚舟，客官们掏钱，买的是那一晚刀尖上的痛快。他们不是来替你这个带头大哥的义气，摇旗呐喊的。”

程砚舟像是被一盆冰水从头浇下，颓然松开紧扣着桌沿、指节发白的手，低声道：“……是我乱了阵脚。”

他险些把南离当成了十九路棋盘上，早已为自己布好的一颗现成的援兵。总觉得只要自己的大龙被围，它就理所当然、不顾一切地飞兵来救。陆宏远那一刀，让他悚然惊醒：南离那块战场上，也有别人正在苦苦维系的阵法，有早已签下的生死契约，绝不能由着他一时的急火攻心，就悍然掀了别人的棋盘。那是弃子争先，可要弃的，是别人的子。

方婉音已转过身，去处理一件更棘手的通牒：一名参战刀客通过正式渠道，要求收回他之前录下的那段私人遗言。

她戴上耳机，调出那段音频。先是沉重的防火墙闸门开启的轰鸣，然后是几声逐渐远去的、决绝的键盘敲击声，最后，是整整七秒钟死一般的留白。

那七秒的寂静，比任何呐喊都更具重量。

她没有动用剪刀，去修饰那段令人窒息的空白，更没有拿它来给平台的伤口抹粉，煽情卖惨。她只是按照江湖规矩，为这段音频加上了“权利人申请封存”的数字印记，然后发送了回执，请那位刀客本人，亲自画押确认。

一个名号，能将刀光剑影的恩怨连成一条荣辱与共的锁链，也可能把清白之身与带血的烂账，死死缠成一个解不开的死结。

但至少，那七秒钟的死寂该如何留在江湖上，还得由握着刀柄的主人，自己说了算。
