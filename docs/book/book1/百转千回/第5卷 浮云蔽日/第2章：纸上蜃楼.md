# 第2章：纸上蜃楼

钱转出去的那一刻，吴秀榕感觉自己的一部分魂魄也跟着那串冰冷的数字，一同汇入了深不见底的暗流。当她将那张颤抖的、几乎被指尖汗水浸透的回单递过来时，陈驰的目光没有停留在上面，而是落在了她那双失神的眼睛上。

那是一张两千六百元的带血回单。所谓的血，是她从牙缝里抠出来的积蓄，是熬过无数个夜换来的辛苦钱。而换回来的，是一纸空文，一张轻飘飘的合约，上面用猩红的印泥画着一个到期三千元的画饼，笔锋张扬，仿佛在嘲笑着所有人的贪婪。

吃钱的黑手，正是“千礁星云”。

那帮潜伏在暗处的牙子，口舌仿佛淬了蜜的刀，将一桩彻头彻尾的骗局，说成了一场稳赚不赔的豪赌。他们诓骗吴秀榕，说刑堂的规矩森严，只验江湖上的刀疤剑痕，从不管私底下的银钱账目，这种台面下的交割，才最干净利落，不落痕迹。为了佐证，他们甚至甩出几张不知真假的早期分赃铁证——泛黄的钱庄票根，上面赫然盖着鲜红的印戳。他们死死咬定，这并非是拿自己的身家性命去赌一个虚无缥缈的明天盘口，而是弯下腰，直接伸手去摘别人早已用命换来的、血淋淋的胜果。

“我……我昨天，天真地以为……”吴秀榕的声音嘶哑，像被砂纸打磨过，眼眶红得像要滴出血来，“既然过了刑堂的眼，有备案，那就算是在江湖上立住脚的真货……谁能想到……”

陈驰的脸沉得像一口深潭，他没有出言安慰，只是递过去一杯温水。“把他们说的每一个字，每一次交锋的细节，都给我抠出来，原封不动地记下。”他的声音不高，却有着不容置疑的镇定，“你不必为了面子，抹去自己当初起贪念买入的痕迹。你眼热那四百元的暴利，妄想着从此能避开刀光剑影，躺在家里安稳数钱，这都是人性。但这些贪得无厌的欲念，绝不能成为他们将一张废纸凭空变现成真金白银的理由。”

千里之外，另一间更为森冷的静室里，陆文渊正用一根檀木镇纸，冷酷地压过三份卷宗。崇远堂口那三场已然陷入死局的血战，粮草账目清清楚楚。

秋声渡的前锋营已经泼出了血本，每一笔抚恤都像滚烫的烙铁；南桥的镖车还在最后的关隘前磨刀霍霍，人吃马嚼，耗损惊人；北岭的夺旗之战，主力按兵未动，可斥候的命已经填进去十几条。三处战场，三盘死棋，每一处都死扣着两万银元的底线。这三座看似互不相干的连环坞，即便被彻底斩断所有退路，依旧能各自清算，独立结账。这才是他的规矩，如同围棋中的“双活”，纵然外势被封，内部也须各自做出两眼，独立存活。

一个不知深浅的下属，竟敢在他面前低声发问：“陆爷，千礁星云这套路数，听起来……怎么跟您有几分相似？”

陆文渊的嘴角勾起一抹冰冷的弧度，他没有发怒，只是伸手从卷宗下抽出另一份文件，如同出鞘的利剑，带着寒气拍在黑胡桃木桌上。那是一纸签了生死状的军令状，墨迹淋漓，仿佛还带着血腥气。

“看清楚了。仗打败了，填不满的窟窿，老子自己割肉来扛。”他的声音不大，却字字如刀，在静室中回响，“打赢了，先结清底下兄弟们的卖命钱，一文都不能少。剩下的肉，才是老子该拿走的。千礁星云把他们的借条吹得再怎么天花乱坠，也绝不敢像我一样，签下这份东西。他们许诺的，是让撒出去的赌本，平白无故地生出一顶保命符。痴人说梦！”

他抬起眼，目光如鹰隼般锐利：“他们许出去的那三千元，你告诉我，将来究竟谁来割肉填？”

千礁星云铺开的这张八阵图，初看之下，确实天衣无缝。旧日的带血战报，将军的虎符，死士身上狰狞的刀痕，钱庄兑付赏金的回单，每一环都能严丝合缝地对应上。可唯独那条牵着吴秀榕这些新买主的诡异藤蔓，却只在契约末尾轻飘飘地写了一句——“承接福报”。

这四个字，如同一团鬼火，既让你在要命时找不到该去讨债的冤主，也拿不出半点符合江湖规矩、血契交换的红契。

那些错综复杂的线索，如同一座精心布置的连环杀阵，层层套叠，环环相扣。林静薇坐在自己的位置上，面前没有卷宗，只有一方十九路的棋盘。在她眼中，这骗局就像一个狂妄的疯子，从十几张传世的绝世棋谱上，各自抠下一块看似完美的“好形”，然后用粗劣的针线，硬生生缝合成一盘号称算无遗策、永不崩盘的假棋。

她纤长的手指在棋盘上缓缓移动，没有落子，只是逆着那些看似精妙的连接，一步步回溯。在棋道中，那些看起来天衣无缝、气脉悠长的连接，恰恰是最该被死死揪住、反复逼问的地方——当初落子之时，你到底是靠什么诡诈手段，才在这里强行接上了本不属于你的气口？

最终，她的指尖停了下来，随即拿起一支朱笔，在面前的白纸上，死死圈住了那虚妄的四个字——“承接福报”。

“虎符，只能证明那名刀客曾在火线上滚过一遭。”她声音清冷，不带一丝感情，“刀痕，是死死焊在那活下来的死士身上的烙印。而他拿到手的赏金，则是一刀一枪，用当初签下的生死契，从刑堂换来的。这三样东西，早已因果了结。”

她顿了顿，笔锋在纸上划出一道血痕：“把这三样东西装进同一个华丽的锦盒里，既不能用前两样虚名，凭空变现出第三样的真金，也绝不能让早就结清的卖命钱，厚颜无耻地再讨一回债。这是弃子争先，不是点石成金。”

一份新递上来的诡异卷宗，让这盘假棋的荒谬之处暴露无遗。千礁星云竟将同一名死士在执行任务时，钻入地洞前、地底厮杀时、杀出地面后所用的三个不同行军代号，硬生生拆解成了三段独立的战功，并以此为凭，妄图向新的买家索要三份赏格。

顾承安的手指顺着卷宗上干涸的血迹一路拼合，最终冷笑出声：“从头到尾，只有一把刀，一场血战，和当初刑堂落下的一笔判词。一个刀客的杀伐，固然可以在不同的阵眼里被反复观察，但绝不能因为他换了个掩体，就在账本上凭空多变出两个人来伸手要钱！”

面对这般质问，千礁星云的辩解显得苍白无力，他们转而厚颜无耻地狡辩，说买主们买的，不过是一份“战功图鉴”的收藏价值。

旁人立刻厉声质问，为何当初要用“旱涝保收的赏金”这种字眼来拉客？他们又立刻改口，诡辩说江湖人看重的，是这段染血历史背后所蕴含的“无价之宝”。

换皮的把戏，在短短一个时辰内玩了千百遍。可那贪婪伸出的手，和那到期三千两的催命毒誓，却半点没变。

“够了。”陈驰一把将那张骗人的布告翻回最初的底稿，动作不大，却让整个房间的争论戛然而止。“不管它换过多少把花里胡哨的剑鞘，拔出来的，永远是同一截见血封喉的毒刃。刑堂不必再去追着那些朝令夕改的假名号白费口舌。”他抬眼看向众人，目光坚定，“先死死盯住它，到底用那把刀，从谁的手里割走了肉，又对谁，画下过怎样要命的画饼。”

周慎衡早已被那些迷魂阵般的名字绕得不耐烦，他猛地站起身，椅子在地上划出刺耳的声响。他懒得再做口舌之争，只扔下一句：“我去钱庄。”随即，便已提着刀，顺着那些沾血的银票，亲自追账去了。

吴秀榕第二次来的时候，脸上多了几分惶恐。她听说刑堂已经介入，怕自己的投诉，会连累其他那些和她一样的人也收不到款。“他们说……是我把事情闹大了，断了大家的财路……”

陈驰只是静静地看着她：“缺口，不会因为你捅破了窗户纸而变得更大；它同样，也不会因为你隐瞒，就把已经亏空的钱凭空补上。真相就在那里，不增不减。”

她在冰冷的椅子上坐了很久，杯子里的水已经凉透。最终，她拿起笔，在申报材料上签下了自己的名字。笔迹歪歪扭扭，却带着一股决绝。

两位曾声称在早期拿过钱的人随后被传唤，他们主动出示了回单。其中一人极不服气，将一张兑付过的银票拍在桌上，高声道：“我亲眼看见的真金白银，亲手拿到的钱，难道还比不过你们几句空口白牙的理论？”

一直沉默的周慎衡，此刻却冷冷地点了点头，承认那银票不假。他反手拽着那人的衣领，将他拖到一堆账簿前，一把掀开了那钱柜的底裤。

“没错，有人曾经从这个钱庄往外掏过银子。但这顶多证明，在那个时辰，这个钱庄还没被彻底掏空。”周慎衡的声音像是淬了冰，“但这，绝不足以证明，那帮骗子口中吹嘘的、财源滚滚的钱生钱阵法，真正在这个江湖上存在过一天！”

那些曾被千礁星云吹嘘得天花乱坠的虚假铁券，被一张张冷酷地钉入了刑堂的死档。卷宗的封皮上，只剩下用血色朱笔写下的几个大字：买主、收钱的黑手、画押的时辰、真金白银的数目，以及那虚妄到可笑的利益。

当周慎衡亲手斩断了那些伪装得花团锦簇的因果连线后，案板上，赫然暴露出几个深不见底、永远无人敢于认领的巨大黑洞。它们静静地躺在那里，散发着吞噬一切的寒气。

吴秀榕死死盯着自己那张带血的交割单，上面的每一个字，都像针一样扎着她的眼睛。这两千六百块的血汗钱，并没有因为刑堂撕开了这层画皮而回来半分，她那颗悬在嗓子眼的心，也远未落下。

但至少，她再也不必为了苦熬一个根本不存在的善终，而继续自欺欺人地假装看不见脚下那些随时会将自己彻底吞噬的黑洞。蜃楼已散，只剩下一片冰冷的荒漠。
