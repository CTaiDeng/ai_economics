# 第10章：按剑止戈

十月底的朔风，如同一柄无形的钢刀，刮过每一寸肌骨。黑市门头那最后一张招摇了整个秋天的招兵旗，终于被一只铁钳般的手冷酷地扯下。帆布在风中发出垂死的悲鸣，仿佛一个被割断了喉管的骗子。

陈驰站在旗下，面沉如水。他没有让手下将这面旗帜付之一炬，而是命人用油布小心翼翼地层层包裹，再用火漆封缄，如同封存一具携带剧毒的尸体。他要的是物证，是那面旗帜被钉死在门楣上的时辰，是那句墨迹淋漓、蛊惑人心的“包赚不赔”的每一个笔画。江湖的追魂簿上，从不因旗幡的卷起，就抹去一笔血债。

官府的六扇门终于拔刀了。一纸冻结令如九天玄雷，精准地劈在钱庄的黑账之上，那道由贪婪和谎言构筑的资金洪流瞬间凝固成冰。刑堂之内，灯火通明，算盘珠子拨得如同急雨敲窗，那摊带血的烂账，终于在判官的朱笔下被一刀刀劈得脉络分明。陈驰手里攥着那份盖着六扇门朱红大印的回执，纸张的边缘锋利得像刀片。平台只负责据实查账，将每一笔银钱的来龙去脉剥离得干干净净，绝不敢越俎代庖，替官府发号施令。

账目，冷酷如铁。二十二名被虚妄的黄金梦迷了心窍的冤大头，合计被卷走了九万六千两雪花银。其中，一万八千两，是骗子们精心计算后吐出的诱饵，用后入场者的血肉，去填补先尝到甜头者的钱袋，以此维系那“包赚不赔”的假象。一万六千两，是砸进三教九流、各路掮客口袋里的拉客钱，每一文都沾着帮凶的唾沫星子。另有两万二千两，早已被幕后黑手以鬼神莫测的手段，暗中转移到了别处的销金窟，如泥牛入海。最终，被官府的封条死死钉在库房里的，只剩下四万两。

这四万两，并非谁的赎金，而是一块无主的腐肉，正散发着诱人犯罪的腥气。它必须在刑堂上，经过最严苛的过堂查验，看谁的状纸上血泪最深，谁的契约上指印最真，才能决定归属。因此，真正被定性为诈骗卷走的血汗钱，是七万八千两——那九万六千两的总额，必须剔除那一万八千两被吐出来、沾着后来者鲜血的诱饵。江湖规矩，也是刑堂铁律：被骗子用你的钱再去骗别人，这笔账，不能再死皮赖脸地算进自己的亏空里。

周慎衡的目光扫过卷宗上那笔流向不明的两万二千两，眼神里没有半分波动。他没有在堂上画下任何“虽远必诛”的虚妄誓言。棋盘之上，弃子争先，与其耗费心力去追一两个已经逃出大龙的残子，不如先稳固腹地，清算内鬼。那砸进黑道的一万六千两拉客钱，才是眼下的棋眼。这里面，谁是真被蒙蔽、赚个辛苦钱的脚力，谁是心知肚明、为虎作伥的伥鬼，谁又该被判官笔一点，直接剁去那双拉人下水的手，这笔账，六扇门的刀还需往下深挖。

堂外传来喧哗，竟是“四海”的庄承裕，还有脸来刑堂叫屈。他形容枯槁，却仍想摆出一方豪雄的气度，声称要重开四海的山门，说什么“底下的弟兄总得有口饭吃”。

这道荒唐的请命，被主审判官冰冷的声音一刀劈开：“弟兄要吃饭，可以！凡身家清白、战功属实者，可凭自己的功劳簿，去江湖上任何一家镖局挂牌，无人阻拦。但四海那些带血的招兵买马、拉皮条和当铺买卖，已全部钉上封条，即刻查抄！休想换个马甲，就重新出来招摇撞骗！”

至于战区里，“四海”空出的那些带兵名额，也严格按兵部的规矩，公开移交。判官的刀，斩的是蛇头，而不是被蛊惑的蛇身。那些不知情的刀客，只要手上没沾过黑市的脏钱，便绝不能因为堂主被抓，就生生剥夺了他们用命拼来的军功与应得的粮饷。但是，那个带头的大哥，那个曾经的“四海”之主，他究竟配不配继续执掌帅印，必须按着江湖门规一笔笔算清。老字号的招牌，不是免死金牌。

同日，刑堂又接下另一桩已然拔刀相向的公案。

九月底那场名为“归雁”的镖局血战，是真刀真枪，从尸山血海里杀出来的。此役，实打实地为东家搂回了两万两白银的红利。按契约，粮草军械烧了四千两，统领抽头两千两，公中留底两千两，剩下的一万二千两，分毫不差地全数投进了参与此役的刀客分赃池。其中一半，六千两，早已分发到那些身家清白的弟兄手中。可剩下的六千两，却因为千礁那帮饿狼，拿着一张来路不明的伪造死契前来强索，被刑堂当即扣下。这笔钱，至今还死死锁在那场血战的功劳库里，与官府查封的赃款分置两处，井水不犯河水。

许嘉榕的九百两，邱庭舟的九百两，以及其他数十位弟兄合计的四千二百两，这整整六千两血汗钱，就这么被压在了一张伪契的刀刃之下。许嘉榕的肩胛上，还留着当初为了摇旗传令而被流矢划开的刀伤；邱庭舟的功劳簿上，明明白白记着他曾冒着箭雨抢修断桥的头功。他们卖命的底薪和搏杀的花红，每一笔都有据可查，验得明明白白。现在刑堂要查的，是谁他娘的吃了熊心豹子胆，敢拿着伪造的虎符，声称这帮刚从鬼门关爬回来的刀客，把自己的活命钱给当了出去！

“这九百两，是我一刀一枪，拿命搏回来的，不是在黑市上听人画饼买来的！”许嘉榕一身洗得发白的劲装，就这么杀进了肃杀的刑堂。她的声音不高，却像一颗颗砸在冰面上的石子，字字带冰。

陈驰坐在上首，抬手虚按，示意她坐下。他的声音同样冰冷，却带着不容置疑的保证：“你的功劳，谁也抢不走。赏银被扣，是为查明伪契，绝不等于你的血没有在战场上流过。这笔安家费，也绝不会被挪去填千礁留下的任何一个黑洞。”他目光如炬，盯着堂下，“伪造虎符、强抢功赏的恶狼，限期三日，必须交出那张带血的死契原件！三日后，刑堂结案，斩钉截铁！”

“从九月底，硬生生把人拖到了现在。”许嘉榕的牙关咬得死紧，一双眸子像是淬了火的寒铁。

林静薇手下的狼毫笔一顿，随即在卷宗的空白处，重重记下：“此案自九月底呈报，拖延至今，缘由待查。”她将这桩冤案最初被官僚主义耽搁的烂账，也一并钉入了死档。刑堂，绝不能只在今日摆出铁面无私的架势，就将旧日的拖沓与冤屈一笔勾销。

许嘉榕冷着脸，从书吏手中卷走那份写明了结案日期的回执，死死攥在掌心，半句“多谢青天大老爷”的客套话都没给。她背脊挺得笔直，像一杆不屈的长枪，没有在这冰冷的大堂里多等一句廉价的安抚，转身便走。

林静薇目送着那冷硬的背影消失在门外透进来的惨白光线里，才将那段被耽误的时日，用朱笔重重圈起，压在了待审卷宗的最下方。话本里的侠客路见不平，拔刀只在一瞬间；可这现实的江湖里，被耽搁的每一日煎熬，都必须一日日地用规矩认领回来，绝不是在堂上喊一句漂亮的口号，就能轻易抹平的。

另一头，崇远镖局的内堂，气氛凝重如铁。

程砚舟与陆文渊相对而坐，面前是一方十九路棋盘，棋子散乱，一局未终。南桥的镖局已经烧了粮草，箭在弦上；北岭的阵地，却还未及砸下第一笔钱。江湖上早已风声鹤唳，退单如潮，底下招募来的刀客也开始军心涣散，人心惶惶。

两人对坐良久，终是程砚舟伸出手，决然地从棋盘上拈起了几枚陷入死地的黑子。这一手，不是妙手，而是挥刀自宫。他斩断了那两场还没来得及正式开打的战役。旧有的战区，依旧由原来的老卒和守阵人死死守着，封死黑市的买卖，绝不等于要把这片真刀真枪拼杀出来的疆土拱手让人。

他提起判官笔，将筹备中的兵阵部署，一行，一行地划掉。落笔时，手腕沉重，竟比当初意气风发、画下这张宏伟蓝图时，沉重了百倍。棋局被逼到了气口将断的死穴，此刻狠心停掉外围虚张声势的“打入”，先于腹地“做活”自保，看清自己究竟还能守住哪一块实地，这远比闭着眼睛，再虚张声势地抛下一枚意图“屠龙”的棋子，要艰难和惨烈得多。

烧掉的粮草，按着签死的契约，各家认亏，各自割肉。没动过的库银，则一文不少，干干净净地退回原主。崇远绝不为了向江湖证明自己还没死，就打肿脸充胖子，强行开这必败之局。但公道也要分明，十月三日那场真刀真枪拼杀过的“秋声回望”之役，其功过赏罚，绝不容许被混淆抹杀。那场血战里的赌注、本金与残血，全被从大账中劈出来，另起一炉，清算得明明白白。

杜启航建议，趁着这封山的空档，重修山门，甚至试探着问，要不要把过去那些刺眼的旧账、那些失败的战报，全数洗白，换个名头，从头来过。

程砚舟死死盯着墙上挂满的一张张盖着官印、写明败绩的带血回执，良久，才从齿缝里挤出一句冰冷的话：

“门楣可以换，但这天下人曾提着刀，上门来找我们要账的血痕，半寸，都不许擦！”

那些曾引来杀身之祸的黑市门面，终于彻底熄了灯。唯有刑堂前，那盏为击鼓鸣冤者而设的灯笼，还在风雨中死死亮着。远处的战区依旧凄风苦雨，这屋里满墙还没解开的死局，也没有被谁自欺欺人地换成粉饰太平的战报。

他们收起了屠刀，按下了剑锋。此举，没有换来江湖上的半点喝彩，反而招来无数“虎头蛇尾”的嘲讽。

但至少这一次，他们没有再指着万丈深渊上的一个虚影，厚颜无耻地告诉别人，闭着眼踩过去，就是一片坦途。
