# 第7章：一子藏劫

岑绍庭踏入刑堂时，天色已近黄昏，冬日的寒气顺着门缝钻进来，像无数根冰冷的钢针，刺着人的骨头。他肩上那个洗得发白的旧布袋里，装着九月那趟护航窗口期的交接册，厚厚一叠，纸页边缘都已磨毛。袋底，还沉着一只他惯用来压纸的旧棋罐，罐身是紫砂的，经年累月的摩挲，已沁出了一层温润如玉的光泽。

他本以为，这只是趟例行公事的查验，核对他带兵护航挣下的那笔赏钱，验明正身，画押了结。直到吴秀榕那只颤抖的手，将一张血契“啪”地一声拍在冰冷的黑胡桃木案板上。那声音不大，却像一记重锤，砸得他心头猛地一沉。

他赫然看见，自己的名号，那三个在江湖上代表着一诺千金的字，竟和一笔包赚不赔的三千两画饼，用猩红的印泥死死地绑在了一起。他还没来得及开口，身侧的潘俊棠已是双眼通红，跟着拍出另一份一模一样的死契，上面那个要命的数额，以及所谓的军牌号，竟与吴秀榕那份分毫不差。

两个面色惨白的冤大头，一个吴秀榕，一个潘俊棠，各掏了足足两千六百两现银。牙子那张巧舌如簧的嘴，将故事编得天花乱坠：大豪岑绍庭，为筹措下一仗的军资，急于用钱，宁可以折损四百两的代价，贱卖手里这枚稳赚不赔的虎符。

可岑绍庭的记忆里，那笔对应着九月护航任务的三千两赏钱，早在九月二十六日，就已经分毫不差、干干净净地落进了他的钱袋。他既没有落魄到要去黑市典当自己的军功虎符，也从未向千礁钱庄借过半个铜板。

“别跟六月那场血战混淆了。”角落里，周慎衡的声音像淬了冰，冷得没有一丝温度。他指节分明的手指轻敲着桌面，“六月那场，带兵的保底加分红，共计两千五百两，账目早已结清，尘埃落定。眼下这笔，对应的是九月另一场拼死护镖的血汗钱。不能因为操刀的是同一个人，就把两笔账张冠李戴，混为一谈。”

陈驰一声不吭，用一柄勘验文书的薄刃钢尺，像撬开一枚顽固的蚌壳般，小心翼翼地撬开那战报原本的封蜡。钢尺的尖端，死死钉住那句“已过账讫”的朱红死印。他将那两份伪契并排置于灯下，黑市上招摇撞骗的那张画皮，阴毒得令人发指——伪造者竟将文书的下半截齐崭崭裁去，只露出一句半真半假的“军功已核实”，反手便给新来的替死鬼，接上了一句催命的“待领赏”。

前半截刀口舔血的战史是真的，岑绍庭的名字和军功无可指摘，如星位般耀眼，也正因如此，后半截许诺出去的那座金山，才显得那般诱人。可那座金山，早就连地基都不剩了。

退一万步讲，就算那笔赏银真的尚未发放，这块代表着完整军功的虎符，也绝不容许在未经他本人点头画押的情况下，被一女两嫁，凭空卖出两个三千两的价钱。更何况，这桩买卖从根子上就是一滩腐肉：岑绍庭早就连本带利收回了自己的卖命钱，他既没去黑市叫卖过第二回，也压根没见过吴秀榕和潘俊棠掏出的那五千二百两碎银中的任何一文。

“那……能不能拿他下一仗的赏钱来抵？”潘俊棠急得口不择言，话音刚落，自己也觉得荒唐，一张脸瞬间臊得通红，比案上的印泥还要红上三分。

岑绍庭死死攥住了那个旧布袋的系绳，粗糙的麻绳勒得他指节发白。他清楚，若是此刻他选择自认倒霉，从自己腰包里掏钱平了这桩烂账，门外那些虎视眈眈的讨债狂徒或许会立刻闭嘴。但他凭什么？他只拿了自己该拿的那份血汗钱，每一文都沾着风沙与血腥。难道就因为他的名号在江湖上最响，就要替两桩他闻所未闻的黑市买卖去割肉挡灾？

那只平日里提得随性洒脱的布袋，此刻仿佛坠满了无数苦命人带血的妄念，沉重得让他喘不过气。他愿意留在这冰冷的刑堂，耗上三天三夜，帮着把幕后那只真正的黑手揪出来，却绝不能为了求一句虚假的太平，就把自己从未画押过的死债，生生背到自己身上。江湖刀客，一诺千金，但这千金的担子，必须得认清楚，究竟是哪个王八蛋在暗中递的刀。

林静薇提笔，笔尖在砚台里蘸饱了墨，神情肃穆地将那两份带血的伪契钉入死档，归为悬案。她的声音清冷而坚定：“刑堂要查的，是谁在拉客，谁吞了黑钱，谁在空口画饼，谁在暗中作伥。绝不能把站在明处最显眼的这位无辜刀客，当成任人宰割的替罪羊。这两张买命的血契，只能证明骗子许下了多大的海口，绝不能凭空证明岑绍庭欠下了这笔阴债。”

潘俊棠绝望地搓了两次手掌，掌心早已被冷汗浸透。刑堂的道理他都听懂了，字字句句都对，可他那两千六百两活命钱，依旧像断了线的风筝，不知该上哪儿去讨。

随后，从暗桩里挖出的一段黑市口供，更为致命。早有生疑的赌徒，曾将两份一模一样的军牌号砸在四海钱庄那名细作的脸上，那孙子竟面不改色心不跳，巧言哄骗，说这是庄家高明，将一块大肉切开分售，钱庄自有通盘安排。这句包藏祸心的谎言，分明是在造假行径败露之后，才临时编出来堵窟窿的，可那所谓的“切肉分售”的红契，却连个鬼影都没见过。

顾承安的眼神像一对铁钳，死死咬住整段口供的头尾，继续深挖那细作的底细、庄家庄承裕究竟是何时知悉这摊烂账，以及那笔阴毒的拉客费，究竟是如何计算分成的。“毫不知情”这四个字，绝不是骗子上下嘴唇一碰就能洗白的；可到底是不是上下串通一气，也绝不能只凭半句断章取义的闲话，就草草问斩。

堂内的空气凝滞如冰。岑绍庭沉默着，缓缓解开布袋，打开那个饱经沧桑的紫砂棋罐。他修长的手指探入罐中，拈起一枚冰冷的黑子，在众人注视下，将它重重地压在那张被穿堂风掀起一角的假账之上。

“在十九路盘上，”他一字一顿地说，声音不大，却清晰地传入每个人耳中，“一颗已经提走的死子，就算在灯下照出两张虚影，也绝不可能凭空多围出一块实地。”

他说得很慢，那枚黑子也只死死压住了其中一张纸。潘俊棠的目光，死死盯着另一张连伪造痕迹都一模一样的血契，终于没好意思再把那把无形的讨债尖刀，指向岑绍庭。他明白了。同一块带血的实地，竟被那帮黑手，同时画进了两个毫无察觉的苦命人的杀局里。他们争夺的，从一开始就是一片虚无。

“哇”的一声，吴秀榕忽然崩溃地落下泪来，压抑许久的绝望瞬间决堤。她当初掏空所有家底时，千挑万选，特意挑了个在江湖上有真刀真枪赫赫威名的豪客。她记得，岑绍庭甚至还在一次复盘残局时，给她这个旁观者让过座位。多么讽刺，正因为那段刀口舔血的战史无可挑剔，才成了将她推下悬崖的最后一道催命符。

岑绍庭从怀里摸出一块干净的手帕递过去，没有说一句“早该听劝”之类的风凉话。他留下仅供核对的账目回单，用自己的衣袖，小心地遮去了账户里其他无关的收支明细，这是他最后的体面。

离开时，潘俊棠默默替他捡起滑落在地的布袋，递还给他，低声说：“岑爷，刚才那句话，您别往心里去。”

刑堂里没有那种抱头痛哭、皆大欢喜的和解。那枚冰冷的黑子，仍死死压在清白的战史旁，像一个沉默而固执的墓碑。陈驰重新提起了那柄薄刃钢尺，转身扎进一堆堆血契故纸里，继续刨根问底。他势要查清，在这座巨大的骗局棋盘上，究竟还有多少人，被骗子用不同的买命钱，强行买下了同一段早就尸骨无存的旧账。
