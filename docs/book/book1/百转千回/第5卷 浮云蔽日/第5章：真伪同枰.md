# 第5章：真伪同枰

一局棋，两本谱。

陈驰的指节，在冰冷坚硬的黑胡桃木桌面上轻轻叩击，发出沉闷如残局终了时投子认负的声响。他面前摊开的，正是那两本名字相近，血脉却截然相反的账簿。一本是千礁精心裱糊过的《功赏录》，辞藻华丽，墨香浮动，仿佛每一笔都记着开疆拓土的赫赫战功。另一本，则是从二十二名苦主手中汇拢来的血契，纸张粗糙，带着血指印的腥气与绝望的褶皱，上面写的不是功名，而是签下就再无归途的买命钱。

“撕掉那些花里胡哨的名头。”周慎衡的声音没有一丝温度，像一口刚刚淬火的钢刀，锋刃径直切向那本《功赏录》的脊梁，“我们不看‘论功行赏’，也不听‘财源广进’。我只要看三样东西：收钱的黑手，画押的时辰，流入的银两。一笔一笔，对上。”

他的话音在肃杀的刑堂里回荡，判官们埋首于卷宗，算盘的噼啪声像是密集的冰雹。二十二个名字，二十二份血契，对应着一笔沉甸甸的数字：九万六千元。这九万六千块现大洋，是真金白银从活人的口袋里被掏走的血肉。其中有红了眼追加赌注的疯徒，有初尝半口蜜糖便押上身家性命的痴人，更有为兄弟义气填了死账的莽汉。周慎衡的目光如鹰隼，死死盯住账目间的每一丝勾连。江湖内部的拆借，绝不能算作外流的本金；回笼的残血，必须与砸进去的赌本一刀两断。他要做的，就是将这锅被千礁搅成一团浆糊的烂账，用最凌厉的刀法，剔骨见肉。

“找到了。”另一侧，顾承安的声音从一片数据的海洋中浮起，带着一丝勘破棋局迷雾的冷峻。他面前没有纸质卷宗，只有一道道幽蓝的数据流，映照着他专注的脸庞。那段被千礁吹嘘得神乎其神的水塔血战，正在他的指尖下被一帧一帧地拆解。

“铁打的战史日志里，前线刀客‘孤狼’，在服务器时间九点十三分零七秒，将虎符交给了系统NPC‘铁卫’。从那一刻起，活人的拼杀已经结束。”顾承安的手指在键盘上敲击，调出两份截然不同的战报。“可黑市上流传的这份假战报，却将‘铁卫’从九点十三分一直到十点整的机械式砍杀，整整四十七分钟的战果，全算在了‘孤狼’一个人头上。他们称之为‘死战不退，孤胆英雄’。”

他像一个耐心的棋手，复盘一局被篡改过的十九路残棋，沿着时间线上每一颗落错的棋子，一寸寸往后追溯。“棋盘上的绞杀固然惨烈，但这并不能证明，最初坐在棋盘边的那个人，始终没有离开过这片死地。”他的手指在九点十三分的时间戳上重重一点，“执黑的手，在这一刻，已经换了。”

另一段伪造则更为阴毒，如同一招深藏腹地的“挖心”之棋。

“看这里，”顾承安调出三份看似独立的档案，“一个代号‘地鼠’的死士。第一份档案，他挂着地面部队的军牌，钻进地底暗道；第二份，是在地府般的暗道中，他用另一份入关谍文与接头人联络；第三份，当他杀回人间时，在沙盘上冒出了一个全新的名号‘归燕’。”

“千礁，就把这同一个人、同一趟九死一生的行程，生生劈成了三段残影。他们吹嘘这是三路大军于绝境中会师，在‘斩将夺旗’的总功榜上，厚颜无耻地申领了三份赏钱。”

顾承安的罗盘，是一套无法被欺骗的追踪算法。它沿着数据留下的血迹，将这名亡命徒的轨迹死死串联在一起。“从地底带出的刀伤数据模型，与下井前的健康报告完全吻合。打空的弹匣序列号，与他出发前领取的后勤补给严丝合缝。根本没有三个替死鬼，更没有人替他挡过三回刀。战史铁卷记住的，是这刀口舔血的连贯。而千礁所有的手段，都用在了切碎棋局、偷梁换柱的阴招上。”

“还有这张。”他亮出一份标注着“毫发无伤”的战报，上面的角色光鲜亮丽，不可一世。“这份数据，是从校场演练的幻境服务器里偷出来的。在真正的修罗场里，这个角色早已被乱刀砍死。后来那个顶着同样诨号的刀客，不过是夺舍而来的另一具躯壳。头顶的诨号没换，绝不意味着两本生死簿、两批粮草，就能被炼成一件永远打不烂的宝铠。”

这些带血的假账，从未经过刑堂的验尸。千礁的手段，就像一个江湖戏法师，把“在此处露过脸”，巧妙地篡改成“提刀上过阵”；再大笔一挥，涂改成“理应拿安家费”；最后，用贪婪的墨汁，硬生生缝上了“包赚不赔”的毒咒。每一句伪辞，都像是在十九路棋盘上，趁着对手不备，悄悄向中腹拱了半步。几步走完，竟已堂而皇之地跨过了所有生死大劫。

“声音也能作伪。”方婉音纤细的手指从一堆嘈杂的音频文件中，精准地揪出了一段被移花接木的旧日誓言。“他们固然可以用技术剪裁声带，但这不意味着他们能凭空捏造出一场根本不存在的血战，更不可能让邱庭舟从未画过押的生死契，凭空显形。”

角落里，一直沉默不语的邱庭舟抬起了头。他看见自己曾拿命换来的修桥履历，此刻正被千礁当作招揽新赌徒的金字招牌，在黑市上四处招摇。他的眼神深邃而平静，像一口古井。他当初拼死夺回那些战报，是为了能干干净净地带着一身伤疤退隐江湖，求一个“事了拂衣去，深藏身与名”的快意。绝不是为了让任何一个捡到他剑鞘的宵小，可以肆无忌惮地拿去典当他根本不曾许下的明天。

他缓缓从怀中取出自己的那份契约，白纸黑字，清晰的指印如同昨日刚摁下。他没有说话，只是将它推到了桌案最显眼处。带着一个干净的名号漂泊江湖，曾是他九死一生换来的自由。如今，这名号却成了贼人四处坑骗的虎符。他必须亲自拔剑，一剑挑明，到底哪一趟镖，他根本就没上过船。

最早被查清的那笔分赃烂账，此刻也露出了它真正的马脚。周慎衡的朱砂笔在账簿上重重画了一个圈，声音冷得像冰。“填补这个窟窿的银子，找到了。不是什么盘口盈利。而是紧挨着它的下一个新替死鬼，刚刚交上来的卖命钱。”

这笔拆东墙补西墙的烂账，虽不足以填平那九万六千元的深坑，却如同一记精准的点刺，一剑刺破了千礁“日进斗金”的谎言气球。它证明了那棵被吹嘘得能结出黄金的摇钱树，从头到尾，就不曾在这片土地上扎下过半寸根须。

“我……我这里还有一张……”吴秀榕战战兢兢地递上一张替兄弟垫钱的内账，声音细若蚊蚋。

刑堂判官接过，冷着脸纠正了名目，与死契对上。最终，外流的真金白银总额，依旧死死地钉在九万六千元上，分毫不差。她瑟缩着低语，生怕自己越是解释，就越像是与那帮黑手同流合污。

“把你咽回肚子里的口供，吐干净。”林静薇的声音响起，不容置疑，“被坑了钱的苦主，是为‘鱼肉’；拉人入局的牙子，是为‘帮凶’；把持钱库的黑手，是为‘元恶’；看破是局，还要继续拉人垫背的伥鬼，则罪加一等。刑堂之上，各有各的铡刀，绝不能用一个笼统的罪名，就把所有人全泼上同一种颜色的血。”

夜深了。周慎衡举着火把，仍在逐笔查账。仍有不少银两，如下了黄泉般查无去向。他没有像从前在商行里那样，找个油滑的名目把亏空暂时抹平。追回来的，死死咬住血契；追不回来的，他直接用浓墨在纸上画出一个狰狞的黑洞，留着让官办的青天大老爷，继续提刀去追。

刑堂里，只剩下翻阅卷宗的沙沙声，像是亡魂在低语。沙盘血战中被拆解的死士残躯，与现实账房里一笔笔带血的银票，终于都被从那件名为“千礁”的华丽锦袍下，残忍地扒了出来，赤裸裸地陈列在众人眼前。

它们虽不能立刻变回失去的真金白银，却让每一个看客都彻骨地看清——同一场本该见血的搏命，究竟被这帮骗子换了几套戏服，卖了几遍票。
