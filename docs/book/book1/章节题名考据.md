# 《百转千回》章节题名考据

版本说明：下文保存2026年9月18日的题名沿革与考据，不作为后续修订的金额基准；例如二卷四章的争议款现为1000元，旧表中的200元属于旧稿。2026年9月28日已复核现稿书名、十个卷名及一百个章名，均保留。

审定日期：2026-09-18。以星原持续世界现稿及用户最新替换的第一卷第十章为依据，核对自该章至全书结尾的91个章名：保留80个，更名11个。第一卷前九章及所有卷名保持不变。下表保留题名沿革和原有引诗；本轮新拟的题名依据具体情节，不冒称古人原句。

“截句”表示直接截取原句中的连续文字；“化用”表示对诗中字词、次序或意象重新组合；“取意”表示据诗意另拟题名；“反用”表示有意倒转原诗的情势。后三类均为本书题名创作，不能当作古人原句引用。引诗只提供题名渊源，表中情节解释属于本书的借用，并不等同于原诗本义。

引文按链接所列文本核对，标点及通行简化字作统一处理；邵雍诗的“闘”“著”分别写作“斗”“着”。钱谦益《武陵观棋六绝句》采用识典古籍《牧斋有学集》所录“且看试手思新着，莫向残灯悔旧棋”本，不混用《弈人传》所引“急须试手翻新局”等异文。
